# 비AI 및 네트워크 검수

- 프로덕션 12경로의 HTTP(S) 요청: 1312건, 도메인 127.0.0.1 하나
- 용도: 앱 HTML·정적 JS/CSS·선택된 한국어 콘텐츠·기존 이미지·폰트
- 외부 도메인/API/생성형 AI 요청: 0건
- 이유 입력 저장·건너뛰기는 IndexedDB/로컬 저장소를 사용한다.
- 녹음은 MediaRecorder 및 로컬 Blob, 재생은 브라우저 오디오를 사용한다. AudioContext는 녹음 길이 확인에만 사용하며 전사·의미 분석을 하지 않는다.
- 생성형 SDK·AI API 키·SpeechRecognition·speechSynthesis·실시간 TTS·자동 번역 호출: 실행 소스·의존성 검사에서 0건
- 원본 콘텐츠에 있는 역사 출처 URL은 문서 문자열이며 요청으로 실행되지 않는다.
- 오프라인 이유 저장: 12/12. 동일 입력/버전의 순수 엔진·책·리포트 모델 결정성은 자동 테스트로 확인했다. 새 실행의 고유 resultId와 생성 시각 자체가 같아야 한다는 뜻은 아니다.
- 로컬 이미지 재사용: 이유 입력 진입 시 기존 AssetRegistry의 제작 완료 이미지들을 문서 메모리에 유지한다. 신규 그림 파일은 만들지 않았다.

원시 요청: ui-completions.json. 미디어 Blob/data URL은 사용자 기기 내부 데이터이며 외부 네트워크가 아니다.
