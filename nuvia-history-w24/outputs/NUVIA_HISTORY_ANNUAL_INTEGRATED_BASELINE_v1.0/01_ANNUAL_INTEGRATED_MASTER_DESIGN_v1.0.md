# NUVIA HISTORY 48주 연간 통합 마스터 설계 v1.0

## 공통 구조

48사건·96조건은 승인된 역사 설계를 유지하며 공통 8단계 미션 엔진, 수행 이벤트, 동일 `resultId`, StoryCanvas, 8쪽 이야기책, 통합 성장 리포트, 저장·이어하기, 인쇄·PDF, 다국어, 결과지 프로필 연동 계약을 재사용한다.

역사·가상·창작 데이터는 다음 순서로 분리한다.

1. 출처가 확인하는 실제 역사
2. Level 1 또는 Level 2 실제 인과 기제
3. 게임에서 변경하는 한 조건
4. 사실과 분리된 Level 3 가능성 A/B
5. 학습자가 만든 말·그림·글 원문

가상 결과는 정답, 적중 점수 또는 실제 역사로 바꾸지 않는다. 금지 문구는 내부 필드에만 두고 사용자 화면·TTS·책·리포트 일반 문장으로 노출하지 않는다.

## 연령 계약

96조건은 각 6개 내부 연령 규칙에 연결되어 총 576행을 구성한다. 사용자 화면에는 연령명, 학년, `preschool`, `ageBand`, QA를 표시하지 않고 결과지 연동값으로 자동 적용한다.

## 이야기책과 비교

모든 조건은 다음 8쪽을 사용한다.

1. 표지
2. 실제 역사
3. 내가 바꾼 조건
4. 나의 처음 예측
5. 변경된 역사
6. 나만의 이야기와 그림
7. 실제 역사와 나의 역사 비교
8. 최초 예측과 실제 역사 비교

최초 예측은 결과 공개 전에 저장하고 사후 변경하지 않는다. 두 비교는 다른 이벤트로 기록하며 StoryCanvas, 이야기, 책, 성장 리포트와 같은 `resultId`를 사용한다. 과거 기록의 없는 값을 소급 생성하지 않는다.

## 버전 계약

- `missionVersion=1.0.0`: 플레이 단계, 상호작용, 이벤트, 저장, 비교와 책 구조
- `contentVersion=1.0.0`: 역사·조건 문구, 연령 표현, 출처, 가능성, 자산 참조와 책 표시 문구
- `appVersion`: 앱 배포 버전이며 위 두 값과 혼용하지 않는다.

새 결과는 `resultId`, `missionId`, `conditionId`, `missionVersion`, `contentVersion`, `appVersion`, `ageBandRuleId`, `createdAt`을 함께 저장한다. 과거 결과는 수행 당시 버전으로 해석한다.

## 상태

P0는 0건이다. P1 27건과 P2 9건은 구현·자산·번역·실기기 단계의 OPEN 항목이며 이번 승격으로 종결되지 않는다.
