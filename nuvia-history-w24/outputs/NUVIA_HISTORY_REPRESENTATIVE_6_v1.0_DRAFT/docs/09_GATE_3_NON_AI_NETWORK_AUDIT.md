| 실제 UI 완주 | 12/12 |
| AI SDK·엔드포인트 정적 탐지 | 0 |
| AI API 키 정적 탐지 | 0 |
| SpeechRecognition·실시간 TTS 코드 | 0 |
| 외부 도메인 요청 | 0 |
| AI 이야기·이미지·번역·리포트 생성 | 0 |
| 신규 이미지·음성 생성 | 0 |

| 도메인 | 요청 수 | 목적 |
| --- | --- | --- |
| 127.0.0.1 | 502 | 로컬 프로덕션 HTML·JS·콘텐츠·폰트·기존 이미지 |

브라우저 검수는 127.0.0.1 이외의 네트워크를 차단한 상태에서 수행했다. 외부 호출 시도도 요청 로그에 수집했으며 발견되지 않았다. API 호출 없이 콘텐츠와 사용자 입력·수행 이벤트로 책/리포트를 생성했다. 보조 저장 계약 검수는 127.0.0.1:5187의 개발 모듈만 로드했다. 이것도 외부 AI 요청이 아니다.

생성 결과의 재현성은 같은 콘텐츠/입력/식별·시각 메타데이터로 모델을 비교했다. 새 미션의 resultId·시각까지 동일하게 만든다는 의미가 아니다. 실제 오프라인 PWA 설치·캐시 기능은 추가하지 않았다.

음성 검수는 Chrome 모의 마이크의 MediaRecorder 녹음·Blob 저장·재생 시간 진행을 확인한 것이다. 실제 사람의 발음·음질·OS 마이크 권한 검수와 구분한다. 사전 녹음 안내 파일은 없으며 제공된 것으로 표시하지 않는다.
