전 경로: 역사 2개 기준 장면 확인 → 조건 선택 → 선택/그림/로컬 녹음 최초 예측 → 변화 B 확인 → revisePlan 또는 prioritizeActions 실제 조작 → 기존 StoryCanvas 사본으로 3종 배치·이동·크기·뒤집기·선·지우개·undo/redo → PNG 저장 → 이야기 → 서로 다른 두 비교 → 8쪽 넘김 → 통합 리포트. 최초 예측 뒤/그림 저장 뒤/완료 뒤 새로고침을 확인했다. 초등 저학년은 2장면, 나머지는 1장면.

추가 실제 UI: 모르는 예측·판단 보류, 손가락 모의 입력의 이동/선 그리기/pointercancel, 미완성 초안 복구, 전체 지우기 확인 취소, Tab·Enter를 이용한 키보드 완주. 실제 휴대전화·터치펜 확인은 포함하지 않는다.
