- 캔버스 초안·그림 예측은 `nuviaRepresentative6.artifacts.v1`에 전체 연결 키와 함께 저장한다. 완성 PNG/좌표/스티커는 run.canvas에도 보관한다. 그림 예측은 append-only로 덮어쓰기를 거부한다.
- localStorage는 현재 resultId 포인터와 로컬 사용자 구분값만, sessionStorage는 연동 프로필 입력을 사용한다. 기존 Gutenberg 저장 DB/키를 읽거나 초기화하지 않는다.
- 다른 사용자 조회, 다른 결과 녹음, 다른 버전 저장, resultId 중복 생성은 거부했고 원본 기록이 그대로였다. 의도적으로 잘못된 ID를 주입한 거부 검수는 실제 정상 기록의 ID 불일치로 계산하지 않는다.
- 그리기 이벤트는 선 수·도구·굵기, 이동은 이동 종료 위치만 기록한다. 좌표열과 PNG를 이벤트에 복제하지 않는다.
- 자동 지원은 supportApplied, 요청 도움은 hintRequested, 비교는 history/prediction을 가진 서로 다른 comparisonCompleted eventId다.
- 문장·음성·그림 예측을 결과 공개 뒤 바꾸지 않았다. 미입력이나 모르겠어요는 성공·점수·약점으로 추정하지 않는다.
- `notRecorded / notObserved / notCollected / notProvided`를 유지한다. 과거 결과에 예측이나 행동을 소급 생성하지 않는다.
