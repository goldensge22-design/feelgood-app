# Gate 3 — W24 실제 게임 구현 및 검수

2026-09-19 · W24 구텐베르크만 · 사용자 검토 대기. 다른 5개 미션의 실제 화면 구현은 시작하지 않았다.

## 결과

공통 하네스가 아닌 프로덕션 앱에서 W24 C1/C2 × 6연령의 12경로를 완주했다. 모의 프로필·검수용 사용자 입력을 사용했으며 실제 아동 검수, 임상적 효과 또는 전체 6개 미션 완성으로 표현하지 않는다.

실행: http://127.0.0.1:5188/?qa=1&age=preschool&mission=gutenberg

URL 값은 명시적인 내부 모의 결과지 프로필이다. 일반 화면에는 연령/QA/검사 코드를 표시하지 않는다. 기본 주소에서 실제 연동 프로필이 없으면 연령을 추정하지 않고 연결 정보가 필요하다고 표시한다. 진행 기록은 새로고침 때 자동 복구한다.

## 보존·구현

- 역사 조건/기준 사실/출처/인과/가상 A·B/PASS/12행 연령 문구는 승인 파일 그대로다. 실행 콘텐츠 3개 파일의 SHA-256도 Gate 2와 동일하다.
- App은 단계와 공통 행동 계약으로 렌더링하며 missionId별 전용 화면 분기가 없다. 배포 진입점의 허용 콘텐츠는 W24 하나다.
- C1 revisePlan은 목표·처음 계획·수정 계획·유지/변경·실제 고른 이유를 저장한다. C2 prioritizeActions는 목표·우선순위·제약·고른 이유를 저장한다. 점수로 바꾸지 않는다.
- 최초 예측은 기본 선택 없이 시작한다. 그림 선택/사용자 그림/로컬 음성/글/모르겠어요를 허용하고 결과 공개 뒤 잠근다. 그림 예측 자체도 덮어쓰기를 거부한다.
- 실제 역사 / 가상 가능성 / 사용자 창작을 별도 표식과 데이터로 구분한다. 책의 가상 페이지는 A/B와 선택 표식을 함께 보여 전제 없는 “없다면”만 남지 않게 했다. 승인 문장 자체는 바꾸지 않았다.
- 기존 StoryCanvas 원본과 격리 코드는 그대로 보존했다. 연결 사본의 SpeechRecognition을 제거하고 주입된 연령·전용 저장 어댑터·조건 설정을 사용한다. 유아 1장면, 초등 저학년 2~3장면, 나머지 선택 삽화다. 글을 쓰지 않고 조건 관련 스티커/그림만으로도 완성할 수 있다.
- 캔버스의 기존 스티커·이동·크기·뒤집기·선·지우개·undo/redo·전체 지우기 확인·PNG를 연결했다. 초안은 별도 소유권 저장소에 자동 저장하며 원본 저장소에 접근하지 않는다.
- 기존 MediaRecorder/재생을 사용한다. 음성은 로컬 Blob, 캔버스 초안에는 로컬 녹음 데이터로 보관한다. 전사/TTS/외부 음성 서비스는 없다.
- 책은 미션별 8쪽이며 넘김·복구·인쇄를 제공한다. 성장 리포트는 하나의 모델/화면/인쇄 문서이며 같은 resultId의 책으로 연결한다.
- 2.5D 기록 패널·프레임·그림자·눌림·MaruBuri SemiBold/Pretendard Variable을 재사용했다. 기존 10개 이미지/SVG와 2개 폰트만 사용하고 새 이미지/음성은 생성하지 않았다.

## 판정과 남은 항목

W24의 구현·브라우저 검수 범위에서 P0 0건. Gate 3 후속 P1 4건/P2 2건은 `OPEN_ISSUES_GATE_3.md`에 OPEN으로 기록했다. 연간 원본 P1 27건/P2 9건은 별도로 그대로 OPEN이다. 사전 녹음 안내 파일, 실기기 손가락·펜, 실제 마이크, Windows 인쇄/PDF, 실제 결과지 연동 및 실사용 관찰을 완료했다고 주장하지 않는다.

W01·W15·W29·W39·W44 화면 구현, 신규 이미지/음성 생성, 동결 기준본 변경, 외부 배포는 진행하지 않았다. Gate 3 결과에 대한 사용자 검토 단계에서 중단한다.
