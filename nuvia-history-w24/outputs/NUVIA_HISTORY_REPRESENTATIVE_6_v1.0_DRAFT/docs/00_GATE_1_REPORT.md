## 기존 기능과 이전 범위

새 공통 엔진 초안과 재사용 컴포넌트 사본을 준비했으나 Gate 1 충돌 확인 후 작업용 폴더로 옮겼다. 사용자 실행 앱으로 공개하거나 빌드하지 않았다. 기존 DB를 읽거나 변환하지 않았고 기존 사용자 기록에 접근하지 않았다. 새 DB 이름은 `nuviaRepresentative6_v1`로 분리하는 초안이다.
