# NUVIA HISTORY v1.1 동결 기준본

질문·답변·활동·결과를 작성하거나 수정하기 전에 `QUESTION_CONTENT_ALIGNMENT_RULE`을 확인한다. 이야기책 7쪽과 8쪽을 작성하거나 수정하기 전에 `STORYBOOK_PAGE_7_8_DISTINCTION_RULE`을 확인한다. 두 규칙을 통과하지 못한 콘텐츠는 구현하지 않는다.

필수 원본: [마스터 v1.1](./NUVIA_HISTORY_MASTER_RULES_v1.1.md) 14·15장과 [공통 비교 계약](./COMPARISON_CONTRACT_v1.1.md). 사용자 승인 완료, 최종 동결. 이 폴더는 덮어쓰지 않고 후속 변경은 새 버전에서 수행한다.

P1 2건/P2 1건은 [OPEN 목록](./OPEN_ISSUES_P1_P2.md)으로 유지한다. 사용자 화면 승인과 실제 휴대기기·터치펜·Windows 인쇄 대화상자 검수를 혼동하지 않는다.
이번 승격 후 코드 추가 구현과 대표 6미션 12조건 의미 검수를 시작하지 않는다. 별도 사용자 명령을 기다린다.
