## 수동 검수 상태 — C-P2-01의 연결 항목, 별도 중복 이슈로 집계하지 않음

| 항목 | 상태 |
|---|---|
| 실제 휴대전화·태블릿의 손가락 조작 | 미검수 / 확인 불가 |
| 실제 터치펜 그리기 | 미검수 / 확인 불가 |
| Windows 인쇄 대화상자에서 PDF 저장 | 미검수 / 운영체제 확인 필요 |
| 실물 이야기책·성장 리포트 인쇄 | 미검수 |

R2에서 수행한 브라우저 viewport 검수와 Chromium PDF 저장은 위 항목의 대체 증거가 아니다. 원본 이슈의 ‘96조건 전수 의미 검수’는 전체 96조건 범위를 뜻하며 W24 외 96개가 추가로 있다는 뜻이 아니다.
기존 연간·Gate3 이슈 목록의 ID·OPEN 상태도 임의 종결하거나 이 목록에 합산하지 않는다. 다음 작업은 대표 6미션 12조건 의미 정합성 검수이지만 이번에는 시작하지 않는다.
