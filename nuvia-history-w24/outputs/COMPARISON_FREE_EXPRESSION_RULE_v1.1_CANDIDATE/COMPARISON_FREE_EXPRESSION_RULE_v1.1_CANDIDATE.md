# COMPARISON_FREE_EXPRESSION_RULE_v1.1_CANDIDATE

2026-09-19 · 사용자 결정 반영 · 공통 규칙 부록 CANDIDATE. v1.0 동결 기준본을 수정·승격하지 않는다.

## 적용 범위와 우선순위

NUVIA HISTORY 48개 미션·96개 승인 조건의 두 비교 단계 전체에 적용하는 공통 규칙이다. W24만을 위한 임시 예외가 아니다. 이 부록이 고정 비교 범주에 관한 과거 설명보다 우선한다. 역사·조건·출처·인과 범위·PASS 주영역·핵심 행동·최초 예측은 변경하지 않는다.

원본 규칙 본문은 이 파일 하나에 둔다. 활성 마스터 규칙, 연간 통합 설계 적용 부속 문서, 대표 6개 미션 공통 구현 계약은 이 파일을 참조한다. 코드가 Markdown을 동적으로 해석한다는 뜻은 아니다. 구현 참조 ID는 app-entry.json의 comparisonRuleId에 명시한다.

규칙 적용 범위 48미션/96조건 × 두 비교와 실제 구현 범위를 구분한다. 현재 실제 UI 구현·재검수는 W24의 C1·C2만이다. 나머지 5개 대표 미션 및 48개 전체 화면 구현·배포·자산 제작을 자동 시작하지 않는다.

## 두 비교와 질문

|comparisonKind|대상|기본 질문|책|
|---|---|---|---|
|history|실제 역사 ↔ 내가 만든 이야기|실제 역사와 내가 만든 이야기를 비교해 보고, 가장 눈에 띈 점 하나를 남겨 보세요.|7쪽|
|prediction|결과 공개 전에 저장한 최초 예측 ↔ 실제 역사|처음 생각과 실제 역사를 비교해 보고, 가장 눈에 띈 점 하나를 남겨 보세요.|8쪽|

처음 예측을 결과에 맞춰 수정하지 않는다. 발견 한 가지만 남겨도 완료한다. 세 가지 질문이나 세 범주 답변을 의무화하지 않는다.

폐기 대상은 `같았어요`, `달랐어요`, `새롭게 알았어요`/`새로 알았어요` 고정 카드, comparisonTag, same/different/newlyLearned 분류, 비교 화면의 '하나를 골라요'와 '그림으로 고르기'다. 사용자가 자유롭게 쓴 글에 같은 낱말이 들어 있어도 삭제·차단·교정하지 않는다. 금지 대상은 시스템의 답안·분류이지 사용자의 원문이 아니다. 최초 예측의 기존 그림 선택지를 이 규칙으로 제거하지 않는다.

## 연령과 표현

|유아|말로 남기기 / 그려서 남기기 / 잘 모르겠어요. 안내: 눈에 띈 점을 말하거나 그려 봐요.|글쓰기 도구·의무 없음. 음성 또는 그림 하나로 완료. 짧은 질문은 역사: 실제 역사와 내 이야기에서 무엇이 눈에 띄나요? / 예측: 처음 생각과 실제 역사에서 무엇이 눈에 띄나요?|
|초등 저학년|말·그림·짧은 글 중 선택. 안내: 눈에 띈 점 하나를 말하거나 그림·짧은 글로 남겨 봐요.|짧은 글은 선택 도구. 문장 시작 도움은 중립적인 미완성 구문만, 입력창 자동 채움·고정 답안 없음.|
|초등 고학년|직접 입력창을 기본 표시. 내가 발견한 점 1~2문장 안내. 말하기 대안, 그려서 보충하기.|별도 짧게 쓰기 모드 버튼 없음. 길이/문장 수를 점수나 성공 조건으로 쓰지 않음.|
|중학생|발견한 점과 이유/근거 두 입력란 기본 표시. 말하기 대안, 그림 보충.|근거 입력은 선택적. 발견 하나나 음성만으로 완료 가능.|
|고등학생|발견한 점과 이유/근거 두 입력란 기본 표시.|답안 분류·의미 평가·금지 단정문 노출 없음.|
|성인|두 입력란, 직접 쓰기 기본, 음성 대안, 그림 보충.|사용자 원문·자료의 한계를 그대로 보존.|

모든 경로에서 잘 모르겠어요를 허용한다. 사용자 화면에 연령명·학년·ageBand·PASS·QA를 표시하지 않는다. 연령은 결과지 프로필로 내부 적용한다. 음성은 사용자 로컬 녹음/재생이며 자동 전사·실시간 TTS·외부 음성 API를 호출하지 않는다.

## 저장 계약

|필드|값/원칙|
|---|---|
|resultId|현재 수행 ID, 다른 결과와 혼합 금지|
|missionId / conditionId|현재 미션·조건의 고정 ID|
|comparisonKind|history 또는 prediction, 각각 별도 기록·이벤트|
|expressionMode|writing / voice / drawing / mixed / deferred|
|discoveryText|사용자가 쓴 발견 원문. 공백·줄바꿈 포함 보존. 음성·그림 내용을 대신 생성하지 않음.|
|evidenceText|사용자가 쓴 근거 원문, 미입력은 빈 문자열|
|voiceRef|현재 사용자·결과에 속한 로컬 녹음 참조, 없으면 생략|
|drawingRef|현재 사용자·미션·조건·결과·버전에 속한 그림 참조, 없으면 생략|
|missionVersion / contentVersion|수행 당시 계약·콘텐츠 버전, 서로 다른 버전 혼합 금지|

본문의 분석·같음/다름/새로운 발견 자동 분류·요약·교정·채점·능력 또는 약점 추론을 하지 않는다. expressionMode는 실제 입력 채널 유무만으로 정하며 의미 분석이 아니다. 두 채널 이상 실제 입력이 있을 때만 mixed다. 근거만 있고 발견/음성/그림이 없는 입력은 발견을 남기거나 deferred를 선택하도록 한다.

잘 모르겠어요 선택 시 expressionMode=deferred, discoveryText/evidenceText는 빈 문자열, 미디어 참조는 생략한다. '이번 활동에서는 남기지 않음'은 상태 표시 문구이며 사용자의 원문 필드에 시스템 문장을 넣지 않는다. 아직 해당 단계에 도달하지 않은 과거/미수집 기록은 기존 missing 상태를 유지하며 deferred로 소급 생성하지 않는다.

comparisonCompleted는 history/prediction별 다른 eventId를 사용하고 같은 resultId에 연결한다. 이벤트에는 comparisonKind, expressionMode, 실제 입력 유무 등 최소 메타데이터만 기록한다. 원문·음성·그림 좌표를 이벤트에 중복 복사하지 않는다. deferred는 provided=false이며 실패·약점·정답·오답·적중률을 기록하지 않는다.

## 이야기책·리포트

정확히 8쪽인 기존 미션 책의 7쪽과 8쪽에 각각 원문·근거·그림·로컬 음성 재생을 연결한다. 출력 문서에서 재생할 수 없는 녹음은 녹음 존재만 표시하며 전사 내용을 만들지 않는다. 통합 성장 리포트도 같은 원문과 실제 표현 방식만 표시한다. 월별 합본이나 다른 resultId에서 내용을 보충하지 않는다.

## 호환과 버전

기존 v1.0 기준본·이미 완료한 기록·기존 ID·예측·미디어는 변경하지 않는다. 과거 고정 카드 선택은 과거 기록으로 읽을 수 있으나 새 자유 표현 결과로 바꾸지 않는다. 신규 쓰기에서는 고정 선택과 comparisonTag 및 임의 필드를 거부한다.

이 부록의 문서 버전 v1.1은 missionVersion과 다르다. 비교·저장 계약 변경이므로 새 W24 실행은 missionVersion=2.0.0, 공통 비교 표시 콘텐츠 추가는 contentVersion=1.1.0, appVersion=0.3.1로 식별한다. 버전 변경은 DRAFT 런타임 사본에만 적용한다. 동결 JSON의 1.0.0과 역사 문구·PASS·다른 5개 미션은 그대로다. 과거 진행 기록은 자동 변환하지 않는다. 이전 버전의 완료본은 읽기 전용 열람하고 미완료본은 보존한 채 새 resultId로 시작한다.

전체 48개 미션의 실제 런타임 버전 배정·확대 배포는 각 구현/검수 시 수행한다. 이 문서를 저장했다는 이유로 96조건의 코드 구현·마이그레이션이 끝났다고 표시하지 않는다.
