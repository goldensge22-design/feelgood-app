# 기존 규칙 충돌 및 W24 변경 전후 계약

## 1. 충돌 위치

| 위치 | 현재 상태 | 최종 규칙 | 판정 |
|---|---|---|---|
| 마스터 규칙 14장 | 질문과 응답의 주체·대상·목적 일치 요구 | 이유 질문에 직접 자유 표현을 제공 | 원칙 일치; 최종 규칙이 구체화 |
| 연간·조건별 행동 계약 | 여러 행동에서 `reasonRef` 필수 | 실제 이유가 있을 때만 `reasonRef` 생성 | 저장 스키마 변경 필요 / P0 |
| 실행 순서 부록 3장 | `activityDeferred`는 핵심 활동 전체 보류로 사용 | `scope=reason`은 이유만 건너뜀 | payload·게이트 구분 필요 / P0 |
| 대표 6미션 의미 기준본 | 이유를 재료 ID 선택으로 기대하는 행이 존재 | reason 질문을 `freeExpression`으로 변경 | 후속 구현에서 부속 의미 데이터 필요 / P1 |
| W24 `ActivityRenderer` | `reason` 역할 재료를 고정 카드로 표시 | 연령별 글·로컬 음성·그림 입력 | 현재 UI 부적합 / P0 |
| W24 리포트 | `reasonRef`를 재료 라벨로 표시 | 실제 이유 레코드 또는 중립적 미기록 문구 | 조회 계약 변경 필요 / P1 |

이 기준본은 동결 문서를 고치지 않는다. 후속 구현에서 별도 버전이 붙은 공통 스키마·콘텐츠 데이터로 충돌을 해소해야 한다.

## 2. W24 현재 화면 계약

| 항목 | 변경 전 | 최종 목표 계약 |
|---|---|---|
| 이유 질문 | `그렇게 고른 까닭은 무엇인가요?` | 저연령 `왜 그렇게 골랐나요?`, 고연령 `그렇게 선택한 이유를 직접 남겨 보세요.` |
| 이전 선택 | 입력 단계 안의 재료 상태로만 존재 | 화면 위에 읽기 전용으로 표시 |
| 이유 응답 | `reason` 역할의 고정 카드 | 연령별 `freeExpression` |
| 모름/보류 | `아직 모르겠어요`가 이유 카드 또는 전체 활동 보류 버튼 | 작은 보조 버튼 `이유는 건너뛸게요`; 이유 범위만 보류 |
| 저장 버튼 | `내 선택 남기기` | `내 생각 저장하기`·`말 저장하기`·`그림 저장하기`·`이유 저장하기` |
| 저장값 | 고정 재료 ID를 `reasonRef`로 저장 | 실제 사용자 이유 레코드를 참조하는 reasonRef 또는 reason-scoped deferred |
| 리포트 | 고정 재료 라벨 표시 | 실제 이유 원문/방식 또는 `이번 활동에서는 이유가 기록되지 않았어요` |
| 이야기책 | 활동 이유가 유입될 수 있는 명시적 차단 없음 | 이유를 이야기·책 문장으로 자동 복사하지 않음 |

## 3. W24 C1·C2 공통 유지 항목

- C1 `revisePlan`, C2 `prioritizeActions`와 PASS 배정을 변경하지 않는다.
- 이전 선택에는 각 조건의 실제 사용자 입력만 표시한다.
- C1 이유를 C2에, C2 이유를 C1에 공유하지 않는다.
- 최초 예측·핵심 활동·변경 결과 공개 순서를 유지한다.
- 이유 입력이나 건너뛰기 저장 전에는 핵심 활동 완료로 확정하지 않는다.
- 계획 활동 문구와 이유를 나만의 이야기로 자동 복사하지 않는다.
- 실제 역사·조건·가상 가능성·연령 문구를 새로 만들지 않는다.

## 4. 48미션·96조건 적용 절차

1. 96조건에서 이유 질문을 `semanticRole=reasonExpression`으로 식별한다.
2. 질문의 선택·배열·분류·수정 대상과 읽기 전용 선택 요약의 ID가 같은지 확인한다.
3. 기존 고정 이유 재료와 `아직 모르겠어요` 이유 카드를 런타임 입력 목록에서 제외한다.
4. 6연령 도구와 공통 문구 키를 연결한다.
5. 실제 이유 또는 이유 건너뛰기 계약을 연결한다.
6. 성장 리포트의 reasonRef 출처를 검증한다.
7. 이야기·이야기책으로 이유가 자동 유입되지 않는지 검사한다.
8. W24를 먼저 검수하고 통과 전 다른 대표 미션과 48개 전체 UI에 확대하지 않는다.

역사 조건·PASS·인과 범위·질문 목적을 바꾸어 충돌을 피하지 않는다. 한 조건에 이유 질문이 없다면 이를 새로 추가하지 않는다.
