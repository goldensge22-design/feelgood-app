## 변경하지 않은 의미

- 48미션·96조건·6연령 적용 범위
- 이유 질문의 자유 표현 원칙
- 6연령 입력 방식
- `typed / recorded / drawn / deferred`
- `reasonExpressionRecorded`와 이유 범위 `activityDeferred`
- 실제 이유가 있을 때만 `reasonRef` 생성
- 건너뛰기 완료 조건과 중립적 리포트 문구
- 이야기·이야기책 자동 유입 금지
- 비AI·기존 기록 비변환 원칙
- P0 3건, P1 4건, P2 2건, 별도 `EO-P1-01` OPEN 상태

후보와 최종본의 규칙 의미 비교 결과는 의미 차이 0건이다.
