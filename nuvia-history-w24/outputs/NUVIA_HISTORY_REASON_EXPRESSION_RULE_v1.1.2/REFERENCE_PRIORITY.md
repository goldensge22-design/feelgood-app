# 참조 우선순위

이유 질문의 입력·저장·리포트 충돌에는 다음 순서로 적용한다.

1. `NUVIA_HISTORY_REASON_EXPRESSION_RULE_v1.1.2`
2. `NUVIA_HISTORY_EXECUTION_ORDER_RULE_v1.1.1`
3. `NUVIA_HISTORY_MASTER_RULES_v1.1`
4. `NUVIA_HISTORY_ANNUAL_INTEGRATED_BASELINE_v1.0`
5. `NUVIA_HISTORY_REPRESENTATIVE_6_SEMANTIC_BASELINE_v1.1`
6. 개별 미션 콘텐츠와 실행 코드

## 우선권의 한계

이 기준본의 우선권은 이유 질문의 자유 표현, 입력 출처, 이유만 건너뛰기, `reasonRef`, 성장 리포트 연결에 한정한다.

- 실행 단계 순서는 `NUVIA_HISTORY_EXECUTION_ORDER_RULE_v1.1.1`을 따른다.
- 역사 조건·인과 범위·PASS 배정·연령별 역사 표현은 각 동결 기준본을 따른다.
- 비교 자유 표현과 이야기책 7·8쪽 규칙을 이유 입력과 혼합하지 않는다.
- 이유 규칙을 근거로 고정된 질문 의미나 역사 콘텐츠를 바꾸지 않는다.

현재 실행 코드와 의미 기준본에 충돌이 있으면 이 최종 규칙에 맞추되, 기존 기록을 변환하지 않고 새 실행 버전에서만 적용한다.
