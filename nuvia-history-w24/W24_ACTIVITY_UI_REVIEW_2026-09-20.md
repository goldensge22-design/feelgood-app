## 질문별 활동 규칙

모든 W24 핵심 활동 질문에는 다음 다섯 항목을 런타임 의미 정보로 명시했다.

1. 사용자가 판단할 내용
2. 목표 PASS 사고 행동
3. 허용하는 답변과 대안
4. 막혔을 때 제공할 도움
5. 수행 완료를 확인할 근거

화면에도 현재 단계의 다섯 항목을 표시한다. 단순히 선택지 수만 늘려 난이도를 높이지 않았으며, 활동의 판단 단위와 완료 근거를 먼저 명확히 했다.

| 경로 | 수정 전 화면과 실제 요구 행동 | 수정 후 화면과 실제 요구 행동 |
|---|---|---|
| C1 목표·조건 | 목표나 조건을 한 개짜리 선택지처럼 고르게 해 판단 과제처럼 보였다. | 목표와 조건은 선택 문제가 아닌 활동 맥락으로 고정해 보여준다. |
| C1 처음 계획 | `인쇄할 내용 우선`, `남은 종이 확인` 같은 명사 나열이 행동을 불명확하게 했다. | `꼭 필요한 내용을 먼저 고를래요`, `남은 종이가 얼마나 있는지 먼저 볼래요`, `무엇부터 인쇄할지 차례를 정할래요` 중 상황에 맞는 첫 행동을 고른다. 세 대안을 모두 허용한다. |
| C1 조건 변화 뒤 계획 | 조건이 달라져도 정답 하나를 추측하는 화면처럼 보였다. | 바뀐 조건을 다시 확인하고 같은 세 대안 가운데 계획을 다시 고른다. 처음 선택과 달라도 허용한다. |
| C2 목표·조건 | `책을 볼 수 있는 사람 제한`이라는 조건을 질문의 유일한 답처럼 다시 제시했다. | `더 많은 사람이 책을 함께 볼 방법을 정해요`와 `일부 사람은 책을 직접 보기 어려워요`를 활동 맥락으로 제시하고 답 선택지에서는 제거했다. |
| C2 핵심 활동 | 세 행동을 순서대로 배열하게 하면서 카드의 `· 1`, `· 2`와 배치·페이지가 순서를 암시했다. | `누가 볼 수 있는지 물어보기`, `함께 볼 시간 찾기`, `모일 자리 찾기` 가운데 먼저 해 볼 한 행동을 고른다. 세 답을 모두 허용하며 번호와 페이지 단서를 제거했다. |

## 연령별 표현 경로

핵심 판단과 허용 답안은 6개 연령대에서 동일하다. 연령에 따라 표현 수단만 조정한다.

| 연령 | 기본 이유 표현 | 보조 표현 |
|---|---|---|
| 유아 | 말로 남기기, 그림으로 남기기 | `다른 방법` 안의 짧게 쓰기 |
| 초등 저학년 | 말하기, 그림, 짧게 쓰기 | 없음 |
| 초등 고학년 | 쓰기, 말하기, 그림 | 없음 |
| 중학생·고등학생·성인 | 쓰기, 말하기 | 없음 |

자유 표현은 현재 질문과 선택을 같은 화면에서 보면서 입력한다. 앱은 작성한 글·그림·음성의 의미를 자동으로 이해하거나 옳고 그름을 평가했다고 표시하지 않는다. 표현이 저장된 것과 목표 사고 행동을 수행한 것은 별도로 취급한다.

## UI 수정

- W24 활동 카드의 빈 그림 자리와 의미 없는 아이콘을 제거했다.
- 선택지 뒤의 숫자 힌트와 순서 암시를 제거했다.
- 3개 선택지를 한 화면에 제시해 내부의 중복 `이전`·`다음` 페이지 버튼을 없앴다.
- 활동 전체 이동 버튼은 한 세트만 유지했다.
- 글쓰기 입력창의 장식 가로줄을 제거했다.
- 모바일에서는 질문 안내와 선택지를 한 열로 배치하고 버튼 폭을 화면에 맞췄다.

자동 테스트는 데이터 계약과 상태 전이를 확인한다. 대표 브라우저 검사는 화면 배치와 실제 버튼 구성을 확인한다. 이것은 교사·사용자의 교육 활동 적절성 판단을 대신하지 않는다.

## 교육 활동 검수 결과와 남은 확인

- 조건을 답으로 반복하는 단일 선택 문제를 제거했다.
- 여러 대안이 가능한 C1·C2의 핵심 질문은 복수의 허용 답을 갖는다.
- C2는 순서 맞히기에서 `상황을 보고 먼저 할 행동 고르기`로 변경했다. 따라서 목표 PASS 행동도 우선순위 정답 맞히기가 아니라 상황에 맞는 시작 행동을 선택하고 이유를 표현하는 것으로 명시했다.
- 도움은 답을 대신 알려 주지 않고 목표·조건을 다시 보게 하는 방식으로 제공한다.
- 완료 근거는 핵심 선택의 저장과 이유의 표현 또는 명시적 건너뛰기 기록이다. 이유를 건너뛰어도 핵심 선택은 생략되지 않는다.

남은 단계는 실제 사용자 화면 검토다. 특히 다섯 검수 항목의 화면 문구가 유아에게 과도하게 길지 않은지, C1·C2의 세 대안이 수업 의도와 맞는지 확인해야 한다. 현재 지원 언어는 한국어 하나이므로 언어 전환 중 진행·작성 내용 보존은 구현·검증 대상으로 주장하지 않는다. 다른 언어를 추가할 때는 동일한 질문 계약과 보존 검사를 필수로 적용한다.
