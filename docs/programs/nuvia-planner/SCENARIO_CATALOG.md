# 플래너 대표 상황카드 목록

모든 항목은 교육용 설계 초안이다. 공식 직무능력 검증 자료나 실무 지침이 아니다.

## 저장 수량

- 직무 상황 원본 6개: 아래 6개 맥락에 각 1개.
- 일상 원본 6개: 공통 행동당 1개.
- 총 고유 카드 12개. 직무별 일상카드 연결은 3개씩 18건이나 원본은 6개를 재사용한다.
- 공용 운영 승인 0개. 15개 언어 중 한국어 원문 초안 1개 언어, 미번역 14개 언어.

| 직무 맥락 | 상황카드 | 연결된 일상카드 |
|---|---|---|
| 항공보안 | 승객 안내 전에 확인할 정보 정하기 (1개) | 모르는 조건을 확인하고 준비하기 / 필요한 도움을 짧게 설명하기 / 계획이 바뀌었을 때 대안 고르기 (3개) |
| 사무·프로젝트 지원 | 회의 자료 준비 순서 정하기 (1개) | 제출 전에 순서대로 확인하기 / 두 가지 방법을 조건으로 비교하기 / 멈춘 곳을 남기고 다시 이어가기 (3개) |
| IT 서비스·개발 지원 | 시연 직전 연결 문제에 대응하기 (1개) | 계획이 바뀌었을 때 대안 고르기 / 모르는 조건을 확인하고 준비하기 / 멈춘 곳을 남기고 다시 이어가기 (3개) |
| 고객 안내·서비스 | 다른 안내를 받은 고객에게 설명하기 (1개) | 필요한 도움을 짧게 설명하기 / 모르는 조건을 확인하고 준비하기 / 계획이 바뀌었을 때 대안 고르기 (3개) |
| 물류·운영 지원 | 분류 작업의 중단 위치 인계하기 (1개) | 멈춘 곳을 남기고 다시 이어가기 / 제출 전에 순서대로 확인하기 / 모르는 조건을 확인하고 준비하기 (3개) |
| 콘텐츠·기획 | 두 가지 안내 콘텐츠 비교하기 (1개) | 두 가지 방법을 조건으로 비교하기 / 필요한 도움을 짧게 설명하기 / 제출 전에 순서대로 확인하기 (3개) |

## 제출 전에 순서대로 확인하기

ID: `daily-sequence` / 일상 적용형 / 행동: 순서와 절차 지키기

제출할 과제가 있습니다. 작성은 끝났지만 파일 이름, 첨부, 제출 확인을 놓칠 수 있습니다.

목표: 내 실제 과제에서 필요한 순서를 정하고 직접 진행해 봅니다.

1. 할 일의 끝난 기준을 정해 주세요.
2. 필요한 단계를 두 개 이상 순서대로 적어 주세요.
3. 실제로 진행한 단계만 표시해 주세요.

예시: 파일 이름 확인 → 첨부 → 제출 상태 확인

남기는 기록: 정한 단계 목록과 직접 진행 표시를 남깁니다.

주의: 실제로 제출하지 않았다면 완료로 표시하지 않아요.

## 계획이 바뀌었을 때 대안 고르기

ID: `daily-adapt` / 일상 적용형 / 행동: 예상 밖의 상황에서 대안 정하기

예정했던 공부 장소를 이용할 수 없거나 필요한 준비물이 없는 상황을 떠올려 보세요. 실제로 그런 일이 생긴 날에 적용합니다.

목표: 바뀐 조건을 확인하고 가능한 대안 중 하나를 선택합니다.

1. 원래 계획에서 무엇이 달라졌나요?
2. 할 수 있는 대안 두 가지는 무엇인가요?
3. 하나를 선택한 이유와 실제로 한 일을 적어 주세요.

예시: 장소를 바꾸기 / 준비물 없이 가능한 부분부터 하기

남기는 기록: 바뀐 조건, 대안, 선택과 실제 행동을 남깁니다.

주의: 예상 밖의 일이 없었다면 일부러 문제를 만들 필요는 없어요.

## 모르는 조건을 확인하고 준비하기

ID: `daily-verify` / 일상 적용형 / 행동: 필요한 정보 확인하기

과제나 모임 준비 중 안내가 불명확한 부분이 있습니다. 내가 아는 내용과 확인이 필요한 내용을 나눠 봅니다.

목표: 추측과 확인된 사실을 구분하고 질문 하나를 정합니다.

1. 이미 확인한 내용은 무엇인가요?
2. 아직 모르는 조건은 무엇인가요?
3. 어디에 어떤 질문을 하고 무엇을 확인했나요?

예시: 마감은 알지만 제출 형식은 모름 → 안내문 또는 담당자 확인

남기는 기록: 확인 전후의 내용과 실제 확인 행동을 남깁니다.

주의: 상대의 이름이나 연락처는 기록하지 않아도 돼요.

## 두 가지 방법을 조건으로 비교하기

ID: `daily-compare` / 일상 적용형 / 행동: 여러 조건을 비교해 결정하기

이번 과제를 혼자 진행할지, 친구와 역할을 나눌지 결정하려 합니다. 시간과 필요한 준비를 비교합니다.

목표: 조건 두 가지 이상으로 대안을 비교하고 하나를 선택합니다.

1. 중요하게 볼 조건 두 가지를 정해 주세요.
2. 각 방법이 그 조건에 어떻게 맞는지 적어 주세요.
3. 선택한 방법과 실행 후 바꾼 점을 남겨 주세요.

예시: 남은 시간 / 자료 준비 정도를 기준으로 비교

남기는 기록: 조건, 비교 내용, 선택 이유와 실제 적용을 남깁니다.

주의: 가장 빠른 방법이 항상 가장 좋은 방법은 아니에요.

## 필요한 도움을 짧게 설명하기

ID: `daily-communicate` / 일상 적용형 / 행동: 상대에게 설명하고 도움 요청하기

팀 과제나 생활 속 부탁에서 무엇을 도와달라는 것인지 전달이 잘되지 않았습니다.

목표: 상황, 요청, 확인 질문을 구분해 설명합니다.

1. 상대가 알아야 할 상황을 한 문장으로 적어 주세요.
2. 필요한 도움과 가능한 시간을 정해 주세요.
3. 상대가 이해했는지 어떻게 확인했나요?

예시: 자료의 이 부분이 막혔어요. 예시 한 개를 같이 볼 수 있을까요?

남기는 기록: 실제 전달한 내용과 확인한 결과를 남깁니다.

주의: 대화 원문이나 상대의 개인정보를 넣을 필요는 없어요.

## 멈춘 곳을 남기고 다시 이어가기

ID: `daily-resume` / 일상 적용형 / 행동: 중단 후 이어가기와 인계하기

하던 과제를 잠시 멈춰야 합니다. 다음번에 어디서 시작할지 남겨 봅니다.

목표: 중단 위치와 다음 행동을 기록하고 다시 열었을 때 활용합니다.

1. 어디까지 했는지 표시해 주세요.
2. 다음에 할 행동 하나를 적어 주세요.
3. 다시 시작할 때 그 기록이 도움이 됐는지 확인해 주세요.

예시: 12번까지 확인 → 다음에는 13번 조건부터 읽기

남기는 기록: 중단 위치와 다음 행동, 복귀가 있었다면 복귀 기록을 남깁니다.

주의: 복귀가 아직 없었다면 복귀 완료로 표시하지 않아요.

## 승객 안내 전에 확인할 정보 정하기

ID: `job-aviation-verify` / 직무 모의 상황형 / 행동: 필요한 정보 확인하기

교육용 가상 상황입니다. 보안검색 중 제한 여부를 확인해야 하는 물품이 발견되어 승객이 당황합니다. 이 카드에는 반입 허용 여부의 정답이나 실제 처리 절차가 제공되지 않습니다.

목표: 확인된 사실과 모르는 정보를 나누고 안내·담당자 확인 순서를 생각합니다.

1. 확인된 사실과 아직 판단할 수 없는 정보는 무엇인가요?
2. 승객에게 확인 중인 상황을 어떻게 설명할까요?
3. 판단 권한과 확인해야 할 담당자·공식 자료를 어떻게 구분할까요?

예시: 확인되지 않은 허용 여부를 단정하지 않고, 필요한 확인 사항을 정리해 설명하기

남기는 기록: 사실·미확인 정보, 설명 문장, 확인 계획을 남깁니다.

주의: 실제 보안 업무 지침이 아닙니다. 현장에서는 해당 기관의 최신 공식 절차와 담당자 지시를 따릅니다.

## 회의 자료 준비 순서 정하기

ID: `job-office-sequence` / 직무 모의 상황형 / 행동: 순서와 절차 지키기

가상 팀 회의 자료에서 내용 확인, 파일 정리, 공유를 맡았습니다. 이전 파일과 새 파일이 함께 있어 혼동될 수 있습니다.

목표: 자료의 순서를 정하고 확인 지점을 넣습니다.

1. 완료했을 때 어떤 상태여야 하나요?
2. 내용 확인부터 공유까지 단계를 정해 주세요.
3. 한 단계를 모의로 진행하고 빠뜨릴 수 있는 부분을 적어 주세요.

예시: 내용 확인 → 버전 구분 → 공유 대상 확인 → 전달 확인

남기는 기록: 단계 목록과 모의 진행 표시를 남깁니다.

주의: 실제 기관 자료나 내부 문서를 업로드하지 않아요.

## 시연 직전 연결 문제에 대응하기

ID: `job-it-adapt` / 직무 모의 상황형 / 행동: 예상 밖의 상황에서 대안 정하기

가상 서비스 시연 직전에 연결 문제가 생겼습니다. 남은 시간은 짧고 원인은 아직 확인되지 않았습니다.

목표: 사실과 추측을 구분하며 가능한 대안을 선택합니다.

1. 무엇이 확인됐고 무엇은 추측인가요?
2. 안전하게 가능한 대안 두 가지를 정해 주세요.
3. 누구에게 무엇을 알리고 어떤 대안을 선택할까요?

예시: 상태를 공유하고 준비된 설명 자료로 시연을 바꿀지 검토하기

남기는 기록: 관찰한 조건, 대안, 선택 이유와 알릴 내용을 남깁니다.

주의: 실제 시스템 설정 변경이나 보안 해제를 요구하는 활동이 아니에요.

## 다른 안내를 받은 고객에게 설명하기

ID: `job-service-communicate` / 직무 모의 상황형 / 행동: 상대에게 설명하고 도움 요청하기

교육용 가상 상황에서 고객이 이전 안내와 지금 안내가 다르다며 설명을 요청합니다. 아직 정확한 변경 사유는 확인되지 않았습니다.

목표: 요청을 정리하고 확인할 내용과 설명할 내용을 나눕니다.

1. 고객이 알고 싶은 내용을 정리해 주세요.
2. 확인되지 않은 부분은 어떻게 설명할까요?
3. 확인 후 다시 안내할 내용을 한 문장으로 써 주세요.

예시: 원하시는 내용을 먼저 확인하고 변경 사유를 확인한 뒤 안내하겠다고 설명하기

남기는 기록: 요청 요약, 확인 질문, 설명 문장을 남깁니다.

주의: 실제 고객의 이름·주문번호·연락처를 입력하지 않아요.

## 분류 작업의 중단 위치 인계하기

ID: `job-logistics-resume` / 직무 모의 상황형 / 행동: 중단 후 이어가기와 인계하기

가상의 물품 목록을 분류하던 중 다른 담당자에게 인계해야 합니다. 완료한 항목과 아직 확인하지 못한 항목이 섞여 있습니다.

목표: 완료·미확인·다음 행동을 구분해 인계 메모를 만듭니다.

1. 어디까지 확인했다고 표시할까요?
2. 다음 담당자가 먼저 확인할 것은 무엇인가요?
3. 메모만 보고 다음 행동을 찾을 수 있는지 확인해 주세요.

예시: 목록 1~5 확인 / 6부터 미확인 / 다음은 6의 분류 조건 확인

남기는 기록: 중단 위치, 미확인 부분, 다음 행동을 남깁니다.

주의: 실제 물품 이동이나 장비 운전 절차를 연습하는 카드가 아니에요.

## 두 가지 안내 콘텐츠 비교하기

ID: `job-media-compare` / 직무 모의 상황형 / 행동: 여러 조건을 비교해 결정하기

가상 행사 안내를 카드 이미지로 만들지 짧은 글로 만들지 결정합니다. 읽는 대상과 제작 시간에 제약이 있습니다.

목표: 대상과 시간 조건을 기준으로 대안을 비교합니다.

1. 안내를 보는 대상과 꼭 전달할 내용을 정해 주세요.
2. 두 형식을 같은 조건으로 비교해 주세요.
3. 선택 이유와 확인받고 싶은 부분을 적어 주세요.

예시: 핵심 전달 / 제작 시간 / 읽기 편의 기준으로 비교

남기는 기록: 비교 기준, 대안별 판단, 선택 이유를 남깁니다.

주의: 선택한 형식만으로 기획 능력이나 직무 적합성을 판단하지 않아요.
