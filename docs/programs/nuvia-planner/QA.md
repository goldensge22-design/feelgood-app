중앙 i18n registry에 실행되지 않는 패키지를 프로그램으로 임의 등록하지 않는다. 중앙 validator의 기존 실패를 이 패키지의 번역 완료 또는 제품 QA 결과로 바꾸지 않는다.

## 개발자가 반드시 추가할 QA

1. 공식 TOP5의 ID·원본 순서·점수 단위·결과 버전 보존, 청소년 adapter 별도 검증.
2. 미연결 직무에는 일반 행동 제공; 가짜 직무 전용 추천/등급을 만들지 않음.
3. 사용자·기관 간 개인 카드/경험 접근 차단, 공유 철회·삭제·export 재확인, 인증된 서버 권한 검사.
4. 새로고침·재접속·언어 변경·백업/복원 뒤 template/task/run/version 연결 보존.
5. 현재 실행 유지, 동시 실행 방지, 타이머 자동 완료 금지, 직접 행동 없이 목표 수행 집계 금지.
6. 일상과 모의 경험을 보고서·자소서 전달까지 구분; 임의 성과 문장이나 수치 생성 금지.
7. AI 호출 명시적 요청·예산 상한·중복 방지·오류 복구·민감정보 최소화·자동 공용 공개 금지.
8. locale별 원문 버전·placeholder·RTL·상단 선택기·샘플 언어 일관성·줄바꿈·인쇄 검수.
9. 공용 카드 갱신/철회 시 기존 경험 snapshot 보존, 재검토 만료 카드 신규 시작 차단.
10. 월간 중복 집계 방지, 분모 0/기록 부족 분리, 다음 달 초안의 사용자 승인.
