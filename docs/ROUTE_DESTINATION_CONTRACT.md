# 모든 프로그램의 경로·도착 화면 검증 규칙

개정: 2026-11-21. 사용자 확정: 모든 진입 경로가 맞는 화면에 도착하도록 구현·검수하고, 같은 누락을 반복하지 않도록 규칙을 저장한다.

이 정책은 FeelGood/NUVIA 전체에 적용한다. 이번 자동 검증 구현 범위는 결과지 활동 수신 경로다. 정책 저장만으로 다른 프로그램까지 수정·검수됐다고 말하지 않는다.

## 경로를 만들기 전에 목적지를 확정한다

1. 프로그램마다 원본 화면/버튼, 사용자 역할, 콘텐츠 대상, 목적지 route, 필수 인자, 저장 범위, 실패 시 동작을 표로 기록한다.
2. 콘텐츠 대상과 로그인 계정은 구분한다. 부모·교사·관리자가 열어도 K-PASS 콘텐츠를 성인 콘텐츠로 바꾸지 않는다. 인증된 계정·학습자 권한을 임의 변경하거나 검사 점수를 전달해 화면 종류를 추측하지 않는다.
3. 같은 목적지의 링크·저장 후 redirect·로그인 복귀·성공 화면 버튼은 검증된 공통 경로 생성 함수를 사용한다. 각 버튼에서 별도로 기본 경로를 하드코딩하지 않는다.
4. 출처에서 확정한 대상/학교급과 locale을 전달하고, 저장 확인·로그인·언어 전환·새로고침에서도 보존한다. 캐시 복원은 같은 requestId/활동에만 적용한다. 다른 보고서나 계정의 직전 값으로 추측하지 않는다.
5. 필수 대상값이 누락·잘못됨·충돌 상태라면 MY NUVIA, HOME, 성인 화면 등 임의 기본값으로 보내지 않는다. 복원 가능한 같은 요청의 값이 있으면 복원하고, 없으면 해당 화면에서 명시적으로 확인·선택하도록 한다. 대상 확정 전 성공 저장/이동을 실행하지 않는다.
6. 옛 링크, 이미 열린 결과지, 캐시된 코드, 로그인 전후·새 탭을 호환성 범위에 넣는다. 최신 원본 새로고침으로만 성공한 검수를 전체 경로 성공으로 확대하지 않는다.

## 결과지 활동의 확정 목적지

| 출처/대상 | 저장 후 화면 | 확인 조건 |
| --- | --- | --- |
| K-PASS 초등 저학년 | 초등 플래너 | `age=elementary_1_3`, 실제 초등 작업대 |
| K-PASS 초등 중·고학년 | 초등 플래너 | `age=elementary_4_6`, 실제 초등 작업대 |
| D-CAS 청소년 | 중고등 MY NUVIA | `report_audience=school` |
| D-CAS 대학생·성인 | 성인 MY NUVIA | `report_audience=adult` |
| 대상 불명인 이전 활동 링크 | 수신 화면에서 대상 확인 | 저장 비활성, 일반 MY NUVIA로 자동 이동 금지 |

K-PASS의 일반 플래너 링크도 같은 초등 구분값을 보존한다. D-CAS의 모든 일반 메뉴까지 위 활동 저장 계약으로 바꾸는 것은 별도 범위다.

## 필수 경로 QA 표

변경 프로그램의 모든 사용자 노출 진입점에 다음을 대조한다. 정상 링크만 검사하지 않는다.

- 원본 버튼 클릭 → 확인 → 권한 있는 저장 → 의도한 화면 → 저장 내용 표시.
- 일반 링크/활동 링크/저장 후 자동 이동/성공 후 다시 열기/로그인 복귀.
- 새로고침·새 탭·뒤로/앞으로·중복 클릭/재시도·기존 열린 탭.
- 누락/잘못된 대상값, 다른 요청의 남은 캐시, 저장 실패, 로그인 만료.
- 역할·학습자별 권한 격리. 콘텐츠 화면 구분값으로 저장 주체를 바꾸지 않음.
- 15개 언어의 대상·locale·query 유지, PC/태블릿/360px, 긴 번역/RTL, 관련 인쇄.
- URL뿐 아니라 대상 컴포넌트와 콘텐츠의 실제 DOM을 검사. HTTP 200·탭 제목·토스트만으로 통과 불가.

## 배포와 완료

- 사용자에게 문제가 발생한 브라우저/세션에서 원본 경로를 확인한다. 별도 검수 계정에서 통과했다면 그 범위만 기록한다.
- 단위 테스트에는 누락값의 잘못된 기본 이동 방지를 포함한다. 브라우저 테스트에는 옛 링크의 저장·이동·복원을 포함한다.
- QA 증거에 해당 route 코드·컴포넌트·locale·검수 스크립트 hash를 연결한다. 실행 소스가 바뀌면 영향 검수를 갱신한다.
- 로컬 QA, GitHub push, CI, 운영 파일/빌드 일치, 실제 운영 경로를 각각 확인한다. 필수 경로 미확인·실패는 미완료다.
- 경로 정책이 바뀌면 이 문서와 해당 프로그램 규칙/테스트/체크리스트를 같은 패치에서 갱신한다. 대체된 활성 규칙은 교체하고 과거 증거는 역사 기록으로 유지한다.

이번 이행: NUVIA의 `report-activity-navigation.ts`와 수신 화면에서 미확정 목적지 이동 차단, 동일 요청의 학교급 복원, 옛 링크 선택을 구현한다. 다른 프로그램에 대한 자동 실시간 경로 감시가 만들어졌다는 뜻은 아니다.
