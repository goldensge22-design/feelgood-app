# C 드라이브 최소 보관과 작업별 정리 의무

적용 범위: 모든 FeelGood/NUVIA 개발·제안서·영상·결과지 작업의 로컬 자료. 규칙 버전 1.2 · 개정일 2026-11-28. 사용자 확정 근거: 지금 쓰지 않는 프로그램·파일은 외장에 두고 필요할 때 연결하며, 개발 중 대체되거나 GitHub·서버에 저장되어 중복된 파일은 그때그때 C에서 삭제하라는 재확인. 같은 날 사용자는 상위 작업 경로 변경 대신 개별 폴더 이동을 선택하고, GitHub 저장 후 C 삭제를 다시 확정했다. 구현 위치: 이 절과 각 작업의 생성·저장·검증·정리 기록. v1.1의 보존·검증 기준을 유지하며 중앙 작업 경로의 변경 범위를 명확히 한다.

- **보존 위치와 C 사본을 구분한다.** 미반영 수정본·최신 유효본·원본도 C에 영구 보관하지 않는다. 올바른 GitHub 커밋, 서버의 복구 가능한 보관본 또는 승인된 외장에 파일 전체가 저장되고 접근·내용 일치가 확인되면, 지금 실행·편집에 필요하지 않은 C 중복 사본을 삭제한다. 서버에서 프로그램이 실행된다는 사실만으로 개발 소스·원본·미반영 수정까지 모두 저장됐다고 추정하지 않는다.
- **개별 폴더 이동을 유지한다.** 2026-11-28 사용자 선택에 따라 `C:\Users\golde\.codex\worktrees` 상위 경로 자체는 외장 junction으로 바꾸지 않는다. 보관이 필요한 개별 작업 폴더를 검증 이동하고 필요한 기존 경로만 연결한다. 새 작업 사본 전체가 자동으로 외장에 생성되도록 중앙 경로를 변경했다고 표현하지 않는다.
- **GitHub 저장 뒤 C 정리를 완료한다.** 작업을 마친 코드·전달물·수정본의 실제 내용이 올바른 저장소·브랜치의 원격 커밋에 반영됐는지 확인하고, 커밋 SHA와 대응 경로·해시를 남긴 뒤 지금 실행·편집에 필요하지 않은 C 중복 사본을 그때그때 삭제한다. 로컬 커밋이나 push 시도만으로 원격 저장을 인정하지 않는다. 민감 원본·대용량 자료 등 GitHub에 부적절한 자료는 승인 외장 또는 보호된 서버의 보존·복구 검증으로 대신한다.
- **생성 시점부터 C 누적을 줄인다.** 지금 작업에 필요하지 않은 이전 작업 사본·전달물·검수 자료와 새로 생성하는 대용량 중간 산출물은 연결된 승인 외장을 우선 사용한다. 외장 미연결 시 임시 C 저장 위치와 정리 대상을 기록하고 외장 연결 후 검증 이동한다. Windows·현재 실행 환경·현재 작업에 꼭 필요한 파일만 C에 둔다. 설치 프로그램은 지원되는 이동/재설치 방법을 사용하며 실행 폴더만 임의로 삭제하지 않는다.
- **매 수정·보완 작업의 마무리에서 실제 정리한다.** 대체 관계가 확인된 불필요한 중간본·구버전과 원격 반영이 확인된 ZIP·PATCH·빌드·다운로드 중복본은 그 작업에서 C 삭제까지 실행한다. 최신 유효본이나 필요한 증분 체인도 검증된 보관 위치에 있으면 C 중복 보관의 예외로 취급하지 않는다. 아직 보관되지 않은 유일본과 반영 여부가 불명확한 변경은 먼저 보존·검증한다. 이미 승인된 이 범위의 일상 정리를 다시 승인받느라 미루지 않는다.
- **외장 사용과 C 공간 확보를 함께 검증한다.** 기존 경로가 필요한 경우 연결을 만들어 Codex·ChatGPT·개발 도구가 외장 파일을 사용하게 하고, 검증된 C 사본을 제거한다. 폴더 잠금은 하위 폴더별 연결 등 안전한 방법을 먼저 검토한다. 해시·경로 연결·남은 C 파일을 확인하고, 외장 복사만 끝난 상태를 C 정리 완료로 보고하지 않는다. 외장이나 원격의 유효 보관본, 결과지 내용 및 운영 서버 데이터는 C 중복 정리를 이유로 삭제하거나 변경하지 않는다.
- **정리 기록이 완료 조건이다.** 삭제한 C 경로, 보존 위치, 원격 커밋/파일 해시, 현재 필요한 최소 잔여 파일과 이유, 확보 공간 및 미완료 항목을 남긴다. 원본·학생 자료·개인정보는 적절한 보호 보관 위치를 사용하고 공개 GitHub에 올리지 않는다. 이 규칙은 매 개발 작업에서 실행하는 절차이며 상시 자동 삭제 서비스가 설치됐다는 뜻이 아니다.

검증/변경 기록: 2026-11-28 사용자 추가 확정 사항을 반영했다. v1.2에서 개별 폴더 이동 유지와 실제 GitHub 저장 후 C 삭제를 명시했다. 기존 결과지 내용 보호·미반영 변경 보호·원격 검증 기준은 유지한다. 상위 worktrees 경로의 외장 전환은 수행하지 않았다. 파일 정리와 규칙의 로컬 저장·GitHub 반영·운영 배포 상태는 각각 기록한다.
