# 전자 교사 가이드 A/B/C 디자인 비교 시안

## 목적

전자 교사 가이드의 A/B/C 디자인 비교 시안을 보존합니다. 이 폴더는 비교와 후속 디자인 작업을 위한 독립 보존본이며, 현재 본제작 교사 가이드를 대체하지 않습니다.

## 디자인 안

- **A안 — Trust & Clarity**: 좌측 탐색 레일을 중심으로 근거와 지원 정보를 구조적으로 안내하는 기관형 가이드입니다.
- **B안 — Cognitive Map**: PASS 네 영역과 지원 흐름을 시각적 지도처럼 연결하는 작업 공간형 가이드입니다.
- **C안 — Editorial Guide**: 읽기 흐름과 장별 안내를 강조한 에디토리얼형 가이드입니다.

B안은 현재 본제작 방향으로 선택되어 `teacher-guide`에 구현되어 있습니다. 기존 본제작 파일은 이 비교 시안과 별도로 그대로 유지합니다.
