# K-PASS·D-CAS·NUVIA 전자 교사 가이드 통합 기획 v2.0

작성 기준일: 2026-09-19  
대상: 초·중·고 교사, 대학 교수·상담자, 검사 운영 담당자  
기준 자료: 「한국판 K-PASS 표준화」, 「K-PASS 교사 가이드(2025년 개정판)」, 「필굿 NUVIA 통합제안서 v3」, K-PASS 인지처리 집단 탐색 보고서 12개 언어 v3

> **언어 수 표기 기준:** 기존 언어는 제외하지 않고 크메르어를 추가한다. 따라서 외국어는 크메르어를 포함해 12개이며, 한국어까지 포함한 화면의 언어 선택지는 총 13개다. 이 문서에서 ‘13개 언어’는 `한국어 1개 + 외국어 12개`를 뜻한다.

## 1. 최종 제안

새 가이드는 긴 PDF 전자책 한 권보다 **한 주소에서 K-PASS, D-CAS 청소년, D-CAS 성인을 선택하는 반응형 웹 가이드**로 제작한다.

- 대표 주소 예시: `guide.feel-good.io`
- 첫 화면에서 대상별 3개 입구 제공
  - K-PASS 아동
  - D-CAS 청소년
  - D-CAS 성인
- 상단에서 한국어 포함 총 13개 언어 전환
  - 현재 집단 보고서의 한국어 포함 12개 언어를 모두 유지
  - 크메르어(캄보디아어)를 추가하여 외국어 12개 지원
- 각 결과지의 QR로 해당 대상과 언어의 정확한 설명 페이지에 바로 연결
- 필요한 장만 PDF로 내려받거나 인쇄할 수 있게 구성
- 81유형은 81페이지를 수작업으로 복제하지 않고 구조화된 문장 라이브러리로 생성

이 방식은 종이책의 신뢰감과 웹의 검색성·업데이트 편의성을 함께 확보한다.

## 2. 제작 모델 권고

이 프로젝트는 대규모 애플리케이션이 아니라 **정적 콘텐츠 중심의 반응형 웹 가이드**이므로 아스트라를 주 모델로 사용할 필요는 없다.

- 주 제작: GPT-5.6 Terra — HTML·CSS·JavaScript 구현, 81유형 데이터 구조, 다국어 라우팅
- 원고·검수: GPT-5.6 Sol — 교사용 문장, 유형별 지침, 용어 통일
- 선택 사용: Astra — 결과지·PDF와 완성 화면을 비교하는 마지막 시각 QA

성공 여부는 모델 이름보다 아래 기준을 먼저 확정하는 데 달려 있다.

- 네 영역의 상·중·하 판정 기준
- 81유형 코드의 공식 순서와 표기
- 동점·균형형·전 영역 상·중·하의 예외 문구
- 아동·청소년·성인별 정적 문장 라이브러리
- 기존 한국어 포함 12개 언어와 추가 크메르어의 정확한 목록·승인 번역본
- 결과지와 가이드의 용어 일치

권장 방식은 **한국어 기준본을 먼저 완성하고, 그 기준본을 외국어 12개로 확장해 총 13개 선택지를 만든 뒤, 필요할 때만 Astra로 전체 화면을 최종 검수**하는 것이다.

## 3. 기존 2025 교사 가이드 진단

기존 가이드는 94쪽이며 다음 장점을 가진다.

- 검사 개념, 결과지 해석, 유형 특성, 계획력·주의력, 교수학습 활용까지 한 흐름으로 설명
- 교사가 수업에서 바로 참고할 수 있는 학습 전략과 협업 아이디어 포함
- 시각적 톤과 색상이 비교적 일관됨

그러나 새 체계에는 다음 한계가 있다.

- K-PASS 한 제품만 설명함
- 좌뇌우세형·우뇌우세형·밸런스형과 계획력 중심이라 4영역 상·중·하 조합인 81유형을 충분히 설명하지 못함
- 유사한 유형 설명이 여러 페이지에 반복됨
- 모바일에서 필요한 내용을 빠르게 찾기 어려움
- D-CAS 청소년과 성인 결과지의 목적 차이가 반영되지 않음
- 검사 후 NUVIA 활동으로 어떻게 이어지는지 설명하지 않음
- 의학적 진단이나 고정된 성향으로 오해할 수 있는 표현을 정비할 필요가 있음

### 유지할 내용

- K-PASS·D-CAS의 기본 목적
- PASS 네 영역의 개념
- 전체 점수와 하위 영역을 함께 보는 원칙

- 수업·상담에서 결과를 활용하는 방법
- 교사·보호자 설명 원칙

### 다시 작성할 내용

- 좌뇌·우뇌 중심 설명은 순차처리·동시처리의 기능적 설명으로 정리
- 27유형 중심 내용을 81유형으로 전환

- NUVIA 프로그램 소개와 효과 확인 방법 추가

## 3-1. K-PASS의 신뢰도·타당도 핵심 근거

전자 가이드의 ‘검사 근거’ 장은 아래 수치를 짧은 카드와 상세 표로 나누어 제시한다. 수치는 「한국판 K-PASS 표준화」에 보고된 값만 사용한다.

### 표준화 표본

| 항목 | 확인된 내용 | 가이드에서의 의미 |
|---|---|---|
| 수집 시기 | 2023년 1월–6월 | 규준 자료의 수집 시점을 공개 |
| 분석 시기 | 2023년 7월–9월 | 규준 개발 과정의 시점을 공개 |
| 표본 | 전국 4–12세 아동 2,700명 | 연령별 규준에 기반한 비교 가능 |
| 연령 구성 | 각 연령 300명, 남녀 각 150명 | 연령·성별 균형 표집 |
| 세부 규준 | 4세–12세 11개월을 3개월 단위 27개 집단으로 구분, 집단별 100명 | 성장 변화가 빠른 아동기의 세밀한 연령 비교 |
| 지역 구성 | 서울·부산·대구·인천·광주·대전·경기·강원·충북·충남·전북·전남·경북·경남·제주 | 전국 지역 분포를 반영하려는 설계 |
| 표집 기준 | 2022년 교육통계연감의 연령·성별·지역 분포 고려 | 표본 구성 근거를 공개 |

### 신뢰도

| 지표 | 대상·방법 | 결과 | 교사용 해석 |
|---|---|---|---|
| 반분 신뢰도 | 4–12세, 홀수·짝수 문항, Spearman–Brown 보정 | 하위척도 `.91–.95`, 전체척도 `.95–.96` | 문항 구성의 내적 일관성이 높은 수준으로 보고됨 |
| 검사–재검사 신뢰도 | 270명, 2–4주 간격, 평균 20일 | 네 하위척도 `.91–.95` | 짧은 기간을 두고 다시 실시했을 때 점수의 안정성이 높은 수준으로 보고됨 |
| 측정의 표준오차 | 연령별 산출 | 하위척도 `2.91–3.82`, 전체척도 `2.51–2.72` | 단일 점수를 절대값처럼 보지 않고 95% 신뢰구간과 함께 해석해야 함 |

### 타당도

| 근거 | 결과 | 의미 |
|---|---|---|
| 내용 타당도 | PASS 이론의 인지기능을 반영하도록 문항분석과 실험 결과를 함께 고려 | 문항이 측정하려는 네 인지과정을 대표하도록 설계 |
| 발달적 변화 | 4–12세에서 네 하위척도 원점수 평균이 연령과 함께 완만하게 증가 | 발달 검사에서 기대되는 연령별 변화가 관찰됨 |
| 하위척도–전체척도 상관 | 4–6세 `.58–.77`, 7–12세 `.43–.83` | 네 영역이 전체 인지처리 지수와 관련되면서도 동일한 하나의 영역은 아님 |
| 확인적 요인분석 | GFI `.97`, CFI `.98`, SRMR `.01`; RMSR 4–6세 `.07–.09`, 7–12세 `.06–.08` | 자료가 계획·주의·동시·순차의 PASS 구조와 양호하게 부합 |
| 지표 요인부하량 | 각 하위척도 지표 `.90–.97` | 각 과제가 해당 하위영역을 강하게 반영한 것으로 보고됨 |
| 2차 전체요인 부하량 | 4–6세 `.64–.69`, 7–12세 `.57–.78` | 네 영역이 전체 인지처리 요인과 연결됨 |
| 하위영역 간 상관 | 4–6세 `.34–.58`, 7–12세 `.32–.47` | 영역 간 관련성은 있으나 서로 구별되는 정보도 제공 |
| KABC-II 준거 관련 타당도 | 7–12세 40명, 약 1주 간격 역균형 실시; 동일·유사 영역 상관: 순차 `.80`, 동시 `.73`, 계획 `.69`; 전체척도 약 `.71–.72` | 이론적으로 관련된 외부 검사와 예상 방향의 상관이 확인됨 |

자료의 표 10은 전체척도 상관을 `.72`로, 이어지는 본문은 `.71`로 기재한다. 전자 가이드에는 **“약 .71–.72”**로 투명하게 표기하고, 원자료 확인 후 하나의 값으로 정정한다.

### 가이드에 바로 사용할 신뢰 문구

> K-PASS는 2023년 전국 4–12세 아동 2,700명의 자료를 바탕으로 연령 규준을 구성했습니다. 각 연령은 300명, 남녀 각 150명으로 구성했고, 4세부터 12세 11개월까지를 3개월 단위 27개 연령집단으로 세분했습니다. 반분 신뢰도는 하위척도 .91–.95, 전체척도 .95–.96이었으며, 270명을 평균 20일 뒤 다시 검사한 검사–재검사 신뢰도는 .91–.95로 보고되었습니다. 확인적 요인분석과 KABC-II와의 비교 결과도 PASS 네 영역을 해석할 수 있는 타당도 근거를 제공합니다. 다만 모든 검사 점수에는 측정오차가 있으므로 단일 점수보다 95% 신뢰구간, 영역 간 패턴, 교사의 실제 관찰을 함께 보아야 합니다.

### 공신력을 설명하는 원칙

- K-PASS 수치는 K-PASS 근거로만 사용하며 D-CAS 청소년·성인의 신뢰도와 타당도로 확대하지 않는다.
- ‘진단한다’, ‘장애를 판별한다’보다 ‘인지처리 특성을 파악하고 추가 관찰과 지원 계획에 활용한다’고 표현한다.
- KABC-II 비교 표본은 40명임을 함께 밝힌다. 높은 상관만 떼어 홍보하지 않는다.
- 표준화 자료는 기술자료의 성격이므로, 독립된 동료심사 논문과 반복 연구가 확보되면 별도 근거로 추가한다.
- ‘2,000명 이상이면 자동으로 정확해진다’고 표현하지 않는다. 2,000명은 국가별 규준 재검토를 시작하는 운영 기준이며, 표본 대표성·데이터 품질·검사 버전의 동일성·통계적 적합성이 확인된 경우에만 정식 규준을 갱신한다.

### 기존의 주기적 표준화와 필굿의 디지털 상시 표준화

전통적인 개별 지능검사는 새로운 판을 개발할 때 대규모 표준화를 실시하고, 다음 개정판이 나올 때까지 같은 규준을 사용하는 경우가 많다. 검사와 국가에 따라 차이가 있으나 이 개정 간격은 흔히 **10년 안팎 또는 그 이상**이 될 수 있다. 따라서 가이드에서는 ‘모든 기존 검사는 정확히 10년마다 표준화한다’고 단정하지 않고, **‘대체로 장기간 고정된 규준을 사용하는 주기적 표준화 방식’**이라고 설명한다.

필굿의 차별점은 검사가 디지털로 운영되기 때문에 국가별 검사 데이터를 지속적으로 축적하고, 표본이 충분해지는 시점에 규준의 적합성을 더 자주 검토할 수 있다는 것이다.

| 구분 | 전통적인 주기적 표준화 | 필굿의 디지털 상시 표준화 체계 |
|---|---|---|
| 데이터 수집 | 새 검사판·개정판 개발 시 대규모 수집 | 실제 운영 과정에서 국가별 자료를 지속적으로 축적 |
| 규준 검토 시점 | 새로운 판을 개발하는 주기에 집중 | 표본 규모와 품질 기준 충족 시 국가별로 수시 검토 가능 |
| 국가별 적용 | 번역·현지화 후 별도 표준화 프로젝트 필요 | 국가별 데이터 풀과 언어·문화권별 품질지표를 분리 관리 |
| 변화 탐지 | 다음 개정 시점까지 규준이 고정될 가능성 | 연령·지역·성별 분포와 점수 변화, 문항 기능 변화를 지속 점검 |
| 규준 업데이트 | 판 전체를 교체하는 방식이 일반적 | 검증·승인된 규준 버전을 단계적으로 배포하고 변경 이력을 보존 |

### 국가별 규준 업데이트 절차

국가별 유효 사례가 2,000명 이상 축적되면 다음 절차에 따라 규준 업데이트 가능성을 검토한다.

1. 중복·비정상 반응·중단·기기 오류 등 데이터 품질을 점검한다.
2. 연령·성별·지역·학교 유형 등 표본 대표성을 확인한다.
3. 언어·문화권에 따라 특정 문항이 다르게 작동하는지 문항기능차이(DIF)를 검토한다.
4. 기존 규준과 새 자료의 평균·분산·백분위·연령별 변화와 점수 이동을 비교한다.
5. 신뢰도, 요인구조, 외부 준거와의 관계가 유지되는지 확인한다.
6. 구버전과 신버전의 점수 동등성과 해석 차이를 검증한다.
7. 전문가 승인 후 새 규준 버전을 배포하고 적용일·표본·변경 내용을 공개한다.

즉, 2,000명은 자동 업데이트 조건이 아니라 **정식 재표준화 검수를 시작할 수 있는 최소 운영 기준**이다. 표본의 대표성과 심리측정학적 검증이 충족되지 않으면 자료가 2,000명을 넘어도 규준을 변경하지 않는다.

### 가이드북에서 강조할 핵심 문구

> 기존의 많은 지능검사는 새로운 개정판이 나오는 약 10년 안팎의 주기에 맞추어 규준을 다시 구성하는 방식이 일반적입니다. 필굿은 디지털 검사 기술을 활용해 국가별 검사 데이터를 지속적으로 축적하고, 유효 사례가 2,000명 이상 확보되면 표본 대표성·신뢰도·타당도·문항 기능·기존 규준과의 동등성을 검수합니다. 검증을 통과한 경우에만 새로운 국가별 규준 버전을 적용하므로, 사회·교육환경과 세대 변화가 규준에 반영되는 시간을 줄이고 검사 정확도를 지속적으로 정교화할 수 있습니다.

첫 화면이나 소개 영상에는 다음과 같이 짧게 제시한다.

> **10년을 기다리는 규준이 아니라, 국가별 데이터로 계속 검수되는 규준.**  
> 필굿은 검사 데이터가 축적될수록 국가별 규준의 적합성을 점검하고, 검증된 경우에만 새 버전으로 업데이트합니다.

### 정확도 향상을 주장할 때의 기준

‘어느 검사보다 정확하다’는 비교우위 표현은 동일한 표본에서 다른 검사와 직접 비교한 연구가 확보된 뒤 사용한다. 현재 단계에서는 다음 표현이 정확하다.

- 사용 가능: ‘규준을 더 빠르게 검토하고 정교화할 수 있는 기술적 구조’
- 사용 가능: ‘국가별 데이터 변화에 대응할 수 있는 지속적 규준 관리 체계’
- 사용 가능: ‘장기간 고정 규준에서 발생할 수 있는 노후화 위험을 줄이는 것을 목표로 한다’
- 근거 확보 전 보류: ‘모든 기존 검사보다 정확하다’
- 근거 확보 전 보류: ‘2,000명만 모이면 자동으로 정확도가 올라간다’

이 차별점을 객관적으로 입증하려면 규준 버전마다 표본 구성, 신뢰도, 타당도, 점수 이동, 문항기능차이, 적용일과 변경 이력을 공개하는 **국가별 규준 버전 카드**를 제공한다.

## 3-2. 검사 개발 전문성과 표현 기준

권장 소개문은 다음과 같다.

> K-PASS와 D-CAS는 교육심리학, 심리측정, 응용통계 및 디지털 기술을 결합한 PASS 이론 기반 인지처리 검사입니다. 한국판 K-ABC와 KABC-II 등 국내 심리검사 표준화 경험을 축적한 문수백 교수가 K-PASS의 연구와 표준화를 이끌었으며, 필굿은 계획·주의·동시처리·순차처리 과제를 게임형 상호작용과 디지털 반응 데이터로 구현했습니다. 검사는 학생을 고정된 유형으로 규정하기보다, 학습 과정에서 나타날 수 있는 강점과 지원 필요를 찾아 수업·상담·후속 훈련을 설계하는 데 목적이 있습니다.

‘세계 3대 검사’, ‘아시아 최초’, ‘한국에 최초 도입’과 같은 표현은 객관적으로 확인 가능한 1차 자료가 확보되기 전에는 사용하지 않는다. 대신 실제 표준화 경력, 표본, 신뢰도, 타당도 수치를 제시하는 편이 공신력을 더 안정적으로 전달한다.

## 5. 첫 화면과 핵심 사용자 동선

### 첫 화면

상단에는 FeelGood 로고, 가이드 제목, 언어 선택만 둔다. 중앙에는 세 대상 카드가 보인다.

1. K-PASS 아동: 교사·보호자가 아동의 학습과 지원 방향을 이해
2. D-CAS 청소년: 교사·상담자가 학습·진로와 자기관리 특성을 이해
3. D-CAS 성인: 대학·기관·기업 담당자가 학습·직무·실행 특성을 이해

카드를 선택하면 바로 ‘2분 빠른 안내’가 열린다. 긴 소개 화면을 먼저 보게 하지 않는다.

### 교사가 가장 자주 쓰는 네 경로

1. 검사 전: 검사 목적, 준비, 학생 안내 문구
2. 검사 직후: 결과지 각 영역의 의미와 주의사항
3. 상담 중: 81유형, 강점, 지원 방법, 보호자 설명 문구
4. 검사 후: NUVIA 추천 활동과 변화 관찰 항목

### 전자 가이드가 가장 먼저 답해야 할 질문

교사가 가이드를 열었을 때 이론 설명보다 아래 질문의 답을 먼저 찾을 수 있어야 한다.

1. 우리 반은 정보를 어떤 방식으로 처리하는 학생이 많은가?
2. 이번 수업에서 어떤 설명과 자료를 더 제공해야 하는가?
3. 공통 수업만으로 충분한 학생과 추가 지원이 필요한 학생은 누구인가?
4. 높은 강점과 지원 필요가 함께 있는 학생을 어떻게 놓치지 않을 것인가?
5. 학생을 유형에 고정하지 않으면서 모둠을 어떻게 구성할 것인가?
6. 검사 후 어떤 NUVIA 활동을 연결하고 무엇을 관찰할 것인가?
7. 4주 또는 8주 뒤 수업과 훈련의 도움 여부를 무엇으로 확인할 것인가?

전자 가이드의 핵심 문장은 다음과 같이 정한다.

> 이 검사는 학생을 분류하기 위한 자료가 아니라, 같은 목표를 서로 다른 방식으로 배울 수 있도록 수업의 설명·자료·도움 수준을 조정하기 위한 자료입니다.

반 대시보드는 점수 표를 보여주는 보고서가 아니라 **교사의 다음 수업 결정을 돕는 작업 화면**이어야 한다.

검토 기준 화면: [K-PASS 인지처리 집단 탐색 보고서](https://goldensge22-design.github.io/feelgood-app/PASS_report_KNUE_Jeungpyeong_FeelGood_12lang_v3.html?lang=ko)

### 현재 집단 보고서에서 유지할 기능

- 분석 인원과 해석연령 범위
- 네 PASS 영역의 반 평균
- 처리 유형 분포
- 지원 우선순위 분포
- 척도별 30백분위 미만 인원
- 고강점 후보
- 강점과 취약이 함께 나타난 학생
- 개별 학생 프로파일 매트릭스
- 교육적 지원 예시와 근거 범위
- 다국어 전환과 PDF 저장

### 현재 보고서에서 개선할 점

- ‘위기’ 명칭은 진단처럼 받아들여질 수 있으므로 ‘우선 확인’ 또는 ‘집중 지원 검토’로 통일한다.
- 상단의 ‘고강점 후보 15명’과 종합 등급의 ‘고강점 2명’은 의미가 다르다. 각각 ‘한 영역 이상 고강점 후보’와 ‘종합 고강점 프로파일’로 구분한다.
- 반 평균과 인원수를 보여준 직후 ‘이번 수업에서 적용할 공통 지원’을 제시한다.
- 81유형을 81개의 작은 범주로 나열하지 않는다. 네 영역별 분포와 실용적인 지원 군집을 먼저 보여준다.
- 전체 학생의 원점수·백분위를 첫 화면에 노출하지 않는다. 반 집계가 기본이며 개별 정보는 권한과 필요에 따라 연다.
- 낮은 점수 순위표처럼 보이지 않도록 학생 간 순위를 기본 화면에서 제거한다.
- 모든 추천에는 ‘검사 결과 기반 제안’과 ‘교사 관찰로 확인할 항목’을 함께 표시한다.

- 강점+취약 동시 지원

각 목록은 ‘진단’이 아니라 교사 관찰과 추가 확인을 위한 운영 목록으로 표시한다.

### 화면 4. 수업 설계 도우미

교사가 학년, 과목, 단원, 학습목표, 수업시간을 입력하면 반 데이터를 반영해 아래 내용을 제안한다.

- 전체 학생에게 공통으로 제공할 설명 방식
- 동시처리 지원: 전체 구조, 관계도, 그래픽 조직자, 예시·비예시 비교
- 순차처리 지원: 단계 카드, 절차 번호, 짧은 순서부터 확장
- 계획 지원: 목표 확인, 전략 선택, 중간 점검, 마무리 성찰
- 주의 지원: 짧은 활동 구간, 핵심 자극 강조, 방해 자극 감소, 명확한 휴식
- 고강점 학생의 심화 질문과 확장 과제
- 모둠별 도움 카드
- 수업 종료 전 확인 질문과 관찰 항목

수업 설계안은 네 유형별로 서로 다른 수업을 네 개 만드는 방식이 아니다. **하나의 공통 학습목표를 유지하면서 설명 방식, 자료 형태, 힌트와 단계 수를 다르게 제공하는 방식**으로 설계한다.

### 화면 5. 모둠 구성

교사는 목적에 따라 세 가지 구성을 선택한다.

| 목적 | 구성 원칙 | 활용 예시 |
|---|---|---|

## 7. 81유형 콘텐츠 설계

### 기본 원칙

세 제품에서 같은 코드 체계를 사용하되 문장은 대상에 맞게 달라야 한다.

- K-PASS: 수업 행동과 아동 지원 중심
- D-CAS 청소년: 학습·진로·상담 중심
- D-CAS 성인: 대학·직무·자기관리 중심

81유형 × 3대상 × 총 13개 언어(한국어 1 + 외국어 12)를 각각 독립 페이지로 작성하면 3,159개 조합이 생긴다. 따라서 아래처럼 구성한다.

1. 네 영역 × 상·중·하의 핵심 문장 12개
2. 영역 간 상호작용 문장
3. 대상별 적용 문장
4. 전 영역 상·중·하, 균형형, 큰 점수 차이의 예외 문장
5. NUVIA 도움 방식과 관찰 지표

### 각 유형 화면의 고정 구성

- 유형 코드와 쉬운 이름
- 한 문장 요약
- 검사 상황에서 나타난 인지처리 경향
- 교실에서 관찰될 수 있는 행동 단서
- 강점을 보일 수 있는 상황
- 부담이 커질 수 있는 상황
- 교사가 제공할 첫 도움
- 도움 뒤 다시 확인할 행동
- 수업·상담에서 피할 접근
- NUVIA 추천 경로
- 4주 후 확인할 변화

- 추가 상담·전문평가를 검토할 조건

### ‘기질적 특성’의 표현 원칙

교사가 체감하기 쉬운 말로는 ‘기질적 특성’이지만, K-PASS가 직접 측정하는 것은 성격이나 타고난 기질이 아니라 **검사 과제에서 나타난 인지처리 수행**이다. 따라서 화면 제목은 ‘기질’ 대신 **‘인지처리 경향과 관찰 가능한 특성’**으로 표기한다.

가이드의 모든 문장은 다음 원칙을 따른다.

- ‘이 학생은 원래 그렇다’가 아니라 ‘이런 상황에서 이런 모습이 나타날 수 있다’고 쓴다.
- 상은 장점만, 하는 결함만 의미하지 않는다. 강점의 과사용과 환경에 따른 변화를 함께 설명한다.
- 한 번의 검사 결과와 교실 행동이 다르면 교실 관찰을 우선 확인하고 검사 조건을 재검토한다.
- 낮은 결과는 진단명이 아니다. 지속 기간, 여러 환경에서의 반복, 학업·생활 영향, 다른 평가 자료를 함께 본다.

### 네 영역별 상·중·하 행동 단서와 지도

| 영역 | 상에서 보일 수 있는 모습 | 중에서 보일 수 있는 모습 | 하에서 보일 수 있는 모습 | 첫 지도 방법 |
|---|---|---|---|---|
| 계획 | 목표를 스스로 정하고 전략을 바꾸며 오류를 점검함. 때로는 지나치게 계획하거나 자신의 방식을 고집할 수 있음 | 익숙한 과제에서는 계획하지만 복잡하거나 처음 보는 과제에서는 질문과 틀이 필요함 | 바로 시작하거나 반대로 시작을 미루고, 같은 방법을 반복하며, 중간 점검·오류 수정이 어려울 수 있음 | 목표 한 문장 → 할 일 3단계 → 중간 확인 → 끝난 뒤 ‘무엇이 효과적이었나’ 질문 |
| 주의 | 핵심 자극을 골라 집중하고 방해 자극을 억제함. 때로는 한 부분에 과도하게 몰입하거나 완벽하게 하려 할 수 있음 | 짧고 구조화된 과제에서는 안정적이나 시간·소음·피로가 늘면 흔들릴 수 있음 | 지시 일부를 놓치고, 주변 자극에 쉽게 반응하며, 서두른 오류나 수행 편차가 나타날 수 있음 | 한 번에 한 지시, 핵심 표시, 짧은 활동 구간, 조용한 자리, 확인 질문 제공 |
| 동시처리 | 전체 구조·관계·공간 정보를 빠르게 파악하고 여러 정보를 통합함. 때로는 세부 절차를 건너뛸 수 있음 | 그림·예시·관계도가 있으면 이해가 좋아지고 복잡한 관계는 구조화가 필요함 | 부분을 전체 의미로 묶기, 핵심과 세부 연결, 도표·공간관계·문맥 파악이 부담스러울 수 있음 | 먼저 전체 지도와 완성 예시를 보여주고, 색·그림·비교표로 부분 간 관계를 연결 |
| 순차처리 | 순서·절차·계열 정보를 정확히 다루고 단계적으로 설명함. 때로는 순서가 불분명한 열린 과제에서 경직될 수 있음 | 익숙한 순서는 따르지만 긴 구두지시나 단계가 많아지면 놓칠 수 있음 | 여러 단계 지시의 순서를 잃고, 소리·기호의 배열이나 절차 재현에서 어려움이 나타날 수 있음 | 지시를 짧게 나누고 번호·체크리스트·단계 카드 제공, 말로 다시 설명하게 함 |

이 표는 교사가 ‘무엇을 볼지’를 돕는 가설표다. 행동 하나만으로 영역 수준이나 진단을 역추론하지 않는다.

### 조합을 읽는 세 가지 규칙

1. **강점으로 낮은 영역에 접근한다.** 예: 동시처리 상·순차처리 하이면 전체 그림을 먼저 보여주고 절차 카드를 연결한다.
2. **두 실행 영역을 함께 본다.** 계획·주의가 함께 낮으면 ‘알지만 시작·지속·점검이 어려운지’를 관찰한다.
3. **두 정보처리 영역을 함께 본다.** 동시·순차가 함께 낮으면 설명을 더 단순하게 하고, 시각·언어·행동 시범을 함께 제공한 뒤 이해를 확인한다.

### 네 영역이 모두 낮게 나온 경우

결과지의 공식 문구는 부드럽지만 분명해야 한다.

> 네 인지처리 영역 모두에서 또래 기준보다 낮은 수행이 관찰되었습니다. 이 결과만으로 학생의 능력이나 진단을 결정할 수는 없습니다. 다만 한 영역의 일시적 어려움보다 전반적인 지원 필요 가능성을 보여주므로, 검사 당시의 건강·수면·정서·언어 이해·기기 환경을 먼저 확인하고 교실 및 가정에서의 실제 어려움이 지속되는지 살펴보아야 합니다. 어려움이 여러 상황에서 반복되거나 학습과 일상 적응에 영향을 주는 경우에는 보호자와 상의하여 학교 전문인력 또는 전문기관의 종합평가를 받기를 권합니다.

#### 교사의 단계별 대응

| 단계 | 해야 할 일 | 판단 기준 |
|---|---|---|
| 1. 결과 유효성 확인 | 수면·질병·불안·동기·검사 지시 이해·주 사용 언어·시청각·기기 오류·중단 여부 확인 | 검사 조건이 불충분했다면 결과를 확정적으로 해석하지 않음 |
| 2. 실제 기능 확인 | 2–4주 동안 수업, 과제, 또래활동, 가정의 관찰 자료 수집 | 여러 과목·상황에서 비슷한 어려움이 반복되는지 확인 |
| 3. 즉시 지원 | 짧은 지시, 시각 자료, 단계 카드, 반복 연습, 추가 시간, 잦은 확인 제공 | 지원을 제공했을 때 수행이 얼마나 달라지는지 기록 |
| 4. 학교 내 협의 | 담임·상담교사·특수교육 담당·보건교사와 사례 협의 | 학습·주의·언어·정서·적응 중 어떤 평가가 필요한지 결정 |
| 5. 전문기관 연계 | 보호자 동의를 받아 소아청소년 정신건강의학과, 발달·심리평가 기관, 교육청·학교 전문지원 체계 등 적절한 기관 안내 | 어려움이 지속되고 학업 또는 일상 기능에 뚜렷한 영향이 있을 때 종합평가 권고 |

전문평가는 필요에 따라 지적·인지기능, 기초학업, 언어, 주의·집행기능, 정서·행동, 적응행동, 감각·의학적 요인을 함께 살펴보는 방식이 적절하다. K-PASS 재검사만 반복하는 것으로 종합평가를 대신하지 않는다.

#### 보호자에게 권하는 문장

> 이번 결과는 아이에게 문제가 있다는 뜻이 아니라, 여러 인지 영역에서 도움이 필요할 가능성이 함께 나타났다는 뜻입니다. 검사 당시 컨디션과 수업에서의 모습을 먼저 확인하고, 어려움이 계속된다면 원인을 더 정확히 이해하기 위한 전문적인 종합검사를 권해드립니다. 평가를 기다리는 동안에도 학교에서는 설명을 짧게 나누고, 시각 자료와 단계별 도움을 제공하겠습니다.

#### 피해야 할 문장

- ‘전체 지능이 낮습니다.’
- ‘지적장애가 의심됩니다.’
- ‘공부가 어려운 아이입니다.’
- ‘네 영역이 낮으니 NUVIA만 하면 됩니다.’

이런 표현은 K-PASS 단독 결과가 제공할 수 있는 범위를 넘어선다. 전문평가 의뢰와 동시에 필요한 수업 지원은 바로 시작한다.

### 특별 프로파일 노출 제안

- 전 영역 상: ‘높은 수행 잠재 프로파일’. 과도한 과제 부여보다 도전 수준과 자기조절을 함께 본다.
- 전 영역 중: ‘균형 안정 프로파일’. 특징이 없다는 뜻이 아니라 상황에 따라 여러 전략을 사용할 가능성이 있음을 설명한다.
- 전 영역 하: ‘전반적 지원 우선 프로파일’. 낙인성 명칭을 쓰지 않고 환경, 컨디션, 검사 참여 상태, 추가 평가 필요성을 함께 확인한다.
- 동점·균형: 우세 영역을 억지로 지정하지 않고 균형성과 실제 행동 정보를 함께 제시한다.

## 8. NUVIA 프로그램 소개

### NUVIA KIDS

대상: 유아·초등 중심  
형태: 하루 약 10분의 짧은 게임형 활동  
핵심: 계획, 주의, 동시처리, 순차처리를 연령에 맞는 활동으로 반복 연습

교사에게 설명할 내용:

- 강점을 이용해 지원이 필요한 영역을 연습한다.
- 연령과 프로파일에 따라 힌트, 시간, 시각화, 단계 수를 조정한다.
- 정확도뿐 아니라 반응시간, 오류, 도움 사용, 전략 변화, 참여 지속성을 함께 본다.
- 훈련 게임에서 좋아진 결과가 곧 학습과 생활의 변화라는 뜻은 아니다.

### NUVIA HISTORY

대상: 5–7세부터 성인  
형태: 역사적 사건과 자료를 활용한 사고력 활동  
핵심: 조건을 살펴보고 선택하며, 근거를 비교하고, 판단을 수정하는 경험

교사에게 설명할 내용:

- KIDS에서 익힌 전략을 역사라는 다른 맥락에서 다시 사용한다.
- 연령에 따라 그림·음성·짧은 선택에서 복수 원인·상충 자료·논증으로 확장한다.
- 실제 역사와 자신의 선택을 비교하며 원인·과정·결과를 이해한다.
- 역사 지식 암기보다 근거 사용과 판단 수정 과정을 중점적으로 본다.

### NUVIA PLANNER

대상: 초4부터 성인  
형태: 메타인지 기반 자기관리 활동  
핵심: 자신의 실행 패턴을 발견하고 적절한 전략을 생활 과제에 적용

주요 영역:

- 계획: 우선순위와 과제 분해
- 착수: 아주 작은 첫 행동
- 집중: 집중 구간과 방해요인 조절
- 시간: 예상 시간과 실제 시간 비교
- 회복: 중단 후 다음 가능한 행동으로 돌아오기
- 점검: 반복되는 패턴을 발견하고 전략 조정

### MY NUVIA

역할: 검사 프로파일과 프로그램 기록을 한 총점으로 합치지 않고 각각의 의미를 유지한 채 변화 과정을 보여준다.

- 검사: 표준화된 기준 정보
- KIDS: 훈련 안에서의 수행 변화
- HISTORY: 새로운 맥락에서의 근거 사용과 전략 적용
- PLANNER: 실제 생활에서의 전략 사용과 독립성
- 교사·보호자: 동의 범위 안에서 지원 방향 확인

### 학교에서 현실적인 ‘숙제형’ 운영안

NUVIA는 정규수업을 대신하거나 수업 중 모든 학생이 동시에 수행하는 방식보다, **짧고 선택적인 숙제형 인지전략 연습**으로 연결하는 편이 현실적이다.

| 항목 | 권장안 |
|---|---|
| 운영 기간 | 4주를 기본 단위로 하고 필요 시 8주까지 연장 |
| 빈도 | 주 2–3회 |
| 1회 시간 | 8–12분, 초등 저학년은 더 짧게 조정 |
| 배정 범위 | 한 번에 핵심 프로그램 1개, 보조 활동 최대 1개 |
| 교사 확인 | 월요일 배정, 주중 1회 알림, 금요일 3분 성찰 |
| 평가 방식 | 게임 점수를 성적에 반영하지 않고 참여·전략 사용·독립성만 관찰 |
| 미참여 대응 | 벌점보다 기기·언어·시간·가정환경 장벽을 확인하고 학교 내 대체 시간 제공 |

#### 영역별 기본 연결

| 주요 지원 필요 | 우선 프로그램 | 숙제 목표 예시 |
|---|---|---|
| 계획 | PLANNER, 어린 아동은 KIDS | 시작 전 목표 정하기, 3단계로 나누기, 끝난 뒤 전략 점검 |
| 주의 | KIDS, 필요 시 PLANNER | 짧은 구간 집중, 방해 자극 줄이기, 중단 후 다시 돌아오기 |
| 동시처리 | KIDS → HISTORY | 전체 구조 보기, 관계 찾기, 원인·결과 연결하기 |
| 순차처리 | KIDS → HISTORY | 순서 기억, 절차 따르기, 사건·정보를 계열로 재구성하기 |
| 실행 영역 복합 | PLANNER + 짧은 KIDS | 착수·집중·점검을 한 주에 한 전략씩 연습 |
| 정보처리 영역 복합 | KIDS + 쉬운 HISTORY | 시각 구조와 단계 정보를 함께 사용 |

네 영역이 모두 낮은 학생에게 여러 프로그램을 한꺼번에 배정하지 않는다. 가장 기초적인 한 목표부터 시작하고, 학습·생활 어려움이 지속되면 NUVIA 수행 여부와 별개로 전문적인 종합평가를 안내한다.

#### 교사용 4주 체크

- 1주: 활동을 시작하고 완료할 수 있는가
- 2주: 힌트가 있을 때 목표 전략을 사용하는가
- 3주: 같은 유형의 새 과제에서 도움 없이 사용하는가
- 4주: 교실 과제나 생활 계획에 스스로 가져오는가

검사 표준점수와 훈련 게임 점수를 하나의 총점으로 합치지 않는다. ‘검사 프로파일’, ‘훈련 안에서의 변화’, ‘교실·생활 전이’를 서로 다른 근거로 보여준다.

### 교사에게 전달할 핵심 문장

> NUVIA는 한 게임의 점수를 높이는 데서 끝나지 않고, 익힌 전략을 다른 학습 상황과 실제 생활에서 사용하는지 단계적으로 확인하도록 설계되었습니다. 현재 가이드는 프로그램의 설계 목표와 관찰 방법을 설명하며, 교육 효과는 시범 운영과 연구 결과에 따라 별도로 제시합니다.

### 효과 관찰의 다섯 수준

1. 참여: 활동을 시작하고 완료하는가
2. 도움받은 수행: 힌트가 있을 때 전략을 사용하는가
3. 독립 수행: 도움 없이 같은 유형의 새 과제에 적용하는가
4. 맥락 전이: HISTORY와 같은 다른 문제 상황에 적용하는가
5. 생활 전이: 과제 준비, 시간 관리, 중단 후 복귀에 스스로 적용하는가

이 다섯 수준을 별도로 표시하고 하나의 총점으로 합치지 않는다.

## 10. 대상별 NUVIA 연결

| 검사·대상 | 기본 연결 | 가이드의 초점 |
|---|---|---|
| K-PASS 미취학–초3 | KIDS + HISTORY | 놀이, 기초 인지, 이야기 이해 |
| K-PASS 초4–6 | HISTORY + PLANNER, 필요 시 KIDS | 사고 전략과 자기관리 입문 |
| D-CAS 청소년 | HISTORY + PLANNER | 근거 판단, 학습 전략, 진로, 독립 실행 |
| D-CAS 성인 | HISTORY + PLANNER | 고차 사고, 프로젝트, 시간, 회복, 직무 적용 |

프로그램을 점수에 따라 자동 배정하는 것처럼 보이지 않게 한다. 결과는 추천의 출발점이며 사용자 선택, 관심, 경험, 현재 목표를 함께 반영한다.

## 21. 근거 자료 표시 방식

전자 가이드의 근거 장에는 다음과 같이 출처와 적용 범위를 함께 표시한다.

- 문수백. 「한국판 K-PASS 표준화」. 표준화 표본, 신뢰도, 타당도 표 1–10.
- 적용 범위: K-PASS 4–12세 규준과 해당 연구 표본.
- D-CAS 청소년·성인의 근거는 각 검사에 대한 별도 표준화·신뢰도·타당도 자료가 확보된 뒤 독립적으로 게시.
- NUVIA는 설계 목표, 프로그램 안 수행 변화, 다른 과제로의 전이, 실제 생활 전이를 구분해 제시.

근거 페이지에는 자료명, 연구자, 표본, 수집 시기, 분석 방법, 핵심 수치, 제한점, 개정일, 원문 보기 링크를 함께 둔다.
