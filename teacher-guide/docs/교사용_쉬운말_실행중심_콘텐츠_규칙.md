# 교사용 쉬운 말·실행 중심 콘텐츠 규칙

이 문서는 전자교사가이드의 한국어 원문, PASS 81가지 조합 분석, 교사지도, 보호자 상담과 다국어 번역에 공통으로 적용하는 콘텐츠 기준이다. 검사 소개·PASS 이론·검사개발·표준화·신뢰도·타당도·공식 척도 설명에서는 정확한 전문용어를 유지하고, 수업·상담·학생관리·가정 안내에서는 행동 설명을 먼저 쓴다.

## 1. 독자와 문장 순서

심리검사와 PASS 이론을 처음 접하는 교사가 내일 수업에서 바로 실행할 수 있어야 한다. 활용 문장은 가능한 범위에서 다음 순서를 따른다.

1. 관찰 장면: 언제, 어떤 모습이 나타나는가
2. 가능한 해석: 점수와 실제 관찰을 어떻게 함께 볼 것인가
3. 내일 할 행동: 교사가 무엇을 바꾸고 학생은 무엇을 하는가
4. 준비물·표시: 카드, 밑줄, 관계도, 체크 칸 등 무엇을 쓰는가
5. 시간·빈도: 몇 분, 몇 회, 몇 주 동안 하는가
6. 확인 기준: 어떤 행동 변화를 기록하는가
7. 다음 조정: 유지·축소·변경 기준은 무엇인가

## 2. PASS 용어

전문 장에서는 `계획`, `주의`, `동시처리`, `순차처리`를 그대로 쓴다. 활용 장에서는 다음 쉬운 설명을 먼저 쓰고 전문용어는 보조 표기로 한 번만 병기한다.

- 목표·방법·점검: 목표를 정하고, 방법을 선택하고, 결과를 확인해 바꾸는 힘 (`계획 능력`)
- 집중·복귀: 필요한 정보에 집중하고, 놓쳤을 때 다시 돌아오는 힘 (`주의 능력`)
- 전체 뜻·관계: 여러 정보를 연결해 전체 뜻과 관계를 파악하는 힘 (`동시처리`, 우뇌 관련·전체·관계 처리 영역)
- 순서·단계: 순서를 기억하고 단계대로 해 나가는 힘 (`순차처리`, 좌뇌 관련·순서 처리 영역)

좌뇌·우뇌 관련 표기는 이해를 돕기 위한 간단한 설명이며 특정 뇌 반구의 기능을 직접 측정하거나 학생을 좌뇌형·우뇌형으로 구분하는 표현으로 사용하지 않는다.

## 3. 학생과 보호자에게 말하는 문장

학생에게 직접 말하는 문장에는 `순차처리`, `동시처리`, `좌뇌영역`, `우뇌영역`, `인지처리 병목`, `규준적 약점`, `내적 약점`, `처리 효율성`, `전략 일반화`를 넣지 않는다. 멈춘 단계, 다음 행동, 사용할 표시와 확인 시간을 말한다.

보호자 상담은 다음 순서로 구성한다.

1. 확인된 강점
2. 학교에서 관찰된 장면
3. 검사 결과와 관찰을 함께 본 해석
4. 가정에서 할 행동 한 가지
5. 학교에서 할 행동 한 가지
6. 2~4주 뒤 함께 확인할 기준

상·중·하를 능력·성격·진단명으로 바꾸거나 특정 과목·진로·직업을 확정하지 않는다.

## 4. 모호한 문장 금지

`강점을 활용한다`, `구조화된 지원을 제공한다`, `단계적으로 접근한다`, `연결해 준다`, `지속적으로 관찰한다`, `적절히 조절한다`, `학습을 관리한다`, `전략을 적용한다`, `학생을 지원한다`, `가정과 협력한다`만으로 문장을 끝내지 않는다. 이런 표현이 필요하면 실행 시점, 교사·학생 행동, 자료, 시간·빈도, 확인 기준과 다음 조정을 같은 카드에 적는다.

## 5. 81가지 조합

네 영역의 일반 설명을 단순히 이어 붙이지 않는다. 각 조합에서 강한 영역을 시작점으로 쓰는 방법, 지원이 필요한 영역에서 막힐 장면, 강점이 어려움을 가릴 수 있는 상황, 쉬운 과제와 어려운 과제의 차이, 먼저 줄 도움, 나중에 줄일 도움, 2주 관찰 행동과 추가 평가를 고려할 조건을 함께 제시한다.

## 6. 다국어와 검수

한국어 원문을 먼저 확정하고 기존 locale pack과 상태 정책을 사용한다. 변경된 문구는 전체 지원 언어에 같은 의미와 구조로 반영하며 검수 전에는 `ai-draft` 또는 `needs-review` 상태를 유지한다. 학생 문장, 보호자 설명, 전문 설명은 사용처를 구분해 수집하고 번역한다.

완료 전 81개 조합의 차별성·빈 값·학생 금지용어·실행 카드 필수 항목, 13개 언어의 누락·한국어 잔존·placeholder·RTL·상태 보존, PC와 모바일의 겹침·잘림을 검사한다.
