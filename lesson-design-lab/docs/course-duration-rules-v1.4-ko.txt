수업설계LAB 기간별 제작 규칙
2026년 11월 4일 | v1.4 제작 기준안

적용 상태
사용자가 지정한 하루 특강의 필수 흐름과 장기 과정의 공동 과제 분리를 반영한다. 세부 시간 배분과 장기 과정 회차는 운영을 위한 기본 제안값이며 교사가 수정한다. 이 문서는 앱 구현 완료를 뜻하지 않는다.
기존 v1.2의 대상별 콘텐츠, 81유형, 개인 자료, 인쇄, 언어, 기록 보존 규칙을 승계한다. v1.3의 “단기 수업은 필요한 단계만 선택” 규칙은 이 문서의 “하루 완성형 특강”에는 적용하지 않는다. TOP5 분반·합동 기능은 장기 과정의 선택 기능으로 배치한다.

1. 첫 화면의 두 과정
하루 완성형 특강: 3시간 / 4시간 / 5시간. 하루 안에 검사 해석, 플래너 기본 연습, 기업·직무 LAB 활용, 직무 활동카드 등록·실행·기록, AI자소서 작성과 저장까지 수행한다.
장기 과정: 1개월 / 2개월 / 직접 설정. 개인 활동을 바탕으로 직무별 분반 공동 과제와 분반 합동 활동을 선택하여 설계한다.
기간과 별도로 중고생용 / 대학생용을 선택하고 중고생용 안에서는 중학생 / 고등학생을 고른다.

2. 하루 완성형 특강의 필수 흐름
안내 → 검사 해석 → 플래너 기본 연습 → 기업·직무 LAB 탐색 → 직무 활동카드 계획·등록 → 미션 수행·실행 기록 → 경험 확인 → AI자소서 작성·수정·저장 → 다음 실행과 마감.
휴식은 별도 블록으로 계산한다. 필수 학습 단계를 삭제하여 시간표만 맞추지 않는다. 짧은 과정은 비교 자료 수·읽기 분량·미션 범위·글 분량을 줄인다.
중고생은 같은 기능 흐름에서 진로탐색LAB 자료를 중심으로 하고 필요하면 기업·직무 LAB의 쉬운 역할 자료를 함께 쓴다. 마지막 글은 활동 소개·진로 이야기로 조정한다. 대학생은 기업별 역할과 직무 경험을 중심으로 한다.

3. 플래너 연습을 두 번 하는 이유와 규칙
첫 번째는 기본 사용 연습이다. 짧은 연습용 활동을 추가하고 날짜·첫 행동·도움·완료 기준을 넣은 뒤 실제로 수행하고 회고를 저장한다. 예: 오늘 사용할 자료를 확인하고 준비 목록 만들기. 프로그램 설명을 듣는 것만으로 연습 완료 처리하지 않는다.
두 번째는 기업·직무 LAB에서 찾은 요구 행동을 자기 직무 활동카드로 만드는 연습이다. 학생이 선택한 직무, 수행할 미션, 산출물과 완료 기준을 확인하고 플래너에 등록한 뒤 수업 중 실제로 수행한다.
기본 연습용 활동과 직무 미션 활동을 구분하여 표시한다. 등록한 계획과 실행 기록은 같은 플래너 활동에 연결한다. 재시도 때 활동을 중복 생성하지 않는다. 실행·경험·피드백 기록용 인쇄 카드가 나뉘어도 모두 같은 실행과 연결할 수 있다.

4. 하루 특강의 직무 TOP5 활용
결과지 TOP5의 순서와 사유를 보존한다. 학생이 오늘 탐색할 직무 하나를 선택하고 필요할 때 비교 후보 하나를 더 선택한다. 3시간 기본형은 한 직무의 요구 행동과 미션을 깊이 다룬다. 4·5시간형은 후보 또는 기업 역할 비교와 재수행을 늘린다.
TOP1 강제 배정, 다섯 직무 전체 수행, 결과 유형에 따른 직무 제한을 하지 않는다. 결과지가 없으면 자기 관심 선택임을 표시한다.
학생은 같은 반에 있어도 각자 다른 직무 미션을 할 수 있다. 좌석 분단과 짧은 짝 피드백은 가능하지만 하루 특강에서 분반 공동 프로젝트나 분반 합동 프로젝트를 기본 생성하지 않는다. 해당 기능은 장기 과정 메뉴에 둔다.

5. 시간표 기본값
아래는 검사 완료와 결과지 준비를 전제로 한 경과 시간 기준이다. 3·4·5시간은 각각 휴식을 포함한 180·240·300분이다.

단계                         3시간  4시간  5시간
목표와 프로그램 안내           10     10     10
검사 해석과 방법 선택           20     30     40
플래너 기본 사용 연습           15     20     25
기업·직무 LAB 또는 진로 탐색    25     35     45
직무 활동카드 계획과 등록       15     20     25
미션 수행과 실행 기록           25     40     50
실제 경험 정리와 사실 확인      10     15     20
AI자소서 작성 수정 저장         40     50     55
다음 실행과 마감               10     10     10
휴식 합계                     10     10     20
총합                         180    240    300

3·4시간형은 탐색 후 휴식 10분을 기본 배치한다. 5시간형은 탐색 후 10분, 경험 정리 후 10분으로 나눈다. 교사는 휴식 위치와 세부 시간을 바꿀 수 있지만 합계와 필수 단계는 확인해야 한다.
시간 조정 시 학습 내용을 먼저 축소한다. 예: 자료 두 개 대신 한 개와 확인 질문, 긴 실무 과제 대신 작은 산출물 하나, 긴 자소서 대신 한 문항의 짧은 완성본. 발표·추가 비교·문장 다듬기 확장은 줄일 수 있다. 학생이 실제로 해 보는 시간과 경험 확인·글 저장은 보존한다.
“현장에서 검사 실시”는 별도 옵션이다. 검사 종류에 따른 실제 소요 시간을 입력하고 총 시간에 더한다. 검사 시간이나 유형을 추정하여 3시간 안에 자동 삽입하지 않는다. 시간이 부족하면 사전 검사 또는 운영 시간 확대를 제안한다.

6. 하루 특강의 완료 기준
학생마다 다음을 확인한다.
① 결과지 또는 자기 경험을 근거로 오늘 사용할 방법과 도움을 선택했다.
② 플래너에 기본 연습 활동을 만들고 실제 수행·회고를 확인했다.
③ 탐색LAB에서 선택 직무와 요구 행동 또는 관심 분야의 활동 근거를 남겼다.
④ 직무 활동카드를 플래너 활동으로 등록하고 수업 중 수행한 산출물·기록이 있다.
⑤ 계획과 실제 수행, 모의 연습과 실제 활동을 구분한 경험 기록이 있다.
⑥ 학습용 또는 실제 지원 문항에 맞는 글을 직접 작성하고 피드백 후 수정본을 저장했다.
⑦ 저장한 글을 다시 열거나 내보낸 파일을 확인했고 다음 실행을 정했다.
글의 분량은 대상과 시간에 따라 교사가 정한다. 기본 목표는 한 문항의 수업용 완성본이다. 여러 문항 전체 지원서나 채용 합격 수준을 보장하지 않는다. 모의 직무 연습은 글에서도 모의 연습임을 유지한다.
AI자소서는 본인이 확인한 경험으로 학생이 작성·검토하게 한다. 질문·점검·수정 제안과 실제 AI 연결 상태를 구분하고, 없던 성과나 실제 직장 경험을 생성하지 않는다.

7. 장기 과정의 설정
달력상의 1개월·2개월과 총 수업 시수를 분리한다. 시작일, 회차 수, 회차별 분, 수업 사이 개인 활동 시간, 휴일과 휴강을 교사가 입력한다.
기본 예시: 1개월은 주 1회 90분씩 4회, 2개월은 주 1회 90분씩 8회. 회차와 시간은 수정 가능하며 기본 예시를 모든 기관에 강제하지 않는다. 회차별 휴식을 넣으면 수업과 휴식 합계를 별도로 표시한다.
수업 방식 옵션: 개인 프로젝트만 / 직무 분반 공동 과제 / 분반 합동 프로젝트 / 단계별 혼합.
분반 공동 과제의 선택 여부와 분반 합동 세션의 선택 여부를 각각 설정한다. 장기 과정이라도 조별 과제를 강제하지 않는다.

8. 1개월 예시 과정
1회: 검사 해석, 플래너 기본 사용, 관심 직무 선택. 개인 연습 기록을 남긴다.
2회: 기업·직무 또는 진로탐색LAB 활용, 개인 미션 계획·일부 수행. 학생별 활동카드를 등록한다.
3회: 선택한 경우 직무 분반 공동 과제 수행·피드백. 개인 과정이면 자신의 미션을 보완한다. 조별 과정도 각자 맡은 일과 받은 도움을 기록한다.
4회: 결과물 공유, 경험 확인, AI자소서 또는 나의 이야기 작성·수정·저장, 다음 실행.
분반 합동을 선택했다면 3·4회 시간표 안에 목적과 시간을 따로 배정하거나 회차를 추가한다. 기존 시간에 큰 합동 과제를 무조건 덧붙이지 않는다.

9. 2개월 예시 과정
1회 검사 해석과 플래너 기본 연습.
2회 기업·직무 또는 진로탐색LAB의 후보·역할·출처 비교.
3회 개인 직무 미션과 플래너 실행·회고.
4회 선택한 직무 분반의 공동 과제 설계와 개인 역할 협의.
5회 공동 과제 수행, 중간 산출물과 피드백.
6회 선택한 분반 합동 프로젝트 또는 교차 검토. 개인·분반 과정만 선택한 경우 해당 결과물 보완.
7회 개인 경험 확인, 글 문항 선택, AI자소서 또는 나의 이야기 초안.
8회 근거 검토와 글 수정, 결과물 발표·보관, 다음 실행.
개인 프로젝트만 선택하면 4~6회를 개인 미션의 반복·확장·검증으로 대체한다.

10. 장기 과정의 TOP5 분반과 합동 규칙
결과지 원순위와 별개로 학생이 이번에 탐색할 직무를 선택한다. 선택 직무·미션·운영 조건을 기준으로 분반 초안을 만든다. 검사 유형만으로 분반이나 역할을 고정하지 않는다.
직무 분반에서는 공동 과제와 개인 수행 분량을 함께 정한다. 분반 합동은 같은 직무의 기업 비교, 서로 다른 직무가 연결되는 프로젝트, 탐색 박람회와 교차 피드백 중 선택한다.
좌석 분단 / 원래 소속반 / 직무 분반 / 합동 조를 구분한다. 인원·시간·교사·공간·중복 배치·결석을 확인하고 교사가 확정한다. 정보가 부족하거나 인원이 불균형하면 조건 조정안을 보여 주고 학생 관심을 임의 변경하지 않는다.
공동 산출물이 완성되어도 개인 경험과 AI자소서는 본인이 수행한 행동을 기준으로 각각 작성한다. 공동 글을 전원에게 복사하지 않는다.

11. 출력 규칙
하루 특강: 강사용 분 단위 수업안, 필요한 개인 활동지, 플래너 기본 연습 안내, 직무 활동카드, 실행·경험 기록, 글 작성·수정 양식, 다음 실행 카드. 내용이 연결되면 한 문서 또는 같은 카드의 기록 면으로 묶어 불필요한 중복 인쇄를 줄인다.
장기 과정: 위 개인 자료를 회차별로 배부하고, 선택한 공동 과제지·역할표·합동 자료·분반 명단·회차 진행표를 추가한다.
대상: 학생 한 명 / 선택 학생 / 소속반 전체. 장기 과정에서 선택 분반·합동 조 출력 추가. 하루 특강도 좌석 분단별로 개인 묶음을 정렬할 수 있다.
활동지 A4, 카드 A4 또는 A5 배치, PDF와 재출력. 학생별 코드·자료 제목·연결·버전·페이지를 표시하고 학생 경계를 보존한다. 점수·81유형·약점은 기본 출력 제외.
템플릿 종류, 배부본 수, 페이지 수, 용지 수를 구분한다. 기존 18개 기본 수업·36종 활동지는 콘텐츠 자원이며 3·4·5시간 및 1·2개월 편성안을 새로운 원본 콘텐츠 수로 중복 계산하지 않는다.

12. 교사용 수업안에 반드시 생성할 내용
단계별 시작과 종료 시간 / 강사가 열 프로그램과 실제 메뉴 또는 확인이 필요한 경로 / 확인할 결과지 항목의 제목과 검증된 번호 / 화면 시범 / 학생에게 할 설명 / 배부할 자료 / 학생의 수행 / 강사 질문 / 산출물과 완료 기준 / 막힐 때 줄 도움 / 저장·출력 확인 / 미연동 시 수동 대체 방법.
운영 화면은 현재 단계와 다음 안내, 개인별 진행·도움 요청·제출 확인을 보여 준다. 외부 프로그램에서 확인한 기록, 학생의 자기 표시, 교사의 확인, 종이 기록을 구분한다.

13. 리플릿 제작 화면 흐름
과정 선택 → 대상과 소속반 → 시간 또는 회차 → TOP5와 학생 선택 직무 → 단계별 과제와 도움 → 장기 과정이면 분반·합동 옵션 → 수업안·활동지·카드 검토 → 출력과 배부 → 수업 진행 → 경험과 글·다음 실행 확인.
하루 특강의 기본 버튼은 “3시간 완성형”, “4시간 완성형”, “5시간 완성형”이다. 세 버튼 모두 필수 프로그램 흐름을 포함한다.
장기 과정의 기본 버튼은 “1개월 과정”, “2개월 과정”, “직접 설정”이다. 회차별 목표와 과제, 개인/공동 방식, 실제 수행 기록을 유지한다.
모드를 바꿀 때 기존 수업과 학생 기록을 조용히 초기화하지 않는다. 복제하여 다른 과정으로 만들거나 변경 내용을 검토한 후 적용한다.

14. 연동과 검수
기존 프로그램의 계정·결과지·플래너·경험·학생 글을 보존한다. 연동이 없다면 복사·프로그램 열기·수동 등록 확인으로 운영하고 자동 등록이나 실시간 수집이라고 표시하지 않는다. 이 기획 문서만으로 실제 학생 운영 준비 완료를 선언하지 않는다.
필수 검수: 180·240·300분 정확한 합계 / 모든 하루 특강에 다섯 프로그램 활용 단계와 경험 확인·저장 포함 / 플래너 기본 연습과 직무 적용 구분 / 하루 특강의 공동 프로젝트 자동 생성 없음 / 장기 과정의 분반·합동 선택과 회차별 자료 / 조 변경 후 개인 기록 보존 / TOP5 원순위 보존 / 개인별 인쇄 경계 / 저장 실패와 수동 입력 표시 구분 / 세 교육단계의 읽기 자료·과제·도움·결과물 차이.

개발 우선순위
먼저 하루 특강 3·4·5시간형의 수업안·개인 자료·플래너 두 번 연습·경험·글 완성 흐름을 구현한다. 이어서 같은 자료·기록 구조를 사용하는 1·2개월 편성과 분반·합동 선택을 구현한다. 기존 계정과 프로그램의 실제 연동은 확인한 연결 계약에 따라 검수한다.
