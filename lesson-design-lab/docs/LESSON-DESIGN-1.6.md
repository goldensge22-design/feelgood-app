# 수업설계LAB 보강 설계 1.6

2026-11-05 · 개발 구현 기준 초안. 사용자 요청에 따른 최신 프로그램 대조 결과를 반영했다. 현재 인계 앱 1.5를 수정하거나 새 규칙의 QA를 완료했다는 의미는 아니다. 1.5의 기록·출력·사실 확인 원칙을 승계하고 충돌 사항은 이 문서와 최신 프로그램 대조표에 명시한다.

## 1. 교사가 선택하는 순서

소속 학교/기관 → 담당 반·학과·합동 명부 → 중고생/대학생 탭 → 중학생/고등학생 세부 단계 → 수업 목적 → 기간 → 수업 방식 → 자료 검토 → 시간표·개인 출력물 생성.

- 기관과 학과는 명부 필터다. 특정 대학 이름으로 과제·직군을 강제하지 않는다.
- 한서대는 ‘학과가 섞인 대학생, 하루 개인 미션’ 저장 예시다. 기본 앱은 기관·학과·직무가 빈 상태로 시작한다.
- 중고생과 대학생이 함께 있으면 학생별 대상이 우선하며 교사용 진행표만 공통으로 묶는다.
- 하루 3/4/5시간은 개인 수행 기본. 1:1 지도는 인력·시간이 확보될 때 선택. 분단 공동 결과물은 1개월/2개월/사용자 지정 장기 과정에서 선택한다.
- 검사 실시와 검사 해석은 구분한다. 아래 180/240/300분은 사전 검사 후 해석 수업이다. 당일 검사를 해야 한다면 검사 운영자가 확정한 소요 시간을 별도 추가하거나 학습량을 조정한다. 검사 시간을 임의로 줄여 끼워 넣지 않는다.

## 2. 세 수업 목적

| 목적 | 핵심 질문 | 주된 프로그램 | 수업 결과 |
|---|---|---|---|
| 진로 탐색 | 무엇을 배우고 어떤 문제에 관심이 있는가? | 진로탐색LAB, 결과지 선택 참고 | 학과/배움 비교, 작은 체험, 생각 변화, 성장 이야기 |
| 직무 탐색 | 실제로 어떤 일을 하고 무엇을 준비해야 하는가? | 기업·직무탐색LAB | 업무·필요 역량·출처 비교, 직무 선택 이유, 연습 카드 |
| 직무 연계 실습 | 지금 배우는 지식으로 어떤 업무 산출물을 만들 수 있는가? | 두 LAB 중 적합한 자료 + 플래너 + 글쓰기 | 실제 수행 산출물, 개인 행동·수정 근거, 경험 문단 |

대학생도 진로 탐색을 선택할 수 있고 중고생도 교육용 직무 탐색을 선택할 수 있다. 중고생에게 채용용 자기소개서 제출을 필수로 요구하지 않는다. 교과연계형은 교사가 교과 성취목표와 진로 목표를 각각 입력하고, 실습과 평가가 두 목표에 어떻게 연결되는지 표시한다.

## 3. 수업안·활동지·카드 수를 세는 규칙

- 현재 앱의 **18개 기본 수업안 = 중학생 6 + 고등학생 6 + 대학생 6**, **36종 활동지 = 대상별 12종**을 보존한다.
- 신규 ‘운영 구성’은 상위 대상 2 × 목적 3 × 기간 5(3/4/5시간, 4/8주) = **30개 선택 조합**이다. 이는 완성된 30개 독립 원고를 구현했다는 뜻이 아니다. 중/고 세부 난이도와 1:1·개인·조별 방식은 추가 옵션이다.
- 81유형은 81개 별도 수업이나 직업 배정표가 아니다. 같은 과제에서 도움의 양·자료 제시·단계·확인 질문을 조절한다.
- 개인 출력본 수는 학생 수 × 선택 자료 수다. 30명이 2장을 받는 60부를 60종 활동지로 집계하지 않는다.
- 활동카드는 계획 카드, 실제 수행 기록, 경험 소재를 구분한다. 후보 추천 수와 플래너에 등록한 활동 수를 따로 센다.

## 4. 하루 수업 진행표

메뉴 이름은 현재 교사용 Studio의 기능에 대응하는 논리 단계다. 외부 프로그램을 여는 버튼·저장 확인은 개발자 연결 후 활성화한다. 미연결 환경에서는 교사가 미리 준비한 자료와 종이 기록으로 진행하고, 전송 성공 표시를 만들지 않는다.

| 순서 | 3시간 | 교사가 어디서 무엇을 하는가 | 학생 행동·제출 |
|---|---:|---|---|
| 시작 | 10분 | 과정/명부에서 대상·출력 언어·개인 미션 확인, 오늘 결과물 제시 | 탐색 질문 한 줄 |
| 결과 해석 | 25분 | 결과 요약에서 PASS 네 점수·척도·유형과 TOP5 원문 확인. 결과 없는 학생은 관심 질문 경로 | 강점 활용 방법 1개, 참고 후보 또는 직접 선택한 관심 대상 |
| 플래너 기본 연습 | 20분 | 플래너 실습에서 예시 과제의 범위·예상 시간·완료 기준 시범. 시작/중단/복귀/종료를 구분 | 작은 연습 1회와 실행 상태 확인 |
| LAB 탐색 | 35분 | 자료 탐색에서 대상별 LAB 열기. 원문 출처·날짜·업무/교육과정·선택 이유 확인 | 1개 대상 입문 탐색. 여유가 있으면 2개 비교 |
| 휴식 | 10분 | 저장 여부 확인 | 휴식 |
| 개인 카드·실행 | 30분 | 현장 활동에서 후보를 검토하되 학생이 목표·단계·결과물을 수정 후 선택. 등록 여부 확인 | 플래너에 카드 1개 등록, 축소 과제 수행, 산출물 남기기 |
| 경험 정리 | 15분 | 수행/경험 기록에서 계획과 실제 행동을 구분. 도움받은 부분·관찰 결과 질문 | 실제 행동·결과·배움·근거 위치 작성 및 활용 항목 선택 |
| 글쓰기 | 25분 | 글쓰기에서 중고생 성장 이야기/대학생 자소서 문항 설정. 선택 사실→팁→초안→학생 수정→V1 저장 | 검토 가능한 한 문항 또는 경험 문단 V1 |
| 마무리 | 10분 | 출력에서 개인 요약·활동지·카드 묶음과 다음 행동 확인 | 다음 활동 1개, 오늘 달라진 생각 |

합계 180분. 3시간의 ‘완성’은 한 문항/한 문단 V1을 학생이 사실 확인해 저장한 상태다. 여러 기업의 전체 지원서 완성을 보장하지 않는다.

**4시간(240분):** 위 흐름에 LAB 비교 20분, 실제 수행·수정 20분, 글쓰기 15분, 마무리 5분을 추가한다. 기업/학과 2~3개 비교, 산출물 수정본, 문항 연결을 강화한다.

**5시간(300분):** 240분 구성에 면담·모의면접 30분, 근거 재확인 및 V2 수정 20분, 수정 내용 공유 10분을 추가한다. 공유는 선택한 내용만 한다. 별도 ‘면담 없이 실습 심화’ 옵션도 같은 60분을 실습 30/피드백 20/정리 10으로 배치한다.

**면담 인력 계산:** 개별 면담 1인 8분이라면 필요 상담사-분은 학생 수×8이다. 상담사 1명이 30분 동안 모든 학생을 면담했다고 표시하지 않는다. 30명은 240 상담사-분이 필요하다. 가능한 학생만 순환 면담하고 나머지는 자기 검토/동료 질문 또는 후속 예약을 한다. 앱은 상담 인원·시간 부족을 시간표 검토에서 알려야 한다.

## 5. 같은 활동명을 대상별로 바꾸는 실제 규칙

| 활동 | 중학생 | 고등학생 | 대학생 |
|---|---|---|---|
| 자료 비교 | 쉬운 학과 소개 2개·핵심 용어 풀이; 배우는 내용/흥미 표시; 예시 문장·선택지; 질문 2개와 비교표 | 대학 교육과정·교과 연결 자료; 과목/탐구 주제 비교; 비교 기준 힌트; 학습 계획과 출처 | 공식 기업/공고·직무기술서; 업무/요구 행동/산출물 비교; 빈 비교 틀; 직무 선택 이유와 준비 과제 |
| 정보 정리 미션 | 학교 행사 안내문에서 날짜·장소·준비물 찾기; 3칸 틀; 수정 안내문 | 학교 행사 자료를 읽고 누락·충돌 확인; 5항목 검토표; 수정본과 판단 이유 | 교육용 고객/운영 자료를 읽고 요구사항·누락·제약 확인; 완료 기준만 제시; 업무 메모와 수정 이력 |
| 플래너 연습 | 10분 과제, 행동 3단계와 시간 칩 | 중간 마감과 선행 과제, 예상/실제 비교 | 가용 시간·담당 작업·대기/인계, 축소 실무 과제 실행 |
| 경험 글쓰기 | 관심→한 행동→느낌→다음 질문; 문장 시작 도움; 성장 이야기 | 탐구 질문→방법→근거→생각 변화; 질문별 도움; 진로 성찰 | 문항 요구→상황/과제→본인 행동→관찰 결과/배움; 근거 확인 질문; 자소서 V1/V2 |

학생이 읽는 자료·수행 과제·도움 수준·제출 결과물을 모두 바꾼다. 제목만 바꾸는 분기는 수용하지 않는다. 대학생도 처음 접하는 과제라면 예시·단계 도움을 추가할 수 있다.

PASS 지원 예: P는 목표/완료 기준을 먼저 고르기, A는 현재 할 한 가지와 방해 메모/복귀 지점, S는 관계도·비교표, Q는 순서 카드·현재/다음 단계. 한 회차에는 연습 목표 하나를 선택한다. 지원 변경은 학생·교사 선택으로 수정할 수 있고 검사 점수로 수행 능력·직업 자격·조장 적합성을 판정하지 않는다. 관찰 기록으로 인지 향상을 단정하지 않는다.

## 6. 개인 활동지와 플래너 카드

**활동지:** 질문, 읽을 자료, 출처, 비교 칸, 생각 변화, 작성 공간, 교사 확인 질문. 수업 중 사고·조사·성찰용이다.

**활동카드:** 제목, 선택 이유, 탐색 원본 ID/버전, 목표 역량(연습 대상), 할 일, 예정일/시간, 완료 기준, 남길 결과물, 도움 방식. 학생이 확인한 뒤 플래너에 담는다.

카드 아래 수행 기록은 실제 행동/결과/배움/생각 변화/결과물 위치를 빈칸에서 작성한다. 계획을 완료했다고 행동이나 성과를 자동 채우지 않는다. 종이 출력은 서버 저장 완료가 아니며, 종이 기록을 옮길 때 학생 확인과 원본 연결을 거친다.

출력은 개인 1명/선택 학생/반 전체/합동 명부를 지원한다. 활동지와 카드를 각각 선택하거나 묶어서 출력하고, 학생별 페이지 시작·학생 코드·활동 ID·버전·작성 언어·페이지 번호로 혼입을 방지한다. 검사 전체 결과와 민감한 개인 문장은 기본 인쇄 대상에서 제외한다. 교사 진행표와 분단 명부는 학생 출력물과 분리한다. QR을 쓴다면 로그인 후 본인 자료로 이동하며 점수·이름·토큰을 QR URL에 넣지 않는다.

## 7. 1개월·2개월 과정과 분단

기본 예시는 주 1회 90분이며 기관 시간표로 조절한다. 매 회기 ‘선택→실행→근거→회고’를 남기고 기록 없는 주를 완료로 표시하지 않는다.

| 주 | 4주 과정 | 8주 과정 |
|---|---|---|
| 1 | 결과/관심 질문, 플래너 기본, 탐색 시작 | 결과/관심 질문, 플래너 기본 |
| 2 | LAB 비교, 개인/공동 과제 설계 | LAB 탐색과 출처 확인 |
| 3 | 수행, 역할별 개인 근거, 피드백 | 2~3대상 비교와 선택 |
| 4 | 경험 글, 면담/피드백, 다음 계획 | 개인/분단 미션 설계·역할 협의 |
| 5~6 | 해당 없음 | 첫 수행→검토→다시 수행 |
| 7 | 해당 없음 | 경험 선택·글쓰기 V1·면담 |
| 8 | 해당 없음 | 사실 확인 V2·결과 공유·후속 계획 |

분단 옵션은 관심 직무/공통 질문, 서로 다른 수행 방법, 유사한 지원 요구, 교사 수동 편성이다. 학생이 선택한 TOP5 후보·TOP5 밖 관심을 우선하고 유형은 지원 참고로만 사용한다. 전체 PASS 점수나 유형명을 조 이름에 쓰지 않는다.

자동 제안→정원/중복/누락/고정 배치 확인→교사 조정→확정의 순서다. 학생 불참·명부 변경 시 기존 확정본을 보존하고 재편성 사유를 남긴다. 지원 정보가 없으면 관심과 인원으로 제안하고 임의 유형을 부여하지 않는다. 합동 수업은 양쪽 명부의 서버 권한을 확인한 경우만 허용한다.

공동 산출물과 개인 행동 기록은 별개다. 같은 조 자료를 모든 학생의 동일 실적/자소서 경험으로 복사하지 않는다. 역할은 학생 선택과 순환을 허용한다. 자동 제안 결과는 확정 전 학생에게 공개하지 않는다.

## 8. AI자소서·면담·면접의 수업 연결

1. 학생이 실제 경험 항목을 선택하고 사실 확인·활용 동의를 한다. LAB 조사 맥락 포함은 별도 선택이다.
2. 문항·지원 직무·작성 언어를 설정한다. 조사 내용은 맥락, 수행 기록은 경험으로 구분한다.
3. 팁과 확인 질문을 먼저 검토한다. 초안은 별도 요청하고 미리보기 후 학생이 적용한다. 기존 글을 자동 교체하지 않는다.
4. V1을 고정하고 면담자는 ‘직접 한 부분/선택 이유/관찰 결과/도움받은 부분/근거 위치’를 질문한다.
5. 학생 답변에서 확인된 사실만 경험 새 버전으로 추가한다. 면담 메모를 사실로 자동 승격하지 않는다.
6. V1 보존→변경 사실 확인→V2 작성→학생 최종 검토. 미확인 내용은 제외하거나 추가 확인 상태로 둔다.
7. 모의면접은 선택한 경험의 60~90초 설명, 후속 질문, 근거·명료성 피드백으로 구성한다. 면담(사실 보완)과 면접(말로 설명 연습)을 구분한다.
8. 기업 공유는 별도 선택이며 수업 완료와 무관하다. 기업 HR 분석·평가는 후속 패치다.
