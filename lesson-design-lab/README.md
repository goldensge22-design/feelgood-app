# 수업설계LAB

중학생·고등학생·대학생을 대상으로 수업을 설계하고, 학생별 활동지와 플래너 활동카드를 생성·출력하는 교사용 독립 앱입니다. 특정 학교나 직군에 고정하지 않습니다.

이 폴더는 **확정 규칙 1.2와 개발자 인계 문서**입니다. Replit 앱의 실행 소스가 포함되었다는 뜻은 아닙니다. 구현·검수·운영 연동 상태는 [인계 상태](HANDOFF_STATUS.json)에서 구분합니다.

## 먼저 읽을 문서

1. [개발자 인계 안내](DEVELOPER_HANDOFF.md)
2. [확정 제작 규칙](PRODUCT_RULES.md)
3. [연동 데이터와 저장 원칙](INTEGRATION_CONTRACT.md)
4. [완료 검수 목록](ACCEPTANCE_CHECKLIST.md)
5. [규칙 변경 이력](CHANGELOG.md)

제작 프로젝트: [Replit 수업설계LAB](https://replit.com/replid/18e270a4-04b0-4056-971c-02cc8e11c84b)

## 확정 범위

| 대상 | 기본 수업안 | 활동지 |
|---|---:|---:|
| 중학생 | 6개 | 12종 |
| 고등학생 | 6개 | 12종 |
| 대학생 | 6개 | 12종 |
| 합계 | 18개 | 36종 |

학생별 배부본·실행카드·시간 변형을 별도 콘텐츠 종류로 세지 않습니다. 개인 활동지는 과제를 수행하는 자료이고, 플래너 활동카드는 그 과제의 계획·실행·회고 기록입니다. 각각 출력하거나 학생별 한 묶음으로 출력합니다.

## 기존 프로그램과의 관계

기존 Teacher AI HTML, 학생용 진로탐색LAB, 기업직무탐색LAB, 플래너, 자기소개서 앱을 교체하지 않습니다. 이 폴더를 추가하는 작업은 기존 서비스 배포나 서버 연동 완료를 의미하지 않습니다.

한서대는 여러 학과 학생이 각자의 관심 직무에 따라 **개인 미션**을 수행하는 활용 사례입니다. 한서대의 인원·시간·직군·카드 수를 앱 전체 기본값으로 고정하지 않습니다.
