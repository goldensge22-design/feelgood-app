# 수업설계LAB 완료 검수 목록

모든 항목은 실제 결과와 근거를 기록한 뒤 판정합니다. 현재 체크되지 않은 항목은 미검증이며 기능 미구현을 단정하는 표시는 아닙니다.

- [ ] A01 범용 진입: 한서대 예시 없이 중학생·고등학생·대학생 수업을 생성하고 기관·목표·시간을 수정한다.
- [ ] A02 수량: 기본 수업안 18개와 활동지 36종이 존재하고 실질적인 자료·과제·지원·제출 기준을 갖는다.
- [ ] A03 대상 차이: 같은 활동 계열의 세 교육단계가 목표·자료·행동·도움·완료 기준에서 실질적으로 다르다.
- [ ] A04 유형: 81유형과 세 교육단계의 243조건에서 누락·잘못된 기본값을 검사한다. 기능 분기 검수이며 교육 효과 검증은 아니다.
- [ ] A05 경계: 동점, 복수 L, H 없음, HHHH·MMMM·LLLL, 결과지 없음, 잘못된 입력, 결과지 버전 불일치를 처리한다.
- [ ] A06 교육단계: 20세 이상을 초등으로 처리하지 않으며 인원만으로 난이도가 변하지 않는다.
- [ ] A07 개별 수행: 서로 다른 학과의 학생에게 서로 다른 직무 미션·개인 카드·완료 기준을 배정한다. 조 생성이 필요하지 않다.
- [ ] A08 한서대: 선택 예시는 개인 미션이며 예시 인원·시간·직군·카드 수가 다른 수업 기본값에 영향을 주지 않는다.
- [ ] A09 조 편성: 조별 단계에서만 제안하고 교사 확정 전 적용하지 않는다. 학생 누락·중복과 정원·고정 배치 충돌을 확인한다.
- [ ] A10 기록 보호: 개별·조별·혼합 전환과 재편성 때 개인 미션·답·결과물을 보존한다.
- [ ] A11 자료 연결: 활동지와 플래너 카드를 별도 자료로 생성하고 여러 카드 연결·기존 카드 재사용을 확인한다.
- [ ] A12 출력 조합: 한 학생·선택 학생·반 전체 각각에서 활동지만·카드만·두 자료 묶음의 9개 조합을 검수한다.
- [ ] A13 일괄 출력: 50명 가상 명단으로 누락·중복·타학생 페이지 혼입, 학생별 경계, 순서와 매수를 확인한다.
- [ ] A14 인쇄: A4·A5 배치, 흑백, 긴 답변, 빈 작성칸, 페이지 나눔, PDF 저장, 수정 후 재출력의 최신 버전을 확인한다.
- [ ] A15 개인정보: 학생용 출력에 점수·81유형·약점 표시가 기본 포함되지 않으며 교사 권한 밖 학생은 조회·출력할 수 없다.
- [ ] A16 시간: 일반 300분 예시의 교육 280분·휴식 20분과 기관별 설정의 합계 및 산출물 작성 시간을 확인한다.
- [ ] A17 결과지: 실제 버전의 항목 번호·제목 대응을 검증하고 번호 미확인 때 가짜 번호를 만들지 않는다.
- [ ] A18 플래너: 미연동의 수동 경로와 연동 성공을 구분하고 실패·재시도·중복 등록·원본 변경·권한 오류를 확인한다.
- [ ] A19 경험과 글: 계획과 완료, 모의와 실제, 학생 확인 상태를 구분하고 글 원문을 자동 덮어쓰지 않는다.
- [ ] A20 다국어: 15개 언어의 UI·샘플·자료·출력과 번역 품질을 확인한다. 대체 언어를 완료로 세지 않는다.
- [ ] A21 상태 보존: 언어 전환과 재접속 때 입력·진행·타이머·수업 저장을 유지한다.
- [ ] A22 화면: PC·태블릿·360px 모바일·아랍어 방향·긴 번역 및 키보드 접근을 확인한다.
- [ ] A23 콘텐츠 출처: 실제 자료의 URL·확인일·원본을 확인하고 미래 아이디어·가상 자료·미확인 정보를 구분한다.
- [ ] A24 인계: 앱 소스 커밋, 의존성 잠금 파일, 실행 설명, 환경변수 이름, 검사 결과와 남은 항목을 인계한다.

## 결과 기록 기준

각 항목에 실행일, 소스 커밋, 가상 입력 조건, 기대 결과, 실제 결과, 통과·실패·미검증, 근거 위치를 기록합니다. UI 표시만 확인한 항목을 실제 서버 연동 또는 운영 배포 통과로 판정하지 않습니다.
