# 남은 외부 연결·인증 작업

현재 앱은 교사용 브라우저 로컬 가상 데모다. 동일 로그인이라는 이유로 데이터 공유가 되는 것은 아니다.
아래 항목은 인계 범위 설명이며 개발 완료 또는 공개 배포 승인이 아니다.

1. **계정·담당 수업 권한:** 실제 로그인과 서버 측 교사/학생/상담자 권한, 담당 수업 제한, 접근 감사, 공유 철회, 보존/삭제 정책. 로컬 역할 버튼은 보안 경계가 아니다.
2. **원본 결과지:** 검사·시행일·척도·버전과 원본 PASS 정답률/확정 유형/TOP5를 권한 있는 API로 가져온다. 정규화 HR 데모 점수와 혼용하거나 유형·순위를 다시 계산하지 않는다. 수정 이력과 자료 생성 당시 스냅샷을 보존한다.
3. **학생 LAB:** 학생의 기업/직무 탐색·출처·선택 내용을 승인된 범위에서 연결한다. 기업대시보드는 별도 HR 제품이며 직원·지원자 평가를 학생 자료에 가져오지 않는다.
4. **실제 플래너:** 원격 등록 성공 영수증·권한·멱등성·실패/재시도·동일 카드/결과물 연결을 구현한다. 현재 로컬 등록·복사/내보내기를 원격 등록 완료로 표시하지 않는다.
5. **AI 및 자소서 앱:** 확인된 실제 사실만 선택 공유한다. PASS 원점수는 기본 전달하지 않는다. AI 미연결은 수동/규칙 기반 질문이다. 미리보기 후 학생 반영, V1/V2 보존, 면담 사실 학생 확인, 외부 자료 변경/철회 후 재확인을 유지한다.
6. **서버 저장과 마이그레이션:** 브라우저 백업의 원문·이력·계획/모의/실제 구분을 보존한다. 기존 데이터에 없던 과거 이력을 만들지 않는다. 실제 학생 데이터 이관은 별도 승인·복구 계획이 필요하다.
7. **운영 검수:** 원어민/교육 전문가 검토, 실제 기관 권한 시나리오, 실물 프린터, 모든 언어/콘텐츠/실서버 조합, 개인정보·보안 검토. 현재 기술 QA로 대체하지 않는다.

한서대는 선택 가능한 학과 혼합 개인 미션 사례다. 범용 앱을 특정 대학 전용으로 바꾸지 않는다.
참조 저장소/URL은 제공된 자료이며 연결·소유권·현재 배포 상태를 추정하지 않는다.
자세한 API/원본 관리 기준은 `docs/lesson-lab/INTEGRATION.md`, `STUDIO-API.md` 및 확정 규칙을 읽는다.
