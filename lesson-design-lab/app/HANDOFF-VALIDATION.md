# STAR 패치 인계 사본 검증

검증 대상은 수업설계LAB v1.5-star 전체 소스다. 다른 앱·실제 학생 기록·외부 서버를 변경하지 않았다.

## 실제 분리 설치·실행

인계 후보 ZIP을 작업공간 밖 `/tmp/lesson-lab-star-handoff-verification/teacher-lesson-lab-handoff`에 압축 해제했다.
그 경로에서 `pnpm install --frozen-lockfile`, `pnpm typecheck`, 실제 빌드와 `CHROME_BIN=... pnpm qa`를 실행했다.
설치는 자체 node_modules를 만들었고 상위 작업공간의 node_modules를 링크/복사하지 않았다. 같은 Linux 컨테이너의 pnpm 다운로드 캐시는 재사용했다.

- Node24.22.1 / pnpm10.26.1 / Linux x86_64 / Chromium155 / Poppler·다국어 글꼴
- 최신 QA 완료: **2026-11-07T15:42:18.157Z**
- **675 통과 / 실패 0**: 기존 564 재실행 + 신규 로직64 + 신규 브라우저47
- 타입 검사/빌드 통과. 기존 큰 번들 경고는 남아 있다.
- 테스트 후 개발 서버를 중단하는 SIGTERM이 로그에 남는 것은 정상 정리다. 검사와 QA 런처의 종료 상태는 성공이다.

앱 소스 집계 SHA-256:

`a03ba2bb733698ca39d11f94aca2a8c2d43ae18d094faf09a9f838016f2d7c3c`

현재 원본과 압축 해제 사본의 앱·공통 소스·검사·잠금 파일을 바이트 대조했다.
검사 후 최종 ZIP에서는 문서와 증거만 추가했으며 검증한 런타임 소스/잠금 파일은 바꾸지 않았다.
최종 파일별 검증은 `SHA256SUMS.json`, 원본 복사 해시는 `provenance/source-files.json`을 따른다.

## 증거 범위

- 자동 출력36PDF·332쪽 + 별도 교사 진행안2PDF·25쪽 = **38PDF·357쪽**.
- 15언어 UI/교육 본문/입력 보존/신규 활동지 PDF와 360px·아랍어 RTL을 확인했다.
- 실제 메뉴 조작과 입력으로 검사했고 메모 저장 실패/개인별 재진입/옵트인 출력/언어 변경 시 인쇄 확인 취소도 포함한다.
- 전체 PDF 육안 승인이나 원어민 검수는 아니다. 구체적인 대표 쪽 확인과 미실행 범위는 `docs/lesson-lab/QA-STAR.md`를 따른다.
- 직전 564 통과와 이전 168PDF·718쪽은 과거 증거다. 이번 보고의 564는 이번 소스로 다시 실행한 결과다.
