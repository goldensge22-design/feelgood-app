## 분리 검증 방식

1. 필요한 소스만 복사한 인계 후보 ZIP을 생성했다. node_modules·dist·캐시·환경파일·Git 저장소·브라우저 데이터는 제외했다.
2. `/tmp/lesson-lab-handoff-validation/teacher-lesson-lab-handoff`에 ZIP을 실제 압축 해제했다.
   이 경로는 현재 Replit 작업공간(`/home/runner/workspace`) 밖이며 상위 node_modules에 의존하지 않는다.
3. **해제된 사본에서** `pnpm install --frozen-lockfile`을 실행했다. 잠금 파일은 그대로 사용됐고 resolution skipped, 패키지 230개 설치를 확인했다.
   같은 Linux 컨테이너의 pnpm 다운로드 캐시는 재사용했다. 새 컴퓨터/새 VM 또는 완전 오프라인 설치 검증은 아니다.
4. 파일 검증: 후보 304개 파일 + 원본과 동일한 복사본 298개 비교에서 불일치 0. 최종 ZIP은 추가 검증 안내/증거가 들어가므로 최종 개수는 `SHA256SUMS.json`을 따른다.
5. 해제된 사본에서 전체 `pnpm qa`, 별도 `pnpm typecheck`를 실행했다. QA는 실제 로컬 Vite·임시 Chrome 프로필·Poppler를 사용했다.
6. 최종 ZIP에서는 안내와 새 검증 증거만 추가하고, 검증한 앱·공통 소스·잠금 파일·실행 도구는 바꾸지 않았다.
   전체 파일 해시와 원본 복사본 해시는 다시 확인했다.

## 미실행·남은 작업

- 네이티브 Windows/macOS/ARM에서의 설치·실행은 미실행. 해당 플랫폼용 선택 패키지 배제는 이식용 사본에서 해제했지만 실제 OS 승인은 아니다.
- 원어민/교육 전문가 의미 승인, 전체 출력 육안 승인, 실물 프린터는 미실행.
- 실서버·실제 인증·담당 수업의 서버 접근 제어·외부 결과지/LAB/플래너/AI 통합은 미구현이며 이 인계에서 추가하지 않았다.
- 브라우저 로컬 저장은 기기·브라우저별로 분리된다. 이 ZIP은 기존 교사/학생의 로컬 저장 데이터를 이관하지 않는다.
- `pnpm qa`는 네트워크·글꼴·Poppler·Chrome을 요구한다. PDF의 행 분할/글꼴 결과는 OS에 따라 달라질 수 있다.
