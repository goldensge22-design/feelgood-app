## 1.5 — 2026-11-04

- 사용자의 최종 기획 전문을 `public/rules/lesson-lab-rules-1.5.md`에 보존했다. 1.0·1.1·1.2는 삭제하지 않았으며 규칙 화면에서 버전별 열람·내려받기를 제공한다.
- 기존 18수업·36종은 유지하고, 하루/장기 과정과 학생별 배부본·활동카드는 별도 생성물로 집계한다. 한서대는 범용 제품의 선택 사례다.
- 플래너 기본 실습 → 탐색 → 시간·도구에 맞는 후보 → 학생 선택·목표 수정 → 예외 검토 → 로컬 등록 → 실제 수행 → 학생 경험 확인을 연결했다.
- 확인한 사실의 V1 작성·선택 공유·면담 예약·추가 사실 확인·V2 비교·내보내기와 별도 모의면접·V3를 추가했다. 원문과 카드·공동 결과물의 수정 이력을 보존한다.
- 180/240/300분과 300분 면담형, 장기 회차, 상담 수용량 및 전원 모의면접의 추가 인원·시간 계산을 구분한다.
- 현재 구현은 **브라우저 저장 기반 가상 시연**이다. 실제 계정 인증·서버 권한·외부 AI·기존 플래너/LAB/자소서 저장 연결·공개 배포를 완료한 것으로 표시하지 않는다.
- 실제 검수와 한계는 [규칙 1.5 검수 기록](VALIDATION-1.5.md)에 별도로 기록했다. 이전 검수 기록은 보존한다.

## 1.2 — 2026-10-27

- 사용자 승인 추가 규칙 전문: `artifacts/teacher-lesson-lab/public/rules/lesson-lab-rules-1.2.md`. 1.0·1.1 전문 및 충돌하지 않는 기준을 보존한다.
- 승인 근거: 「그러면 개인별 활동지와 활동카드(플래너에 활동으로 등록하고 기록할)가 각각 만들어진다는 말이지? 그러면 개별로 모두 출력할 수 있도록 설계되는것도 규칙에 있지?」
- 개인 활동지는 읽기·질문·수행 과제·답안·제출 기준, 플래너 활동카드는 계획·실제 수행·회고를 다루는 별도 문서로 생성하고 서로 연결한다.
- 한 활동지에서 여러 실행 카드로 나누기 및 기존 활동 재사용을 지원한다. 같은 생성 요청의 반복으로 카드가 중복되지 않아야 한다.
- 학생 한 명·선택 학생·소속반 전체, 활동지만·카드만·두 자료 묶음의 출력과 버전 고정 재출력을 구분한다. 학생별 페이지 경계와 실제 용지 매수를 별도 집계한다.
- 계획·확인된 수행·복사·내보내기·수동 입력 확인·외부 등록 성공은 서로 다른 상태다. 현재 실제 플래너와 학생 계정 권한은 미연동이며 외부 등록 성공을 표시하지 않는다.
- 범용 제품, 한서대 개인 미션 사례, 수업 18개·기본 활동지 36종·81유형 지원·언어·출력 기준을 축소하지 않는다.

- 규칙 저장, 구현 적용, 실제 동작 검수, 번역·실출력 검수, 외부 연동과 공개 배포는 별도다.
