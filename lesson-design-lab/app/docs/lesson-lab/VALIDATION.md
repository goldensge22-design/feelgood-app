# 제작 상태와 검수 기록

## 현재 수정 — 규칙 1.5 / 2026-11-04

새 과정·현장 운영·글과 상담·출력의 구현 및 검수는 [규칙 1.5 검수 기록](VALIDATION-1.5.md)을 기준으로 확인한다. 아래 1.2 기록은 이전 검수 결과이며 새 기능 전체의 검수 완료를 뜻하지 않는다.

## 이전 수정 — 규칙 1.2 / 2026-10-27

### 저장 및 실제 구현

- 1.2 사용자 추가 규칙 전문을 보존하고 규칙 보기·내려받기·변경 이력을 갱신했다. 1.0·1.1 전문과 18수업·기본 활동지 36종은 유지한다.
- 개인 활동지와 플래너 실행 카드는 별도 인스턴스·내용·수정 이력으로 생성하며 안정된 ID로 연결한다. 한 활동지의 여러 카드 분할 및 기존 계획/직무 카드 재사용을 확인하고 중복 생성을 막는다.
- 한 학생·선택 학생·소속반·전체 명단을 구분하고, 활동지만·카드만·두 자료 묶음 출력과 버전 고정 재출력을 제공한다. 기본 이름 비공개, 학생 코드·제목·연결·버전·학생별 페이지 번호를 사용한다.
- 별도 활동지는 A4, 카드는 A4 또는 A5 면 배치다. 긴 내용과 작성 공간은 자르지 않고 이어지는 면으로 분리한다. 기본 문서 인스턴스 수와 실제 면·용지 수는 별도로 계산한다. 기존 캠프 카드의 간이 계산은 새 자료의 확정 용지 수가 아니라고 안내한다.
- 종이 전사 기록과 실제 수행은 확인 후 저장하며 계획·인쇄용 확정·외부 등록 성공과 구분한다. 현재 실제 외부 플래너와 학생 계정 다운로드 권한은 미연동이다.

### 검증 근거

- `scripts/rules-1.2-checks.mjs`: 21항목 통과. 서로 다른 직무, 기존 원문·답안·버전 보존, 연결·분할·재사용·중복 방지, 세 출력 모드와 두 카드 배치, 한 명·소속반 선택, 혼입 차단, 미확정 자료 누락 방지, 긴 원문 보존, 수행 확인·종이 전사 확인, 등록 상태 경계와 백업 복원을 확인했다.
- 가상 50명 전체 반에서 개인 활동지 50부와 실행 카드 200개가 생성되며 기본 활동지 종류는 여전히 36종이다. 이어지는 면을 포함한 실제 용지 수를 생성 계획에서 계산하고 학생별 페이지 경계를 확인했다. 이 시험은 50명 PDF 전 페이지의 시각 검수가 아니다.
- `scripts/browser-materials-checks.mjs`: 격리된 Chromium 프로필과 가상 학생만 사용했다. 실제 UI의 생성·반복 생성·교사 일괄 확정, 학생 범위 선택, 인쇄 진입을 조작했다.
- 활동지만·카드만·두 자료 묶음을 카드 A4/A5 배치별로 Chromium의 실제 PDF 엔진으로 저장했다. 샘플 PDF의 물리 페이지 수와 앱의 용지 수 일치, 학생 코드 순서, 타학생 코드 혼입 없음, 기본 이름 제외, 내용 넘침 없음, 내부 화면 안내 누출 없음을 점검했다.
- 한 학생 PDF와 소속반 선택, 이후 편집에 영향을 받지 않는 같은 버전 PDF 재출력을 확인했다. 미리보기와 출력은 동일한 저장 스냅샷과 렌더러를 사용한다.
- 브라우저에서 미확인 수행 저장 차단, 종이 내용 확인 후 실제 수행 저장, 실제 클립보드 복사, 수동 입력 확인이 외부 등록 성공으로 바뀌지 않음을 확인했다. 기존 경험 기록을 자동 생성하거나 덮어쓰지 않는다.
- 아랍어 방향 전환 시 저장 전 학생 작성 원문이 유지됨을 확인하고 360픽셀 모바일 화면을 확인했다. 신규 UI 및 출력 문구는 14개 비한국어 언어에 작성 번역으로 추가했고 기존 번역은 유지했다.
- 개발 프록시의 화면 안내와 여백이 인쇄에 섞이는 문제는 배부용 인쇄 루트 분리로 수정했다. 실제 PDF에서 안내 누출과 추가 페이지 문제가 해소됨을 확인했다.

### 미완료 및 외부 상태

- 물리적 프린터, 모든 언어·모든 사용자 수정 길이·모든 기기의 인쇄 결과 및 교육 내용의 전문가 의미 검수는 완료로 주장하지 않는다.
- 자동 검사와 샘플 PDF 검수는 전체 243조건의 교육적 타당성 또는 모든 15개 언어 번역의 사람 검토를 대신하지 않는다.
- 외부 플래너 성공 응답·권한 경계의 성공 사례는 어댑터 계약의 단위 시험용 응답이다. 실제 서버 연동 성공 증거가 아니다. 학생 계정 직접 다운로드·계정 권한·서버 저장·공개 배포는 하지 않았다.

- 범용 빈 설정과 선택 가능한 한서대 개별 미션 사례를 분리한다. 기존 캠프 설정은 이전 설정으로 보존하고 학생·개인 카드·수정 이력·경험은 유지한다.

- 최종 타입 검사와 빌드 통과. 기존 구조 진단과 1.1 진단을 합한 자동 항목 18개 통과. 수업 18개·활동지 36개·243 지원 조건·126개 시간 조합·학생별 페이지 묶음·버전 보존·14개 번역 언어의 UI/카드 키 누락 없음 및 콘텐츠 필드 구조를 확인했다.
- 신규 UI 문구와 개인 역할 문구를 14개 비한국어 언어에 작성 번역으로 추가했고 기존 번역은 유지했다. 번역의 의미와 인쇄 품질은 검수 완료로 표시하지 않는다.
- 실행 화면 확인: PC의 일반 수업 운영 설정이 기관·인원·카드·시간표를 채우지 않은 상태이며 개별 수행으로 표시됨. 360픽셀 모바일의 현재 규칙 1.1·이전 1.0 선택 및 내려받기 링크와 본문 표시를 확인했다. 브라우저 오류 로그 없음.
- 학생 명단의 개인/일괄 생성도 운영 설정과 같은 카드 종류 선택을 따른다. 가상 명단의 한서대 전공 예시는 한서대 사례를 명시적으로 선택했을 때만 사용한다. 조 편성 화면은 인쇄에서 제외한다.
- 위 로직 및 정적 화면 점검은 모든 화면 조작·실물 인쇄·PDF 내용·번역 의미·외부 연동의 완료 증명이 아니다. 실제 브라우저 조작으로 모드 전환·편집 저장 복원·출력 확정까지 확인하는 종합 검수는 남아 있다.
- 외부 서버·계정·플래너 연동과 공개 배포는 여전히 하지 않는다. 실학생 데이터는 사용하지 않는다.

## 이전 1.0 기록 — 아래 내용은 최초 제작 당시 기록으로 보존

기준일: 2026-10-27 · 기준 규칙 1.0

## 구현

- 교사용 별도 웹앱과 한국어 기본 콘텐츠, 18개 수업안과 36종 활동지.
- 교육단계와 개인 지원의 독립 적용, 가상 학생 명단, 선택 직무별 과제 카드.
- 브라우저 저장·백업·복원, 교사 수정·확정·개정 이력, 출력 요청과 재출력용 배부 명세.
- 동일 학생·동일 카드 종류 재생성 시 기존 ID와 이전 버전을 보존한다. 선택하지 않은 기존 카드도 내부 원본에서 삭제하지 않고 보관한다.
- 학생별 페이지를 분리한다. 카드가 홀수이면 마지막 반쪽에 다른 학생 카드를 끼우지 않는다. 따라서 50명 × 3카드는 150카드이지만 A4 100매다.
- 15개 언어 선택과 한국어 원본 및 다른 14개 언어 작성 번역. 번역된 UI·직무 자료·수업·활동지를 연결하고 학생 입력은 임의로 번역하지 않는다.
- A4 단일 카드 및 A4에 두 카드 배치, 브라우저 실제 인쇄 대화상자를 통한 PDF 저장 경로.

## 확인 근거

- TypeScript 검사 통과.
- 자동 구조 점검: 18/36 개수, 12계열×3단계, 필수 항목·고유 읽기 자료, 243 지원 조건의 존재, 126 수업·시간 조합 합계.
- 자동 구조 점검: 가상 50명·200카드·100매, 한서대 200분 교육+30분 휴식, 일반 5시간형 280+20분.
- 자동 구조 점검: 14개 외국어 UI·직무 사전 키, 36활동지와 18수업의 번역 필드 및 배열 구조. 이 검사는 번역 의미나 교육 적합성 보증이 아니다.
- 실행 화면 캡처: 1440px PC 첫 화면과 360px 모바일 첫 화면 정상 표시. 실행 로그에 앱 오류 없음.

## 대기 및 한계

- 규칙 전문과 구현의 항목별 교육적 최종 대조.
- 전체 243조건에 대한 전문가의 실제 안내 효과 및 교육 내용 검토.
- 모든 번역의 원어민·교육 전문가 의미 검수. 작성 번역을 검수 완료라고 표시하지 않는다.
- 실제 브라우저의 인쇄 미리보기·PDF 파일·물리 프린터, 언어별 A4/A5 페이지 적합성 검수. 특히 긴 번역이나 교사 수정으로 A5 반쪽을 넘을 가능성은 남아 있다. 내용을 잘라 숨기지 않으며 긴 카드의 A4 출력이 필요할 수 있다. 따라서 모든 경우의 A5 적합성이 검수됐다는 주장은 하지 않는다.
- 언어 변경 후 모든 열린 입력 폼의 동작, 태블릿과 아랍어 RTL 전체 화면 검수.
- 실학생 자료, 실제 검사 원본, 인증·권한·기존 서버와 플래너 연결은 미연동이다.
- 제안서 원본 PDF는 이 제작 세션에서 직접 검토하지 않았다.

## 배포

공개 배포하지 않았다. 제작 승인을 공개 배포 승인으로 취급하지 않는다.
