# 결과지 원순위·수정 이력 보존 후 기술 QA

검수일: 2026-11-05. 가상 QA 데이터만 사용. 외부 연동·실제 인증·공개 배포는 이번 범위가 아니다.

## 적용한 수정

- TOP5 빈 첫 자리·중간 자리를 제거하거나 뒤 직무의 순위를 당기지 않는다. 결과 화면, 별도 개인 결과 요약, 후보의 원순위, PDF가 같은 원본 배열 인덱스를 사용한다. 공용 활동지에 민감 결과를 추가하지 않는다.
- 재저장은 현재 결과와 이전 결과 스냅샷을 한 브라우저 저장 작업으로 반영한다. PASS4·점수 종류·척도·유형·TOP5·검사명·시행일·원자료 버전·확인/연결 상태를 스냅샷으로 보존한다.
- 결과 화면의 **결과지 저장 이력**에서 현재 저장 버전과 이전 값, 출처 상세를 확인한다. 저장 버전과 결과지 자체의 검사 버전은 별개다.
- 기존 결과에는 과거 이력을 소급 생성하지 않는다. 첫 수정 시 실제 관찰된 기존 저장본 한 개만 보존하며 과거 저장 시각은 미확인으로 표시한다. 보관 시점은 원래 저장 시점으로 표현하지 않는다.
- 새 미션은 선택 당시 결과를 고정 보존한다. 최신 결과는 새 후보와 지원에 사용하지만 이전 카드·자료·실제 기록·학생 글·V1/V2는 결과 재저장으로 바꾸지 않는다.
- 이전 생성 근거를 기록하지 않은 기존 자료는 현재 결과로 추정하지 않는다. 교사 이력 화면에서 자료 식별자와 당시 근거/미기록 상태를 구분한다.
- 추가 이력·근거 문구는 15언어로 제공한다. 원문 검사명·직무명·사유·학생/교사 글은 그대로 둔다.
- 실패한 저장은 성공으로 표시하지 않는다. 저장소·메모리·현재 결과·이력은 기존 상태를 유지하며 최신 편집 초안으로 재시도한다.
