## 규칙 1.5 인계 — 2026-11-04

- 현재 동작·검수·미연동 구분: [VALIDATION-1.5.md](VALIDATION-1.5.md). 클라이언트 함수 계약: [STUDIO-API.md](STUDIO-API.md).
- `src/lib/studio`는 브라우저 상태를 받아 새 상태를 반환하는 시연 로직이다. `StudioActor`를 사용자가 선택하므로 서버 인증·실제 권한 증명으로 신뢰하면 안 된다.
- 실제 서버는 세션에서 담당 교사/학생/상담자와 수업 배정을 확인하고, 점수/글/회고는 학생의 항목별 공유 동의를 별도 검사해야 한다. 원격 저장 시점의 권한·자료 버전·철회를 다시 검사한다.
- 현재 외부 연결 패키지가 공유하는 진행 건수 권한과, PASS 요약/글/경험의 추가 공유 권한은 다른 계약이다. 로그인 상태 공유만으로 본문 접근을 허용하면 안 된다.
- 미션 ID/활동지 ID/플래너 ID를 멱등 키로 재사용하고 네트워크 재시도·중복 요청·버전 충돌을 검수한다. 서버 응답의 실제 등록 성공 전에는 원격 성공으로 바꾸지 않는다.
- V1, V2/V3, 원본 카드, 실제 수행, 공동 결과물, 원문과 학생 확인 이력을 보존한다. 공동/가정/계획을 개인의 실제 완료 경험으로 변환하지 않는다.
- 실제 AI에는 학생이 확인·선택한 사실과 허용된 요구 행동만 전달한다. PASS 원점수/기업 HR 평가/미공유 초안은 기본 제외한다. 자료 변경·공유 철회 후 새 활용 전 재확인한다.
- 기존 서버와 저장 방식을 먼저 조사한다. 기존 학생 LAB·플래너·AI자소서·기업대시보드 또는 데이터베이스를 이 앱으로 교체·이전하지 않는다.

## 규칙 1.2: 별도 자료와 플래너 연결

- 기본 활동지 템플릿과 학생별 개인 활동지 배부본 및 플래너 실행 활동은 다른 개체다. 개인 활동지는 자료·과제·답안, 실행 카드는 계획·실제 수행·회고를 보존한다.
- 한 활동지에 여러 실행 활동, 한 기존 실행 활동에 여러 활동지를 연결할 수 있다. 연결 시 학생 소유자가 일치해야 한다. 기존 직무 카드 재사용 시 원본 카드는 변경·삭제하지 않는다.
- 외부 연동의 멱등 키는 실행 활동의 안정된 ID를 사용한다. 재시도마다 새 활동을 등록하지 않는다. 외부 ID, 실제 저장 성공 응답 시각, 서버에서 검증한 교사/학생 권한, 원본 및 변경 이력을 보존한다.
- 현재 등록 상태의 준비·복사·내보내기·수동 입력 확인은 **외부 등록 완료가 아니다**. 수동 입력 확인은 앱 외부의 저장 성공을 검증하지 못한다.
- 향후 어댑터는 실제 연결 상태와 권한 검증 및 저장 성공 응답이 모두 있을 때만 등록 성공으로 전환한다. 클라이언트의 체크박스나 임의 응답을 서버 권한 검증의 대체로 사용하지 않는다. 어댑터의 단위 시험 응답은 실제 연동 증거가 아니다.
- 인쇄용 자료 확정과 실제 수행 확인은 다르다. 종이 기록의 전사 여부와 확인자·실제 행동을 보존하며, 계획이나 출력만으로 완료 경험을 생성하지 않는다.
- 학생 계정의 직접 다운로드는 인증·학생별 읽기 권한 연동 이후 별도 검수한다. 현재는 교사의 가상 명단 선택에 따른 브라우저 출력이다.
- 인쇄 묶음은 문서 버전·연결·수행 기록·페이지 순서의 스냅샷으로 보존한다. 인쇄 요청 시각은 출력 성공 증명이 아니며, 브라우저 PDF 저장 경로와 물리적 프린터 출력은 구분한다.

## 현재 경계

이 앱은 기존 학생용 앱과 별도인 교사용 준비 도구다. 현재 모드는 가상 학생을 사용하는 브라우저 저장 시연이다. 로그인·서버 저장·기업직무 LAB·학생 LAB·플래너의 실제 자동 연동을 의미하지 않는다. 실학생 개인정보를 입력하지 않는다. 브라우저 저장 삭제나 기기 변경으로 기록이 사라질 수 있으므로 내보내기 백업을 제공한다.

## 서버 연결 전 합의할 계약

1. 기존 서버의 소유자와 API 계약, 접근 권한, 학생·교사·기관 관계를 확인한다. 이 문서에 가상의 API 주소를 실제 주소로 제시하지 않는다.
2. 검사 결과의 원본 식별자, 검사명·버전·검사 기준, 교육단계, 원본 항목 제목과 번호, 네 영역의 원해석, 동점, TOP5 원순위·이유를 읽기 전용 원본으로 보존한다.
3. 점수 척도를 혼합하지 않는다. 기준 미확인 점수에 H/M/L을 추론하지 않는다. 교사 수정은 원본이 아닌 별도 주석과 활동 지원 선택으로 남긴다.
4. 계정·기관 범위를 서버에서 검증한다. 교사용 근거 화면은 실제 교사 권한에만 제공하고 학생용 출력에서 검사 점수·유형 코드·낙인을 제외한다.
5. 학생 코드만으로 권한을 부여하지 않는다. 실사용 전 인증·인가·보존 기간·삭제·내보내기·동의와 외부 공유 절차를 검수한다.

## 카드 및 플래너 대응

- 카드마다 안정적인 원본 카드 ID, 학생 원본 ID, 수업/활동지 원본 ID, 배부 묶음 ID, 개정 번호를 연결한다.
- 서버에서 동일 카드 ID와 개정 번호에 대해 멱등성을 보장한다. 전송 재시도나 재출력이 새로운 활동이나 완료 경험으로 중복 집계되지 않아야 한다.
- 카드 원본과 수정 이력 및 변경 이유, 배부 명세와 재출력 이력을 보존한다.
- 계획·실행·회고·경험카드를 구분한다. 모의 수행과 실제 수행을 별도로 기록한다.
- 실제 상황, 실제 행동, 바꾼 방법, 결과물, 피드백, 학생 확인 여부를 포함한다. 계획만으로 실제 경험을 생성하지 않는다.
- 자소서 제안은 원문과 분리한다. 학생 확인 경험만 인용하고 학생 작성 글을 자동 덮어쓰지 않는다.
- 미연동 상태는 복사·JSON 내보내기·수동 입력으로 전달한다. 자동 저장·동기화 성공으로 표시하지 않는다.
- QR은 정상 인증과 유효한 개인 기록 경로가 확보된 뒤에만 제공한다.

## 콘텐츠 및 언어 원본

수업안과 활동지 원본 ID는 이름·시간·지원 변경에도 유지한다. 18개 수업안과 36종 활동지, 개인별 배부 수량을 별도 집계한다. 번역은 언어별 원문 버전·번역 버전·검수 상태를 기록하며 학생 글을 임의 번역하지 않는다. 번역 누락은 대체 언어임을 명시한다.
