# 수업설계LAB v1.5 구현·검수·미연동 상태

검수일: 2026-11-04. 공개 배포 승인이 아니며 실제 학생 정보는 사용하지 않았다.

## 실제 구현 범위

- `/studio`: 중고생/대학생·중학생/고등학생 선택, 하루 3/4/5시간/5시간 면담형과 장기/직접 설정, 수업 생성·수정·보존, 가상 명단 추가, 교사 준비 틀·자료·도구·지원 설정.
- `/studio/results`: 원본 PASS 정답률 또는 별도 정규화 가상 점수의 표시 종류 구분, 확정 유형·TOP5 순위 유지, 원본 정보 펼침. 점수·유형 재산출이나 카드 자동 배정 없음.
- `/studio/sources`: 자료 출처 종류·업무·요구 행동·지식/기술/태도·확인 방법·버전·교육 공유·철회 기록. URL만으로 공식 출처 처리하지 않음. 실제 서버 승인 조회는 미연동.
- `/studio/agenda`: 단계별 프로그램/화면·교사 안내·학생 행동·제출물·완료 확인·막혔을 때 대안과 시간표.
- `/studio/live`: 기본 플래너 실제 연습, 탐색과 선택 이유·질문·출처 기록, 3개 후보, 짧은 시간에는 미니 과제로 실제 범위 축소, 학생 목표·첫 행동·범위 확인, 교사 예외 검토, 로컬 플래너 등록/실패/재시도, 실제 행동·결과·회고·증거, 학생 경험 확인, 다음 실행.
- `/studio/print`: 학생/선택 학생/전체, 활동지만/카드만/묶음, A4 활동지·A4 또는 A5 2면 카드, 미리보기 확인 후 실제 인쇄 경로와 PDF, 학생 코드·제목·연결·버전·수정 시각·학생별 쪽 번호. 배부본/카드/학생/A4 용지 집계. 별도 교사 진행안·빈 활동지·예시·개인 요약·면담 준비·상담 질문/피드백·수정 전후·면접 회고.
- `/studio/writing`: 학생이 선택·확인한 실제 사실로 수동/규칙 기반 V1, 원문을 바꾸지 않는 제안 미리보기, 선택 공유, 면담 예약, 사실 후보와 표현 제안 분리, 학생 확인 후 V2/V3 추가, 버전 비교·텍스트 내려받기·최종 점검. 저장된 V2 이후는 별도 선택 공유이며 작성 중 초안은 공유하지 않음.
- `/studio/interview`: V2 이후 경험/가정 질문 구분, 답변·꼬리질문·피드백·재답변, 추가 사실의 학생 확인, 후속 계획. 가정 답변은 실제 경험으로 전환하지 않음.
- 장기 과정의 소속반/좌석/직무 분반/합동 조 구분과 교사 확정, 공동 과제·결과물 수정 이력. 공동 결과물을 개인 경험이나 글로 자동 변환하지 않음. 하루 과정에는 공동 프로젝트 자동 배정 없음.
- `/rules`: v1.5 원문과 이전 규칙, 변경 이력, 구현·미연동·검수·번역 상태의 구분.

기존 18개 수업·36종 활동지와 기존 명단·수업·기록 저장 구조를 유지했다. 기간 프리셋과 생성 인스턴스는 고유 콘텐츠 수에 더하지 않는다.

## 실제 Chromium 화면 및 PDF

`scripts/browser-studio-checks.mjs`는 격리된 브라우저 프로필과 가상 데이터로 실제 버튼을 눌러 검수한다. 사용자 브라우저 저장소는 변경하지 않았다.

- 새 수업 생성과 이전 수업 보존, 상담 수용량 부족 표시.
- 학생 역할의 기본 플래너 실습 → 12분 후보 → 선택 → 교사 검토 → 등록 실패 → 재시도 → 실제 기록 → 학생 경험 확인.
- V1 저장 → 작성 중 글의 아랍어/RTL 전환과 새로고침 보존 → 선택 공유 → 실제 슬롯 예약 → 상담자 질문/추가 사실 → 학생 사실 확인 → V2 추가.
- 브라우저에서 텍스트 파일 실제 다운로드, V1/V2 포함 확인.
- 교사 확인 없이 인쇄 요청 불가. 전체 30명 빈 활동지 **90쪽**, 별도 선택 공유한 한 학생 V1/V2 비교 **1쪽**, 한 학생 A4 활동지+A5 카드 혼합 **5쪽**의 실제 PDF를 생성했다.
- DOM 인쇄 쪽 수와 PDF 실제 페이지 수 일치, 인쇄 영역 높이 초과 없음. 공용 출력에 글 본문이 없고 개인 혼합 출력에 다른 학생 코드가 없음을 확인했다.
- 학생 역할에서 기존 전체 자료 목록 화면 접근 차단, 360픽셀 화면의 가로 넘침 없음.
- 장기 공동 결과물의 화면 저장·수정 이력과 개인 경험 미생성 확인. 브라우저 예외 없음.

PDF는 Chromium 인쇄 경로에서 검수했다. 실제 프린터 급지·양면·재단, 15개 언어 모든 긴 문장/모든 생성 조합의 PDF는 최종 사람 검수 전이다.

## 미완료·미연동·공개 상태

1. **실제 인증·서버 권한·서버 저장 미구현:** 역할 선택은 가상 시연용 로컬 필터다. 브라우저 저장은 보안 경계가 아니므로 실제 학생의 민감한 기록을 넣어 운영하면 안 된다. 별도 로그인, 담당 수업 권한, 상담 공유 철회와 서버 접근 제어 검수가 필요하다.
2. **기존 결과지/플래너/LAB/AI자소서/기업 자료 API 미연동:** 로컬 플래너 저장을 외부 등록 성공이라고 표시하지 않는다. 복사·내보내기·수동 입력 경로를 사용한다. 기존 외부 앱은 변경하지 않았다.
3. **생성 AI 미연결:** 수동 작성과 규칙 기반 질문·사실 구성 미리보기다. 실제 AI 생성 또는 이력서/개인 맞춤 분석 완료로 표시하지 않는다.
4. **15개 언어:** 신규 UI/교사용 안내/인쇄 템플릿을 14개 비한국어 사전에 추가하고 기존 번역과 학생 원문을 보존했다. 번역 필드·키 검사를 통과했지만 전문가 의미 검수 완료가 아니다.
5. 원격 저장소 생성·푸시·공개/권한 변경 및 공개 배포는 수행하지 않았다.
