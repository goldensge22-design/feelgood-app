# 수업설계LAB v1.5 — 경험 정리·STAR 선택 도움 보강 규칙

기록일: 2026-11-07. 기존 1.5와 승계 1.2·1.1·1.0은 보존한다. 충돌하지 않는 추가 규칙이며 별도 AI자소서 앱 변경·외부 연동·공개 게시 승인이 아니다.

## 사용자 제공 외부 앱 확인 내용

별도 AI자소서는 상황과 내 역할·목표의 선택 입력, 연결 경험의 빈 항목을 질문 하나씩 묻는 규칙형 코치를 한국어 우선으로 보강했다. 본문 자동 작성·삽입 없이 학생 직접 작성을 유지한다. 경험 문항은 STAR, 지원동기·가치관·계획은 기존 문항별 코치를 기본으로 하되 학생이 도움 방식을 선택한다. 이는 사용자가 전달한 확인 내용이며 교사 앱에서 별도 앱의 코드나 실제 플래너 연결을 검증했다는 뜻이 아니다.

## 교사 앱 적용 규칙

1. 경험 정리는 상황, 본인 역할·목표, 직접 행동, 관찰 결과, 배움과 근거를 다룬다. 상황·역할은 선택이고 다른 칸도 빈칸을 추정하거나 네 칸 완성을 강제하지 않는다. 실제·모의·미확인 출처를 유지한다.
2. V1 전에도 도움을 펼치고 질문을 하나씩 볼 수 있다. 닫기·건너뛰기·도움 없음 상태에서도 직접 작성·초안 저장이 가능하다. 확인 사실 없이 저장한 글은 검증된 경험/최종 글로 취급하지 않는다. 문항 목적은 선택·수정 가능하며 지원동기·가치관에 STAR를 강제하지 않는다.
3. 중학생은 활동/맡은 일/해 본 행동/알게 된 점, 고등학생은 탐구 질문/역할/수행·근거/생각 변화, 대학생은 직무 상황/책임·목표/본인 행동/결과·배움을 중심으로 자료·질문·지원·산출물을 다르게 한다. 가상 예시를 학생 기록으로 자동 채우지 않는다.
4. 교사용 진행안은 수업설계LAB의 자소서·면담/경험 도움 단계에서 교사가 시범을 보이고 학생이 기록하고 교사가 확인할 질문을 표시한다. 기존 180/240/300분·5시간 면담형 총합과 휴식을 유지하고 현장 검사는 별도 추가한다. 기존 글쓰기 시간 안에서 경험 선택→선택 도움→직접 작성→사실 점검을 수행한다. 장기/면담형은 V1 보존→면담→학생 추가 사실 확인/제외→직접 수정→V2로 이어진다.
5. 경험 정리, 글쓰기 점검, 면담·수정 기록을 별도 선택 출력하며 개인/선택 학생/전체 반의 묶음에 포함한다. 플래너 카드는 수행할 행동·완료 기준, 글쓰기 활동지는 수행 후 경험 정리라는 역할을 유지한다. 생성 배부본을 기존 18개 수업·36종 활동지의 새로운 고유 종류로 세지 않는다.
6. 보조 메모는 별도 저장·별도 버전이며 확인 사실·본문·과거 버전으로 자동 승격되지 않는다. 학생이 출력과 담당 교사 공유를 각각 선택한 경우에만 교사용 출력에 포함한다. 자신의 출력만 선택한 경우 다른 사람에게 공개하지 않는다. 공개하지 않은 과거 메모 버전도 공유하지 않는다.
7. 연결 경험이 변경되거나 철회되면 새 활용 전에 재확인하고 기존 메모/글 버전은 보존한다. 상담자의 말은 사실 후보이며 학생 확인 또는 제외 후 다음 글 버전에 사용한다. 가정 답변을 학생 경험으로 전환하지 않는다. 기존 선택 사실 미리보기는 자율 작성과 구분하고 명시적 선택 없이 본문에 적용하지 않는다.
8. TOP5·결과지는 선택 참고이며 직접 탐색하고 선택·확인한 활동만 플래너에 등록한다. 본 패치는 플래너에 활동을 자동 등록하지 않는다.
9. 신규 교사 화면·도움·제품 예시·활동지·진행안·출력은 기존 15언어를 지원한다. 학생/교사 원문·문항·도움 선택·작성 위치를 언어 전환과 재진입 때 보존한다. 별도 AI자소서의 한국어 우선 보강과 혼동하지 않는다. 번역은 작성 번역이며 원어민 승인이 아니다.
10. 실제 대시보드·플래너·AI 서버 연결과 인증은 개발자 담당이다. 현재 브라우저 로컬 저장·가상 명부의 범위를 유지하며 서버 성공 응답을 꾸미지 않는다. GitHub 연결·공개 배포는 수행하지 않는다.
