# 수업설계LAB 확정 제작 규칙 1.0

기준일 2026년 10월 27일. 사용자가 이 대화의 대상별 수업 설계 및 활동지 차별화 규칙을 승인하고 Replit 제작과 규칙 저장을 요청했다. 학생별 직군·직무 플래너 활동카드 출력 요구를 함께 반영한다. 제작 시작 승인이며 구현 완료나 공개 배포 승인이 아니다.

## 제품과 범위

교사용 Teacher AI 대시보드의 진로 수업 도구인 수업설계LAB을 별도의 Replit 웹앱으로 제작한다. 기존 학생용 LAB, 플래너, 자기소개서 앱과 GitHub 배포본을 교체하거나 수정하지 않는다. 기존 결과지와 LAB을 수업에 활용하는 교사용 설계·활동카드·출력 기능이 중심이다. 실제 학생 기록이 없는 시연은 명확히 구분된 가상 학생으로 진행한다. 이후 기존 서버 연동은 개발자가 담당하도록 연동 안내와 데이터 원본 관리 규칙을 함께 보존한다. 지금 외부 서비스 연동이 된 것처럼 표시하지 않는다.

## 규칙 저장

이 문서 전체와 향후 변경 이력을 Replit 프로젝트 안에 영구 보존하고 교사용 규칙 보기와 내려받기 기능을 제공한다. 날짜와 버전을 기록하며 현재 규칙, 구현된 범위, 연동 대기 항목, 검수 결과를 구분한다. 사용자 요구 없이 확정 수량이나 교육 목표를 축소하지 않는다.

## 대상과 수량

첫 화면에 중고생용과 대학생용 두 탭을 둔다. 중고생용 안에서 중학생과 고등학생을 선택한다. 나이만으로 교육단계를 추정하지 않는다. 중학생 수업 6개와 활동지 12종, 고등학생 수업 6개와 활동지 12종, 대학생 수업 6개와 활동지 12종으로 총 18개 기본 수업안과 36종 활동지를 집필한다. 시간 변경, 학생 이름 변경, 유형별 안내 변경만으로 별도 수업이나 활동지 수를 늘리지 않는다. 학생별 출력 카드는 이 콘텐츠의 개인화된 배부본이며 고유 활동지 종류 수와 구분하여 집계한다.

## 수업 모델

나의 방법 발견, 진로 후보 비교, 정보와 근거 확인, 미션과 협업, 강점 활용 방법 실험, 탐색부터 실행까지 캠프의 6개 모델을 각각 세 교육단계에 맞게 만든다. 각 수업에는 목표, 사전 준비, 사용할 결과지 항목의 제목, LAB에서 볼 내용, 교사 시연, 실제 학생 행동, 시간표, 필요한 활동지, 교사 발문, 관찰 기준, 제출물, 다음 행동을 포함한다. 단순 제목 목록이나 빈 입력폼을 완성된 수업으로 취급하지 않는다. 교사가 목표와 인원 및 시간을 고르고 수업을 편집·저장·복제·인쇄하며 활동을 교체할 수 있게 한다. 반복 이력을 반영하고 바꾼 이유를 이해할 수 있게 한다.

## 활동지 12개 계열

결과 설명과 실제 경험 대조, 결과지에 관심사를 더한 탐색 방향, 학과·직무 후보와 경로 비교, 출처·사실·미확인 정보 구분, 직무 과정과 요구 행동 지도, 선배·현직자에게 묻는 질문, 현재 분야·미래 아이디어·창업 경로 설계, 역할 분담과 미션 수행, 플래너 실행 계획, 산출물 점검과 동료 피드백, 진로 지도·경험을 나의 이야기로 연결, 다음 7일 실행과 진로 재검토를 각각 세 교육단계로 작성한다. 수업에는 필요한 활동지만 선택해 묶는다.

## 실질적인 대상별 차별화

모든 대상별 활동에 학습 목표, 읽는 자료, 실제 수행 행동, 선택할 도움, 제출물과 완료 기준을 각각 작성한다. 명칭과 문장 난도 또는 입력 칸 수만 바꾸지 않는다. 중학생은 관심 확장과 짧은 체험, 고등학생은 학과·교과·준비 경로 및 탐구, 대학생은 기업별 역할·요구 행동·직무 수행 결과물을 중심으로 한다. 중학생에게 국내외 학과나 창업 정보를 막지 않는다.

예를 들어 스포츠와 데이터의 진로 비교에서 중학생은 두 직업 사례를 읽고 하는 일을 표시하여 관심 역할과 이유를 제출한다. 고등학생은 실제 학과의 공식 교육과정을 읽고 수업과 과제 및 관련 교과를 비교해 탐구 계획을 제출한다. 대학생은 기업별 직무 자료를 읽고 요구 행동을 비교해 수행 과제와 근거를 제출한다. 실제 자료가 없으면 교육용 가상 자료임을 밝히며 대학이나 기업의 사실을 꾸며내지 않는다.

## 중고생용 경로

결과지에 관심사를 더하기, 현재 분야와 미래 가능성 탐색, 국내외 학과의 배울 내용과 전공 결합 비교, 직업·직무·창업 또는 프로젝트 경로, 직접 해보기 활동을 플래너에 담기, 실제 경험 기록, 진로 지도와 청소년용 나의 이야기 수정의 순환을 만든다. 관심사 입력을 별도 검사로 분리하지 않는다. 결과지가 없으면 자기 진술로 임시 탐색하되 검사로 확인한 것과 구분한다. 대학은 이름이나 순위보다 공식 교육과정과 프로젝트 및 전공 결합 기회로 비교한다. 현재 확인된 직업과 학생이 구상한 미래 아이디어를 구분한다. 관심 감소나 방향 변경도 탐색 결과로 보존한다.

## 대학생용 경로

결과지와 관심 직무, 기업직무탐색 LAB의 기업별 역할 비교 및 출처, 요구 행동 선택, 직무 모의 과제나 실제 프로젝트, 플래너 실행, 결과물과 경험카드, 본인 작성 자기소개서와 질문·피드백, 다음 실행으로 이어진다. 결과지의 TOP5 원순위와 이유를 보존하고 교사용 앱에서 재평가하거나 합격 확률로 표시하지 않는다. 학생은 TOP1 이외의 직무도 선택한다.

## 81유형 규칙

결과지의 계획·주의·동시처리·순차처리 네 영역을 모두 반영한다. 검사 종류와 버전이 확인된 결과지의 해석을 원본으로 보존하며 서로 다른 검사의 점수 척도나 기준을 섞지 않는다. 정해진 검사 기준이 없으면 점수를 임의로 H/M/L로 재산정하지 않는다. 동점은 모두 보존하고 계획→주의→동시→순차 순서로 하나만 고르는 방식은 사용하지 않는다. 여러 지원 필요에는 도움을 함께 주되 한 수업에서 의식적으로 연습할 목표는 1~2개로 좁힌다.

HHHH에는 독립 수행과 대안 비교 및 확장, MMMM에는 방법 비교, LLLL에는 짧은 자료·시범·단계 안내·중간 확인을 제공하는 기본안을 마련하고 교사가 수정할 수 있게 한다. H가 없는데 낮은 영역을 절대 강점이라 명명하지 않는다. 학생이 선택한 방법과 실제 수행 피드백을 반영한다.

학년별 기본 과제와 개인별 지원은 독립적으로 적용한다. 같은 대학생 과제에도 순서표, 핵심 표시, 관계 비교표, 단계 카드 등 서로 다른 지원을 제공한다. 유형으로 학과나 직무 선택을 제한하지 않는다. 난이도는 연령·유형·인원수만으로 결정하지 않고 사전 경험과 수행 증거를 반영한다. 전체 학급 인원과 실제 작업 모둠 인원을 별도로 받는다. 20세 이상을 초등 연령대로 보내는 기본값을 금지한다. 관찰은 과제 수행과 도움 효과의 기록이며 검사 점수 향상이나 인지 향상의 증거로 바꾸지 않는다.

## 학생별 직군·직무 활동카드

결과지에 제시되거나 학생이 선택한 학과·전공을 출발점으로 여러 직군과 직무 예시를 탐색하게 한다. 학생이 관심 직무와 과제를 선택하면 해당 직무의 행동을 연습하는 플래너 활동카드를 만든다. 학과 한 개를 직무 한 개에 고정하지 않는다. 대학생 결과지에 학과 필드가 없거나 미연동이면 학생이 직접 전공과 관심 직무를 고르게 한다. 학과·직무가 맞지 않는 임의 추천은 하지 않는다.

교사는 학생 코드, 교육단계, 학과·전공, 관심 직군과 직무, 확인된 결과지 정보, 선택한 도움, 사전 경험, 수업 시간을 입력하거나 검토한 명단에서 선택하여 일괄 생성한다. 누락 정보는 임의로 채우지 않고 확인 필요 또는 일반 지원 카드로 처리한다. 학생별 미리보기와 교사 수정 후 확정·출력하며 배부 명세와 재출력 버전을 제공한다.

카드는 오늘의 목표, 직군·직무와 교육용 상황, 읽을 자료, 첫 행동, 실행 순서, 활용할 방법과 선택 도움, 내 역할, 예상 시간, 제출물, 완료 기준, 중간 점검, 실제 한 행동과 조정, 결과물·피드백, 다음 실천을 담는다. 공통 직무 목표와 핵심 완료 기준을 유지하면서 개인별 안내와 지원을 바꾼다. 점수·81유형 코드·약점이라는 낙인은 학생 배부용에 기본 인쇄하지 않는다. 교사용 추천 근거는 권한이 있는 별도 화면에서 확인한다.

A4 한 장과 A4에 A5 카드 두 장을 배치하는 출력 방식을 제공한다. 흑백 가독성, 한글 줄바꿈, 페이지 나눔, 학생별 묶음, 명단 순서, 빈 기록칸, 동일 내용의 화면과 인쇄를 검수한다. PDF 저장은 실제 동작하는 출력 경로를 사용한다. 로그인이나 연동이 없는 QR을 정상 개인기록 링크처럼 만들지 않는다. 학생 데이터가 없는 현재 데모는 가상 학생으로만 만든다. 전체 카드 수와 고유 활동지 수를 구분한다.

종이 카드와 플래너 기록을 대응시키되 미연동일 때는 복사·내보내기·수동 입력 경로를 제공하고 자동 저장이라고 표현하지 않는다. 실제 연동 후에도 중복 생성 없이 동일 카드와 결과물을 연결하고 원본·수정 이력을 보존한다.

## 한서대 캠프 적용

사용자가 제공한 한서대학교 4개학과 취업캠프 발표제안서는 2026년 11월 17~18일 추진안, 2~4학년 약 50명, 항공보안학과·항공교통물류학과·공항행정학과·항공외국어학과 공동 모집이다. 이는 제안서 기준이며 최종 일정 확정 사실로 표현하지 않는다. 학과에 관계없이 희망직무에 따라 공항직무반, 항공사직무반, 보안·물류직무반을 선택한다.

공항운영·행정은 교육용 공항 안내자료 두 개 대조와 수정 요청, 항공서비스·운영은 상황별 고객 안내문 작성과 전달, 보안·물류는 교육용 절차 순서 또는 물류 기록 대조와 누락 보고의 예시 과제를 마련한다. 실제 보안 취약점이나 우회 방법이 아닌 일반적인 정확성·절차 준수·안전한 보고·협업을 연습한다. 언어 강점과 전공 경험을 선택적으로 활용하며 특정 학과에 특정 반을 강제하지 않는다.

동일한 안내자료 대조 과제라도 계획 지원 학생에게 단계별 할 일과 중간 점검표, 주의 지원 학생에게 짧게 나눈 자료와 항목 표시, 동시처리 지원 학생에게 자료 간 관계표, 순차처리 지원 학생에게 순서 카드 등을 제공한다. 이는 가상 예시이며 실제 학생의 결과지를 대신하지 않는다.

한서대 1일차 오후는 13시30분~17시20분, 50분 수업 네 차시와 차시 사이 10분 휴식 세 번으로 교육 200분과 휴식 30분이다. 일반 5시간 캠프는 교육 280분과 휴식 20분으로 별도 유지한다. 한서대 전용 운영안은 1차시 결과지·관심직무·계획, 2차시 직무 예시 자료 탐색과 첫 실행, 3차시 피드백과 재실행·경험 기록, 4차시 경험 설명 글과 둘째 날 전문가 질문 및 다음 계획으로 구성한다. 이 배분은 교사용 앱의 운영 제안으로 표시하고 제안서 원문의 상세 편성으로 오인하지 않게 한다.

학생 한 명당 계획 카드, 수행·점검 카드, 경험·피드백 카드, 전문가 질문·7일 실천 카드의 네 장을 묶는 한서대 기본안을 제공한다. 50명을 선택하면 개인화 카드 200장이고 A4 두 장씩 인쇄하면 총 100장이다. 실제 학생 수와 카드 선택을 바꾸면 매수를 다시 계산한다. 이것은 36종 활동지와 별개로 새로운 200종이 생기는 것이 아니다. 캠프 이후에는 주간 실행과 월간 경험 정리 및 자소서·면접 활용으로 연결한다.

## 시간과 결과지 항목

수업 시간 선택에 따라 활동 범위와 결과물도 조정하며 글만 압축하지 않는다. 휴식 포함 여부와 총합을 명시하고 반드시 산출물 작성 시간을 남긴다. 결과지 몇 번을 읽는지는 검사 종류·버전·교육단계의 실제 항목 제목과 번호를 함께 확인하여 표시한다. 항목 번호를 모르거나 버전이 다른 경우 번호를 지어내지 말고 제목과 수동 확인으로 안내한다.
