## 후속 개발 순서

1. 기존 계정·기관·반·교사/학생/상담자 서버 권한과 저장소 계약을 확정합니다. 가상 역할 버튼을 실제 로그인으로 대체하고 타인 결과·글 접근 차단을 검사합니다.
2. 결과지 식별자, PASS4 원값/척도, 확정 유형, TOP5 원순위, 버전·출처·확인 시각을 연결합니다. 재동기화 시 현재/과거 이력과 기존 자료 근거를 보존합니다.
3. 학생 선택 직무·탐색 출처·요구 행동을 LAB과 연결합니다. 기업HR 지원자/직원 원자료·가상 매칭 점수를 교육 추천에 사용하지 않습니다. 공식/교육 공유 승인/교사 자료/학생 조사/가상 출처를 구분합니다.
4. 학생이 확정한 카드만 실제 플래너에 등록합니다. 멱등 식별자, 실패·재시도·중복 방지, 원본 버전과 수행 기록 상호 참조를 검사합니다.
5. 학생이 확인하고 선택 공유한 경험만 AI자소서에 전달합니다. V1 보존, 새 사실 확인 후V2, 수정본 별도 공유를 실제 계정·AI로 검증합니다.
6. 기존 `lib/teaching.ts`의 `proposeGroups` 및 `components/group-editor.tsx`에는 자동 제안·교사 확정 기능이 있습니다. 이를 새 Studio 장기 과정의 공동 과제와 연결하고 검수합니다. 유형으로 조장·성취·직무 자격을 판정하지 않습니다.
