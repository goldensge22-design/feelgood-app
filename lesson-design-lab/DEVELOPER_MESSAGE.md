## 2. 이번에 구현된 내용

1. **V1을 쓰기 전부터 경험 정리 도움 사용:** 상황·본인 역할/목표·직접 행동·결과·배움·근거를 정리합니다. 상황/역할과 나머지 메모는 선택 입력이며 빈칸을 허용합니다. 도움을 닫고 바로 글을 써도 됩니다.
2. **문항 목적에 맞춘 질문:** 경험 문항에 STAR를 기본 적용하고 지원동기·가치관·계획에는 목적별 질문을 제공합니다. 학생이 STAR/목적별/도움 없음으로 바꿀 수 있습니다. 규칙형 질문이며 외부 AI 분석 완료로 표시하지 않습니다.
3. **중·고·대학 대상 차별화:** 같은 제목이어도 읽을 예시·질문·도움·산출물이 다릅니다. 중고생은 활동/탐구/성장 이야기, 대학생은 직무 관련 경험 설명으로 사용합니다.
4. **강사용 진행안:** 사용할 프로그램·교사 시범·학생 기록·확인 질문·막힐 때 대안을 반영했습니다. 기존 글쓰기 시간 안에 도움→직접 작성→사실 점검을 넣어 180/240/300분과 휴식·검사 별도 시간 원칙을 유지합니다.
5. **부속 활동지 3종:** 경험 정리, 글쓰기 점검, 면담·수정 기록. 개인/선택 학생/묶음 출력과 기존 A4/A5 자료와의 혼합 출력을 지원합니다. 기본 18개 수업·36종 활동지를 보존하며 신규 부속 양식 3종을 별도 집계합니다.
6. **V1→면담→V2:** 학생이 추가 사실을 확인 또는 제외한 뒤 수정합니다. 메모와 상담자 발언을 본문·사실·플래너 실적으로 자동 복사하지 않습니다. V1과 과거 버전을 보존합니다.

## 3. 서버 연동 시 반드시 지킬 사항

- 기존 로그인과 담당 학교/반/학과/과정 명부를 사용합니다. 로컬 교사·학생 역할 전환은 서버 권한이 아닙니다. 서버에서 소유권과 담당 수업 범위를 검증하세요.
- 선택 메모는 과정+학생에 속합니다. `experienceNotes`가 없는 구 기록에 과거 메모·확인 시각을 만들어 넣지 마세요. 메모 버전과 글의 V1/V2는 별도입니다.
- 교사에게 메모를 공유하는 선택과 출력에 포함하는 선택은 분리합니다. 현재 구현은 교사 출력에 두 선택이 모두 필요합니다. 과거 비공개 메모 버전·원본 수신정보는 교사에게 반환하지 마세요.
- 원본 경험 ID·버전·출처·실제/모의/미확인 상태·철회 여부를 보존합니다. 원본 변경/철회는 새 활용을 차단하고, 가능한 원본만 학생이 재확인합니다. 이전 글과 기록은 소급 덮어쓰지 않습니다.
- 자유 초안은 확인된 경험이 없어도 저장할 수 있지만 **미검증 초안**입니다. 체크박스만으로 사실 확인 완료나 최종본으로 승격하지 마세요.
- 플래너 기록은 학생이 선택한 내용만 가져오고 별도 활용 동의를 확인합니다. TOP5 전체 자동 카드 생성, 계획의 자동 경험 전환, 공동 산출물의 개인 실적 자동 복사를 하지 마세요.
- AI자소서로 보낼 경험·조사 맥락·메모의 범위를 각각 합의하세요. 현재 별도 AI자소서 STAR는 한국어 우선이며 이 교사 앱의 15언어 검증과 다릅니다. 계약이 없는 필드를 임의 전송하거나 성공한 것처럼 표시하지 마세요.
- 실제 저장에는 버전 충돌·원자적 저장·재시도/중복 방지를 연결하세요. 교사 피드백과 학생 사실 확인은 서로 다른 사건으로 저장합니다.
- 기업 HR 수업/지원자 평가/직원 성과 연계는 후속입니다. 학생 수업에 기업 인사 원자료를 자동 노출하지 마세요.

상세 연결 기준은 [기존 1.6 명세](docs/INTEGRATION-AND-ACCEPTANCE-1.6.md)를 함께 읽으세요. 1.6 전체 설계가 이번 STAR 패치로 모두 구현된 것은 아닙니다.

## 4. 개발 환경 실행 순서

Node.js 24와 pnpm 10.26.1을 준비한 뒤 **`lesson-design-lab/app/`에서** 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm verify:files
pnpm typecheck
pnpm build
pnpm dev
```

전체 검사는 Chrome/Chromium, Poppler, 다국어 글꼴을 준비하고 `CHROME_BIN`을 지정한 뒤 `pnpm qa`를 실행합니다. 운영 계정이나 실제 학생 프로필 대신 격리된 가상 명부를 사용하세요. 상세 환경 및 포트는 app 안내를 따릅니다. `verify:files`는 인계 원본 확인용이며 개발 수정 후에는 기존 해시가 일치하지 않는 것이 정상입니다. 변경 후에는 새 소스 해시와 새 QA 결과를 남기세요.

## 5. 적용 후 수용 확인

- V1 전 접근, 빈 메모 저장, 도움 없음, 목적 변경, 본문 직접 작성이 모두 가능할 것.
- 중학생/고등학생/대학생의 예시·질문·출력 차이와 기존 18/36 자료가 유지될 것.
- 학생 A/B 전환·재접속·실계정 변경 시 메모·본문·출력이 섞이지 않을 것.
- 공유 안 함/출력 안 함/둘 다 선택을 각각 확인하고, 타 교사·타 과정의 직접 API 접근도 차단할 것.
- 원본 수정/철회/동의 철회 및 재확인을 실제 플래너·AI 연결에서 확인할 것.
- V1 보존, 면담 후보 사실의 확인/제외, V2·수정본 공유와 내보내기를 확인할 것.
- 15개 언어에서 원문·문항·도움 선택·작성 위치 보존을 확인하고, 미검증 모바일 조합과 실제 프린터를 보완할 것.
- 3/4/5시간 합계, 휴식, 현장 검사 별도 추가, 면담 인력·예약 충돌을 유지할 것.
