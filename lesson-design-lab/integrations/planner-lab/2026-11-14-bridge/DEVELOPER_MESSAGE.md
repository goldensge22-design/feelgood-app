# 개발자 적용 지시: 플래너 → 기업 LAB 연결

2026-11-14 추가 패치입니다. 먼저 [전체 적용 지침](START_HERE_개발자_전달.md)을 읽고 [수정 항목·수용 기준](developer-issues.json)의 INT-01~08을 완료해 주세요.

## 구현한 흐름

결과지 TOP5/검증된 관심 직무 선택 → LAB 요청 → 추천 후보 표시 → 카드 하나 선택·서버 등록 → 판단·행동·결과·느낌·메모 작성 → 저장·다시 열기·수정.

## 우선 처리

1. **원본 TOP5 조회:** 현재 소유자의 결과지 id/version/rank/label을 유지하세요. PASS로 TOP5를 추정하거나 임의 직무를 연결하지 마세요.
2. **같은 사용자의 SSO:** 중앙 NUVIA 세션과 LAB 주체를 연결하고 생성 후 세션을 재확인하세요. 공용 관리자 토큰을 쓰지 마세요.
3. **캠프 코드 없는 개인 이용:** LAB에는 개인 공간 경로가 있습니다. 로그인한 개인에게 캠프 코드를 필수로 요구하지 말고, LAB 세션이 확인한 공간 ID를 요청에 사용하세요. 만료 캠프는 명시적인 개인 공간 전환으로 처리하세요.
4. **운영 DB/API:** PostgreSQL pool·마이그레이션·HTTP 진입부·CSRF를 연결하세요. SQLite와 합성 QA 인증은 운영 완료 근거가 아닙니다.
5. **플래너 진입·기존 기록 통합:** 실제 로그인/수업 공간 전환 때 바뀌는 세대 키로 새 패널을 연결하세요. 기존 일정·할 일·통계 통합과 실제 플래너 열기 경로를 적용하세요.
6. **계약 구분:** 이번 경로는 /lab/daily 연습 카드입니다. 기존 timed-decision-card/1.3 시나리오 수신·서명 영수증·STAR 전송을 완료한 것으로 취급하지 마세요.
7. **AI자소서:** 별도 연결 시 학생이 선택·동의한 저장 리비전의 실제 행동·결과·직무 연결만 전달하세요. 모의 연습 표식을 유지하고 감정·자유 메모는 기본 제외하세요.
8. **다국어·회귀 QA:** 새 화면은 한국어입니다. 4프로필×15언어 코드 라우팅 검사는 합성 응답 검사이며 실제 번역 품질·15언어 화면 QA가 아닙니다. 기존 기능 회귀와 실제 계정 테스트를 완료하세요.

## 완료 판정

실제 샘플 로그인 → 캠프 코드 없이 LAB 접속 → 원본 TOP5 일치 → 추천 후보 표시 → 카드 1개 등록 → 중복 클릭해도 1개 → 기록 저장 → 재접속 복원 → 수정 → 다른 계정·공간에서 접근 차단을 확인하세요. 실제 LAB 생성기·PostgreSQL·기존 플래너 일정 통합도 별도로 확인하세요.

## 이번 검증 범위

합성 HTTP 테스트 24개 통과, 새 React 컴포넌트 타입 검사·번들 통과, 브라우저 선택·기록·저장·복원·재수정 확인, 패치 적용·충돌 거부·복원 검증 통과입니다. 운영 SSO·운영 DB·배포 완료를 뜻하지 않습니다.

기존 파일에 무조건 덮어쓰지 말고 apply_patch.py의 기본 충돌 검사부터 실행하세요. main 병합과 운영 배포는 이 인계에 포함하지 않습니다.
