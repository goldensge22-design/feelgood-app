# 수업설계LAB 확정 제작 규칙

버전 1.2 · 2026년 10월 27일 · 사용자 승인된 제작 요구사항입니다. 구현 완료 판정은 별도의 검수 결과를 따릅니다.

## 제품과 수업방식

중고생용과 대학생용 두 탭을 제공하고, 중고생용에서 중학생·고등학생을 선택합니다. 교육단계는 교사가 선택하며 20세 이상을 초등 연령대로 처리하지 않습니다. 기관·소속반·대상·관심 분야·목표·시간·인원·수업방식을 설정합니다.

1:1 지도, 개별 수행, 조별 수업, 혼합 수업을 구분합니다. 같은 반의 학생들이 각자 과제를 수행하는 것은 개별 수행이며 1:1 지도와 다릅니다. 조별 단계에서만 수동 편성과 자동 편성 제안을 제공합니다. 학생이 같은 반에 속한다는 이유로 동일 미션을 강제하지 않습니다.

자동 편성은 교사가 정한 관심 분야·미션, 활용 방법의 다양성, 비슷한 지원 필요 등을 고려하고 교사 확정 후 적용합니다. 인원 범위·고정 배치를 지키고 누락·중복·조건 충돌을 표시합니다. 81유형 일치만으로 조를 강제하거나 유형으로 역할을 고정하지 않습니다. 혼합 수업은 단계마다 개인·조별 방식을 지정하며 기존 기록을 보존합니다.

## 콘텐츠 수량과 차별화

교육단계마다 아래 6개 수업과 12종 활동지를 집필합니다. 총 18개 기본 수업안과 36종 활동지입니다. 제목 목록·빈 양식·시간 변경·유형 문구 변경만으로 수량을 채우지 않습니다.

수업: 나의 방법 발견 / 진로 후보 비교 / 정보와 근거 확인 / 미션과 협업 / 강점 활용 방법 실험 / 탐색부터 실행까지 캠프.

활동지: 결과 설명과 실제 경험 대조 / 결과지에 관심사를 더한 탐색 방향 / 학과·직무 후보와 경로 비교 / 출처·사실·미확인 정보 구분 / 직무 과정과 요구 행동 지도 / 선배·현직자 질문 / 현재 분야·미래 아이디어·창업 경로 / 역할 분담과 미션 수행 / 플래너 실행 계획 / 산출물 점검과 동료 피드백 / 진로 지도·경험과 나의 이야기 / 다음 7일 실행과 진로 재검토.

모든 대상별 활동에 학습 목표, 읽는 자료, 실제 수행 행동, 선택할 도움, 제출물과 완료 기준을 따로 작성합니다. 중학생은 관심 확장과 짧은 체험, 고등학생은 학과·교과·준비 경로와 탐구, 대학생은 기업별 역할·요구 행동·결과물을 중심으로 합니다. 중학생도 국내외 학과와 창업을 탐색할 수 있으며 자료량과 범위를 조정합니다.

스포츠·데이터 비교 예시: 중학생은 두 역할의 짧은 사례에서 하는 일을 찾아 관심과 이유를 제출합니다. 고등학생은 공식 학과 교육과정을 비교해 탐구 계획을 만듭니다. 대학생은 기업별 직무 요구를 비교해 수행 과제와 근거를 제출합니다. 가상 자료는 가상임을 밝히고 실제 대학·기업의 사실을 만들지 않습니다.

## 결과지와 81유형

검사 종류·버전·척도가 확인된 원본의 네 영역을 모두 반영합니다. 서로 다른 검사의 임계값을 섞거나 수업 도구에서 임의 재판정하지 않습니다. 동점 후보와 복수 지원 필요를 보존하며 한 차시의 명시적 연습 목표는 1~2개로 좁힙니다.

HHHH는 독립 수행·대안 비교, MMMM은 방법 비교, LLLL은 짧은 자료·시범·단계 안내·중간 확인의 기본안을 제시하고 교사가 수정할 수 있게 합니다. H가 없을 때 낮은 영역을 절대 강점으로 명명하지 않습니다. 결과지가 없으면 자기 진술과 선택 지원으로 시작하며 검사 확인 정보와 구분합니다.

학년별 과제와 개인 지원은 독립적입니다. 같은 과제에서도 순서표·핵심 표시·관계표·단계 카드 등을 선택합니다. 사전 경험과 실제 수행 피드백을 반영하며 연령·유형·인원만으로 난이도를 정하지 않습니다. 유형으로 학과·직무를 제한하거나 결과지 TOP5를 재정렬하지 않습니다. 관찰을 검사 점수 변화 또는 인지 향상으로 바꾸지 않습니다.

결과지 번호는 검사 종류·버전·교육단계의 항목 제목과 대응시킵니다. 실제 번호를 확인할 수 없으면 제목과 수동 확인으로 안내합니다.

## 대상별 프로그램 연결

중고생: 결과지에 관심사 더하기 → 현재 분야·미래 아이디어 → 국내외 학과의 교육과정과 전공 결합 → 직업·직무·창업 경로 → 플래너 실천 → 경험 → 진로 지도·나의 이야기.

대학생: 결과지·관심 직무 → 기업별 역할과 공식 출처 → 요구 행동·미션 → 플래너 실행 → 결과물·경험카드 → 본인 작성 글과 질문·피드백 → 다음 실행.

계획과 실제 경험, 모의 활동과 실제 활동을 구분합니다. 학생이 확인한 근거만 글에 반영하며 작성 글을 자동 덮어쓰지 않습니다. 미연동 상태에서는 복사·내보내기·수동 등록을 제공하고 자동 저장이라고 표시하지 않습니다. 국내외 대학 정보는 공식 교육과정과 출처·확인 시점을 근거로 하며 자료가 없는 부분을 꾸며내지 않습니다.

## 개인 활동지와 플래너 활동카드

개인 활동지는 읽는 자료·질문·수행 과제·필요한 도움·답안 및 산출물 작성 공간·제출 기준입니다. 플래너 활동카드는 관련 과제를 실행할 제목·목표·이유·일정·시간·범위·첫 행동·순서·도움·완료 기준·실제 행동·조정·결과물·피드백·다음 행동을 담습니다.

학생마다 서로 다른 직무와 미션을 선택할 수 있습니다. 동일 과제에서는 공통 핵심 목표를 유지하면서 도움을 달리합니다. 활동지 한 개를 여러 실행 카드로 나누거나 기존 계획 카드에 연결할 수 있습니다. 계획만으로 실제 경험을 생성하지 않습니다.

교사는 학생별 미리보기·수정·확정을 수행하고 다음 조합으로 출력합니다.

| 선택 대상 | 출력 내용 |
|---|---|
| 학생 한 명 / 선택 학생 / 소속반 전체 | 활동지만 / 활동카드만 / 학생별 두 자료 묶음 |

A4 활동지 및 A4·A5 배치 카드, PDF 저장, 재출력, 학생별 페이지 경계와 작성 공간, 흑백 인쇄를 지원합니다. 학생 코드·자료 제목·연결 표시·버전·페이지를 표시하고 이름은 필요 시 선택합니다. 점수·81유형·약점 표시는 기본 제외합니다. 학생 수·자료 종류 수·생성본 수·용지 매수를 구분합니다.

플래너 실제 등록은 권한과 학생 확인 및 저장 성공을 전제로 합니다. 재시도 때 중복 등록하지 않습니다. 종이 작성 내용은 확인 후 입력하며 자동 동기화된 것으로 표시하지 않습니다. 학생 자기 계정 다운로드 권한은 교사의 학생별 출력 기능과 구분합니다.

## 한서대 활용 사례

범용 앱의 선택 예시로만 제공합니다. 여러 학과 학생이 각자의 관심 직무와 특성에 따라 개인 미션·활동카드·완료 기준·결과물을 받습니다. 자동 조 편성이나 조별 공통 미션을 기본 적용하지 않습니다.

공항 안내자료 대조, 상황별 서비스 안내문, 교육용 절차·물류 기록 점검 등은 교사가 바꿀 수 있는 예시 과제입니다. 전공 하나에 직무 하나를 고정하지 않습니다. 실제 보안 취약점이나 우회가 아닌 정확성·절차 준수·안전한 보고를 연습합니다.

4차시·50명·학생당 카드 네 장은 예시 설정입니다. 일반 5시간 캠프는 교육 280분과 휴식 20분을 분리합니다. 한서대 사례의 오후 4차시 예시는 교육 200분과 휴식 30분입니다. 기관별 설정 변경이 다른 수업이나 공통 규칙을 변경하면 안 됩니다.

## 언어와 화면 및 기록 보호

15개 언어는 ko, en, ja, zh-CN, zh-TW, mn, th, vi, ar, ru, km, es, fr, it, az입니다. UI·접근성·샘플·활동지·인쇄를 포함하고 대체 언어 표시를 번역 완료로 세지 않습니다. 원문 의미가 바뀐 부분만 번역 갱신 대상으로 관리합니다.

언어 선택은 주요 화면 우측 상단에서 바로 접근합니다. 언어 전환 때 입력·진행·타이머·저장 상태를 유지하고 학생 작성 글을 임의 번역하지 않습니다. PC·태블릿·360px 모바일·아랍어 방향·긴 번역·인쇄를 확인합니다. 내부 개발 상태는 일반 학생 출력물에서 제외합니다.

기존 계정·결과지·플래너·경험·사용자 작성 글과 외부 계약을 보존합니다. 개인 기록 외부 공유는 별도 선택으로 처리합니다. 구현·검수·연동·공개 배포 상태를 각각 관리합니다.
