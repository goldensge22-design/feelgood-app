# 수업설계LAB 규칙 변경 이력

## 버전 1.2 2026년 10월 27일

개인 활동지와 플래너 활동카드의 용도를 구분했습니다. 학생 한 명·선택 학생·반 전체에서 활동지만·카드만·학생별 묶음을 출력하는 규칙, 실제 플래너 연동 전후의 상태, 종이 기록의 확인 입력과 중복 등록 방지를 명시했습니다.

## 버전 1.1 2026년 10월 27일

범용 교사용 앱을 명시하고 한서대는 개인 미션 활용 사례로 정정했습니다. 소속반과 조를 구분하고 1:1 지도·개별 수행·조별·혼합 수업을 나눴습니다. 한서대 인원·시간·직군·카드 수를 제품 고정값으로 사용하지 않도록 했습니다.

## 버전 1.0 2026년 10월 27일

별도 Replit 앱 제작을 시작했습니다. 중학생·고등학생·대학생용 수업안 18개·활동지 36종, 81유형별 수행 지원, LAB·플래너·경험·글 연결, 학생별 활동카드와 인쇄, 15개 언어를 기준으로 정했습니다.

## GitHub 인계

사용자가 기존 feelgood-app 저장소의 별도 폴더를 선택했습니다. 최신 적용 규칙은 PRODUCT_RULES.md이며 변경 이력보다 우선합니다. GitHub에 문서를 저장한 사실과 Replit 실행 소스를 저장한 사실은 구분합니다.
