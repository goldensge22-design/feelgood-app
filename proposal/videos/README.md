# FeelGood proposal promotion videos

The proposal cover selects a video from `proposal-v2/i18n/manifest.js`.

- `feelgood-promo-ko.mp4`: shown when `lang=ko`
- `feelgood-promo-en.mp4`: shown for the other 14 supported languages
- `feelgood-university-job-analysis.mp4`: shown when `audience=university`

Replace either file with the final export while keeping the filename. The cover will load the new video without an HTML change. Use an H.264 MP4 with a 16:9 frame for the broadest browser support.
