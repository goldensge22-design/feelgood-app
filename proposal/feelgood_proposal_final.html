학교 제안 요약

기존 창체·인성교육을 데이터 기반 개인 맞춤 시스템으로 업그레이드합니다. 정규수업 없이 의무시수만으로 운영 가능합니다.

진정한 글로벌 교육의 탁월함은
학생 개인의 인지적 특성을 이해하는 것에서 시작됩니다.

K-PASS / D-CAS는 비언어 중심, 정답이 존재하는 문제평가로 정확한 뇌 기능을 평가합니다. 교사의 업무 부담을 줄이는 동시에 진정한 학생 중심 학습 환경을 구현합니다.

Curriculum

32회 연간 커리큘럼 (예시)

PASS 4축 기반 4단계 × 8회, 주 1회 40분 × 32주 + 매일 10분 조례/종례 루틴 병행.
초등 창의적 체험활동과 중고등 진로 수업에 최적화된 회차별 콘텐츠로 구성됩니다.

PHASE 01
1~8회 · 1학기 전반

자기이해
& 감정 인식

Self Awareness
🔵 "나는 어떤 뇌를 가진 사람인가"
  • 1회 K-PASS 초기검사 & 두뇌유형 공개초등: 내 뇌 캐릭터 만들기 / 중고: 두뇌유형 자기소개서
  • 2회 PASS 축 강점 이해초등: 강점 빙고게임 / 중고: 강점-직업 매핑
  • 3회 감정 언어 확장초등: 감정 색깔 그림 / 중고: 감정일기 구조화
  • 4회 내 감정 패턴 발견초등: 감정 달력 / 중고: 트리거 분석
  • 5회 학습 선호 방식 탐색초등: 수업 방식 투표 / 중고: 학습전략 매칭
  • 6회 강점 스토리 만들기초등: 슈퍼파워 발표 / 중고: 포트폴리오 초안
  • 7회 두뇌유형별 감정 반응 이해
  • 8회 1단계 점검 & 성장 확인
PHASE 02
9~16회 · 1학기 후반

자기조절
& 실행력

Self Regulation
🟢 "생각을 행동으로 바꾸는 힘"
  • 9회 계획력(P축) — 마인드맵초등: 오늘 할일 맵 / 중고: 진로 로드맵
  • 10회 루틴 설계 & 습관초등: 아침루틴 카드 / 중고: 주간 플래너
  • 11회 충동 조절 전략초등: STOP 신호 게임 / 중고: 의사결정 매트릭스
  • 12회 집중력 향상 (A축)초등: 뽀모도로 체험 / 중고: 딥워크 설계
  • 13회 목표 설정 & 실행초등: OX 목표 게임 / 중고: SMART 목표
  • 14회 자기 대화 패턴 점검
  • 15회 성취 경험 설계하기
  • 16회 중간 리포트 & 반환점 점검
PHASE 03
17~24회 · 2학기 전반

관계
& 도덕적 사고

Social Thinking
🟡 "타인과 함께 살아가는 사고"
  • 17회 두뇌유형별 갈등 패턴초등: 갈등 역할극 / 중고: 갈등 유형 분석
  • 18회 공감 & 관점 전환초등: 친구 마음 읽기 / 중고: 다양성 토론
  • 19회 딜레마 카드 토론초등: 동화 속 선택 / 중고: 사회 이슈 딜레마
  • 20회 협력 과제 (S축)초등: 모둠 프로젝트 / 중고: 팀 리더십
  • 21회 윤리적 판단 훈련초등: 옳고 그름 스토리 / 중고: 직업윤리
  • 22회 리더십 유형 탐색초등: 리더 역할 체험 / 중고: 리더십 브랜드
  • 23회 갈등 해결 전략 실습
  • 24회 관계 성장 스토리 작성
PHASE 04
25~32회 · 2학기 후반

가치
& 습관화

Meaning & Identity
🔴 "나는 어떤 사람으로 살 것인가"
  • 25회 핵심 가치 발견초등: 가치 카드 분류 / 중고: 직업 가치관 매칭
  • 26회 철학 기반 딜레마초등: 가치 선택 / 중고: 진로·사회 딜레마 심화
  • 27회 자기 선언문 작성초등: 나는 ○○하는 사람 / 중고: Personal Statement
  • 28회 장기 목표 & 진로 연결초등: 꿈 직업 타임라인 / 중고: 진로 로드맵 완성
  • 29회 내가 만들 세상 디자인초등: 미래 도시 그리기 / 중고: 사회문제 해결 기획
  • 30회 두뇌유형별 성장 포트폴리오
  • 31회 변화 발표 & 피어 피드백
  • 32회 최종 평가 & 성장 리포트

Age Group

연령별 핵심 포인트

👶

유치 / Kindergarten

5~7세
감정 인식기본 자기조절사회성 기초
"아이들이 자신의 감정을 이해하고 표현하는 능력은 모든 학습의 출발점입니다."

적용: 감정 선택 UI, 스토리 기반 딜레마, 놀이형 MindCompass

🧒

초등 / Primary ⭐

8~12세 · 창체 수업 핵심
자기조절력집중력습관 형성창체 연계
"이 시기는 '머리가 좋은 아이'보다 '스스로 조절하는 아이'가 성장을 결정합니다."

창체 연계: 계획력 훈련, 루틴 관리, 감정 딜레마
효과: 학습태도·집중력·숙제 수행률 개선

🧑

중고등 / Secondary

13~18세 · 진로 수업 연계
가치관 형성자기 정체성진로 탐색비판적 사고
"'무엇을 아는가'보다 '어떻게 판단하고 선택하는가'가 중요한 시기입니다."

진로 연계: 철학 딜레마, 진로 로드맵, Personal Statement
효과: 대학 진학 준비, 리더십, 윤리적 사고

기존 프로그램과의 차별점

❌ 기존 SEL / 인성교육

  • 😐 정성적 평가 — 측정 어려움
  • 😐 결과 데이터 없음
  • 😐 일괄적 교육 (개인 맞춤 없음)
  • 😐 교사 주관 개입
  • 😐 성장 증명 불가

✅ BRAINMAP · MindCompass

  • ✨ 데이터 기반 정량 평가
  • ✨ 학기별 성장 리포트 자동 생성
  • ✨ 81가지 두뇌유형별 개인 맞춤
  • ✨ AI 자동 분석으로 주관 차단
  • ✨ 행동 변화 추적 & 증명 가능

학교 도입 결정 포인트

01

추가 수업 아님

창체·SEL 시수를 데이터 기반 업그레이드. 정규수업 침범 Zero.

02

교사 부담 없음

자동 콘텐츠·자동 리포트. 교사는 진행만, 설계는 시스템이.

03

학부모 만족도↑

개인별 성장 리포트 제공. 학부모가 직접 변화를 확인 가능.

04

학교 브랜드↑
