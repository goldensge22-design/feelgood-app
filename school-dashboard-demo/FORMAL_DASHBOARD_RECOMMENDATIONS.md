# 정식 대시보드 제품 구성 제안

데모 확정 후 정식 버전은 검사 종류, 대상 연령, 사용 역할을 분리하되 공통 분석·권한·i18n 엔진을 공유한다.

## 권장 제품 매트릭스

| 범위 | 청소년 | 대학생·성인 |
|---|---|---|
| 학교·기관 전체 | K-PASS/D-CAS 집단 분포, 학급 비교, 검사 완료율, 지원 수요, 추세 | K-PASS/D-CAS 집단 분포, 전공·직무군 비교, 참여율, 재검사 추세 |
| 반·그룹별 | 학생별 지원 검토, 수업 전략, 보호자 상담, 재검사, 모둠 초안 | 개인별 직무 적합 탐색, 팀 역할, 학습·훈련 권장, 상담 기록 |
| 개인 연계 | 학교생활기록 활동 근거, 진로군, 선택과목, 상담 근거 | 직무군 우선 추천, 요구 역량, 보완 훈련, 실행 계획 |

## 청소년 우선 기능

1. 학교생활기록 제안은 자동 완성 문장이 아니라 `실제 활동 → 교사 관찰 → 근거 문장 초안`의 3단계로 만든다.
2. 추천 진로군과 선택과목에는 추천 이유, 사용한 검사 영역, 학생의 관심·활동 근거를 함께 표시한다.
3. 보호자 상담에는 강점 우선 설명, 비교·낙인 방지 문구, 다음 행동 한 가지를 제공한다.
4. 영재·위기처럼 확정적으로 들리는 명칭 대신 `심화 탐색 후보`, `우선 검토 필요`를 사용하고 전문 검토 흐름을 연결한다.

## 대학생·성인 우선 기능

1. 직무 추천을 첫 화면의 핵심 결과로 둔다. 추천 직무군, 적합 근거, 요구 역량, 현재 강점, 보완 과제를 함께 보여준다.
2. 전공만으로 직무를 고정하지 않고 관심, 경험, 자격, 근무 선호, 실제 수행 데이터를 결합한다.
3. 추천 결과는 순위 하나가 아니라 `우선 탐색`, `대안 탐색`, `추가 정보 필요`의 세 묶음으로 제공한다.
4. 취업 준비 행동으로 연결되는 30·60·90일 실행 계획과 훈련 콘텐츠를 제공한다.

## API·데이터 계약

- 공통 식별자: `tenantId`, `schoolId/organizationId`, `academicYear`, `classId/groupId`, `userId`, `testId`, `resultId`.
- 결과 계약: Planning, Attention, Simultaneous, Successive/Sequential, IQ, 인지특성, 81유형, 연령·교육단계와 원본 검사 버전을 보존한다.
- 화면은 `API → adapter → normalized data → analytics engine → view model`로 분리한다.
- 담임, 상담교사, 학교 관리자, 기관 관리자별 최소 권한을 적용하고 조회·수정·출력 기록을 감사 로그로 남긴다.
- 상담 메모와 조치 상태는 브라우저 저장소가 아니라 서버에 암호화해 저장한다.
- 판정 규칙은 코드 상수가 아니라 버전·근거·승인자·적용일을 가진 정책 데이터로 관리한다.

## 확정 전에 결정할 항목

- K-PASS와 D-CAS를 한 화면에서 전환할지, 별도 제품으로 보일지
- 청소년 학교생활기록 초안의 승인 주체와 보관 기간
- 대학생·성인 직무 데이터의 분류 체계와 외부 직업정보 연동 범위
- 학교 전체와 반별 화면에서 허용할 학생 식별 수준
- 실제 운영 지원 locale과 외국어 전문 검수 순서
