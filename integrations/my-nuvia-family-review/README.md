## 주요 동작 및 수정

- 첫 일주일 추천 → 편집 가능한 계획 초안 → 직접 확인·저장 → 직접 시작 → 중단·새로고침·이어하기 → 종료와 완료 구분 → 돌아보기 → 주간 요약.
- 히스토리 자료 선택·순서 변경에 따른 가상 모델 결과 → 기록 저장 → 확인 후 플래너 초안 전이.
- 본인이 선택한 본인 활동 기록과 원본 버전 → 문장 틀 → 편집·저장·다시 열기. 현재 실제 AI 생성 기능은 연결되지 않았다.
- 부모에게 자녀 개인 초안을 노출하지 않고, 교사에게는 담당 학생이 명시적으로 공유한 기록만 반환한다. 개인 메모와 부모 관찰을 자소서·교사 공유에 자동 포함하지 않는다.
- 모든 언어에서 언어 선택기를 물리적 오른쪽 상단에 유지하고, 아랍어 본문 RTL 및 언어 변경 중 입력·대상·경로·진행 상태를 보존한다.
- 자동화 기록을 방문자 데이터와 분리하고, 숫자 표현·명암 대비·200% 확대 넘침·인쇄 상단 잘림을 수정했다. 기존 사용자 작성 원문은 번역하거나 삭제하지 않았다.
