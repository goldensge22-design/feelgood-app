# MY NUVIA 실제 브라우저 검증

> 이 문서의 기존 검사는 역사적 기준이다. 최신 증거는 [최종 15언어 QA](MY-NUVIA-FULL-QA.md)와 `generated-artifacts/nuvia-qa-full/final-report.json`이다. 최신 135사례/900단계/315출력은 인쇄 여백 수정 후 고정 소스에서 별도로 실행했으며 과거 부분 검사의 재포장이 아니다.

## 범위와 재현 방법

2026-11-06 개발 미리보기에서 Playwright Core와 설치된 Chromium 152로 실행했다. 브라우저는 실제 DOM, 클릭, 입력, 새로고침, 쿠키 세션과 개발 서버를 사용했다. 물리 휴대폰·태블릿·PC를 사용한 검증은 아니다. 운영 FeelGood 계정·자료·주소·배포는 사용하거나 변경하지 않았다.

공개된 가상 검토 계정을 사용한다. 실제 개인정보를 입력하지 않는다. 이미 존재하는 가상 자료의 개수를 0으로 가정하지 않으며, 테스트는 자신이 만든 고유 제목·ID를 확인한다. 기존 다른 기록을 삭제하지 않는다.

재현 스크립트는 `scripts/src/nuvia-browser-*.mjs`이다. 웹·API 관리 워크플로가 실행 중인 상태에서 프로젝트 루트에서 `node scripts/src/<스크립트명>.mjs`로 실행한다. `REPLIT_DEV_DOMAIN`의 개발 미리보기를 대상으로 한다.

실행 JSON, 화면 캡처, API 회귀 출력은 `generated-artifacts/nuvia-browser/`에 저장한다. 생성물은 Git과 배포에서 제외한다. 보고서에는 인증 쿠키·토큰을 저장하지 않는다.

## 발견 후 수정한 기능

- 교사의 담당 외 자녀 주소에서 데이터 요청은 차단됐지만 화면에 이유가 없었다. 접근 불가 설명과 허용 대상 복귀 링크를 추가하고 브라우저·403을 재검증했다.
- 히스토리 모형 결과가 언어 변경 뒤 이전 언어로 남았다. 사용자 이유 입력은 그대로 두고, 생성된 모형 설명만 구조화된 선택에서 현재 언어로 다시 표시한다. 저장된 원본 기록·사용자 입력은 번역하지 않는다.
- 세션이 없거나 만료된 진입 화면에 이유와 다시 진입하는 방법을 명시했다.

## 여기서 완료로 취급하지 않는 항목

- 실제 FeelGood 신원 확인·로그인, 기존 운영 프로그램 연결, 운영 데이터 동기화, 운영 오류 수정, 운영 회귀: **미연결·미확인**.
- 실제 AI 응답: **없음**. 도움말 및 사용자가 검토하는 문장 틀이다.
- 15개 언어 원어민 의미·문화 검수: **미실행**. 브라우저 표시/키 구조 검사로 검수 완료를 주장하지 않는다.
- 물리 기기 간 검증, 실제 소프트 키보드, 스크린리더, 전체 접근성 인증, 모든 브라우저 엔진: **미실행**.
- 30분을 실제 기다린 만료 검사는 아니다. 서버 세션 폐기로 무효 세션과 401 복구를 재현했다.
- 서버 재시작 내구성·장시간 실행·부하·운영 보안 감사: **미실행**.

## 최종 추가 실행 결과

- **언어 30/30 그룹 통과:** `locales.json`. ko/en/ja/zh-CN/zh-TW/mn/th/vi/ar/ru/km/es/fr/it/az 각각 360·1440px에서 첫 화면과 네 내부 경로, 총 150 조합. 선택기 포인터 조작 가능 여부·언어 변경·새로고침·긴 문구/가로 넘침·예시/생성 결과·입력/주소 보존 검사. 원어민 검수는 없음.
- **접근성 4/4 그룹 통과:** `accessibility.json`. 부모의 미연결 대상 UI와 복구, 주간 선택 방향키/서버 저장/새로고침, 네 핵심 화면 조작 요소의 이름/44px 영역, en-GB 지역 분리와 월 이름을 쓴 날짜. 스크린리더·전체 WCAG 적합성 인증이 아님.
- **실패·충돌·원본 3/3 그룹 통과:** `edge.json`. 서버가 이미 저장했으나 브라우저에는 실패로 보인 상황에서 새로고침·재시도해도 계획 하나, 409 입력 보존·최신 버전 재시도, 자소서 선택 원본 버전 변경 후 차단·내용 유지·재확인 저장.
- **최종 반응형 5/5 그룹 통과:** `responsive.json`. 부모/본인/교사를 각각 360·768·1440px에서 확인. 일반 가족 DOM에 교사 메뉴 없음, 교사는 별도 틀. 360px 교사 아랍어 RTL·새로고침 및 전체 15개 언어의 재로딩 중 한국어 프로그램 메뉴가 생성되는지 관찰해 미관찰.
- 합계 **55개 브라우저 검사 그룹 통과**. API 회귀 16+5, 타입 검사, 번역 구조 검사도 별도 통과했다.

추가로 라디오 방향키/Home/End·그룹 이름, 이름 없는 저장 진행 버튼을 보완했다. 개발 배너가 상단 조작을 가리던 문제를 제거하고 헤더 줄바꿈을 보완했으며, 최종 언어·접근성·반응형 검사에서 재검증했다.

초기 긴 단일 렌더러 검사에는 시간 초과·브라우저 중단이 있었다. 언어별 독립 컨텍스트로 재실행한 최종 JSON은 30/30 통과이며, 중단된 시도를 통과로 간주하지 않았다. 기존 API 재실행 때는 본인 개인 메모를 빈 값으로 가정하던 테스트를 기존 값 유지 비교로 바꿨다. 개인정보 격리 검증을 완화한 것이 아니라 기존 가상 자료가 있어도 같은 경계를 검증하도록 수정한 것이다.

가상 제목/이유/저장 원본의 한국어·영어 혼용은 입력/원본을 번역하지 않는 동작이다. 현재 UI·새 예시·현재 생성 모형 설명과 구분한다.

최종 검토 화면 변경 후 `review-isolation.json` 추가 1개 검사도 통과했다. 일반 홈에 검증 메타데이터가 없고, `/review`에는 실제 증거 참조와 부분/없음 상태가 있으며, 인쇄에서는 내부 검토 내용이 숨겨진다. 위 핵심 55개 합계와 구분한 추가 검사다.
