# MY NUVIA 개발자 인계

## 범위와 운영 경계

이 앱은 **독립적인 실행 가능 기능 검토본**이다. 기존 FeelGood 앱, 배포, 공개 주소를 수정하지 않았다. 운영 로그인 오류가 해결됐다는 증거가 아니다. 기존 운영 통합 소스는 확보하지 않았으며 기존 플래너·히스토리·AI 자소서 회귀를 검증했다고 주장하지 않는다.

실제 학생 이름·점수·결과지·토큰을 가져오거나 수집하지 않는다. 입력은 가상 자료만 사용한다. 점수 해석, 새로운 유형, 인지능력 향상률, 진단, 순위, 연속 출석 목표는 범위에 없다.

## 검토 계정과 인증

- `/review`에서 명시적으로 가상 부모·어린이·청소년·성인·교사를 선택한다.
- 계정 선택은 **공개된 검토용 계정 진입 장치**다. 누구나 검토 공간에서 가상 교사 계정을 선택할 수 있다. 따라서 운영 신원 확인·교사 자격 증명으로 사용할 수 없다.
- 무작위 세션 쿠키는 HttpOnly/SameSite=Lax이며 서버에는 해시만 보관하고 30분 만료를 적용한다. 실제 FeelGood 토큰, 관리자 토큰 또는 비밀번호를 사용하지 않는다.
- 서버가 세션 역할과 고정된 가상 대상자 관계를 확인한다. 주소·요청의 role 값을 바꾸는 것으로 권한을 얻지 못한다.
- 가상 부모: 어린이 A와 청소년 B만. 가상 본인: 해당 본인만. 가상 성인 C는 부모와 연결하지 않음. 가상 교사: 어린이 A의 명시적으로 공유한 활동만.
- 가족 API와 교사 API는 상호 분리한다. 교사는 가족 작업공간 전체를 요청할 수 없다.

## 독립 서버 저장 범위

개발 데이터베이스의 `nuvia_review_workspaces`에 가상 계획·단계·실행 상태·누적 시간·활동 기록과 작성자별 메모·관찰·문장 틀 초안·주간 선택을 저장한다. `nuvia_review_sessions`는 검토 세션의 해시·계정·만료만 저장한다.

가상 계정은 검토자들이 함께 쓰는 고정 계정이다. 같은 가상 계정을 쓰는 다른 사람은 그 가상 계정의 데이터를 볼 수 있다. **실제 개인정보를 입력하면 안 된다.** 현재 독립 서버 저장과 실제 FeelGood 계정 연동은 별개다. 운영 보존 정책·삭제 정책·감사·실사용 동의는 구현하지 않았다.

서버의 대상자별 행 잠금 트랜잭션, 버전 비교, 요청 ID 중복 방지로 충돌·중복 생성을 처리한다. 성공한 서버 응답만 저장 성공이다. 타이머의 경과 시간은 서버 시작 시각과 누적 시간을 기준으로 계산한다. 타이머 종료와 과제 완료는 별개다.

개인 메모는 계정별 분리, 부모 관찰은 부모만, 자소서 초안은 본인만 읽는다. 교사 응답에는 메모·관찰·초안 필드가 없다. 부모 작성 활동은 본인 자소서의 근거로 사용하지 못한다. 본인이 직접 선택한 본인 작성 기록과 원본 버전만 문장 틀에 연결한다.

## 실행한 검사

2026-11-06 `node scripts/src/nuvia-api-check.mjs` 성공. **브라우저 E2E가 아니라 HTTP API 통합 검사**이며 가상 검증이라고 표시한 데이터를 서버에 남긴다.

| 익명 작업공간 요청 | 401 | API 검사 |

| 본인의 다른 사람·교사 데이터 요청 | 403 | API 검사 |
| 교사의 담당 외 학생·가족 데이터 요청 | 403 | API 검사 |
| 성인 본인 범위 | 다른 자녀 403 | API 검사 |

두 쿠키 세션의 HTTP 상태 공유는 실제 두 물리 기기의 화면 조작을 검증한 것과 다르다.

추가로 `node scripts/src/nuvia-sharing-check.mjs`의 5개 공유 검사가 성공했다. 담당 교사는 명시적으로 공유된 가상 기록을 볼 수 있고, 같은 대상자의 미공유 기록과 비공개 메모·초안은 받지 못한다. 번역 구조·화면 캡처·미실행 범위와 심각도는 [검증 기록](MY-NUVIA-VERIFICATION.md)에 구분했다.

## 운영 소스 확보 후 비교 적용 순서

1. 현재 운영 소스·버전과 실제 라우팅, 기존 프로그램 진입, 결과지 언어 파라미터 계약을 확보한다. 운영 배포는 별도 승인 없이 하지 않는다.
2. 기존 인증의 사용자·역할·자녀 연결·성인 당사자 동의·교사 담당 및 공유 권한을 서버에서 검증하는 어댑터로 교체한다. 가상 계정 진입은 제거한다.
3. 기존 플래너의 한 실행, 시간 미정, 중단·동일 위치 복귀, 종료/완료 분리, 돌아보기·메모 동작을 비교한다.
4. 결과지 → 목적 활동 → 만료 → 재로그인의 언어·자녀·선택 활동·복귀 위치 계약을 실제 로그인에 연결한다. 공개 URL 외부 리다이렉트는 허용 목록으로 제한한다.
5. 히스토리의 기존 검증된 교육 콘텐츠와 연결한다. 이 검토본의 가정 모형을 실제 역사나 기존 프로그램 대체물로 취급하지 않는다.
6. 선택된 활동 원본과 버전, 편집된 근거 문장만 실제 자소서 작성기에 전달한다. 부모 관찰·개인 메모는 기본 포함 금지다.
7. 실제 AI를 붙이기 전 동의, 개인정보 최소화, 결과 검토, 허위 성취 방지와 미연결 안내를 유지한다.
8. 실제 저장소·보존·삭제·감사·세션 수명·접근 제어를 운영 정책에 맞추고 동시 수정·오프라인·장애 재시도를 검증한다.
9. 15개 언어의 원어민 검수와 접근성 검수를 완료하고 운영 승인 이후에만 별도 배포 절차를 진행한다.

## 실제 브라우저 검증 추가

개발 미리보기에서 부모·본인·교사의 실제 브라우저 조작, 두 독립 BrowserContext, 실패·세션 복구를 실행했다. 세부 요구사항과 결과 JSON/화면 캡처 연결은 [브라우저 실행 증거](MY-NUVIA-BROWSER-EVIDENCE.md)를 참조한다. 이전 초기 화면 캡처와 API 검증만으로 내부 화면을 검증했다고 하지 않았던 제한은 이 추가 실행 범위에 한해 해소됐다.

## 미실행 또는 별도 확인이 필요한 검사

15언어 확장 실행의 최종 매트릭스·소스 지문·출력 검사와 결함/해결 기록은 [확장 QA 인계](MY-NUVIA-FULL-QA.md)를 참조한다. 과거 55개 검사와 최종 전수 실행을 합쳐 언어별 통과 수를 부풀리지 않는다. 기본 방문자는 visitor, 자동화는 qa-*, 이전 자료는 legacy에 보존하며 /review에서만 자료 공간을 명시한다.

- 실제 FeelGood 인증·운영 프로그램·운영 데이터·운영 회귀: **미확인 / 미연결**.
- 브라우저 핵심 상호작용은 위 증거 범위에서 실행. 실제 소프트 키보드·실기기 터치·스크린리더, 실제 태블릿·휴대폰 간 이어하기: **미실행**.
- 전체 15개 언어의 원어민 의미·문화·접근성 검수: **미실행**. 구조 검사가 번역 품질 검수를 대신하지 않는다.
- 서버 재시작·네트워크 단절·장시간 실행·대규모 부하·운영 보안 감사: **미실행**.
- 첫 렌더의 해상도별 시각 검사와 정적 타입/번역 검사는 별도 검증 기록을 참조한다. 화면 캡처만으로 입력·새로고침·만료 복귀가 동작했다고 기록하지 않는다.
