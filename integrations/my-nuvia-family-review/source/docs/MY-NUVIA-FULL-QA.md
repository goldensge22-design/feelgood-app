언어: ko, en, ja, zh-CN, zh-TW, mn, th, vi, ar, ru, km, es, fr, it, az.

각 언어·화면 조합에서 부모, 어린이 당사자, 교사를 별도로 실행한다. 따라서 목표는 **45개 언어·화면 조합 / 135개 역할 사례**다. 부모에게 자소서 메뉴는 있지만 당사자의 작성·초안은 열리지 않는 것이 올바른 결과다. 교사에게는 가족용 프로그램 탐색이 없는 별도 화면이 올바른 결과다.

실행 원장은 `generated-artifacts/nuvia-qa-full/`이다. **최종 집계 파일이 없는 시도, RUNNING, 중단된 시도, FAIL을 통과로 세지 않는다.** 스크린샷과 실제 버튼·입력·서버 응답 검사를 구분한다.

- 작업 시작: `start.json` — 당시 Git 기준과 작업 트리, 소스 SHA-256.
- 최종 실행 시작: `final-start.json`.
- 실행 묶음별 `results.json` — 언어·정확한 뷰포트·역할·단계·실행 시각·통과/실패·DOM/axe/키보드 결과.
- 묶음별 `finish.json` — 시작/종료 소스 지문 일치 여부.
- 최종 집계: `final-report.json` — 행별 결과, PDF 검사, 지문 일치, 합계.
- 검토 화면용 `public/review-qa-summary.json` — 비민감 요약만. 일반 화면에서는 사용하지 않는다.

지문은 웹/API 소스, API 명세, 재현 스크립트의 내용을 계산한다. 보고서·스크린샷·PDF·집계 JSON은 검사 대상 동작을 바꾸지 않는 실행 산출물이므로 지문에 포함하지 않는다. Git 기준만 같고 수정 파일이 다른 경우를 동일 버전으로 간주하지 않는다.

1. `/review`에서 해당 언어로 가상 계정과 자료 공간을 선택·확인해 진입.
2. 홈의 세 프로그램 카드와 권한 없는 요소 미생성 확인.
3. 첫 일주일 카드 클릭 → 실제 수정 가능한 초안 → 선택 언어 예시 → 긴 제목·세 단계·시간 미정.
4. 쉬운 첫 단계/아이에게 말하기/못 한 날 도움말의 미리보기 → 보류/수정/수락 조작. 실제 AI가 아닌 고정 도움말이다.
5. 저장 전 서버 미생성 → 가상 503 실패 → 실패 표시·입력·버전 보존 → 새로고침 → 중복 클릭 재시도 → 계획 하나.
6. 명시적 시작 → 다음 단계 → 다른 시작 버튼 비활성 → 실행 중 미저장 입력 작성.
7. 다른 언어와 원래 언어를 연속 선택 → 과제·시작 시각·단계·입력·자녀·경로·주소의 별도 정보 보존. 렌더 프레임에서 프로그램 메뉴와 선택 언어가 불일치하는지 관찰.
8. 새로고침 → 서버 세션 폐기 → 저장 401 → 만료 이유·재진입 → 원래 목적지·언어·과제·입력 복구.
9. 중단 → 새로고침 → 같은 단계·누적 시간 → 이어하기 → 실행 종료(ended).
10. 조금 해봄 선택·돌아보기 저장 → 아직 ended임 확인 → 명시적 마침 선택·돌아보기 저장 → completed.
11. **탐색 메뉴 클릭**으로 주간 요약에 실제 생성 기록 확인·유지 선택.
12. 별도 1분 타이머 계획을 실제 UI로 생성·시작. 브라우저 시계를 통제해 만료 안내를 표시하고 서버 상태가 running인 것을 확인. 자동 완료되지 않으며 사용자가 종료한다. 실제 1분 대기를 했다고 표현하지 않는다.
13. **탐색 메뉴 클릭**으로 히스토리 → 자원 선택·순서 버튼 → 이유·도움 → 모형 실행 → 자원 수정·다시 실행 → 결과 변화 → 기록 저장.
14. 히스토리에서 플래너 초안으로 가져오기 → 저장 전 미생성 → 사용자 확인 저장 → 원본 기록 연결.
15. **탐색 메뉴 클릭**으로 AI 자소서:
    - 부모: 당사자 비공개 초안·작성 폼이 없고 안내만 있음.

    - 명시적 교사 공유로 원본 버전을 바꾼 후 기존 초안 저장 차단·입력 보존 → 원본 재확인 → 다시 저장.

- 언어 선택기의 현재 언어·44px 높이·상단 직접 노출·**물리적 오른쪽 위치**. 아랍어의 문서/본문 RTL과 분리한다.

- 각 주요 화면에서 200% 텍스트 확대 후 같은 검사.

## 정적·번역 보조 검사

`nuvia-qa-static.mjs`로 15개 사전의 265개 키 및 언어별 첫 일주일 3개 문구를 검사한다. 키 일치·중복·빈 값·자리표시자·위험 문자열·비한국어 사전의 한글 잔존과 실제 지원 상태를 검사한다.

15개 사전에 대해 의미·버튼 의도·종료/완료/중단·비공개/공유·연령/성별·교육용 가정·실제 AI 미연결의 자동 보조 의미 검토도 실행했다. 결과는 `assisted-meaning-review.json`, 주간 수 표현의 별도 검토는 `weekly-number-assisted-review.txt`다.

보조 모델의 자체 “검토 키 개수” 추정은 실제 키 개수와 달랐으므로 커버리지 증거로 쓰지 않는다. 결정적인 키 개수는 정적 검사 결과다. “AI 자소서” 이름을 없애라는 제안은 사용자가 지정한 프로그램명과 충돌하므로 적용하지 않았다. 내부 체크리스트의 항목명을 실제 연결 주장으로 오인한 제안도 적용하지 않았다. 원문의 종료/돌아보기 구분을 임의로 통합하거나 정상 번역 전체를 재생성하지 않았다.

영어의 `1 recorded days`는 숫자와 직접 수 일치를 요구하지 않는 **Recorded days: 1** 형식으로 고쳤다. 스페인어·프랑스어·이탈리아어도 같은 의미의 항목명:숫자 구조를 사용한다. 아랍어는 “기록된 날의 수”, 러시아어는 “기록이 있는 날의 수”를 명시한다. 나머지 언어의 기존 수량 표현은 유지한다. 숫자 0/1/2/3/11/21에 대한 자동 보조 검토의 의심 항목은 원어민 확정 판정이 아니다.

모든 사전은 정적 import다. 비동기 언어 API/로더가 없으므로 **늦은 번역 응답·번역 API 실패는 해당 없음**이다. 일반 앱 JS 전체 로딩 실패를 번역 실패 복구 통과로 위장하지 않는다.

추가 실제 브라우저 fallback 검사(`fallback.json`)는 15언어 각각을 선택·저장한 후 `lang=unsupported-review-language`로 플래너를 새로 열어 저장된 지원 언어와 문서 언어/방향이 유지되는지 확인했다. 이어 15언어를 연속 선택하는 동안 신규 번역 요청이 0건인지 확인했다(15+1 통과). 재현은 가상 성인 계정으로 진입→각 지원 언어 선택→위 미지원 언어 주소 새로 열기→선택기/문서 언어·방향 확인 순서다. 이 부가 검사는 45개 핵심 조합의 수에 더하지 않는다.

**원어민 검수는 15언어 모두 미실행이며, 외국어 초안을 ready로 올리지 않았다.**

## 출력과 개인정보

앱에 전용 PDF/DOCX 다운로드·내보내기 기능은 없다(해당 없음). 실제 제공되는 브라우저 인쇄를 대상으로 실행·히스토리 결과·주간 요약·저장된 자소서의 A4 PDF를 생성한다. 결과 파일명은 언어·화면·역할·출력 화면을 포함한다.

인쇄에서 탐색·조작 버튼·입력·개인 메모·부모 관찰·선택용 원본 목록·내부 QA 정보를 제외한다. 저장된 당사자 초안과 연결 원본 제목은 보존한다. 내용 제목까지 숨기던 광범위한 header 인쇄 규칙을 좁혔다. PDF 텍스트 추출에서 한글 잔존·내부 메타데이터·빈 출력·대체 문자와 페이지 수를 검사한다. PDF 생성 성공만으로 모든 페이지의 수동 시각 검수를 통과했다고 하지 않는다.

## 방문자와 자동화 자료 분리

방문자는 기본 `visitor` 자료 공간, 자동화는 실행·언어·화면별 `qa-*` 자료 공간을 사용한다. 과거 자료는 `legacy`에 **삭제·재번역 없이** 보존한다. 전용 검토 화면에서만 자료 공간을 명시해 들어갈 수 있다. 자료 공간은 실인증도 역할도 아니며 담당 관계를 추가하지 않는다.

공간은 서버 세션에 저장한다. 일반 데이터 요청의 body/query 공간·역할을 바꿔도 다른 공간이나 교사 권한으로 이동하지 않는다. 브라우저 복구 초안도 공간·계정·대상별로 나눈다. 신규 방문자에게 이전 `fictional-browser-*`, 공유 검사, 영문 모형 기록을 노출하지 않는다.

`isolation.json`: 과거 부모 자료 해시를 전후 비교, 격리된 QA 공간에 생성, 방문자 데이터에서 미노출, 방문자 360px 홈/플래너 등에서 이전 검사 표식 부재, 한국어·영어·아랍어 신규 예시 확인. 기존 직접 작성 기록을 지운 것이 아니다.

## 별도 회귀와 남은 사항

API 16개 및 공유 경계 5개, 저장 응답 유실 후 중복 방지·409 충돌 입력 보존·원본 재확인, 독립 두 브라우저 세션 저장/이어하기, 키보드/날짜/검토 공간 격리 검사를 별도 실행한다. 전부 자동화 전용 자료를 사용한다.

- **P0:** 최종 실행에서 실제 잔여 치명 실패가 있으면 완료 판정 금지.
- **P1 운영 전환 차단:** 가상 계정은 실제 신원 확인이 아니다. FeelGood 인증·프로그램·운영 동기화·실제 AI 연결은 미완료다. 운영 소스 확보·승인·보존/삭제/감사 정책 없이는 실제 자료 사용 금지.
- **P2 사람 검수:** 실제 iOS/Android·소프트 키보드·스크린리더·원어민 의미/문화 검수·전체 출력 수동 검수·다른 브라우저 엔진은 미실행.
- **P3:** 비차단 번들 크기 및 기존 소스맵 경고.

“15언어 모든 QA 완료” 대신 **구체적인 자동화 매트릭스의 실행/통과 수와 남은 사람 검수**를 함께 보고한다.

## 재현

웹/API 관리 워크플로를 실행한 개발 환경에서:

```sh
node scripts/src/nuvia-qa-baseline.mjs final-start
node scripts/src/nuvia-qa-static.mjs
QA_LANGS=ko,en,ja QA_RUN=done-1 node scripts/src/nuvia-qa-matrix.mjs
QA_LANGS=zh-CN,zh-TW,mn QA_RUN=done-2 node scripts/src/nuvia-qa-matrix.mjs
QA_LANGS=th,vi,ar QA_RUN=done-3 node scripts/src/nuvia-qa-matrix.mjs
QA_LANGS=ru,km,es QA_RUN=done-4 node scripts/src/nuvia-qa-matrix.mjs
QA_LANGS=fr,it,az QA_RUN=done-5 node scripts/src/nuvia-qa-matrix.mjs
node scripts/src/nuvia-qa-report.mjs done-1 done-2 done-3 done-4 done-5
node scripts/src/nuvia-qa-isolation.mjs
```

재실행은 고유 QA_RUN을 사용한다. 이전 실행 공간의 기록을 삭제해 초기화하지 않는다. 요약 생성기는 소스 지문 불일치나 실패가 있으면 실패 종료한다. 운영 서비스·공개 배포는 실행하지 않는다.
