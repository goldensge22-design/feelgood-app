# 독립 검토본 검증 기록

> 과거 검증 범위의 기록이다. 2026-11-06 최종 15언어 × 3뷰포트 × 3역할 실행과 인쇄 결함 수정 후 재검사는 [최종 QA 인계](MY-NUVIA-FULL-QA.md)를 기준으로 한다. 과거 검사 수를 최종 통과 수에 합산하지 않는다.

최종 검증일: **2026-11-06**. 범위는 개발 미리보기와 공개된 가상 계정뿐이다. 운영 배포·운영 패치 검증이 아니다.

## 실행한 검사

- 실제 Chromium 152 브라우저 **55개 검사 그룹 통과**:
  - `planner.json`: 3개. 부모의 첫 일주일 초안 수정·확인 저장, 중복 클릭, 실행·중단·새로고침·이어하기·종료/완료·돌아보기·주간 기록.
  - `history-story-security.json`: 5개. 본인 히스토리 모형과 계획 전이, 선택 원본만 자소서 문장 틀에 포함, 공유, 가족·교사 화면/서버 거부.
  - `recovery.json`: 5개. 503 입력 보존·새로고침·재시도, 두 독립 브라우저 세션, 실행 중 언어 변경, 세션 폐기 후 복귀, 키보드 입력·Enter 저장.
  - `accessibility.json`: 4개. 미연결 대상 복귀, 주간 선택의 방향키와 서버 저장, 주요 화면 조작 요소 이름·44px 터치 영역, 영국 지역 설정·날짜.
  - `edge.json`: 3개. 서버 저장 후 응답 유실·새로고침·재시도에도 중복 없음, 409 입력 보존과 재시도, 자소서 원본 변경 시 차단·재확인 후 저장.
  - `locales.json`: **30개**. 15개 언어 × 360/1440px. 각 경우 첫 화면·플래너·히스토리·자소서·주간 돌아보기 **5경로, 총 150 언어/너비/경로 조합**. 언어 선택기 실제 조작 가능 여부, 새로고침 유지, 문서 언어/방향, 긴 문구 클리핑·가로 넘침, 플래너 예시·입력 보존, 히스토리 자원·생성 결과의 선택 언어 일치 확인. 영어·아랍어·크메르어·태국어 내부 화면 캡처 포함.
  - `responsive.json`: 5개. 부모·본인·교사를 각각 360/768/1440px에서 확인, 별도 교사 틀·가족 메뉴, 모바일 아랍어 교사 화면, 15개 언어 새로고침 중 한국어 프로그램 메뉴가 잠깐 생기는지 DOM 변경 관찰.
- 기존 API **16개 그룹 + 공유·권한 5개** 회귀 검사 통과. HTTP 검증과 브라우저 검증을 별도로 유지.
- 전체 워크스페이스 TypeScript 검사 성공. MY NUVIA Vite 빌드는 관리 서비스의 PORT/BASE_PATH 값으로 성공. 이 빌드는 공개 배포가 아니다.
- 번역 구조 검사 성공: **15 × 265 키 + 첫 일주일 45문구**. 누락·빈 값·자리표시자·위험 문자열 검사이며 원어민 의미 검수가 아니다.
- 최초 한 렌더러를 오래 유지한 언어 검사에서 대기 시간 초과·브라우저 중단이 있었다. 언어별 독립 컨텍스트와 공유 메모리 의존을 줄인 실행으로 최종 30/30 통과했다. 중단된 시도를 앱 통과 증거로 세지 않았다.

실행 JSON·캡처·API 출력: `generated-artifacts/nuvia-browser/`. 재현 스크립트: `scripts/src/nuvia-browser-*.mjs`. 상세 요구사항별 증거는 [브라우저 실행 증거](MY-NUVIA-BROWSER-EVIDENCE.md)를 참조한다.

검토 공간 증거 표기를 반영한 뒤 `review-isolation.json` 추가 1개 검사도 통과했다. 일반 홈에는 내부 검증 정보가 없으며 `/review`의 증거·미완료 상태는 인쇄에서 숨겨진다. 핵심 55개와 구분한다.

## 수정 및 남은 심각도

- **수정·회귀 통과:** 교사의 담당 외 대상 주소에서 빈 화면 대신 거부 이유·허용 대상 복귀 제공. 히스토리 생성 결과가 언어 변경을 따르도록 수정. 세션 부재/만료 이유 표시. 라디오 선택 방향키·Home/End와 그룹 이름 보완. 개발 배너가 상단 조작을 가리던 문제 제거, 가족 헤더 줄바꿈 보완.
- **운영 전환 차단 / 높음:** 공개 가상 계정은 실인증이 아니다. 실제 개인정보 저장·운영 서비스 사용 금지. FeelGood 인증·관계 검증 어댑터와 보존·삭제·감사 정책이 필요하다.
- **번역 품질 / 중간:** 한국어 외 기계 보조 초안은 원어민 미검수. UI 검사 통과를 의미·문화 검수 완료로 올리지 않았다.
- **실기기·접근성 / 중간:** 실제 소프트 키보드·안전영역·터치·스크린리더·다른 브라우저 엔진은 미실행.
- **운영 통합 / 미확인:** 현재 운영 소스 확보 후 비교와 별도 승인이 필요하다. 장시간·재시작·부하·운영 보안 감사도 미실행이다.
- **빌드 경고 / 낮음:** 번들 크기 권고와 기존 tooltip 소스맵 위치 경고가 있으나 빌드는 성공했다.

남은 실행 불가·권한 우회·데이터 손실·핵심 오류는 **이번에 실행한 검증 범위에서는 발견되지 않았다**. 미실행 범위의 무결성을 보증하는 표현은 아니다.

저장된 가상 기록·사용자 입력은 생성 당시 언어와 원본을 유지한다. 언어 선택으로 과거 기록을 자동 번역하지 않는다. 새 가상 예시·현재 모형 출력과 UI만 선택 언어를 따른다. 검증 기록은 방문자의 실제 성과나 검사 결과가 아니다. 운영 서비스·공개 주소는 변경하지 않았고 운영 배포는 실행하지 않았다.
