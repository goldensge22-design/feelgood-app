# NUVIA HISTORY 비교·장면·연령 데모 규칙 v1

- 상태: `DRAFT CANDIDATE — 사용자 화면 검토용`
- 적용 범위: W24-C2 계획 경로의 유아·중학생·고등학생 데모
- 상위 기준: HISTORY MASTER v1.1의 질문 정합성, 7·8쪽 구분, 비교 계약
- 비적용 범위: 동결 기준본 수정, 전체 48주, 다른 PASS 경로, 운영 기록

## 비교 기록이 없을 때

1. 비교 레코드를 다른 단계의 글·그림·선택값으로 채우지 않는다.
2. 책 7쪽과 8쪽에 `비교 기록이 없어요`를 표시한다.
3. 7쪽은 실제 역사 핵심 요약과 나의 이야기 원본을 함께 보여 준다.
4. 8쪽은 결과 공개 전 최초 예측 스냅샷과 실제 역사 핵심 요약을 함께 보여 준다.
5. 실제 역사 요약은 승인된 콘텐츠 키를 사용하며 런타임 AI로 만들지 않는다.
6. 누락 상태는 표시용이며 사용자 원문 필드에 저장하지 않는다.

## 이야기와 이미지 정합성

1. 자유 글의 의미를 자동 해석하여 이미지를 고르거나 생성하지 않는다.
2. 이미지 선택은 구조화된 목표·방법·결과 ID에서만 결정한다.
3. 선택 결과와 일치하는 승인 이미지가 없으면 관련 없는 이미지를 대체하지 않는다.
4. 이 경우 `승인 이미지 준비 중` 상태를 표시하고 텍스트·사용자 그림·진행 기록은 보존한다.
5. 사용자가 직접 그린 그림은 나의 이야기 페이지에만 표시한다. 비교 그림으로 자동 복사하지 않는다.
6. 실제 역사, 변경 조건, 사용자 상상은 서로 다른 `factMode`와 장면 역할을 유지한다.

## 연령 난이도

- 유아: 한 질문·한 행동, 그림과 짧은 선택, 목표→방법→결과→유지/수정.
- 중학생: 직접 효과와 정확성 위험을 함께 확인하고 판단 이유 하나를 남긴다.
- 고등학생: 복수 원인, 반론, 불확실성을 구분하고 판단 근거와 남은 한계를 각각 남긴다.
- 연령이 높아져도 선택지 수만 늘려 난이도를 만들지 않는다.
- 세 연령 모두 같은 역사 조건과 sourceFactId를 공유하며 요구하는 인지 행동의 깊이만 달라진다.

## 완료와 저장

- 필수 PASS 행동 완료와 비교 표현 저장은 별도 상태다.
- 비교가 없어도 책의 파생 보기는 만들 수 있으나 누락 상태를 명시한다.
- `comparisonKind=history|prediction`, 별도 eventId, 같은 resultId 계약은 유지한다.
- 데모 기록은 `demo:age-v1:` namespace와 연령별 localStorage 키를 사용하며 운영 기록으로 승격하지 않는다.

## 질문·선택지 관련성 — 2026-09-21 사용자 추가 지시

상위 의미 계약은 저장소 루트의
`nuvia-history-w24/outputs/NUVIA_HISTORY_MASTER_RULES_v1.1/QUESTION_CONTENT_ALIGNMENT_RULE_v1.1.md`
및 마스터 14장을 참조한다. 동결 원본은 유지하고, 이 절은 현재 데모의 구체적인 적용·검수 기준이다.

1. 시스템 질문과 각 선택지에 현재 conditionId, 질문 목적, 사용자 행동, 예상 결과의 연결을 확인한다. ‘현재 조건에서 왜 이 항목을 고려해야 하는가’를 설명할 수 없으면 노출하지 않는다.
2. 사건과 같은 시대의 단어라는 이유만으로 관련 있다고 판정하지 않는다. 현재 바뀐 속성·사용자의 목표·결과 사이의 인과 연결이 필요하다.
3. 조건에 없던 평가 기준을 예고 없이 별도 목표로 추가하지 않는다. 정확성처럼 방법 선택에서 발생하는 위험은 해당 방법의 결과에 구체적으로 연결해 설명한다.
4. 질문 뒤에 각 선택지를 대입해 직접 답하는지 사람이 읽는다. 목표를 묻는 곳에는 목표, 방법을 묻는 곳에는 방법을 제시하며 서로 다른 층위를 섞지 않는다.
5. 계획 과제에 무관한 오답을 난이도 조절용으로 넣지 않는다. 의도적인 방해 정보는 주의 과제에서만 허용하며 내부 검수 자료에 표적 단서·방해 이유·배제 행동을 명시한다. 학생에게 정답 표시는 하지 않는다.
6. 중·고등 판단 이유는 고정 이유 카드로 대신하지 않는다. 선택한 방법과 예상 결과를 입력칸 바로 위에 유지하고 직접 쓰게 한다. 중학생은 유지/수정 이유, 고등학생은 이유와 결과가 달라질 조건·추가 확인 자료를 각각 남긴다.
7. 자유 글은 빈 입력 여부만 검사하며 의미의 옳고 그름이나 글자 수로 사고 능력을 판정하지 않는다. 목표→방법→결과 확인→유지/수정 행동이 선행되어야 한다.
8. 방법이나 목표가 바뀌면 새 결과 확인과 유지/수정 결정을 다시 요구한다. 작성 중인 이유는 초안으로 보존하고 새 결정 전에는 완료로 처리하지 않는다. 과거 이유 선택 ID는 보존하되 직접 작성 원문으로 변환하지 않는다.
9. 기계 검사는 필수 입력·단계·저장/복구와 참조를 검사한다. 문항의 실제 관련성·역사적 타당성·연령 적합성은 질문/선택/후속 결과를 함께 읽는 사람 검수가 필요하며 자동 승인하지 않는다.
10. 공개 난이도 검토 데모의 연령 전환은 QA 모드에서만 제공하며 연령별 기록을 보존한다. 운영 학생 화면의 연령 자동 적용 규칙은 변경하지 않는다.

### 이번 수정의 의미 대조

| 항목 | 수정 전 | 수정 후 및 현재 조건과의 연결 |
|---|---|---|
| 중학생 목표 | 정보 접근 / 내용 정확성 | 직접 볼 수 없는 사람에게 내용 전달 / 원문 확인 기회 확대: 둘 다 열람 제한에 대응 |
| 고등학생 목표 | 접근 확대 / 신뢰성 보존 | 열람 제한 대상에게 전달 / 원문 확인 기회 확대; 신뢰성은 방법별 부작용에서 검토 |
| 판단 이유 | 직접 효과·정확성 위험 카드 | 자기 방법과 예상 결과를 보면서 직접 작성 |
| 고등학생 한계 | 미리 쓴 불확실성 카드 | 결과가 달라질 조건과 추가 자료를 직접 작성 |

문구 수정만으로 사용자 검수 완료로 승격하지 않는다. 전체 48주 문항에 적용 완료했다고 표시하지 않는다.
