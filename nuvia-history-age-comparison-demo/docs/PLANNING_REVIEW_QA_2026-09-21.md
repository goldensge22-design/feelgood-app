## 확인한 불변식

- 한계 글 없이 고등 완료 불가. 공백만 입력한 글은 통과하지 않음.
- revise만 선택하고 같은 방법을 유지한 채 완료 불가.
- 방법 변경 전 글/정보/판단은 history에 보존. 가져온 글은 재확인 전 완료 불가.
- 정보·글을 다시 편집하면 충분성 판단과 최종 결정을 다시 요구.
- 최초 예측은 돌아가기·새로고침 이후에도 원문/ID 불변. 읽기 전용 재진입 가능.
- 기존 ageComparisonDemo.v1 키에 넣은 테스트 sentinel 불변. 이번 데이터는 새 key/namespace만 사용.
- 사용자 글의 HTML은 escape하며 자동 평가·요약하지 않음.
- 책 4쪽에서 시스템 선택 목록과 학생 원문을 분리. 미확인 상태 유지.
- 책 7쪽에는 실제 역사와 이야기+독립 history 비교, 8쪽에는 최초 예측과 실제 역사+독립 prediction 비교. 미룬 비교는 누락으로 표시하고 타 단계 입력으로 채우지 않음.
- 비교 두 레코드의 eventId와 comparisonKind 분리, 같은 resultId 유지. 원문의 앞뒤 공백 보존.
- 테스트한 페이지 오류/자산 HTTP 오류 0. 가로 넘침과 컨트롤 화면 밖 배치 없음. PC 입력 화면 및 모바일 판단 화면 직접 시각 점검.
- 자동화 캡처: `../qa-reconsider/`. `results.json`의 시간은 자동화 실행값이며 실제 학생 소요 시간의 근거로 사용 금지.
