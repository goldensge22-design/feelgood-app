## 원문·기록 보호

- 새 namespace: `nuviaHistory.teenWritingDemo.v1`. 기존 키를 읽어 변환하지 않는다.
- resultId는 `demo:teen-writing-v1:`이며 runMode=demo 불변. 조건·예상·이야기·비교는 같은 resultId 및 attemptId를 참조한다.
- 각 기록을 `.record.<resultId>`로 보존하고 연령별 이어쓰기 포인터를 별도로 둔다. new=1은 새 기록을 만들며 이전 기록을 삭제하지 않는다.
- 최초 예상은 expression 원문 스냅샷. 뒤로 돌아가도 읽기 전용이며 결과 보고 덮어쓸 수 없다.
- 방법 변경은 실제 다른 방법을 골라야 하며 이전 방법의 입력은 기존 엔진의 history에 남는다.
- 저장한 이야기/완료한 계획을 수정하면 기존 작품·비교를 previousStoryVersions에 보존하고 새 비교는 미완료로 둔다. 이전 비교를 새 작품의 비교로 통과시키지 않는다.
- 그림은 옵션이며 새 이미지 생성·녹음·음성 노출 변경 없음. C-P1-01은 OPEN 그대로 유지한다.
- 학생 글·그림의 의미/사실성을 자동 판정하지 않는다. 화면의 학생 작성 라벨은 작성 주체 표시이지 검증 완료 표시가 아니다.
- 다운로드 기록 JSON은 사용자가 명시적으로 누를 때만 생성한다. 검토 자료 JSON/Markdown에는 학생 기록이 없다.

## 이미지와 i18n

- 기존 승인 공방 WebP 한 장을 재사용한다. 실제 장면의 교육용 삽화이며 개인 이야기에는 배경 참고라는 설명을 붙인다. 학생 결과의 정확한 재현이라고 하지 않는다.
- 자산은 기존 W24 레지스트리의 bytes/SHA-256과 대조한다. 새 아트·다른 사건 대체·런타임 생성 없음.
- 한국어만 제공. lang에 미지원 값이 있으면 본문을 렌더링하지 않고 한국어 선택 링크만 제공한다. 기존 기록은 보존한다.
- 새로운 학생 화면 문구는 기존 src/locales 구조의 ko-writing.mjs에 둔다. 기존 공통 i18n 검사기의 HISTORY 3건은 별도 OPEN이며 다국어 완료로 표시하지 않는다.

## 공개 검토 경계

이 데모는 규칙을 확인하기 위한 별도 실행본이다. 정식 W24 저장 계약의 대체·기존 기록 소급 전환·전체 연간 앱 승인·48편 완료·전체 연령/PASS 검수를 의미하지 않는다. 실제 학생의 난이도, 의미 이해, 소요 시간은 대상 학생 검토가 필요하다.
