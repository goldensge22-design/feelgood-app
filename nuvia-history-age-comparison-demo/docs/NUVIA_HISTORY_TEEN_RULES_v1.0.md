# NUVIA HISTORY 중·고등학생용 규칙서

**상태: 설계 규칙 확정 — 중·고등학생 적용 기준**
**실행 적용: 사건·경로별 계약 대조 및 검수 후 별도 승인**
**기존 프로그램과 저장 기록에는 자동 적용하지 않는다.**

**표기 안내:** **[조건부]**는 신규 적용 시 해당 사건의 자료와 활동 계약이 지원할 때만 적용한다는 뜻입니다. **[고등 격리 데모 합의]**는 고등 격리 데모의 방향으로 합의된 내용이며, 사건별 정식 적용은 별도 승인을 따른다는 뜻입니다.

## 0. 적용 범위와 지위

- 적용 대상은 중학생·고등학생 경로입니다. 유아·초등 규칙은 바꾸지 않습니다.
- 기존 공통 규칙을 대체하지 않습니다. 공통 i18n·반응형·접근성·Git 보호 규칙은 그대로 참조합니다.
- 기존 `resultId`, 최초 예상, 초안 복구, 데모·운영 기록 분리, 기존 기록 무변환 원칙을 유지합니다.
- 활동 단계와 이야기책 쪽수는 일대일로 묶지 않습니다. 저장·책 발행 계약은 별도로 유지합니다.
- 이 규칙서는 **설계 원칙**을 확정합니다. 사건별 구체적인 입력 구조, 저장 필드, 경로 구현까지 승인한 것이 아닙니다.
- 표와 원칙은 설계 기준이며, 특정 사건·조건에서 해당 경로가 승인되었거나 구현되었다는 뜻이 아닙니다.

## 1. 목적과 기본 흐름

활동의 중심은 **역사적 조건을 바꾸고, 달라질 과정을 구성한 뒤, 실제 역사와 비교하여 자신의 설명을 남기는 것**입니다.

**실제 역사 확인 → 변경 조건 선택 → 최초 예상 → PASS 필수 활동 → 내 이야기 구성 → 실제 역사와 내 이야기 비교 → 최초 예상과 실제 역사 비교 → 이야기책 정리**

| 구분 | 중학생 | 고등학생 |
|---|---|---|
| 핵심 요구 | 자신의 예상과 과정을 작성하고, 실제 역사와 다른 점 및 이유를 설명 | 중학생 흐름에 근거와 가정의 구분, 필요한 정보, 반증·한계 검토를 추가 |

## 2. 변경 조건과 최초 예상

**조건 선택**
- 학생은 해당 사건에 승인된 변경 조건 중 하나를 선택합니다.
- 선택한 조건은 예측·PASS 활동·이야기·비교의 공통 기준으로 계속 표시합니다.
- 조건의 의미를 활동 도중 조용히 바꾸거나 다른 조건을 추가하지 않습니다.
- 질문은 선택한 조건과 현재 수행할 행동에 직접 연결합니다.

**최초 예상**
- 최초 예상은 **선택한 변경 조건 아래에서 일어날 일에 대한 예상**입니다.
- 실제 역사 자료는 기존 승인 흐름에 따라 제공합니다. 다만 변경 조건에 대한 시스템의 결과 예시·피드백을 보기 전에 최초 예상을 확정합니다.
- 확정한 최초 예상 원본은 수정하지 않고 보존합니다. 생각이 바뀌면 별도 기록으로 남깁니다.
- 이후 최초 예상과 실제 역사의 비교는 정답 채점이 아닙니다. **다른 조건에서 예상한 내용과 실제 역사의 차이를 돌아보는 활동**임을 화면에 표시합니다.
- 선택형 문장은 생각을 돕는 자료일 뿐 학생의 설명을 대신하지 않습니다. 답을 먼저 제시하고 그대로 쓰게 하지 않습니다.

| 구분 | 중학생 | 고등학생 |
|---|---|---|
| 최초 예상에 포함할 것 | 예상 결과와 그렇게 생각한 이유 | 예상 결과, 근거로 삼은 정보, 아직 모르는 정보 |
| 추가 구분 | — | 직접 영향과 장기 가능성의 구분 [고등 격리 데모 합의] |

**고등 '직접 영향·장기 가능성 구분'의 적용**
- 고등 격리 데모에서 합의된 사항입니다. 사건별 정식 적용은 자료·입력 구조·완료 계약을 대조한 뒤 승인합니다.
- 장기 가능성을 쓰게 한다고 장기 결과를 단정하게 하지 않습니다. **"현재 자료로는 판단하기 어렵다"와 그 이유**도 유효한 답으로 허용합니다.

## 3. PASS 약점 훈련 — 이야기 구성 과정으로 연결

PASS 활동은 이야기와 무관한 별도 문제가 아닙니다. 학생이 수행한 행동이 이야기의 방법·단서·순서·관계 구성으로 이어져야 합니다.

| 영역 | 공통 필수 행동 | 중학생 | 고등학생 추가 [조건부] |
|---|---|---|---|
| 계획 | 목표 선택 → 방법 선택 → 결과 확인 → 유지 또는 실제 수정 | 유지·수정 판단과 그 이유를 선택한 방법·결과에 연결해 설명 | 결과가 목표에 충분한지 판단하고, 목표 달성을 어렵게 할 수 있는 요인과 더 확인할 정보를 검토 |
| 주의 | 관련 단서 탐색 → 방해 정보 제외 → 단서 적용 | 고른 단서와 제외한 정보의 이유를 핵심 단서 중심으로 설명 | 출처·관점 차이를 확인할 승인 자료가 있는 과제에서만 그 차이를 구분 |
| 순차처리 | 조건 변화 → 중간 과정 → 결과의 순서 구성 | 순서를 구성한 뒤 핵심 연결의 이유를 설명 | 연결 사이에 필요한 조건 확인, 다른 경로의 가능성 검토 |
| 동시처리 | 인물·장소·도구·제도 등의 관계 연결 | 요소들이 함께 작용한 방식을 설명 | 관계의 방향·역할·의존 조건 구분. 강도는 자료가 있을 때만 검토 |

**실행 범위**
- 이 표는 경로별 설계 원칙입니다. 모든 사건·조건에 네 PASS 경로가 제공됨을 뜻하지 않습니다.
- 승인된 경로만 실행하며, 미구현 경로는 다른 경로로 조용히 대체하지 않습니다.
- 승인된 배정 계약에 따른 경로를 사용합니다. 매번 네 영역을 모두 요구하지 않습니다.
- 고등 추가 행동은 모두 한꺼번에 넣지 않습니다. 사건의 자료와 활동 계약이 지원하는 항목만 사용합니다.
- **`[조건부]`는 신규 적용 범위를 정하는 기준입니다. 기존 경로에서 필수로 운영하던 행동(예: 두 방법 비교·재검토)을 선택 사항으로 바꾸는 근거가 아닙니다. 변경하려면 해당 경로의 계약 변경과 별도 검토가 필요합니다.**
- 고등 경로의 난이도 차이는 추가 글쓰기만이 아니라 **비교·자료 확인·재판단 행동**에서도 유지합니다.

**운영 규칙**
- 강점은 지원 방식으로 쓰며, 약점의 필수 행동을 대신하지 않습니다.
- 자유 글·그림 저장이나 이유 건너뛰기로 필수 행동을 우회할 수 없습니다.
- 방법을 수정했다면 실제 재선택과 새 방법에 대한 재검토가 필요합니다.
- 같은 행동의 결과를 학생의 목표에 맞춰 바꾸지 않습니다. 목표에 따라 달라지는 것은 결과의 충분성에 대한 판단입니다.

**고등 기존 입력 계약**
- 정보–결정 연결 입력과 반증·한계 입력은 **해당 계약이 있는 경로에 한정하여** 유지합니다. 현재 확인된 것은 고등 계획 경로입니다.
- 이 계약을 다른 PASS 경로에 그대로 확장하지 않습니다.
- 이후 이야기 화면에서는 같은 내용을 다시 쓰게 하지 않고, 앞서 작성한 내용을 참고하며 이어서 구성하게 합니다.

## 4. 직접 작성의 범위

- 직접 작성은 **학생이 자신의 내용을 구성한다**는 뜻입니다. 모든 조작마다 별도 서술을 요구한다는 뜻이 아닙니다.
- 앞 단계의 학생 작성 내용은 다음 단계에서 참조·이어쓰기할 수 있게 하며, 같은 설명을 반복 입력하게 하지 않습니다.
- 예상·이야기·두 비교는 목적이 다르므로 별도 기록을 유지합니다. 필요한 이전 내용은 함께 보여줍니다.
- 접근성 대체 입력은 기존 승인 기능 범위에서 허용합니다. 실제 지원하지 않는 기능(예: 음성 입력)을 제공한다고 표시하지 않습니다.

## 5. 개인 이야기 작성

- 선택한 조건, PASS 활동 결과, 확인한 자료를 보면서 하나의 이야기 초안을 이어서 작성합니다.
- 이야기에는 **바뀐 조건 → 중간 과정 → 결과**의 연결이 드러나도록 안내합니다.
- 시스템 요약을 학생의 1인칭 작품으로 자동 저장하지 않습니다.
- 확인되지 않은 정보는 '아직 확인하지 못한 것'으로 유지합니다. 이야기책에서도 확인된 사실로 바꾸지 않습니다.
- 학생이 직접 그린 그림은 작품으로 보존할 수 있으나, 시스템이 의미를 분석했다고 표시하지 않습니다.

**두 가지 구분은 별개입니다.**

| 구분 축 | 내용 |
|---|---|
| 내용의 성격 | 실제 역사 / 변경 조건 / 학생의 상상 / 미확인 정보 |
| 작성 주체 | 학생이 직접 작성한 내용 / 시스템이 정리한 활동 기록 |

- 학생이 역사적 사실을 직접 적을 수도 있으므로, 두 축을 각각 표시합니다. 한쪽으로 다른 쪽을 대신하지 않습니다.
- 내용의 성격 구분(사실·상상 구분)은 기존 원칙을 중·고등 경로에도 적용하는 것입니다. 유아·초등 경로의 변경을 뜻하지 않습니다.

| 구분 | 중학생 | 고등학생 |
|---|---|---|
| 학생에게 요구하는 분석 | 문장별 근거·가정 분류까지는 요구하지 않음 | 자신의 설명에서 근거와 가정을 직접 구분 |
| 참조 | 앞 단계 작성 내용을 보며 이어서 작성 | 앞서 작성한 정보–결정 연결·반증·한계(해당 계약이 있는 경로)를 참고하며 이어서 작성 |

## 6. 실제 역사와 비교

| 비교 항목 | 실제 역사 | 내 이야기 |
|---|---|---|
| 조건 | 자료로 확인된 조건 | 내가 바꾼 조건 |
| 과정 | 확인된 역사적 과정 | 내가 구성한 과정 |
| 결과 | 확인 가능한 결과 | 내가 만든 예상 결과 |

학생은 두 질문에 자신의 설명을 남깁니다.
1. **실제 역사와 내 이야기에서 무엇이 달라졌나요?**
2. **바꾼 조건이 어떤 과정을 거쳐 그 차이로 이어졌나요?**

| 구분 | 중학생 | 고등학생 |
|---|---|---|
| 요구 | 다른 점과 그 이유 설명 | 자료로 확인되는 부분과 가정·한계를 함께 구분 |

- 반드시 다른 결과를 만들도록 요구하지 않습니다. 차이가 작거나 같다는 설명도 허용합니다.
- 비교를 위해 확인되지 않은 역사적 과정이나 결과를 만들어 넣지 않습니다.
- 비교 기록이 없으면 실제 역사 자료는 보여주되 **"비교 기록이 아직 없어요"**로 표시합니다.
- 실제 역사–내 이야기 비교와 최초 예상–실제 역사 비교는 별도 기록으로 보존합니다.

## 7. 이미지 사용

**실제 역사**
- 초등 경로에 구축된 해당 사건의 승인된 역사 이미지를 재사용합니다.
- 새로운 설명이나 역할에 연결할 때는 기존 이미지가 그 내용을 실제로 뒷받침하는지 확인합니다.
- 중·고 화면 적합성은 **핵심 정보의 정확성·가독성·과제 관련성**을 우선 확인합니다. 그림체가 어려 보이는지는 기준이 아닙니다.

**이미지와 역사적 근거**
- 교육용 재현·생성 삽화는 역사적 주장의 증거로 취급하지 않습니다.
- 사료·유물의 디지털 이미지는 출처와 설명, 해석 범위가 확인된 경우 근거 자료로 사용할 수 있습니다.
- 이미지 사용 승인만으로 역사적 주장까지 승인된 것으로 보지 않습니다.

**개인 이야기**
- 개인 이야기 전체에서 사건별 공통 맥락 이미지를 **1~2장** 사용할 수 있습니다. 관련 이미지가 없으면 **0장도 허용**하며, 수를 맞추기 위해 이미지를 넣지 않습니다.
- 매 쪽에 이미지를 넣을 의무는 없습니다. 같은 이미지의 반복은 해당 쪽의 내용과 역할에 맞을 때 허용합니다.
- 중심은 학생이 작성한 글과 직접 그린 그림입니다.
- 공통 이미지를 학생이 상상한 특정 행동·결과의 재현으로 취급하지 않습니다.
- 뒷받침하지 않는 이미지는 생략하고, 다른 사건의 이미지로 대체하지 않습니다.
- 실제 역사와 상상 이야기는 색상만이 아니라 제목·라벨·프레임으로 구분합니다.

**적용 범위:** 1~2장 원칙은 개인 이야기의 참고 삽화에만 적용합니다. 주의·순차·동시처리 필수 활동 자료는 별도로 확보해야 하며, 필수 자료가 없으면 동등한 승인 대체 자료 없이 활동을 완료 처리하지 않습니다.

1. PASS 필수 행동 수행
2. 개인 표현 저장
3. 실제 역사와 내 이야기 비교 기록
4. 최초 예상과 실제 역사 비교 기록
5. 이야기책 구성·발행 상태

- 글이 입력됐다는 사실은 표현 저장의 근거이지, 사고의 타당성이나 인지능력의 증거가 아닙니다.
- 자유 서술의 의미를 자동 채점하지 않습니다.
- 비교 보류를 비교 완료로 바꾸지 않습니다.
- 책의 완성·발행은 기존 승인 계약을 따릅니다.

## 9. 조건·방법 변경 시 기록 처리

새 식별자 체계를 만들지 않고, 기존 `resultId`·시도 구분 계약에 연결합니다.

**조건 변경**
- 기존 조건의 예상·활동 기록을 보존하고, 기존 계약에 따른 별도 시도로 구분합니다.
- 이전 기록을 새 조건의 증거로 재사용하지 않습니다.

**방법 변경**
- 이전 입력은 보존하되 **이전 방법의 기록**으로 표시합니다.
- 새 방법에서는 필요한 정보와 판단을 다시 확인합니다.
- 이전 글을 초안으로 가져오는 것과 새 방법의 수행 완료를 구분합니다.

## 10. 문항·화면 검수 기준

모든 문항에서 다음 연결이 확인되어야 합니다.

**선택한 조건 → 현재 PASS 행동 → 학생이 만드는 내용 → 다음 단계에서 사용하는 기록**

| # | 검수 항목 |
|---|---|
| 1 | 질문과 선택지·입력 방식이 서로 대응하는가? |
| 2 | 학생의 답이 다음 이야기와 비교에 실제로 연결되는가? |
| 3 | 일반적인 이유 문항이 현재 조건·방법과 무관하게 반복되지 않는가? |
| 4 | 답을 먼저 제시하고 그대로 쓰게 하지 않는가? |
| 5 | 이미지가 본문과 다른 행동이나 결과를 암시하지 않는가? |
| 6 | 중·고등 차이가 어휘·선택지 수·글자 수가 아니라 실제 수행 행동에서 나타나는가? |
| 7 | 같은 내용을 중복 입력하도록 요구하지 않는가? 학생이 새로운 자료를 보고 설명을 수정·확장하는 것은 허용하며, 최초 예상 원본은 보존하는가? |
| 8 | 중·고 경로에서 내용의 성격(실제 역사·변경 조건·학생의 상상·미확인 정보)과 작성 주체(학생 작성·시스템 정리)가 각각 구분 표시되는가? |
| 9 | 고등 추가 요구가 해당 사건의 자료와 활동 계약으로 뒷받침되는가? |
| 10 | `[조건부]`를 이유로 기존 경로의 필수 행동을 조용히 제거하지 않았는가? |
| 11 | 미구현 경로를 다른 경로로 조용히 대체하지 않았는가? |
| 12 | 지원하지 않는 입력 기능을 제공한다고 표시하지 않았는가? |
| 13 | 삽화를 역사적 증거처럼 사용하지 않았는가? |

기술 검사 통과와 교육적 적절성·학생 화면 승인은 별도로 판단합니다.

## 11. 사건·경로별 적용 전 필수 확인 사항

다음 항목은 규칙 자체의 미완성이 아니라, 실제 적용 전에 사건·경로별로 확인할 사항입니다.

- 중·고 경로별 승인된 배정 계약의 구체 내용, 그리고 3장 `[조건부]` 항목과의 충돌 여부
- 사건별 승인된 변경 조건 목록
- 조건별 실행 가능한 PASS 경로·완료 계약·검수 상태
- 초등 승인 이미지의 중·고 화면 적합성 검수 결과
- 고등 '직접 영향·장기 가능성 구분'의 사건별 정식 적용 승인 (자료·입력 구조·완료 계약 대조 후)
- 실제 학생 대상 난이도 적절성 (격리 데모 검토로 확인)
