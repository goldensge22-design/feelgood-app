# D-CAS 채용 실무 가이드 검증 기록

이 기록은 **전자책**만을 대상으로 한다. 대시보드 수정이나 공개 배포는 하지 않았다.

## 범위와 결과

- 한국어 207개 문자열을 기준으로 14개 외국어의 같은 경로 **2,898쌍**을 네 묶음씩 AI 대조했다. 누락 경로는 0개다. 의미 오류·표기 불일치만 선별 수정했고 원어민 검수는 **0개 언어**다. 14개 외국어의 내부 상태는 계속 `ai-draft`다. 최초의 큰 묶음 AI 검토 결과는 부분 응답이 있었으므로 네 묶음 재검토가 최종 범위 기록이다.
- 한국어 원문 전체를 읽어 1장 회사 기준 → 2장 기존 직원 평가 → 3장 지원자 연결 확인 → 4장 면접 준비 → 5장 면접·과제 후 기업 평가 → 6장 비교·후속 조치를 확인했다. 기존 직원의 업무성과 입력과 지원자의 면접 후 입력은 구분된다. 운영 플래너·AI 자소서 자료는 아직 연결되지 않았다는 사용자 확인에 맞춰 조건부 안내한다.
- 공개 원본의 **15개 언어** 메뉴명 165곳과 확인 가능한 기존 직원/지원자 평가 버튼명 45곳을 원본 언어 사전과 대조했다. 다만 원본의 **외국어 14개 사전**에는 1장의 역량 모델 버전 관리용 버튼 세 개가 각각 버튼명 대신 동일한 일반 설명문으로 되어 있다. 한국어 원본의 실제 버튼 세 개에 충실한 기존 번역은 유지했으며 외국어 **운영 화면에 실제 표시되는 버튼명까지 인증한 것은 아니다**.
- Chromium 138 실제 브라우저에서 15개 언어 × 8개 화면(표지·6장·체크리스트) × PC 1440 / 노트북 1024 / 태블릿 768 / 모바일 360 = **480 화면**, 대표 긴 번역·RTL 5개 언어 × 8개 화면 × 가로형 740 = **40 화면**을 조작·캡처했다. 총 **520 화면 상태**, 0건의 자동 기하/잘림 오류다. 65개 화면 접촉시트에 들어 있는 각 장의 펼친 예시와 체크리스트도 눈으로 확인했다. 추가로 태국어·크메르어 수정 후 두 언어의 **80 화면**을 재실행해 오류 0건이었다.
- 두 시작 경로, 전체 목차의 활성 상태·제목 포커스, 이전/다음, 실제 예시 펼침/접힘, 체크 여섯 개/초기화, 새로고침·언어 전환·URL의 별도 파라미터와 hash 보존을 각 언어에서 조작했다. 네 언어의 로딩 순서를 지연시켜 연속 전환의 역전·한국어 깜빡임도 브라우저에서 검사했다. 외부 데모 링크 **165곳**을 실제 눌러 새 창 이동 URL과 언어/hash를 확인했다. 외부 서비스 내 로그인 후 데이터 동작 검증을 뜻하지 않는다.
- 각 언어에서 실제 인쇄 버튼을 눌러 브라우저 `beforeprint` 발생을 확인하고 Chromium 인쇄 엔진으로 A4 PDF를 만들었다. **15개 PDF / 210쪽** 모두 페이지 이미지로 렌더링해 15개 인쇄 접촉시트와 문제가 있었던 개별 페이지를 눈으로 확인했다. 본문·예시·표지·체크리스트가 포함되고 목차 조작부 등은 빠지며, 빈 페이지·안전 여백 밖 텍스트·명백한 글자 상자 오류는 최종본에서 발견되지 않았다. PDF 텍스트 추출만으로 글꼴 정상 여부를 판정하지 않았다.

**현재 전자책 내부에서 관찰된 P0/P1 미해결 항목은 없다.** 원어민의 전문 용어 감수는 아직 없고, 외부 원본에 잘못 입력된 외국어 1장 버튼명도 외부 서비스의 실제 표기를 확인할 수 없어 미검증 상태다. 외부 운영 서비스의 로그인 후 명단 연결·실제 저장/반영, 다른 브라우저 및 물리 프린터 출력은 수행하지 않았다. 자동 테스트 통과나 AI 대조를 원어민 인증/운영 데이터 검증이라고 표현하지 않는다.

## 재현 가능한 내부 증거

- `execution.json`: 최초 15개 언어의 **언어 × 화면 폭 × 표지/6장/체크리스트** 기하 수치, 화면별 파일 경로, 목차·포커스·상태·인쇄 동작·링크·연속 언어 전환 결과.
- `execution-th-km-recheck.json`: 해당 2개 언어의 폰트 수정 후 80개 화면과 링크·인쇄 재실행. 수정 전 화면·PDF는 `generated-artifacts/dcas-qa-before/fonts-th-km/`.
- `visual-review.json`: 언어별 실제 이미지 검사 범위와 출력 페이지. `print-pages.json`: 언어별 **모든 페이지**의 단어 경계·빈 페이지·글자 대체 표시 검사. `evidence-manifest.json`: 이미지·PDF 해시.
- `translation-review/`: 첫 AI 응답과 이를 대체한 `언어-0..3.json` 항목별 대조. `translation-triage.json`과 `translation-terms-recheck.json`·`translation-terms-decisions.json`: 수정 수용/거절 판단. `dashboard-terms.json`·`dashboard-entry-titles.json`: 공개 원본의 확인 가능한 명칭.
- 대용량 이미지/PDF는 Git에 넣지 않고 `generated-artifacts/dcas-qa/<언어>/`에 보관한다. `<폭>-<화면>.png`가 화면 전체, `guide.pdf`와 `print-page-XX.png`가 전체 인쇄 결과, `screen-contact-<폭>.png`/`print-contact.png`가 검토용 한눈 이미지다.

실행: `pnpm --filter @workspace/dcas-quick-guide validate:i18n`, `pnpm --filter @workspace/dcas-quick-guide typecheck`, `node artifacts/dcas-quick-guide/scripts/qa-dashboard-terms.mjs`, `node artifacts/dcas-quick-guide/scripts/qa-full.mjs`, `MAGICK_THREAD_LIMIT=2 python3 artifacts/dcas-quick-guide/scripts/qa-print-evidence.py`. 로컬 셸에서 빌드할 때는 아티팩트 설정에 필요한 값을 넣는다: `PORT=21888 BASE_PATH=/ pnpm --filter @workspace/dcas-quick-guide build`. 실제 빌드는 성공했다.
