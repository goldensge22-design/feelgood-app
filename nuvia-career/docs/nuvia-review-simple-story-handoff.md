# 나의 강점 스토리보드 · 한국어 검토본 인계

## 적용

- `/demo/review`에서 성인 체험을 연 뒤 `/demo/review/storyboard`로 이동합니다. 한국어 성인 검토본만 세 단계(재료, GPT 문장, 편집·저장·다운로드)를 사용합니다. 일반 작성 공간, 아동·보호자 화면과 기존 15언어 편집 화면은 유지합니다. 신규 번역은 키로 관리하며 한국어 이외 검수는 별도입니다.
- 결과지 강점 해석은 가상입니다. 활동은 사용자가 선택·확인한 저장 기록과 버전, 회사·직무는 선택적으로 LAB에서 확인한 공개 근거를 사용합니다. 가상 기업은 실제 GPT 기업 근거로 보내지 않습니다. 원본 변경, 수정 중인 기록, 다른 결과지로 확인했던 회사 매칭은 재검토 대상입니다.
- 편집창은 이전 네 섹션을 하나로 읽되 편집 전에는 원래 섹션과 이력을 변경하지 않습니다. `초안 저장`은 활동과 로그인 없이 본문과 생각을 기기에 보관합니다. 파일을 받으려면 직접 확인한 뒤 `다운로드용 버전 저장`을 따로 누릅니다. 활동을 한 번도 연결하지 않은 직접 작성문은 확인 후 내려받을 수 있지만, 연결된 기록이 변경·철회된 경우 다시 확인하기 전에는 다운로드를 잠급니다. 활동 없이는 GPT 후보를 보내지 않습니다. 후보 생성 자체로 원문은 바뀌지 않고 이전 저장본과 적용 직전 원문을 유지합니다. 파일에는 확인한 편집창 본문과 제목만 들어갑니다.
- 검토본의 문장·생각·후보 및 선택 내역은 기존 가상 프로필 기기 저장소와 백업에 속합니다. 연구 및 기업 공유는 별도입니다. 운영 결과지·중앙 SSO·계정 영구 저장이 연결되었다는 뜻이 아닙니다.

## GPT와 공개 링크

- `POST /api/career/review-story`는 Clerk 인증과 명시 동의가 필요합니다. `GET /api/career/review-story/:id`는 요청 소유 계정만 읽습니다. 기존 글쓰기 공급자 환경과 모델을 사용합니다. 동일한 보관 기간 중의 동일 계정·내용 요청을 재사용하며, 의도적인 클릭 외에는 새 호출하지 않습니다. 인증이나 검토 자료 저장을 중앙 계정에 쓰지 않습니다.
- 생성은 승인된 활동·선택적인 합성 해석·공개 기업 근거만 전송합니다. 다듬기는 확인 후 현재 본문과 사용자의 생각을 추가로 보냅니다. 기록 식별자는 모델용 `A1` 같은 임시 참조로 바꿉니다. 점수·계정 ID·원본 전체·미선택 및 비공개 필드는 계약에 없습니다. 입력은 자료이고 명령이 아닙니다. 후보의 참조가 요청과 일치하는지 검사하지만 사용자 사실 확인을 대체하지 않습니다.
- 개발 검토용 대기 작업은 프로세스 메모리에 20분 보관됩니다. 프로세스 재시작이나 다른 서버의 결과 복구를 보장하지 않으며, 찾을 수 없으면 자동 재생성하지 않습니다. 운영 연결 시 기존 공유 대기열과 소유권·재사용 규격을 적용해야 합니다. 운영 DB의 변경이나 자동 마이그레이션을 이 패치에 추가하지 않았습니다.
- LAB의 선택 공개 URL은 공개 HTTPS 구문과 허용된 공개 식별자만 사용합니다. 직접 원문 대조는 공개 IPv4 응답만 고정해서 TLS로 읽고, 인증·쿠키·리다이렉트·스크립트 실행을 허용하지 않습니다. GPT 웹 도구가 정확한 페이지를 열거나 위 방식으로 실제 동일 페이지에서 발췌를 대조한 경우에만 인정합니다. 외부 본문 내 지시나 대체 문서 결과는 성공으로 취급하지 않습니다. 페이지가 확인되지 않으면 회사·직무 이름 검색을 안내합니다.

## 개발자 적용과 검증

1. 기존 프로젝트와 같은 단독 검토본에서 적용합니다. 최초 패치 기준과 파일별 이전·이후 해시는 ZIP `MANIFEST.json`을 따르며 중앙 저장소에 강제 적용하지 않습니다.
2. 기존 관리형 웹·API 워크플로를 실행합니다. 키는 소스·ZIP에 포함하지 않습니다. 공개 재게시나 운영 DB 작업을 수반하지 않습니다.
3. `pnpm --filter @workspace/api-spec run codegen`, 웹·API `typecheck`, 웹 `build`를 확인합니다.
4. 시험 커밋·시각, 실제 모델·브라우저·단위 검사, 미실행 항목은 같은 인계 QA ZIP의 `RESULTS.md`에 있습니다. 문서 구조/렌더 검사는 Microsoft Word·한컴에서 직접 열기와 별개입니다.
