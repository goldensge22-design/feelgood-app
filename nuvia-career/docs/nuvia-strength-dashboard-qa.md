## 최종 수정 후 재검사 (약 02:29–02:36:52Z)

- F1 성공 경로 **통과**: 사용자가 복원하고 기기 저장 성공 뒤 사본 1→0, 알림 제거, 새로고침 후 재등장 없음.
- F1 실패 경로 **통과**: 원본 저장 실패 주입을 유지한 복원은 실패 표시·사본 1개·복구 알림을 그대로 유지.
- F2 화면 감사 **45 통과 / 0 실패**, 너비별 15언어. 감사한 활성 타깃의 클릭 영역 44px 이상, 가로 넘침 0, 오류 0.
- **중요한 범위 차이**: 첫 45개는 기록이 연결된 작성 화면이었다. 마지막 높이 변경 후 45개는 도구 문맥 초기화로 **빈 초안**에서 검사했다. 연결 기록 전용 버튼은 일부만 별도 치수를 측정했다. 이를 최종 코드에서 45개 전체 작성 여정을 실행한 것으로 확대하지 않는다.
- 실제 측정: 저장 47×44, 활동 변경 125×44, 복원 149×44, 언어/단계/원본 이동 타깃 44px 이상. 체크박스는 클릭 가능한 전체 라벨 영역으로 검사했다.
- 기록 원본 재확인 버튼·원본 설명 펼침·가져오기 검토 라벨은 최종 45개에서 열어 측정하지 않았다. 해당 코드에 최소 44px를 적용했지만 화면 확인과 구분한다.
- it/1440 로드가 한 차례 개발 미리보기 **502**로 시간 초과됐고 재시도는 정상. 원인은 확인되지 않았다. 재시도 성공을 원인 해결로 표시하지 않는다.
- 마지막 소스 해시 목록: `final-source-sha256-run2.txt`, 테스터 집계 지문 `51d21fc4892c45579d42c5b4d03bca2a93008f7029052f1ca4458b9c6307c6c8`.
- 위 목록은 당시 문서·메모리도 포함한 파일 집합이다. 이후 QA 문서 정리/인계 패키징은 실행 소스 변경이 아니다. 배포용 코드 지문은 별도로 패키지 `MANIFEST.json`에 정확한 범위와 계산법을 기록한다.
- PDF/DOCX/HWPX 생성부·서버는 F1/F2 수정으로 변경되지 않았으므로 앞선 실제 파일 본문 검사는 해당 생성부 기준으로 유효하다. 최종 재검사에서 다운로드를 반복했다고 주장하지 않는다.
