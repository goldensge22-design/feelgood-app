- 원본은 사용자가 제공한 FEELGOOD-Co-LTD/nuvia `7b5219839c9a2adb7294901ba72629b22c0c01d7`의 Planner/Contracts이다. 필요한 의존 파일을 `artifacts/nuvia-career/vendor/nuvia-original/`에 포함했다. `/demo/review/planner`는 해당 Studio 컴포넌트·타이머·시간표·선반·작업대·완료 모음·돌아보기·자유기록을 별도 문서에서 직접 사용한다. 이전 검토본에 남긴 기록은 플래너 하단 별도 링크로 열며 삭제하거나 서버 데이터로 옮기지 않는다.
- 원본 대비 동작 수정은 `StudioApp.tsx`(검토 슬록과 원본 운영 메뉴 분리), `StudioPage.tsx`(선반·작업대·자유 기록의 선택적 슬록), `store.ts`(명시적 검토 모드 전용 탭 키, 운영 서버 및 이전 공간 접근 없음)이다. CSS, 타이머 로직, 시간 배정·위치 전환·자유기록 구현, contracts 원본은 변경하지 않았다. `demo/review/studio-frame.html`, 시작 준비 신호, `review-studio-main.tsx` 및 스토리보드 브리지는 검토본 전용이다.

- 프레임은 준비 또는 실패를 자체 표시하고, 부모는 같은 출처·같은 프레임의 확인 신호뿐 아니라 문서 상태도 검사한다. 새 탭과 새로고침에서 준비가 완료되기 전에는 빈 화면으로 보이지 않게 하고, 모듈 로드 오류·12초 무응답 시 재시도 또는 같은 탭 직접 열기를 제공한다. 메시지에는 상태만 있고 기록이나 인증 값은 없다.
