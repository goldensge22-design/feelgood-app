# NUVIA 검토본 — 공개 기업·직무 GPT 검색

- `검색`은 두 공개 검색어만 기존 인증을 거쳐 `/api/career/lab-search`로 보낸다. 체험 시작은 로그인이나 검색 권한을 부여하지 않는다. 로그인 링크는 기존 로그인 화면에서 동일 출처의 LAB으로 돌아온다. 별도 웹 검색 링크와 검토한 공개 참고자료는 실제 GPT 결과로 분류하지 않는다. 붙여넣기 UI만 제거했으며 기존 저장 키, 과거 스토리와 버전은 삭제하지 않는다.
- 서버는 OpenAI Responses API에서 완료된 `web_search_call`과 URL 근거를 확인한다. 공급자 인용 또는 완료된 웹 도구의 출처 목록·열람 URL과 일치하지 않는 항목은 제외한다. 기업 소개·이념/철학·가치·인재상과 업무·공고 지원요건·우대·직무역량을 분리한다. 공고 요건은 특정 공고에 한하며, 자료 없음은 추정하지 않는다. GPT 발췌는 원문 열람을 돕는 검색 근거이며 키워드나 최신 모집 상태에 대한 독립 검수는 아니다. 회사별 미리 준비된 도메인과 공개 URL은 출처 오연결을 줄이기 위한 것이며 일반 검색은 모델이 수행한다.
- `gpt-cited-lab-v2`는 기업·직무 입력어 복사와 의미 없는 제목을 제외한다. 기업이 핵심가치로 명명한 원문 이름은 확인된 기업 도메인·가치 항목·정확한 이름 조건을 모두 만족할 때만 공식 라벨을 붙인다. 한국어 번역이나 요약은 AI 요약·해석으로 표시한다. 공고는 원문 구획을 반환하며, 구획이나 명시 우대 표현이 뒷받침하지 않으면 지원요건을 추정하지 않는다. 기존 검색/연결과 확정 스토리 기록은 유지되며 구버전 분석에서 새 강점 연결을 추가하려면 다시 검색한다.
- 개발은 기존 관리형 OpenAI 연결을 재사용한다. 새 키가 필요한 경우에만 안전한 비밀 설정을 사용한다. 운영 담당자는 `CAREER_LAB_SEARCH_PROVIDER=openai`와 서버 비밀 설정의 `OPENAI_API_KEY`로 표준 OpenAI 주소에 직접 연결할 수 있다. 공급자 옵션 미지정 시 기존 `CAREER_AI_PROVIDER`를 따른다. `CAREER_LAB_SEARCH_MODEL` 기본값은 `gpt-5-mini`이고 별도 회사 검색 모델만 변경한다. 쓰기·음성 모델, 결제, 중앙 서비스는 바꾸지 않는다.
- 프로필 브라우저 저장 및 백업은 검색어·조건과 검색/외부 열기 시도, 선택 근거와 확인된 분석의 시점·공개 출처·공고·버전, 가상 결과지의 해석 버전과 강점·확인 시각을 보존한다. 키워드와 인지 강점은 후보이며 점수, 채용 적합도나 수행을 증명하지 않는다. 회사나 근거를 바꿔도 새 연결은 명시 확인 전까지 기존 연결을 대체하지 않는다. 원문 입력·플래너 기록·검사 내용·기업 지원 여부는 GPT로 보내지 않는다. 기업 전송·개인톡 발송·연구 전송을 하지 않는다.
- 계정별 프로세스 캐시 15분, 요청 합치기, 동시 6개 및 분당 계정 4건/서버 20건 상한, 공급자 자동 재호출 없음. POST는 202·작업 ID를 바로 반환하고 GET 상태 조회도 본인만 허용한다. 화면을 떠난 뒤 로그인되어 있으면 기존 작업 ID로 조회만 재개한다. 결과를 찾지 못하면 검색어를 남기고 재시도 여부를 사용자에게 맡긴다. 다중 인스턴스와 재시작을 넘는 검색 공유가 필요하면 운영 연결 시 기존 공용 작업 관리자와 조율한다.
- 플래너 렌더링/시간/작업대 런타임은 이 변경에서 건드리지 않았다. `docs/nuvia-planner-original-files.json`은 제공된 원본 `7b5219839c9a2adb7294901ba72629b22c0c01d7` 대비 실제 가져온 195개(동일 180/수정 15) 비교 목록이다. `docs/nuvia-review-device-data-handoff.md`의 계정·기기 저장/백업/동의 계약은 유지된다. 
- 실공급자 재현(정확히 세 건, 비용 발생): `NUVIA_LAB_LIVE_QA=1 pnpm --filter @workspace/scripts exec tsx src/nuvia-review-lab-live-qa.ts`. 보고서에는 검색어, 확인 가능한 근거 URL, 시각, 성공/실패, 토큰만 기록한다. 브라우저 반복 회귀의 오류 주입 및 실응답 재생은 실호출 수에 포함하지 않는다. 최종 범위와 실행 결과는 QA ZIP의 `RESULTS.md`를 따른다.
