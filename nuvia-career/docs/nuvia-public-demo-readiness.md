## 체험 진입·기록 보호

- 체험 경로: `/demo?lang=ko`. 현재 개발 확인 주소:
  `https://546ebb1e-3eed-447d-99fc-f558586d3f51-00-1hmnxial7hba6.pike.replit.dev/demo?lang=ko`
- 위 주소는 **개발 미리보기**다. 누구나 접속하는 공개 배포 URL은 아직 제공하지 않는다.
- 로그인 불필요. 기존 로그인 상태여도 `/demo`에서는 합성 예시 클라이언트 문맥만 선택한다. 실제 계정·guest·기존 예시의 localStorage를 읽거나 덮어쓰지 않는다.
- 탭별 sessionStorage 전용 이름 공간을 사용한다. 같은 탭 새로고침은 복원하고, 새 방문 탭/별도 브라우저에는 다른 체험 기록을 읽지 않는다.
- `체험 기록 지우고 다시 시작`은 이 체험 이름 공간만 제거한다. 기존 사용자 기록은 보존한다. 개인정보 입력 금지와 탭 저장임을 15개 언어로 안내한다.
- **한계:** 브라우저의 ‘탭 복제’/opener 동작은 초기 sessionStorage를 복사할 수 있다. 이후 저장은 독립적이다. 이것을 사람의 신원을 구분하는 서버 격리라고 부르지 않는다. 공용 기기는 체험 종료 시 지우고 탭을 닫는다.
- 합성 결과지·활동은 실제 검사결과나 실제 플래너 조회 성공이 아니다. 실제/모의 성격과 카드 유형은 별개로 유지한다.
