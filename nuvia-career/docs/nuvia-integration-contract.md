# NUVIA 자소서 앱 — 외부 연결 인수 조건

## 범위와 보존

이 앱은 대학생·취업 준비생 대상의 새 제품이다. 특성화고·마이스터고는 후속 확장 대상이다.
기존 D-CAS 결과지와 NUVIA PLANNER를 대체하지 않는다. 공개 GitHub 소스는
읽을 수 있지만 운영 인증·배포·사용자 데이터의 접근 권한은 제공되지 않았다.
따라서 기존 제품을 수정하거나 기존 플래너 보강이 완료·배포되었다고 간주하지 않는다.
공개 배포는 이번 범위가 아니다.

## 현재 외부 연결 상태

| 대상 | 상태 | 실제 검증 |
|---|---|---|
| D-CAS | 미연결 | 인증·조회·원본 복귀 미검증 |
| NUVIA PLANNER | 미연결 | 원격 계획 저장·선택 경험 전송·원본 복귀 미검증 |
| 기업 대시보드 | 자료 없음 | 공개 승인 자료 API 미제공 |

이 앱의 로컬 활동 기록은 기존 NUVIA PLANNER에 저장되지 않는다.
가상 여정과 직접 작성 기능은 연결 성공을 대신하지 않는다.

### 제공된 플래너 프로젝트 참조

- 사용자가 제공한 제품 식별 주소:
  https://replit.com/replid/3fbdef46-a3e0-40cb-a926-036c82ed4b47
- 이 주소는 API 주소, 배포 주소, 레코드 복귀 URL 또는 접근 권한이 아니다.
- 2026-10-23 비로그인 공개 조회는 Replit의 404 페이지를 반환했다.
  프로젝트 삭제/비공개/권한 중 어느 원인인지는 확인할 수 없다.
- 현재 프로젝트의 연결된 외부 통합 목록은 비어 있다. 이후 사용자가 지정한
  공개 GitHub 저장소에서 아래 소스/계약을 확인했다. 이는 해당 Replit 제품의
  운영 코드와 동일하다는 검증이나 실제 API 접근 권한은 아니다.
- 읽기 가능한 프로젝트 초대/소스 또는 문서화된 API와 테스트 권한이
  필요하다. 비밀번호·키·토큰을 채팅에 보내지 말고 승인된 연결/비밀값 경로를 쓴다.

### 새로 확인한 공개 소스 — 운영 연동과 구분

2026-10-23 읽기 전용으로 확인했으며 원본은 변경하지 않았다.

- 저장소: `goldensge22-design/feelgood-app`.
- main `35a3216e980bd4dd0c0391e5c6790508bb9e72f7`의
  `result-reports/MAIN_HANDOFF.md`,
  `integration/RESULT_REPORT_INTEGRATION.md`,
  `integration/result-report-adapter.js` 및 성인 content engine을 확인했다.
  이 경로에서 integration은 `result-reports/` 하위다.
- 기존 계약은 `P/A/S/Q`를 사용하며 D-CAS는 0~100 정답률이다.
  성인 엔진은 `Q`를 `순차처리`, 직무 profile의 `successive`도
  `순차처리`로 표시한다. 새 앱의 `sequential`과 의미를 대응시키되
  원본 키/척도/값을 변경하지 않아야 한다.
- `__TEST_PROFILE__` 주입 계약은 결과지 **입력** 계약이다.
  인증된 결과 조회 API나 개인에게 실제 표시된 TOP5 **출력** 계약은 아니다.
  성인 엔진이 만든 `ranked.slice(0,5)`의 표시 순서·`item.reason`을
  원본 시스템에서 제공받아야 한다. 새 앱에서 점수로 다시 순위를 만들지 않는다.
- `codex/recover-planner-dcas81`의
  `ab5f1b1b86d4bb6665bf206b63471dc28201d524`에서
  `nuvia-planner/README.md`, `docs/NUVIA_PLANNER_RESULT_SERVER_INTEGRATION.md`,
  `docs/STUDIO_DEVELOPER_HANDOFF_2026-10-20.md`를 확인했다.
  README는 source/demo와 Studio 후보를 구분하며, Studio 인계는 실제
  서버·인증·소유권·동기화 미연결을 명시한다.
  이 후보를 사용자의 기존 정식 플래너로 간주하거나 통째로 교체하지 않는다.
- 따라서 추가 요청은 전체 소스의 재제출이 아니라 **현재 운영 버전 식별,
  인증된 서버 API/원본 복귀 주소와 테스트 접근**으로 좁혀진다.

## D-CAS에 필요한 계약

- 실제 결과지 URL, 서버 인증 방법, 사용자 동의 범위, 동일 소유자 검증 규칙.
- 개인정보를 제거한 실제 응답 예시 및 스키마. 네 축 전체의 원점수·척도·해석·처리 유형, 전공 맥락, 직무 역량 설명.
- TOP5 원래 순서와 근거, 실제 추천 수. 두 강점으로 재계산하지 않으며 부족한 추천을 채우지 않는다.
- 사용자·검사·결과 식별자, IQ, 81유형의 기존 계약과 버전. 새 앱 외부 URL이나 제출물에는 포함하지 않는다.
- 순차 처리의 기존 명칭과 식별자 목록. 원래 명칭을 보존하고 표시명만 정확한 계약에 따라 매핑한다. 현재는 명칭을 추측하지 않는다.
- 결과에 실제 포함된 NCS 내용과 공식 출처·기준 시점. 분류 코드만으로 역량 문구를 만들지 않는다.
- 원본 복귀 경로, 소유권/권한/버전 변경·삭제·철회 조회 방식.

연결 토큰·원본 검사 데이터·개인 식별정보를 URL 쿼리로 전달하지 않는다.
서버 인증과 소유권 확인 후 최소한의 표시용 정보를 전달하는 어댑터가 필요하다.
현재 클라이언트가 report를 임의 저장하거나 공식 결과처럼 표시하도록 허용하지 않는다.

## 플래너 보강 계약

- 기존 우선순위·상태·지원 전략·언어 식별자 보존.
- 사용자가 수정하고 수락한 목표/단계/날짜/완료 기준/확인 근거/강점 전략만 저장.
- 계획 생성 멱등 키를 사용자·요청별로 적용하고 재시도 응답을 동일하게 반환.
- 실행·중단·재개·부분 완료. 시간 블록 종료와 과제 완료를 분리.
- 회고는 실제 행동·바꾼 점·관찰 결과·배움을 선택적으로 기록.
- 전송 직전 필드별 확인. 개인 메모·생각 기록을 통째로 보내지 않는다.
- 원본 위치·버전·권한과 연결. 변경/삭제/공유 철회 시 재확인하고 자소서 초안·제출 스냅샷은 유지.
- 연결 카드 추가는 기존 플래너 저장소에 대한 별도 보강 작업이다.

## 출처 신뢰 경계

공식 NCS, 결과 해석, 공통 실천 예시, 사용자가 붙여넣은 공고, 기업 공개 승인 자료를 구분한다.
현재 제공하는 공통 실천 예시는 `common_example`이며 공식 NCS 기준이 아니다.
별도로 공식 NCS 공개 페이지에서 확인한 직업공통능력 3개
(문제분석·대안발굴·의사결정, 26v1)를 `official_ncs` 스냅샷으로 제공한다.
공식 출처: https://www.ncs.go.kr/unity/th03/TH0309.do?jobCd=03
(조회일 2026-10-23). 이는 특정 개인 결과지의 NCS 내용이나 IT 서비스기획
직무 고유 능력 전체가 연결됐다는 뜻이 아니다. 원문은 한국어로 유지한다.
기업 평가 원문·직원 점수·면접관 메모·비공개 가중치·다른 지원자 자료는 입력 계약에서 제외한다.
클라이언트가 공식/기업 공개 출처를 자칭해 저장할 수 없도록 서버에서 거부한다.
공식 NCS는 서버의 고정된 승인 스냅샷과 정확히 일치할 때만 선택·저장할 수 있다.
자료 없음·조회 실패·만료·권한 없음은 서로 다른 상태 식별자를 사용한다.
버전에 사용된 기준은 당시 스냅샷으로 보존하며 후속 기준 변경으로 덮어쓰지 않는다.

## 인증과 제출물

Clerk 세션 쿠키에서 소유자를 결정한다. 요청 본문/URL의 사용자 ID는 신뢰하지 않는다.
새 앱의 계정 인증은 기존 D-CAS/플래너의 인증이 연결되었다는 뜻이 아니다.
기존 계정과의 연결/SSO가 필요하면 외부 제품의 계약이 추가로 필요하다.
원본 검사 데이터, 강점 태그, 내부 ID, 코치 질문, 플래너 원문은 내보내기 허용 목록에 없다.
DOCX는 실제 OOXML 패키지, HWPX는 실제 OWPML/HWPX ZIP 패키지로 생성한다.
원문 4개 필드만 새 패키지에 넣고 템플릿의 작성자·미리보기 이미지·스크립트는
복사하지 않는다. ZIP/XML/본문 재판독을 확인했다. 네이티브 Word/한컴의
시각적 열기와 레이아웃은 아직 확인하지 못했으며 UI에도 이를 안내한다.

## 언어와 검증

FeelGood 프로그램은 15개 언어를 기본 범위로 한다:
한국어, 영어, 일본어, 중국어 간체/번체, 몽골어, 태국어, 베트남어, 아랍어,
러시아어, 크메르어, 스페인어, 프랑스어, 이탈리아어, 아제르바이잔어.
기존 제품의 실제 언어 식별자와 별칭 목록은 아직 미제공이므로 기존 식별자를 변경하지 않는다.
번역 키 존재와 번역 검토 완료는 다르며, 원어민 검토·화면 검증 전 완료라고 표시하지 않는다.
사용자가 작성한 문항/본문/메모는 UI 언어 변경으로 번역하지 않는다.
