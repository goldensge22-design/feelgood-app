# NUVIA 실제 AI 자소서 — 최종 기술 규격과 한국어 1차 완료 기준

갱신: 2026-11-15 한국시간. 기존 HeavenlyWiltedConstants/FeelGood 자소서의 누적 보강이다. 기존 요청·구현·저장 자료를 취소하거나 새 앱으로 교체하지 않는다. 이 문서는 요구사항이며, 항목의 존재 자체가 구현·QA·원격 저장 완료 증거는 아니다.

## 우선순위와 완료의 정의

1. **한국어 신규 기능 구현**을 먼저 끝낸다.
2. **실제 생성형 모델 호출을 포함한 한국어 신규 QA**를 통과한다.
3. 최신 소스와 변경 패치를 **GitHub 작업 브랜치에 저장**한다.
4. **원격 커밋과 전달 소스/파일 해시를 대조**한다.
5. 위 근거와 한국어 완성본을 사용자에게 전달한다.

다섯 단계가 모두 충족돼야 한국어 1차 완료다. 로컬 커밋·ZIP·체크포인트·모의 AI 응답은 원격 저장 또는 실제 AI QA의 대체 증거가 아니다. 한국어 1차 완료 뒤 나머지 14개 언어의 신규 번역·기능을 확장한다. 기존 15개 언어의 기능·번역·사용자 원문과 이미 추가된 초안은 삭제·초기화하지 않는다. 한국어 미완성 중 추가 다국어 확장에 시간을 사용하지 않는다.

## 제품 흐름과 실제 AI의 역할

- 동의한 결과지 강점 해석·직무 TOP5·원래 추천 근거와 버전 → 사용자가 선택·확인한 플래너의 행동·선택 이유·수정·결과 → 직접 추가한 일상/학업/동아리/아르바이트/프로젝트 등 경험을 활용한다. 결과지가 없어도 직접 경험으로 작성할 수 있다.
- 원래 TOP5 순서와 이유를 보존한다. 누락을 채우거나 재계산하지 않는다. 실제 외부 자료가 제공되지 않았으면 연결 완료로 표시하지 않는다.
- AI는 강점과 원문 행동의 **연결 후보와 이유**, 기록별 **개별 STAR 질문 한 개**, 확인된 사실만 사용하는 **문장/문단 후보**를 제안한다. 지원동기·가치관에는 적합한 질문을 사용하고 STAR 네 칸을 강제하지 않는다.
- 사용자가 강점 연결과 본문 적용을 확인·수정·거부/취소할 수 있어야 한다. 비교와 원문 복원을 제공하며, 자동 삽입·본문 덮어쓰기는 금지한다.
- 근거 없는 직책·성과·수치·근무 이력·기업 절차를 만들지 않는다. 정보가 부족하면 질문 또는 확인 필요로 남긴다. 실제/모의/미확인, 계획/수행, 자기보고/외부 확인, 제공받은 도움/본인 행동을 구분한다.
- 학생의 선택·확인은 외부 사실 검증이 아니다. 기존 고정 질문은 고정 가이드로 표시하며 실제 모델 성공으로 계산하지 않는다.

## PASS와 개인 화법

- PASS는 단계별 질문·전체 구조 먼저 보기·핵심 집중·복귀 도움 등 작성 지원 방식에 사용한다. 점수만으로 말투·성격·표현 능력을 단정하지 않는다.
- 활용 동의한 본인 문장·답변·직접 수정/선택에서 관찰할 수 있는 규칙 후보와 원문 예시를 제시한다. 검토하지 않은 AI 생성문을 본인 화법의 증거로 쓰지 않는다.
- 사용자 확인 뒤에만 적용하며 언어·작성 목적별 조정, 수정·끄기·초기화를 제공한다. 수정 시 관련 확인을 해제한다. 자료가 적으면 잠정 후보다. 사실과 의미를 보존하고 모델 재훈련·AI 탐지 회피를 주장하지 않는다.

## 동의·저장·보안

- 전송할 경험·답변·결과 해석을 사용자가 확인·선택한다. AI 처리 동의·학생 사실 확인·기업 공유 동의는 별개다. 비공개 메모·미선택 자료·타인 자료·원점수/IQ·검사 식별자·비밀값은 불필요하게 보내지 않는다.
- 문항·경험·기록/근거 버전·선택·답변이 바뀌면 이전 기준 응답과 확인을 무효화한다. 취소되거나 늦게 온 응답을 새 문항/본문에 적용하지 않는다.
- 사용자 원문·기존 저장·과거 제출 버전·내보내기 허용 범위를 보존한다. 보조 기록과 미선택 AI 후보는 파일·기업 공유에 자동 추가하지 않는다.
- 현재 새 코치 답변·화법 예시/규칙·제안 이력은 계정 문맥별 **기기 저장**이다. 새 기기/브라우저에 영구 동기화된다고 표시하지 않는다. 실패 시 성공 표시나 입력 삭제를 하지 않는다.
- 실제 결과지·플래너 인증, 중앙 로그인 계약, 계정별 영구 저장 확장은 담당 개발자 범위다. 합성 기기 QA와 운영 연동 QA를 분리한다.
- 실제 AI 연결 설정이 없으면 설정 종류·차단 조건과 미실행을 알리고 직접 작성은 유지한다. 고정문 생성으로 실제 모델 성공을 대신하지 않는다. 비밀값은 서버 전용 안전한 설정으로만 관리한다.

## 한국어 필수 신규 QA

각 항목은 검사 시각·최종 코드 지문·실제/모의 전송 여부·관찰 결과와 연결한다. 실패는 수정 후 영향 범위를 재검사한다.

- 실제 모델 연결/요청 성공, 서로 다른 두 개인 기록의 질문 **및 문장** 차이.
- 직접 경험만 있음, 결과지만 있고 행동 없음, 근거 부족, 실제/모의 혼합, 강점 불일치, 없는 정량 성과·과장 유도·자료 속 명령.
- 기록 수정과 경험/문항 전환의 제안·확인 무효화, 화법 후보 확인·해제·수정·끄기·초기화와 미검토 AI 문장 제외.
- 실패·제한·시간 초과·취소·중복·즉시 재시도·늦은 응답, 저장 실패/복구.
- 본문 불변 → 명시적 선택 적용 → 원문 복원. 입력·새로고침 보존, 기존 버전의 비교/복원·과거 버전 불변.
- 한국어 PC1440·태블릿768·모바일360의 실제 화면, 문서 복사/TXT/DOCX/HWPX 내용·줄바꿈·실제/모의 맥락·비공개 메타데이터 제외.

과거 고정 질문 QA, 모의 응답, 45개 언어/화면의 레이아웃만으로 위 전체를 통과 처리하지 않는다. 운영 로그인/SSO·DB·다중 사용자 권한·실제 외부 연동·Word/한컴 직접 열기·원어민 검수는 수행 여부를 따로 기록한다.
