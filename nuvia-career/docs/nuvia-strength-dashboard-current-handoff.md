## 실제 연결의 확인 범위

이번 개발 API의 `/api/career/overview` 응답은 `dcas=unconnected`, `planner=unconnected`, `company=no_data`다. 공통 기준은 6개 반환된다. 이는 개발본 응답이며 중앙 운영 상태를 뜻하지 않는다. 반환 목록의 존재를 공식 NCS/기업 인재상 실제 연동 완료로 세지 않는다.

현재 Git 원격은 `gitsafe-backup`이라는 Replit 내부 백업이며 GitHub 원격이 아니다. 새 저장소 생성·원격 수정·푸시·운영 배포는 하지 않는다.

확인된 상대 제품 식별:

- 중앙: FEELGOOD-Co-LTD / nuvia, https://nuvia.feel-good.io
- 기업 LAB: https://replit.com/replid/9180b529-621d-4547-8da5-54fa03c9800b
- 플래너: https://replit.com/replid/3fbdef46-a3e0-40cb-a926-036c82ed4b47

위 프로젝트 식별 주소는 API 주소/인증 권한이 아니다. 상대 앱에 보내는 가짜 endpoint를 만들지 않는다.

## 개발자가 이어 연결할 항목

1. **결과지**: 승인된 조회/소유권, 원본 결과 버전, 네 영역의 원래 명칭·점수·단위·척도 범위, 기질 원문, TOP5의 원래 순서/순위/근거 및 그래프 원본 계약. 수치·기여도가 없으면 그래프를 만들어 채우지 않는다.
2. **기업·직무 자료**: 실제 기업/직무와 일치하는 기준의 원문·출처·기준 시점·버전 및 공개 승인 범위. 교육용 예시와 공식 자료를 구분한다. 현재 텍스트 비교는 자동 직무능력 인증이 아니다.
3. **플래너/LAB 전달**: 사용자 소유권·선택한 항목·동의 범위·원본 ID/버전·실제/모의 성격·확인 상태·철회/삭제·중복 키·원본 복귀 URL을 양쪽에서 합의한다. 수신 어댑터만 있는 것을 실제 송수신 성공으로 세지 않는다.
4. **저장**: 스토리보드 보조 초안은 계정 문맥을 분리한 기기 보관이다. 실제 계정 서버 저장 및 다중 기기 동기화는 별도 계약이다. 임시 보관과 서버 응답 확인·제출·기업 공유를 구분한다.
5. **시험 환경**: 승인된 실제 시험 계정, 상대 제품의 시험용 endpoint, 원본 변경/공유 철회 시나리오 및 중앙 배포 버전이 필요하다. 실제 학생 기록을 시험용으로 가져오지 않는다.

## 출처·동의·원문 불변 조건

- 카드 종류와 실제/모의 여부는 별개다. 명시적 성격과 같은 원본 버전을 받은 경우만 보존하며 누락은 미확인으로 남긴다.
- 모의 기록을 실제 회사 근무·성과로 승격하지 않는다. 개인 메모·미선택 내용은 자동 전송/출력하지 않는다.
- 학생이 확인한 기록·문장만 확정한다. 원본 변경 시 재확인하며 과거 확인 버전은 덮어쓰지 않는다.
- 작성 사용 동의, AI 처리 동의, 기업 공유 동의는 서로 다르다. 이번 보강으로 기업 자동 전송은 하지 않는다.
- 저장 실패 시 본문과 가능한 복구 사본을 유지한다. 원문 복구는 병합이 아니므로 사용자가 검토해 선택한다.

## 이번 누적 수정

- 대시보드의 다음 행동·키워드 후보와 실제 경험 선택기가 같은 `storyboardBlockReason`을 사용한다. `confirmed`만 있는 이전 경험이나 성격 누락/잘못된 값·권한 철회가 있는 기록을 작성 가능한 출처로 안내하지 않는다.
- 출처를 고르기 전에도 자유 초안은 유지한다. 대신 작성란 직전에 기록 선택 조건·기기 보관 범위·최종 확인 후 내보내기 조건과 경험 보관함으로 가는 동작을 직접 표시한다. 화면낭독기에도 이 안내를 연결한다.
- 새 안내는 기존 15언어 문구를 재사용한다. 기존 번역 재생성이나 학생 원문의 자동 번역은 없다.
- 스토리보드 페이지에서 내부 알림 함수를 외부로 내보내던 부분을 제거했다. 개발 중 비컴포넌트 export로 Fast Refresh가 전체 새로고침으로 바뀌던 경고를 줄이는 소스 수정이며 운영 오류 전체의 원인 해결을 뜻하지 않는다.
- 계정 원본 목록을 불러오는 중에는 저장된 최종 확인을 해제하지 않는다. 실제 원본 수정/삭제/철회 또는 미확인 성격을 확인한 뒤에만 해제하며, 원본을 되돌려도 학생의 재확인을 요구한다. A16R에서 지연 조회·새로고침·실제 출처 상태 변경 경로를 재검사했다.
- 기존 서버·인증·원본 계약·AI 모델·비용 설정은 변경하지 않았다.

## 파일 형식과 언어

- 실제 PDF 생성, TXT, 기존 DOCX/HWPX를 보존한다. PDF는 이미지 기반이며 한 장 여부/한글 표시는 합성 출력으로 검증한다.
- 이 환경에는 HWP/DOC 변환기 및 Microsoft Word/한컴 실행 환경이 없다. HWP/DOC 생성과 해당 앱 열기/편집/재저장은 BLOCKED다. 다른 형식의 확장자를 바꿔 제공하지 않는다.
- 기존 15개 언어와 원문 입력을 보존한다. 이번 새 화면 검사는 실행 사례에 적힌 언어/너비만 해당하며 45개 전체 여정 또는 원어민 검수를 새로 완료했다고 하지 않는다.

## 인계 파일 재생성

`python scripts/src/package-story-dashboard.py`

- 재생성에는 기존 Replit 작업본의 Git 기준과 이전 인계 ZIP이 필요하다. Git 이력 없는 새 폴더에서 패치 이력을 재구성하는 명령은 아니다. 전체 소스 자체의 실행에는 제외한 비밀 설정을 별도로 구성해야 한다.
- 최신 전체 소스: 기존 Career 앱/API/공유 패키지/필수 실행 설정·lockfile·번역·인계 문서.
- 증분 패치: 위 기준 및 이전 인계 ZIP의 실제 바이트와 대조한다. 중앙본의 기준이 다르면 강제 적용하지 않는다.
- 변경 전/후 파일 해시, 최종 소스 지문, 실제 사본 적용/해시 대조 결과 및 새 QA 증빙을 함께 담는다.
- `.env`, 값이 든 `.replit`, 비밀키·세션·운영 데이터·DB 덤프·캐시·`.git`·다른 앱·과거 생성 패키지는 제외한다.
- 수신 개발자가 기존 승인 설정을 안전한 환경변수 경로로 구성해야 한다. 신규 비용 설정·가입은 하지 않는다.
- 이번 검수의 요약은 `nuvia-strength-dashboard-current-qa.md`, 시점별 원기록과 최종 소스 해시는 ZIP의 `qa/`에 포함한다.
- 이후 추가된 경험 모달의 미저장 입력 유실과 공개/편집 빌드 비교는 `nuvia-experience-unsaved-input-fix.md`, `qa/experience-unsaved/`로 구분한다. 이전 스토리보드 검사 통과가 이 입력창의 통과를 뜻하지 않는다.
