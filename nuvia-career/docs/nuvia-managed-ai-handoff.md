# NUVIA 실제 관리형 AI 작성 보조 — 개발자 인계

## 한국어 최종 전달 / GitHub 쓰기 제한

최종 신규 QA는 `docs/nuvia-korean-final-qa.md`와 패키지의 `qa/korean-final/final-required-qa.json`을 따른다. 현재 연결로 GitHub 트리 생성이 `403 Resource not accessible by integration`을 반환하여 신규 원격 커밋/브랜치 갱신은 수행되지 않았다. 권한 우회·초대·다른 인증정보 수집은 하지 않았다. 원격 `f051942eef7487157c5ad1bfea6125f068bc0ae2`는 기존 규칙 문서 기준이며 신규 AI 저장 증거가 아니다.

로컬 GitHub 인계자는 최신 ZIP의 **`patch/github-f051942-korean-ai.patch`**를 사용할 수 있다. 이는 실제 조회한 해당 원격 기준을 재구성한 사본에 적용하고 전체 소스 해시와 보호 규칙 문서를 검증한 패치다. `github-base-patch.json`의 결과를 확인하고 저장소 루트에서 `git apply --check` 후 적용한다. 원격 기준이 바뀌었으면 먼저 차이를 확인한다. `bd181075`/`7802fa3`용 패치는 서로 다른 로컬 기준의 대안이므로 중복 적용하지 않는다. 소스 위치는 저장소 내 `nuvia-career/`이며 다른 프로그램·main·DB·배포를 변경하지 않는다.

작성일: 2026-11-14. 기존 HeavenlyWiltedConstants / FeelGood 대학생·취업준비생 자소서 앱의 누적 패치다. 다른 LAB·플래너를 대체하지 않는다.

우선순위 갱신: 2026-11-15 한국시간. 최신 확정 규격은 `nuvia-managed-ai-spec.md`다. **한국어 구현 → 실제 모델 포함 신규 QA 통과 → 작업 브랜치 원격 저장 → 원격 커밋/파일 대조 → 한국어 완성본 전달**까지가 1차 완료다. 기존 15개 언어는 보존하되, 나머지 14개 언어의 추가 확장은 이 완료 뒤 진행한다. 아래 구현/과거 QA 근거만으로 이 완료 조건을 충족했다고 주장하지 않는다.

## 이번 기능

- 실제 Replit 관리형 OpenAI 연결을 서버에서 호출한다. 모델은 `gpt-5.6-luna`다. 고정 `ContextCoach`는 기존 안내로 보존하고 새 AI 패널과 구분한다.
- 작성 화면에서 전송할 문항·기업·직무·현재 글·선택 경험의 개별 항목·선택 강점 해석·본인 답변을 검토하고 선택한다. 경험의 실제/모의/미확인·출처·버전은 선택 사실과 함께 유지된다.
- **문항·경험 연결**: 문항 요구 행동, 선택 경험의 적합 부분과 한계, 근거 부족, 강점–원문 행동의 연결 후보를 AI 피드백으로 보여 준다. 전체 비공개 보관함을 자동 전송하거나 실제 직무 능력을 판정하지 않는다.
- **질문**: 현재 기록·선택 답변을 읽고 부족한 맥락을 한 번에 하나 질문한다. 본문은 바뀌지 않는다.
- **문장 후보**: 별도 학생 사실 검토와 AI 처리 동의 후 2~3개 표현 후보를 요청한다. 비교·선택·추가/교체·바로 이전 본문 복원을 제공한다. 미선택 후보는 본문·파일·기업 공유에 들어가지 않는다.
- **화법**: 학생이 자기 원문 또는 직접 수정한 원문이라고 확인해 추가·선택한 예시만 사용한다. 원문 발췌를 포함한 잠정 규칙을 제안한다. 저장 후 다시 확인·활성화한 언어/용도별 규칙만 표현 선호로 전송한다. 규칙 편집 시 확인은 해제된다. 끄기·초기화 가능. 점수로 말투·성격을 추론하거나 모델 재훈련/탐지 회피를 주장하지 않는다.
- AI 결과·연결 설명은 해석 후보다. 사용자 선택이나 필드 채움은 외부 사실 검증이 아니다.
- 응답 대기·취소·시간 초과·제한·설정 없음·실패·재시도·출처 변경 상태를 처리한다. 중복 클릭은 진행 중 요청을 추가 생성하지 않는다.
- 경험·문항·언어·원문·답변·선호가 바뀌면 현재 제안/동의를 무효화한다. 늦은 응답은 사용하지 않으며, 다른 문항에 이전 결과를 적용하지 않는다. 과거 제출 버전은 수정하지 않는다.

## 서버 / 보안 경계

`POST /api/career/ai-assist`는 기존 Clerk 인증을 요구한다. 로그인 우회·소유권 검사 변경은 없다. 공개 합성/기기 모드에서는 실제 AI 호출을 허용하지 않는다.

서버 전용 설정 이름은 `AI_INTEGRATIONS_OPENAI_BASE_URL`, `AI_INTEGRATIONS_OPENAI_API_KEY`다. 값은 소스·브라우저·인계 ZIP에 포함하지 않는다. 별도 유료 상품 가입은 하지 않았다.

- `confirmed`: 이번 선택 자료의 AI 처리 동의. 기업 공유/기존 작성 동의를 대신하지 않는다.
- `factsConfirmed`: 문장 후보 요청 전 학생이 선택 기록의 맥락과 사실을 검토했다는 자기 확인. 외부 검증은 아니다. 문장 요청은 이 값이 없으면 거절한다.
- 원점수·IQ·검사 식별자·전체 검사 원문·비공개 메모는 전송 계약에 없다. 앱/경험 ID는 모델 입력에서 제거한다. 브라우저의 지문은 요청/응답 연결에만 쓰고 모델에는 보내지 않는다.
- 자료 속 명령은 데이터로 취급하도록 지시한다. 실제/모의·미실행 계획·합성 예시를 실제 성과로 승격하지 않는다. 공식 회사 자료가 없거나 기업/직무가 다르면 확인 필요로 남긴다.
- 요청/응답 본문을 별도 DB나 서버 로그에 기록하지 않는다. 관리형 공급자의 처리/보존 조건까지 “저장하지 않는다”고 보장하는 것은 아니다.
- 사용자당 프로세스 메모리 기준 분당 8회, 요청 크기 제한, 45초 모델 제한, 연결 취소를 적용한다. 여러 운영 인스턴스의 통합 제한·사용량 정책·감사/보존 계약은 운영 개발자의 후속 항목이다.

## 저장 범위 / 호환

기존 자소서 본문·계정 저장·버전·내보내기 경로는 유지한다. **새 코치 답변·본인 화법 예시/규칙·AI 제안 이력은 기존 provenance sidecar의 계정별 기기 저장뿐**이다. 계정 서버에 영구 동기화된다고 표시하지 않는다. 기기 삭제/변경 시 잃을 수 있다.

기존 sidecar에 `ai`가 없어도 빈 기본값과 병합한다. 저장 실패 시 성공 표시나 입력 삭제를 하지 않는다. AI 데이터는 기존 `CareerState`나 내보내기 필드에 자동 편입하지 않는다.

원본 공유 철회·삭제·변경 상태의 경험은 AI 전송에서 제외한다. 기존 학생 글과 제출 버전은 보존한다. 예전 AI 제안은 기기 이력에서 읽을 수 있지만 최신 원문 확인 없이 자동 적용하지 않는다.

## 외부 개발자 인계 — 미완료를 뜻하는 항목

실제 D-CAS 인증/결과 계약(4축·TOP5 원래 순서·이유·결과 버전), 플래너 선택 기록/원본 권한·버전, 기업LAB/NCS 출처, 중앙 로그인 계약, AI 보조 기록의 계정별 영구 저장은 별도 개발자 범위다. 이번 합성 검사/기존 계정 API는 이 운영 연결의 완료 증거가 아니다.

결과지 원점수 등은 AI에 보낼 필요가 없다. 승인된 해석·지원 전략과 선택 직무·근거 버전만 최소 계약으로 연결한다. `recommendationReason`이라는 새 AI 입력 필드에는 현재 강점 지원 전략만 들어가며, TOP5 재산출 근거로 쓰지 않는다.

## 15개 언어

기존 번역은 보존하고 새 AI 문구만 15개 언어에 추가했다. 작성 언어와 UI 언어는 분리한다. 언어 전환은 학생 원문을 번역하지 않는다. 모든 신규 번역은 내부 초안 검토 수준이며 원어민 검수는 미실행이다. 키 검사·브라우저 검사·원어민 검수는 서로 다른 판정이다.

위 문단은 이미 저장된 작업의 상태다. 이후 우선순위는 한국어 1차 완료이며, 기존 초안을 삭제하거나 다시 생성하지 않고 추가 다국어 작업은 보류한다.

## 실행 / 검사

의존성: 저장소의 pnpm workspace와 lockfile을 사용한다. 관리형 서비스는 Replit의 기존 두 워크플로로 실행한다. 직접 빌드는 서비스 설정을 명시한다:

```sh
pnpm install --frozen-lockfile
pnpm --filter @workspace/api-spec run codegen
pnpm --filter @workspace/nuvia-career run typecheck
pnpm --filter @workspace/api-server run typecheck
PORT=24976 BASE_PATH=/ pnpm --filter @workspace/nuvia-career run build
pnpm --filter @workspace/api-server run build
pnpm --filter @workspace/scripts exec tsx --tsconfig ../artifacts/nuvia-career/tsconfig.json src/nuvia-ai-contract-check.ts
# 다음 검사는 실제 관리형 AI 요청을 사용하며 사용량을 소비한다. 합성 자료만 사용한다.
pnpm --filter @workspace/scripts exec tsx src/nuvia-managed-ai-smoke.ts
```

현재 증거와 미검증은 `docs/nuvia-managed-ai-qa.md` 및 인계 패키지의 manifest/QA에 기록한다. 이전 고정 코치 QA나 과거 45화면 결과는 재사용하지 않는다.

한국어 후속 신규 시험·수정 및 원격 보존 적용 안내는 `docs/nuvia-korean-final-qa.md`가 최신이다. 실제 모델 시험의 최초 실패/재검사 기록도 보존한다.

## 적용

이번 패치는 실제 현재 기준 HEAD 위에 적용한다. 기준 커밋·변경 목록·전후 SHA256·작업트리 상태와 사본 적용 검사는 패키지 manifest를 따른다. 과거 고정 질문 브랜치 `fc000de`, 기존 `c51d3f2...`/이전 ZIP을 최신 소스 위에 덮어쓰지 않는다. 다른 기준 저장소에는 개발자가 diff를 검토·충돌 해결하고 생성 코드를 계약과 함께 적용한다.

공개 재배포·main 병합은 하지 않는다. GitHub 작업 브랜치 저장과 원격 대조는 이제 한국어 1차 완료의 필수 조건이다. 현재 인계 ZIP 생성이나 과거 커밋은 그 증거가 아니다. 사용자가 알려 준 원격 규칙 커밋/이전 소스 및 보존 원칙은 최신 규격을 따른다.
