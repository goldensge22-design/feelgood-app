## 학생 작성과 근거

- 학생이 네 영역(소개, 관심 기업·직무/이유, 판단·행동 경험, 배움/다음 적용)을 직접 쓴다.
- 원래 경험의 행동·결과·배움은 읽기 전용으로 확인한다. 새 문장을 자동 생성하거나 삽입하지 않는다.
- 기존 AI 질문·문장 후보·선택형 STAR는 별도 지원 초안을 명시적으로 만든 뒤 기존 `/write`에서 사용한다.
- 연결한 초안이 있으면 재사용하여 반복 클릭으로 같은 초안을 중복 생성하지 않는다.
- 초안에서 수정한 글은 미리보기에서 대상 영역과 적용 동의를 선택해야 스토리보드에 반영된다.
- 스토리보드의 문장들은 선택 경험 한 건의 정확한 원문/출처/성격/권한/동의 스냅샷에 내부적으로 연결된다.
  이는 로컬 연결 근거이며 원격 검증 서명이나 자동 사실 판정이 아니다.
- 실제/모의/미확인, 합성 예시, 제공받은 도움과 독립 행동의 기존 구분은 유지한다.
  결과지 인지특성·키워드는 실제 직무 능력이나 성과의 증명이 아니다.
- 최종 확인은 현재 입력 버전과 원본 연결에만 유효하다. 편집·직무 변경·원본 변경·삭제·철회 시 해제한다.
  확인 후 원래 텍스트로 되돌려도 자동 재확정하지 않는다.
- 기업 공유 동의를 대신하지 않으며 기업 전송은 없다. 과거 확인 버전은 별도 스냅샷으로 남긴다.

## 저장·실패와 격리

새 스토리보드는 `nuvia:storyboard:v1:<scope>` 기기 보조 저장이다.
scope는 guest/demo/account 문맥으로 분리하며 공개 합성 체험은 기존 public-demo 세션 저장 규칙을 따른다.
계정 서버 영구 저장·다른 기기 동기화가 아니다. 브라우저 데이터 삭제 시 잃을 수 있다.
원문 경험과 기존 자소서 버전을 이 저장소로 이동하거나 초기화하지 않는다.

지연 자동 저장과 명시적 저장, 실패 안내/재시도, 새로고침 복원을 제공한다.
저장소 손상/접근 불가 시 빈 초안으로 덮어쓰지 않는다.
동일 브라우저 다른 탭의 더 최신/동일 버전 상충 저장은 거절한다.
이는 브라우저 기기 저장 보호이며 운영 서버의 다중 사용자 충돌·소유권 QA를 대체하지 않는다.
브라우저에서 관찰하지 못한 원격 변경/철회는 실제 연결 전에는 확인할 수 없다.

## 실제 파일 형식

| 형식 | 이번 구현 | 제한 |
|---|---|---|
| PDF `.pdf` | 브라우저에서 실제 PDF 바이트 생성. 기본 선택 | 이미지 기반 PDF이며 검색/본문 텍스트 선택용이 아님. 브라우저 폰트가 필요 |
| DOCX `.docx` | 기존 서버의 진짜 OOXML 생성 재사용 | Microsoft Word 실제 열기 별도 미검증 |
| HWPX `.hwpx` | 기존 서버의 진짜 HWPX 생성 재사용 | 한컴 실제 열기 별도 미검증 |
| TXT `.txt` / 복사 | 학생이 작성·확인한 영역만 사용 | 클립보드는 브라우저 권한에 따라 거절될 수 있음 |
| HWP `.hwp` | 미지원으로 비활성 표시 | HWP를 실제 생성하는 승인된 변환기/실행 환경 및 한컴 편집·재저장 검증 필요 |
| DOC `.doc` | 미지원으로 비활성 표시 | 진짜 legacy binary DOC 변환기 및 Word 편집·재저장 검증 필요 |

확장자 바꾸기/HTML 위장은 하지 않는다. 자동으로 외부 변환 서비스에 학생 글을 보내지 않는다.
PDF는 읽을 수 있는 글자 크기를 유지하고 넘치면 추가 페이지를 만든다.
분량 예측 경고와 미리보기를 제공하며 한 페이지를 맞추기 위해 원문 삭제/숨김/과도한 축소를 하지 않는다.
출력은 제목·기업·직무·학생이 작성한 네 영역만 허용한다.
선택 키워드/인지 점수/IQ/81유형/내부 식별자/비공개 메모/동의 메타데이터/QA 상태는 자동 출력하지 않는다.

  https://replit.com/replid/9180b529-621d-4547-8da5-54fa03c9800b

- 위 주소는 사용자가 제공한 **프로젝트 식별 링크**이며 API/레코드 복귀 링크가 아니다.
- 과거 인계 문서는 `goldensge22-design/feelgood-app`의 결과지/플래너 자료를 참고했으나
  현재 승인된 중앙앱/운영 백엔드의 프로젝트명·주소·인증 계약을 확정하지 않는다.
- 현재 자소서 서버는 미승인 `planner` 출처를 거절하는 기존 경계를 유지한다.
  직접 입력 출처로 바꿔 통과시키거나 인증을 약화하지 않는다.

담당 개발자가 연결할 최소 계약:

1. 중앙 사용자 신원과 각 앱 소유권 매핑, 허용된 테스트 계정/환경. 인증정보는 안전한 설정 경로만 사용.
2. 선택한 기업/직무/키워드와 해당 자료 버전·출처. 결과지 TOP5는 원래 순서·추천 이유 그대로 전달.
3. 사용자가 선택·확인한 **수행** 기록의 식별/버전, 행동·판단·수정·관찰 결과·배움 중 동의한 항목만.
   실제/모의·활동 카드 종류·자기보고/외부 확인·지원 방법은 독립 필드로 보존.
4. 서버에서 검사 가능한 소유권·공유 동의/철회 상태, idempotency 키, 중복 응답 규약,
   최신 버전 재조회 및 변경/삭제/권한 만료 오류. 비공개 원문 메모는 전달 금지.
5. 검증된 원본 레코드 복귀/왕복 주소와 새로고침·계정 전환·지연 응답 시 대상 일치.
6. 새 스토리보드/동의/근거/확인 버전의 계정 영구 저장 및 충돌 계약.

요청 발송/파일 복사/합성 데이터 수신은 실제 앱 간 전송 완료의 증거가 아니다.
이 패치는 연결 계약이 없는 데이터를 임의 endpoint로 보내거나 등록 성공을 만들지 않는다.

## 언어와 검증 구분

신규 문구는 15개 언어 별도 사전으로 추가하고 기존 사전 원문은 유지했다.
학생 원문은 언어 변경으로 번역하지 않는다. 아랍어 RTL과 기존 태국어/크메르어 폰트 규칙을 사용한다.
비한국어 신규 문구는 기계 초안이며 원어민 검수 완료로 취급하지 않는다.

`generated-artifacts/storyboard-qa/`의 시각·소스 지문·브라우저 보고서를 함께 본다.
