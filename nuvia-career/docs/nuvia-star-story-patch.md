# STAR 경험 정리 보강 — 개발자 인계 및 검증

이 문서는 자소서 프런트엔드의 선택형 STAR 경험 정리와 15개 언어 확장 범위, 검증 상태를 설명한다. 실제 플래너·D-CAS 연결, 계정 서버 저장, 오피스 앱에서의 시각 검증이 완료됐다는 뜻은 아니다.

## 이번 프런트엔드 변경

- 경험 보관함에서 기존 행동·결과·배움은 유지하고 당시 상황(S), 내 역할·목표(T), 행동 선택 이유, 결과 확인 근거를 선택 입력으로 추가했다.
- 작성 화면에 기본 접힘 상태의 ‘경험 정리 도움’을 두었다. 필요한 항목만 사용자가 자기 말로 입력하고, 행동·결과·배움은 기존 경험 저장 흐름을 쓴다. 도우미 내용은 자소서 본문에 자동 삽입·재작성되지 않는다.
- 질문 코치는 연결 경험에서 비어 있는 맥락을 우선하여 정해진 한국어 질문 하나를 보여 준다. 모의 활동에는 모의 상황·제공된 도움·스스로 선택한 행동을 구분하는 질문을 사용한다. AI 본문 분석·사실 판정·능력 점수는 하지 않는다.
- 지원동기·가치관·계획으로 확인되는 문항은 기존 코치 질문을 기본으로 유지한다. STAR 질문은 사용자가 작성 화면에서 명시적으로 선택할 수 있다. 문항 분류는 한국어 문구에 대한 고정 규칙이며 AI 분석이 아니다.
- 실제 수행/모의 연습과 일상 적용형/직무 상황형을 별개로 표시한다. 직접 입력한 옛 경험은 성격을 추정하지 않고 ‘확인 전’으로 둔다.
- 플래너가 제공하기로 한 필드가 경험 입력에 이미 포함되면 읽어 사용하도록 준비했지만, 실제 플래너 조회·저장·왕복 연동은 하지 않았다.
- 카드 유형과 경험 성격을 별도로 표시한다. 기존에 의미가 바뀌지 않은 14개 언어 문자열은 덮어쓰지 않았다.
- STAR 전용 제목·설명·입력 레이블/안내·저장 상태·오류·코치 질문을 15개 기본 언어에 추가했다. 번역 상태는 내부 인계 문서와 테스트에서만 관리하며 일반 화면에는 검수 메타데이터를 노출하지 않는다.
- 신규 번역은 원어민 검수 전 기계 번역 초안이다. 한국어 원문과 기존 14개 언어 번역은 보존했다. 합성 예시는 기존 로케일별 샘플 번역을 사용하고, 사용자가 쓴 경험·문항·본문은 언어 전환으로 번역하지 않는다.

## 보관·전송 경계

- 상황, 역할·목표, 선택 이유, 결과 확인 근거는 `nuvia:provenance:v1:<context>` 기기 보조 기록으로만 저장된다. 공개 합성 데모는 별도 브라우저 세션 저장 영역을 사용한다.
- 이 추가 STAR 보조 기록은 계정 서버, 플래너, 자소서 본문, 버전 문서, 복사, DOCX/HWPX 내보내기에 자동 전송되지 않는다. 기존 경험의 행동·결과·배움은 기존 워크스페이스 저장 규칙을 유지한다.
- 기록 실패 시 입력을 남기고 재시도를 표시한다. 기존 불변 버전의 STAR 메타데이터를 편집할 때 과거 버전은 변경하지 않는다.
- 개발자 측에서 서버 보관을 확장할 경우 사용자 확인, 소유권, 기기 데이터 이관 동의, 원본 버전·공유 권한 재검증 계약을 별도 합의해야 한다. 현재 프런트엔드의 sidecar 값을 서버 계약으로 간주하지 않는다.

## 한국어 우선 패치의 이전 기준 QA 기록

2026-11-07 UTC, 최신 빌드 산출물을 로컬 브라우저로 검사했다. 테스트는 로그인 계정이 아닌 합성 공개 데모 세션을 사용했다.

- 한국어 1440×1000, 768×1024, 360×800: 각 7개 주요 체크 통과. 카드 유형과 경험 성격의 별도 표시, 직접 기록의 미확정 유지, 모의 코치, 접힌 도움 열기, 지원동기 문항에서 기존 코치 유지와 사용자의 STAR 전환, 언어 전환·경로·입력 유지, 기기 저장 실패 후 재시도, 새로고침 복원, 2개 버전 비교와 이전 버전에서 새 초안, 복사·DOCX·HWPX 다운로드 및 STAR 보조 기록의 내보내기 제외를 확인했다.
- 세 크기 모두 수평 넘침이 없고 언어 선택기의 최소 영역이 44×44px였다.
- 단위·로케일·워크스페이스 검사 19/19 통과, 웹 타입 검사 통과, 기존 합성 provenance 브라우저 스모크 통과.
- 합성 데모에서 실제 내려받은 DOCX/HWPX의 본문·ZIP/MIME/XML·미리보기 텍스트를 입력과 기계 판독 대조했다. STAR 보조 기록은 전송 페이로드에 없었다.
- Microsoft Word·한컴에서 실제 열기/화면 확인은 미실행이다. 실제 계정 로그인, 플래너·D-CAS 연동, 서버 저장·소유권은 별도 개발자 범위이며 이번 검증에서 실행하지 않았다. 15개 언어 전체의 신규 STAR 번역 품질 검수도 미실행이다.
