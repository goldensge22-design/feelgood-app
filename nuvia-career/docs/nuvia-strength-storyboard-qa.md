## 실행 결과와 수정

타입 검사와 웹 배포 빌드 성공. 빌드의 기존 sourcemap/큰 번들 경고는 남아 있다.
직접 shell 빌드 첫 시도는 관리형 서비스가 제공하는 `PORT`/`BASE_PATH`를 생략하여 실패했으며,
두 값을 명시한 아래 명령으로 정상 빌드했다. 앱 코드 오류를 숨긴 것이 아니다.

```sh
pnpm --filter @workspace/nuvia-career typecheck
PORT=24976 BASE_PATH=/ pnpm --filter @workspace/nuvia-career build
pnpm --filter @workspace/scripts exec tsx \
  --tsconfig ../artifacts/nuvia-career/tsconfig.json --test \
  ../artifacts/nuvia-career/src/lib/storyboard.test.ts \
  ../artifacts/nuvia-career/src/lib/provenance.test.ts \
  ../artifacts/nuvia-career/src/lib/star-story.test.ts
```

단위/관련 기존 STAR·출처 회귀: **18 통과 / 0 실패 / 0 건너뜀**.
신규 7건은 15언어 신규 사전 완전성, 입력/원본 확인 격리, 과거 버전 보존,
브라우저 문맥별 격리·오래된 탭 저장 거절, 저장 실패/손상 방지,
출력 허용 목록·모의 문맥, AI 편집기 연결 시 원문 확인 유지다.

브라우저:

- 합성 모의 기록 선택 → 기업/직무/키워드 → 학생 직접 네 영역 작성 → 저장/새로고침 →
  사실·사용 확인 → 별도 지원 초안 → 기존 작성 화면 → 검토한 부분 가져오기 → 버전 복원.
- 빠른 동기식 중복 클릭이 지원 초안을 두 건 만들던 문제를 ref 잠금으로 수정했다. 수정 후 한 건 생성 확인.
- 지원 초안 연결만으로 사실 확인이 불필요하게 해제되던 문제를 수정했다.
  **과거 본문 버전을 복원할 때 확인을 해제하는 것은 요구사항대로 유지한다.**
- 가져오기 미리보기를 편집 가능하게 바꿔 검토·선택한 부분만 대상 영역에 적용한다.
  미리보기 편집 시 적용 동의를 다시 받는다. 다른 영역은 유지됨을 재검사했다.
- 같은 기업/직무/경험 버전 복원은 연결된 지원 초안을 유지한다.
  다른 대상 복원 시 링크 해제 분기는 브라우저에서 별도 실행하지 않았다.
- 기존 합성 경험 편집기의 맥락 선택에서 합성 값이 빠져 일상 실제 수행처럼 보이던 문제를 수정했다.
  합성 값 유지·편집 불가를 재검사했다.
- 원본 경험 복귀 링크가 해당 경험을 선택·강조하고 왕복 후 스토리보드 입력과 버전을 유지함을 확인했다.
- 모바일 저장 안내 문구의 비정상적인 폭 축소를 수정했다.
- 모바일 가로 넘침의 최초 의심 대상은 알림 영역이었으나 알림을 숨겨도 재현됐다.
  브라우저 DOM 실험에서 단계 안내의 `min-w-max`를 제거하면 360px로 돌아옴을 확인했다.
  단계 안내를 줄바꿈 가능한 레이아웃과 44px 링크로 수정했다.
  효과가 없던 알림 수정은 원복했고 전역 overflow 숨김으로 가리지 않았다.
  최종 재검사 결과는 아래 최종 보충 및 원본 JSON을 따른다.

최초 실패와 수정 후 재검사를 지우지 않고 `summary.json`, `final-qa.json` 등 원본 결과로 구분한다.
원본 보고서의 내부 키 입력 변경 횟수는 제출 버전 수나 사용자 점수가 아니다.

## 문서

실제 브라우저 다운로드: PDF/TXT/DOCX/HWPX.
짧은 합성 예시 PDF는 실제 A4 1페이지로 렌더링해 한국어 제목과 내용을 시각 확인했다.
360px 터치 환경에서도 PDF 다운로드를 확인했다.
PDF는 이미지 기반이므로 텍스트 추출 결과를 원문 검증으로 꾸미지 않고 시각 렌더를 확인한다.
TXT 본문, DOCX XML, HWPX ZIP/본문 구조를 검사했고 모의 표현을 보존한다.
허용 목록 단위 검사에서 원본 메타데이터가 자동 포함되지 않음을 확인했다.
다운로드 파일의 해시는 `downloads-sha256-final.txt`를 본다.

진짜 HWP와 legacy DOC 변환은 미지원이다. 확장자 변경 파일을 만들지 않았다.
Microsoft Word·한컴 실제 앱 열기/편집/재저장은 미실행이다.
