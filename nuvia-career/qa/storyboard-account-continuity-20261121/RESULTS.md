- 직전 공유 통합 소스 `f70499a71a419016408407d30cb76f7a9411ea70`. 1차 브라우저 기준 `cb8e03abf87ac4176123def7ac17ea3d32f8e922`는 에이전트 첨부 메타데이터만 차이가 있어 앱 실행본 동일.
- 최종 소스 `fe7a9d313b4864e1e5d12a52964b7d10a9ef28d5`. 변경은 스토리 ‘보관한 글’의 복구 사본 표시·미리보기·이어쓰기 안내와 테스트에 한정. API, 인증, 저장·다운로드·원본 플래너 동작은 변경하지 않았다. `browser-initial-pass.md`의 저장 오류/모의 표시/다운로드 결과는 해당 코드 변경 없이 유지되며 복구 경로는 최종 소스에서 재확인한다.
- 최종 웹 typecheck, 웹 빌드, 충돌 복구/세션 세대 등 관련 테스트 8건 성공. API 소스에는 변경이 없어서 이전 통과한 빌드를 이유 없이 다시 실행하지 않았다.
- `integration.patch`는 최초 기존 계정 통합 기준 `8dcc40a` 대비 누적 변경, `continuity-only.patch`는 원본 통합 `f70499a` 대비 이번 변경 3개. 둘 중 자신의 기준에 맞는 패치 하나만 적용한다. 두 패치는 각각 사본에 검사·실제 적용하고 최종 소스와 바이트 단위로 대조한다.
- 다른 프로젝트, 계정 서버 스키마, 운영 DB, 공개 게시, GitHub 원격은 변경하지 않았다. 실제 사용자 대신 개발 합성 계정만 썼다.
