# NUVIA 자소서 추가 개발 규칙

적용 범위: 이 `nuvia-career/` 프로그램과 기업 대시보드로 전달하는 데이터 계약. 다른 프로그램 전체에 적용하는 규칙이 아니다.

2026-10-27 사용자 요청으로 추가한 규칙이다. 상세 규격은 [기업 공유·행동 근거 규칙](docs/COMPANY_SHARING_EVIDENCE_RULES.md)을 따른다. 기존 문서와 이 추가 기능의 정책이 충돌하면 해당 범위에서는 이 규격을 우선한다. 원본 스냅샷이나 과거 QA 기록은 완료 증거로 소급 수정하지 않는다.

1. 한국어로 결과지 → 기존 플래너 → 자소서 → 기업 공유의 흐름을 먼저 구현·검토하고, 수정·재검증 후 확정한다. 이후 변경된 기능을 나머지 14개 언어에 반영한다. 기존 언어·입력·정상 기능은 제거하지 않는다. 새 UI는 처음부터 translation key를 사용하며 미검수 언어를 완료로 표시하지 않는다.
2. 지원서 작성 사용 동의, 사용자 사실 확인, 특정 기업에 공유하는 동의를 별도로 취급한다. 작성 동의나 `confirmed`만으로 기업에 전송하지 않는다.
3. 기업 공유 동의는 최종 검토·내보내기 화면의 별도 기업 공유 흐름에서, 수신 기업·채용 공고·자료·버전·열람 기간을 미리 본 뒤 받는다. 일반 다운로드에는 기업 공유 동의를 요구하지 않는다. 기본 미선택이며 서버 검증과 공유 이력을 구현한다.
4. 확인 역량 수와 근거 일치도는 공유된 실제 행동 근거와 사전 승인된 직무 기준의 연결 상태를 나타낸다. 사용자 자기확인만으로 검증 완료라 하지 않는다. IQ·PASS·D-CAS 점수·81유형·직무 TOP5·활동 수행률로 채용 점수나 이 지표를 계산하지 않는다. 모의 활동은 별도 표시한다.
5. 공통 근거와 면접 확인사항에는 동의 범위 안의 원문·출처·버전·연결 기준을 붙인다. AI는 관련 문장과 질문 후보를 제안할 수 있지만 사실·경력·성과·누락값을 만들어 채우거나 합격·서열을 결정하지 않는다.
6. 실제 결과지·플래너 API, 소유권·공유 권한·서버 저장은 담당 개발자가 연결한다. 기존 인증·출처 검사를 우회하지 않고 기기 저장을 서버 연동 완료로 보고하지 않는다.
7. 문서 저장과 기능 구현을 구분한다. 한국어 수용 검사를 통과하기 전 다국어 반영 완료나 기업 공유 기능 완료라고 보고하지 않는다.
