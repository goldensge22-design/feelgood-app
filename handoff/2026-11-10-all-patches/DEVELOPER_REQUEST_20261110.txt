이전 STAR 단독본과의 관계

이 누적본은 기존 STAR 보강과 새 직무 연결 기능을 함께 포함합니다. 이전 AI자소서_STAR_15언어_보강패치_20261110.zip의 20파일 패치를 추가로 중복 적용하지 않습니다. 누적 변경의 기존 GitHub 기준은 b2afd61이고, Replit 원본은 bd181075입니다.



반영할 기능

상황·역할/목표·직접 행동·결과 근거를 정리하는 선택형 STAR 도움과 한 번에 질문 하나씩 보여주는 코치를 유지합니다.

지원 직무의 구체 업무 → 학생이 한 행동과의 공통점 → 배운 원칙 → 향후 적용을 기록합니다. 막연한 성실함·꼼꼼함 표현에서 끝나지 않도록 돕습니다.

출처 종류·자료명·기업·직무·버전을 기록하고, 다른 회사나 직무의 근거가 현재 지원서와 맞지 않으면 확인을 막습니다. 앱이 외부 출처를 자동 조회·검증하는 기능은 아닙니다.

일상에서 실제 수행한 경험, 수업 모의훈련, 실제 직무 경험과 미확인 자료를 구분합니다. 계획이나 예시를 수행 성과로 바꾸거나 없는 정량 성과를 만들지 않습니다.

학생 확인은 선택한 지원서·경험·근거에 묶습니다. 관련 내용을 바꾸면 확인을 해제하고, 값을 되돌려도 자동 복구하지 않습니다.

학생의 본문을 자동 수정하지 않고, 승인한 보조 기록도 본문·내보내기·기업 공유에 자동 삽입하지 않습니다. 과거 제출 버전은 보존합니다.



저장과 실제 연결

새 직무 연결 보조 기록은 현재 기기 전용 저장입니다. 계정별 서버 저장이나 다른 기기 동기화 완료로 처리하지 말고, 기존 API·권한·동의·원본 버전·철회 규칙을 연결해 확장해 주세요.

운영 연결 흐름은 플래너의 실제 실행 기록 → STAR 정리 → 직무 연결과 배운 점 → 학생 확인 → 자소서 작성입니다. LAB는 직무·활동의 근거를, 플래너는 실제 행동·결과를, 자소서는 이를 활용한 표현을 담당합니다.



최신 검수 기록

단위 32/32, 15언어×3화면 45/45와 540개 흐름 검사, TXT·DOCX·HWPX 45파일의 내용·구조 검사 통과. 타입·production 빌드도 통과했습니다. GitHub fc000de 저장을 확인했습니다.

실제 로그인·계정 격리·서버 저장·결과지/플래너/LAB 연결, Word·한컴 직접 열기, 원어민 검수는 남아 있습니다. 규칙형 질문 코치를 실제 생성형 AI 연결 완료로 표시하지 않습니다.
