# 결과지 언어 적용 범위

`전체`은 정적 화면, 개인화 문장, 메뉴, 접근성 문구, 인쇄/PDF까지 같은 locale로 표시되는 상태다. `부분`과 `레이어`는 운영 언어 선택기에 노출하지 않는다.

## 현재 판정

| 결과지 | 전체 적용 | 부분 적용 | 레이어 전용 | 미적용/누락 |
|---|---|---|---|---|
| K-PASS 아동 | `ko` | `en/th/vi/ru/ar/es/zh/ja/it` 표지·메뉴 | 없음 | `az/km` |
| D-CAS 청소년 | `ko/en` | 없음 | 81유형 `ja/zh/es/ru/vi/th/ar/it/az/km` | 전체 결과지 기준 해당 레이어 언어 |
| D-CAS 성인 | `ko` | 없음 | 81유형 `en/ja/zh/es/ru/vi/th/ar/it/az/km` | 전체 결과지 기준 해당 레이어 언어 |
| `files.zip` 직무 패치 | 없음 | 직무명 10개+학과명 `ko/en/ja/zh/es/ru/vi/th/ar/it/az` | 직무 라벨 전용 | `km`, 추천 이유, 결과지 본문 |

## 혼재가 발생했던 이유

### K-PASS

`I18N`에 여러 언어의 표지·메뉴가 있지만 본문과 개인화 엔진 문장은 한국어다. 영어는 경고문도 `null`이라 전체 번역처럼 보였지만 실제로는 한국어 본문이 남는다. 통합 후보본은 `fullReportLocales=["ko"]`만 언어 메뉴에 노출하도록 바꿨다. 부분 locale 데이터는 삭제하지 않고 향후 전체 번역에 재사용한다.

### D-CAS 청소년

`teen.work.html`은 한국어/영어 전체 섹션을 가지고 있다. 반면 `dcas-profile81-bank.js`는 12개 언어이므로, 81유형 언어를 `km`으로 직접 바꾸면 나머지 셸과 동적 문장은 한국어/영어로 남는다. 서버/사용자 언어는 반드시 전체 셸 locale와 81유형 locale를 한 번에 전환해야 한다.

### D-CAS 성인

`adult.work.html`과 `dcas-adult-content-engine.js`는 한국어 중심이다. 81유형만 12개 언어다. 따라서 현재 운영 가능한 전체 locale는 `ko`뿐이다.

## 캄보디아어 완료 조건

각 결과지에서 다음 영역이 모두 `km`이어야 manifest의 `fullReportLocales`에 추가한다.

| 영역 | K-PASS | D-CAS 청소년 | D-CAS 성인 |
|---|---:|---:|---:|
| 표지/메타/언어 선택기 | 필요 | 필요 | 필요 |
| 목차/탐색/버튼 | 필요 | 필요 | 필요 |
| 기질/강점/약점 | 필요 | 필요 | 필요 |
| 점수·그래프 라벨 | 필요 | 필요 | 필요 |
| 개인화 문장 엔진 | 필요 | 필요 | 필요 |
| 학습/업무 방식 | 필요 | 필요 | 필요 |
| 진로·학과·직무 | 필요 | 필요 | 필요 |
| FAQ/주의/보호 안내 | 필요 | 필요 | 필요 |
| 접근성/오류/빈 상태 | 필요 | 필요 | 필요 |
| 인쇄/PDF/파일명 | 필요 | 필요 | 필요 |
| Google 번역 및 기술 QA | 필요 | 필요 | 필요 |

현재 D-CAS 81유형 `km`은 `ai-draft`이고 위 표의 일부만 충족한다. 사용자의 지시에 따라 원어민 검수 없이 Google 번역으로 작업하되, 전체 번역과 기술 QA가 끝날 때까지 전체 결과지 언어 선택기에 노출하지 않는다. 검사 판정 기준의 확정 여부는 번역 완료와 별도로 관리한다.

## 승격 절차

1. 기준 `ko` stable key를 확정한다.
2. 신규 locale 리소스의 key·placeholder를 기준과 비교한다.
3. 사용자 이름/점수/날짜가 locale 리소스에 고정되어 있지 않은지 검사한다.
4. 실제 프로필 2개 이상으로 모든 섹션을 렌더한다.
5. PC, 390px 모바일, A4 PDF를 확인한다.
6. 한국어 잔존, key 노출, 빈 값이 0건이어야 한다.
7. Google 번역 및 위 기술 QA 완료 증거를 기록한 후 manifest의 `fullReportLocales`에 추가한다. 내부 번역 상태는 실제 근거에 맞게 유지한다.
