# 결과지 언어 적용 범위

`전체`은 정적 화면, 개인화 문장, 메뉴, 접근성 문구, 인쇄/PDF DOM까지 같은 locale로 표시되는 상태다. 세 결과지 모두 12개 locale 전체 적용 후보본으로 승격됐다.

## 현재 판정

| 결과지 | 전체 적용 | 부분 적용 | 레이어 전용 | 미적용/누락 |
|---|---|---|---|---|
| K-PASS 아동 | `ko/en/ja/zh/es/ru/vi/th/ar/it/az/km` | 없음 | 없음 | 없음 |
| D-CAS 청소년 | `ko/en/ja/zh/es/ru/vi/th/ar/it/az/km` | 없음 | 기존 81유형 12개 언어 보존 | 없음 |
| D-CAS 성인 | `ko/en/ja/zh/es/ru/vi/th/ar/it/az/km` | 없음 | 기존 81유형 12개 언어 보존 | 없음 |
| `files.zip` 직무 패치 | 없음 | 직무명 10개+학과명 `ko/en/ja/zh/es/ru/vi/th/ar/it/az` | 직무 라벨 전용 | `km`, 추천 이유, 결과지 본문 |

## 혼재가 발생했던 이유

### K-PASS

기존 `I18N` 표지·메뉴 번역은 보존했다. 공통 locale 번들과 runtime이 한국어 source DOM 전체와 개인화 엔진 문장을 번역하며, 기존 부분 번역이 전환 상태를 오염시키지 않도록 초기 shell은 한국어 source로 고정했다.

### D-CAS 청소년

공통 runtime이 결과지 shell과 `dcas-profile81-bank.js` 81유형 언어를 함께 전환한다. 81유형 기존 번역은 재생성하지 않고 보존한다.

### D-CAS 성인

성인 shell, 개인화 엔진, 전공·학습·업무·진로·직무 문장을 12개 locale 번들로 연결했다. `person.majorName`은 번역 리소스에 고정하지 않고 서버값을 유지한다.

## 캄보디아어 완료 상태

각 결과지에서 다음 영역이 모두 `km`이어야 manifest의 `fullReportLocales`에 추가한다.

| 영역 | K-PASS | D-CAS 청소년 | D-CAS 성인 |
|---|---:|---:|---:|
| 표지/메타/언어 선택기 | 완료 | 완료 | 완료 |
| 목차/탐색/버튼 | 완료 | 완료 | 완료 |
| 기질/강점/약점 | 완료 | 완료 | 완료 |
| 점수·그래프 라벨 | 완료 | 완료 | 완료 |
| 개인화 문장 엔진 | 완료 | 완료 | 완료 |
| 학습/업무 방식 | 완료 | 완료 | 완료 |
| 진로·학과·직무 | 완료 | 완료 | 완료 |
| FAQ/주의/보호 안내 | 완료 | 완료 | 완료 |
| 접근성/오류/빈 상태 | 완료 | 완료 | 완료 |
| 인쇄/PDF DOM | 완료 | 완료 | 완료 |
| Google 번역 및 기술 QA | 완료 | 완료 | 완료 |

한국어 정적 원문 3,607개와 실제 프로필 렌더에서 수집한 동적 원문 1,549개를 Google 번역으로 11개 대상 언어에 번역했다. 잔여 한국어·대괄호 예시 51개와 런타임 성별 라벨 2개도 별도 보정했다. 기존 D-CAS 81유형 `km` 레이어의 `ai-draft` 출처 표시는 보존한다. 전체 번역은 `Google machine-translated + technical QA` 상태이며 원어민 검수 완료를 의미하지 않는다.

실제 Chrome에서 세 결과지 × 12개 locale의 390px 렌더, RTL, 사용자 이름·성인 전공 보존, 한국어/내부 토큰 잔존, 가로 overflow와 live locale 전환을 검사했다. 대표 한국어 D-CAS PDF 자동 생성은 통과했지만 12개 언어 전체 PDF의 원어민·육안 검수는 별도 배포 QA 항목이다.

## 승격 절차

1. 기준 `ko` stable key를 확정한다.
2. 신규 locale 리소스의 key·placeholder를 기준과 비교한다.
3. 사용자 이름/점수/날짜가 locale 리소스에 고정되어 있지 않은지 검사한다.
4. 실제 프로필 2개 이상으로 모든 섹션을 렌더한다.
5. PC, 390px 모바일, A4 PDF를 확인한다.
6. 한국어 잔존, key 노출, 빈 값이 0건이어야 한다.
7. Google 번역 및 위 기술 QA 완료 증거를 기록한 후 manifest의 `fullReportLocales`에 추가한다. 내부 번역 상태는 실제 근거에 맞게 유지한다.
