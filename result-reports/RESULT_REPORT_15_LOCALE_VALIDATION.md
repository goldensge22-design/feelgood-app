# K-PASS / D-CAS 15개 언어 적용 검증

검증일: 2026-09-22  
개발 브랜치: `codex/result-reports-15-locales`  
기준 커밋: `245e2edb410c57efcc3b27b4dda95dce18382cf3`

## 지원 언어

세 결과지 모두 다음 15개 locale을 전체 결과지 후보 범위로 제공한다.

`ko`, `en`, `ja`, `zh`, `zh-TW`, `es`, `fr`, `ru`, `vi`, `th`, `ar`, `it`, `az`, `km`, `mn`

- `zh`: 중국어 간체 호환 코드
- `zh-TW`: 중국어 번체
- `km`: 크메르어(캄보디아어)
- `mn`: 몽골어

## 변경 방식

- 기존 번역은 재생성하지 않았다.
- K-PASS 기존 12개 번역 배열과 D-CAS 기존 11개 번역 배열을 기준 커밋과 SHA-256 방식으로 비교해 모두 동일함을 확인했다.
- K-PASS에는 `zh-TW`, `fr`만 증분 추가했다.
- D-CAS 청소년·성인에는 `zh-TW`, `fr`, `mn`만 증분 추가했다.
- D-CAS의 기존 81유형 원본 레이어 12개 언어는 변경하지 않았다. 신규 언어의 81유형 화면 문장은 전체 결과지 공통 번들이 한국어 source DOM을 번역한다.
- 번역 상태는 `Google machine-translated + technical QA`이며 원어민 검수 완료를 의미하지 않는다.

## 자동 검증 결과

- locale 정적 검증: 15개 언어, 누락·빈 값·한국어 잔존·내부 token·인코딩 오류 0
- placeholder 검증: 동적 placeholder 보존
- 기존 번역 보존: K-PASS 12개, D-CAS 청소년 11개, D-CAS 성인 11개 기존 target 배열 동일
- 모바일 실제 DOM: 3종 × 15개 = 45개 조합 통과
- RTL: 아랍어 방향 전환 통과
- live locale 전환: URL, 사용자 이름, 성인 전공 유지 통과
- 가로 overflow: 390px 전 조합 통과
- 항공보안학과 10개 직무: `ko/zh/zh-TW/fr/km/mn` 실제 DOM 통과
- K-PASS 개인화 및 15개 언어 메뉴 통과
- D-CAS 81개 조합, H/M/L 경계, S/Q 차이 0·10·11, 누락·비정상 점수 통과

## 배포 전 남은 확인

- 전체 15개 언어의 모든 PDF 페이지를 사람이 한 장씩 육안 검수한 것은 아니다.
- 기계 번역 문체와 전문용어는 향후 원어민 또는 분야 전문가 검수 시 증분 수정한다.
- 현재 작업은 후보본과 번역 번들만 갱신한다. `main` 병합, 기존 운영 결과지 교체, 서버 연동은 별도 승인과 staging 검증 후 진행한다.
