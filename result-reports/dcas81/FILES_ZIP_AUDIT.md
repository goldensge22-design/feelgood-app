## 다국어 범위

원본 ZIP의 직무명/학과명에는 `ko`, `en`, `ja`, `zh`, `es`, `ru`, `vi`, `th`, `ar`, `it`, `az`만 있다. 현재 후보본은 원본의 별도 label getter를 운영 의존성으로 추가하지 않고, 기존 공통 locale runtime과 증분 번역 카탈로그를 통해 직무명·추천 이유·결과지 문장을 `km`까지 연결한다.

따라서 다음을 구분해야 한다.

- 재사용 가능: 직무 라벨 getter와 `setLang(lang)` 패턴
- 별도 추가 필요: `km` 직무명/학과명, 직무 추천 이유, 화면 제목·설명·접근성 문구, 인쇄/PDF 문구
- 별도 검수 필요: 추정 직무 프로파일 10건

## 현재 최종 후보본과의 관계

원본 ZIP은 증거자료로 그대로 유지한다. 현재 개발 후보본은 새 patch script를 운영 시 추가 로드하지 않고 다음 항목을 성인 후보본의 기존 데이터·엔진에 직접 통합했다.

1. 기존 항공보안 4개를 요청된 10개 직무로 교체.
2. 항공보안과 산업보안 2개 중분류를 함께 조회.
3. `항공보안과`와 `항공보안학과`를 동일한 전용 10개 풀로 처리.
4. 일반 직무 풀의 `항공보안교육담당자`가 끼어드는 충돌 차단.
5. 12개 D-CAS locale 증분 번역과 실제 `ko/zh/km` DOM 검사 추가.

남은 운영 조건은 10개 `pass_profile`의 전문가 검수다. 현재 값은 원본과 동일한 `estimated`, confidence 0.5이며 이 상태를 숨기거나 확정값으로 승격하지 않는다.
