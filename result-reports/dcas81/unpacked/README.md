# D-CAS 청소년·성인 81유형 통합 패치 v1.0

작성일: 2026-09-19

## 패치 목표

1. P/A/S/Q 네 영역을 각각 상(H)·중(M)·하(L)로 판정
2. `P-M / A-H / S-L / Q-M` 형식의 81유형 코드 생성
3. 축별 정적 문장 라이브러리 조합 — 생성형 AI/API 미사용
4. 동점·균형형·전영역 저/중/고 예외 처리
5. 표지와 기질 특성 영역에 81유형 실제 표시
6. 학습·진로·직무 추천 설명에 81유형을 추가 입력으로 사용
7. 전영역 하/중 노출 규칙 확정
8. 11개 언어 지원

## 폴더 구성

- `PATCH_FILES/`: 기존 최종본에 덮어쓸 파일만 모은 패치
- `APPLIED_FULL/`: 패치가 이미 적용된 청소년·성인 전체 실행 폴더
- `TESTS/`: 81조합·경계값·11개 언어 자동 검증
- `TEST_REPORT.md`: 검증 결과

## 결정된 노출 방식

### 네 영역 모두 하 — `LLLL`

- 유형명: **균형형·전반적 기반 강화형**
- 표지 코드: `P-L / A-L / S-L / Q-L`
- 강점 표시: `상대적 강점 없음`
- 해석: 특정 한 영역만 취약한 것은 아니지만 네 영역의 기초 지원이 함께 필요
- 추천: 짧고 쉬운 단위, 한 번에 한 단계, 시각화, 즉각적 피드백, 완료 경험
- 진로/직무: 현재 점수만으로 선택지를 배제하지 않고 지원 환경에서 실제 수행을 확인

### 네 영역 모두 중 — `MMMM`

- 유형명: **균형형·표준 범위 탐색형**
- 표지 코드: `P-M / A-M / S-M / Q-M`
- 강점 표시: `특정 우세 영역 없음`
- 해석: 여러 전략을 활용할 수 있는 표준 범위이며 관심·지속성·과제별 성과를 통해 개인 강점을 탐색
- 추천: 계획·집중·전체 보기·순서 처리 전략을 번갈아 사용해 효과 비교
- 진로/직무: 점수만으로 확정하지 않고 흥미, 경험, 교육 가능성을 함께 반영

### 네 영역 모두 상 — `HHHH`

- 유형명: **균형형·고역량 통합형**
- 표지 코드: `P-H / A-H / S-H / Q-H`
- 추천: 복합 과제와 관심 분야의 심화·전문화

네 축이 같은 절대 수준에 속하면 작은 점수 차이만으로 임의의 최고축·최약축을 만들지 않습니다.

## 판정 기준

D-CAS의 현재 0~100 정답률 구조와 기존 코드 기준을 유지했습니다.

- H: 75 이상
- M: 53~74
- L: 52 이하
- 균형형: 최고점-최저점 차이가 20 미만

기준은 `dcas-profile81-bank.js`의 `DEFAULT_THRESHOLDS` 한 곳에서 관리합니다. 실제 규준 감수 후 값이 변경되면 이 상수와 기존 결과지 구간을 함께 변경해야 합니다.

## 11개 언어

지원 코드:

`ko`, `en`, `ja`, `zh`, `es`, `ru`, `vi`, `th`, `ar`, `it`, `az`

81유형의 유형명·요약·12개 축별 문장·학습/진로/직무 적용 문구가 모두 정적으로 저장돼 있습니다. 아랍어는 `dir="rtl"`로 표시합니다.

현재 전달받은 결과지 본문 셸은 청소년이 한국어/영어, 성인이 한국어 중심입니다. 이 패치는 **81유형 레이어 자체를 11개 언어로 완성**했으며, 기존 11개 언어 셸에서 아래 API로 연결할 수 있습니다.

```javascript
DCasTeenEngine.setProfile81Language('ja', PROFILE);
DCasAdultEngine.setProfile81Language('ar');
```

전체 결과지의 메뉴·일반 문단까지 11개 언어로 보이려면 기존 11개 언어 결과지 셸이 함께 연결돼야 합니다. 이 패치가 한국어로 남아 있던 일반 본문 전체를 새로 번역하는 것은 아닙니다.

## 적용 방법

가장 안전한 방법은 `APPLIED_FULL/`의 해당 폴더를 실행하는 것입니다.

기존 최종본에 적용하려면:

1. 원본을 백업합니다.
2. `PATCH_FILES/DCAS_TEEN/`의 파일을 청소년 폴더에 덮어씁니다.
3. `PATCH_FILES/DCAS_ADULT/`의 파일을 성인 폴더에 덮어씁니다.
4. HTML에서 `dcas-profile81-bank.js`가 콘텐츠 엔진보다 먼저 로드되는지 확인합니다.
5. `node TESTS/profile81.test.js`를 실행합니다.

## 추천 로직 적용 원칙

81유형은 기존 P/A/S/Q 점수에서 파생됩니다. 따라서 같은 점수를 직무 적합도 계산에 다시 가중하면 중복 반영이 됩니다. 이번 패치에서는:

- 기존 직무 순위 계산은 유지
- 81유형으로 학습 지원 강도 변경
- 진로 탐색 방식 변경
- 직무 추천 이유와 필요한 환경 조건 변경

으로 연결했습니다. 실행 결과는 `window.__DCAS_PROFILE81__`에도 저장되어 후속 추천 모듈이 동일한 유형을 재사용할 수 있습니다.
