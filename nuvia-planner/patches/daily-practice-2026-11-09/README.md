# 일상 활동 추천 연동용 검토 패치

먼저 [개발자 시작 지시서](../../docs/DAILY_PRACTICE_DEVELOPER_START_HERE_2026-11-09.md)를 읽으세요.

**이 폴더는 기존 실행 소스에 적용하지 않은 인계 패키지입니다.** 현재 GitHub 기준과 14개 파일 상태가 달라 바로 덮어쓸 수 없습니다. Replit 기준 전체 소스 또는 선행 변경을 확보해 개발자의 최신 결과지 연동본과 비교해야 합니다.

- 원본 ZIP과 추출한 payload/문서/QA 기록의 바이트는 보존했습니다.
- `verify-package.mjs`는 읽기 전용 무결성·번역 key·선택적 기준 버전 검사입니다.
- `PACKAGE_VERIFICATION.json`은 2026-11-09 GitHub 인계 시 독립 검증 결과입니다.
- 동봉 `README.txt`, `SOURCE_MANIFEST.json`, `qa/QA_STATUS.json`의 완료 표시는 신규 추천 기술 검수 범위에 한정합니다. 제품 전체 QA·실제 서버 연동·공개 출시 완료가 아닙니다.
- 신규 추천 10종 × 5연령 변형 50개, 신규 103 key × 15언어. 콘텐츠와 번역은 전문/원어민 검토 전입니다.
- 적용 스크립트는 실행하지 않았습니다. 실제 적용 전 검토하고 변경 전 해시가 다르면 중단하세요.
- 원본 `SHA256SUMS.txt`는 Replit 패키지 원본에 대한 것입니다. 이 README, 검증 도구/결과, `.gitattributes`, 원본 ZIP 자체는 GitHub 인계 과정에서 추가했습니다.
