# 일상 추천 연습 패치 QA

## 완료 판정

신규 추천 기능의 자동 검사와 대표 전체 여정, 15언어 화면/추가 흐름은 통과했다.
마지막 도움 선택 버튼의 올바른 명칭/수동 선택 유지 변경도 재검수 통과했다.
신규 패치는 기술 검수 완료로 인계하되, 전체 기존 테스트 통과·공개 승인·전문/원어민 검수 완료를 뜻하지 않는다.
과거 미완료 검수와 신규 검수는 별도로 보존한다.

## 신규 테스트 중 바로잡은 항목

- 합성 fixture의 subject/assessment ID를 기존 개인 저장 계약에 맞춰 수정했다.
- 새 일상 문맥의 로드맵 검증을 명시적으로 허용하되 미승인 직무 첨부 제한은 유지했다.
- 보고서의 HTML escape를 실제 문자열 그대로 검증하도록 테스트 기대 표현을 보정했다.
- 추천에서 선택한 도움을 실제 과제 표시/실행 support와 연결하고 기존의 이후 자기선택 도움도 존중했다.
- 제품 기본값과 학생 작성 원문을 구분하는 provenance/편집 이력 경계를 추가했다.
- 일본어 Other 후보의 grid 최소폭/CJK 줄바꿈을 수정해 360px의 15px 가로 넘침을 해소했다.
- 강점만 변경할 때 비교 화면을 재생성하던 동작을 없애 날짜·조건·작성 문장과 같은 목표를 유지했다.
- 날짜·역할을 순서 단계로 오인하지 않게 했고 초기 설정을 거짓 계획/도움 변경으로 세지 않는다.
- 빌드 도중 Go/esbuild의 OS thread 한도 오류가 한 번 발생했다. 원문 로그를 보존했으며
  해당 명령의 병렬도만 `GOMAXPROCS=2`로 제한해 통과했다. 플랜/결제/시스템 한도는 변경하지 않았다.

## 브라우저 계획과 증거

범위를 구분한다:

- 15언어×1440/360: 추천 열기/다른 후보/미리보기/수정/명시적 추가, 현지어 제품 문구·접근성·RTL·넘침·콘솔.
- 대표 전체 실행: 한국어/영어 데스크톱, 일본어 360px에서 실제 시작/멈춤/깃발/복귀/종료/완료·응답.
  모든 언어에서 전체 기존 타이머·백업 여정을 반복했다고 주장하지 않는다.
- 한국어/영어 데스크톱의 실제 개인 백업 다운로드/파일 복원/새로고침.
  최종 코드에서도 새 공개 기록으로 21,987바이트의 실제 다운로드 파일을 복원하고

  고등학생 date/date/text/text, 성인5개+대기 선택. 고등학생/성인의 강점 변경 후 작성값 유지와 명시적 추가 확인.

## 검수 환경 사건과 남은 한계

개발 중 HMR로 비교 상태가 중단된 기록을 보존한다. 소스를 동결한 뒤 새 context로 재검수했다.
명시적 workflow 재시작 직전의 오래된 탭 WebSocket disconnect는 새 페이지의 결함과 구분했고
완료한 조합을 삭제하거나 미실행을 통과로 만들지 않았다.

초기의 UI 404는 URL/시점이 포착되지 않아 원인을 확정하지 않는다.
별도 API 서비스의 GET `/` 404와 혼동하지 않는다. 최종 신규 화면의 page/console/HTTP/request error는 관측되지 않았다.

전체 목표×강점 UI 격자를 전부 수동 반복하지 않았다. 해당 계약의 자동 검사와 대표 강점 비교가 근거다.
원어민 번역 검수·전문 콘텐츠/효과 검증·실제 학생 독립 사용/장기 추적·실제 결과 서버/인증·기기간 동기화는 미검증 또는 미연결이다.
