# NUVIA PLANNER · 내 하루 작업대 검토 결과

이 보고서는 정식 운영 승인이나 연구 결과가 아니라 **독립 로컬 후보의 개발 검수**입니다.
기존 기준본·B형·enhancement·personal-monthly는 보존하며 새 진입점은 `studio.html`입니다.

## 사용 방법
- 일반 진입: 중학생 / 고등학생 / 대학·성인을 고르고 오늘 할 일 한 줄을 입력합니다. 새 과제는 선반에 놓입니다.
- 네임택 선택 → 작업대에 올리기 → 필요한 분량·첫 행동과 도움 선택 → **바로 시작**. 선택·이동만으로 시작되지 않습니다.
- 실행 중 보관: 선택적 이어 볼 자리·다시 볼 날 → 보관함. 일시정지한 동일 실행을 보존합니다. 꺼내기 후 별도로 이어갑니다.
- 끝내고 돌아보기 → 과제 마침 여부·미완료의 다음 선택 → 기록 남기기. 과제 마침을 확인한 경우만 컬렉션으로 이동합니다.
- 더보기 → 나의 로드맵: 월별 원본 → 경험카드 작성·확인·선택 → 초안 문장 확인·선택 → 미리보기·복사/HTML. 문장에서 원본 사실과 실제 과제로 이동할 수 있습니다.
- 월간 예시: `studio.html?review=1` → **월간 예시 불러오기 → 바꾸기** → 돌아보기. 다음 달 초안은 수정·저장 후 받아들이기 전에는 일정을 변경하지 않습니다.
- 월간 비교 예시: 검토 관리의 **월간 비교 예시 (완료된 두 달)** 펼치기 → 비교 예시 불러오기·확인 → 지난달 선택 → 리포트.
- 위 합성 예시는 검토 공간만 교체합니다. 일반 개인 공간에는 자동 입력하지 않습니다.

## 기존 원형 테스트의 알려진 불일치
보관 로그에는 261개 중 257 통과·4 불일치가 있습니다. 정확한 원인은:
1. 검사 단위를 섞은 입력을 허용하던 예전 기대값 1개와 현재 명시적 단위 검증의 불일치.
2. 계획/주의 활동의 시작을 막는 기대값 2개와 현재 ‘항상 바로 시작, 목표 수행 인정은 별도’ 규칙의 불일치.
3. 다단계 과제의 타이머 버튼을 비활성화하던 기대값 1개와 같은 직접 시작 규칙의 불일치.

이 원형 스위트의 runner는 현재 작업 의존성에 없어 **이번에 재실행하지 못했습니다**. 보관 로그를 근거로 분류했으며 원형 소스나 검사 기준을 바꿔 통과시킨 것이 아닙니다. 원형 전체 통과·개발자 최신 연동본 호환성을 주장하지 않습니다.
