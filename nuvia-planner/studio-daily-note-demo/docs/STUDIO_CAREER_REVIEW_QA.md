# 성인 결과 → 진로 과제 → 경험 소재 검토 QA

## 상태

로컬 독립 검토 흐름 구현 및 아래 개발 QA를 수행했습니다.
기존 Studio 공개 재게시/데이터 교체/서버 연동은 하지 않았습니다.
공식 결과지 TOP5 wire 계약과 최신 개발자 브랜치의 통합 호환성은 미확인입니다.

## 최신 완료 기준: 15언어 실제 기능 여정

이 절이 최신 결과이다. 아래 “최초 QA”는 이전 단계의 기록이며,
이제 표시 검사만으로 전체 기능을 통과 처리하지 않는다.

15언어 각각 1440px 데스크톱과 360px 모바일에서 **30/30 독립 기능 여정**을 완료했다.
각 여정은 별도 브라우저 컨텍스트에서 실제 UI로 다음을 수행했다.

1. 언어 선택 → 합성 결과 출처·네 해석·TOP5 직업명을 해당 언어 리소스와 정확히 대조.
2. 추천 직업 선택 → 합성 과제 제목·방법·완료 기준·남길 근거 직접 작성 → 저장.
3. 명시적 시작(Enter) → 멈춤과 약 1.1초 동안 시간 정지 확인 → 복귀(Space)와 시간 진행 → 종료.
4. 처음에는 빈 경험 필드 확인 → 테스트에서 작성한 action/learning만 입력·선택·확인.
5. 미리보기 → 실제 JSON 파일 다운로드·파싱. 선택 문장·원본/실행 참조 확인,
   전체 검사 점수·미선택 문장 미포함 및 `local-file-only`/`user-confirmed-only` 확인.
6. 새로고침 → 언어·원문·경험 유지 → 실제 백업 다운로드·파싱.
7. 파일 업로드 → 복원 미리보기 1결과/1과제/1실행/1경험 → 취소 시 유지 → 재업로드·확정 후 유지.
8. 결과/계획/실행/경험/내보내기 5화면의 가로 문서 넘침·최소 버튼 높이·방향 확인.

완료된 상태를 주입해 이 여정을 대체하지 않았다. 작성한 영문 합성 원문은 사용자 입력
보존을 확인하기 위한 테스트 데이터이며, UI 영어 fallback으로 간주하지 않는다.
원본 식별자·기술 JSON·보존해야 하는 원본 출처도 현지화 UI와 구분했다.

### 검수 도구 문제와 보완 이력

- 최초 통합 en/1440 실행은 브라우저 도구의 45초 호출 제한으로 중단됐다.
  짧은 단계별 체크포인트로 다시 실행해 전체 여정을 통과했다.
- es/360·fr/1440의 내보내기 locator, fr/360·it/1440의 시작 locator에서
  도구의 3초 대기 시간 초과가 있었다. 이후 실제 미리보기·다운로드 파일 및
  실행 ID·시간·종료 후 빈 경험 상태로 진행 결과를 확인했다.
  제품 오류 수집은 0건이며 원래 도구 오류와 복구 기록을 JSON에 보존했다.
- 최초 ko/en 데스크톱 결과의 일부 화면 치수 기록이 빠져, 별도 두 컨텍스트에서 보완했다.
  해당 테스트의 합성 owner만 사전 설정하고 초기 자료가 비어 있음을 확인한 후,
  해당 여정의 실제 백업을 UI로 업로드·복원해 5화면을 측정했다.
  기존 전체 여정을 다시 수행한 것으로 세지 않으며 원래 trace도 변경하지 않았다.
- 최종 `metricCoverageGaps`는 빈 배열이다.

### 증거·재현 범위

`generated-artifacts/studio-career-review/full-locale-qa/results.json`에 30행의
단계·실행 ID·언어별 예시·실제 내보내기·복원 결과·화면 치수·오류·trace 경로가 있다.
`run-ui-journey.js`는 지원 Playwright 브라우저 노트북에서 단계별로 실행하는
체크포인트 코드이다. 독립 Node 명령으로 바로 실행되는 스크립트는 아니다.
`startQArow` → `qaRunPhase` → `qaExpPhase` → `qaFinishPhase` 순서와
해당 노트북의 `newBrowserContext`, `fs`, `REPLIT_DEV_DOMAIN` 바인딩이 필요하다.

원본 30 trace ZIP은 합계 약917MB로 ignored 생성물 경로에 보관한다.
추가형 패치에는 이 큰 trace ZIP·테스트 백업 파일 자체 대신
결과 JSON·코드·trace SHA-256 목록·대표 JPEG·로그를 포함한다.
테스트의 모든 자료는 합성이며 실제 사용자 자료는 포함하지 않는다.

### 최신 자동 검사와 결함 분류

신규 6,077 assertions 및 기존 Studio 1,392 / 데모 언어 1,606 / i18n 439 /
메모 365 / 알림 545 / 외부 데모 68 assertions를 재실행해 통과했다.
기존 1,138키×15언어와 메모20키×15언어 validator, Studio TypeScript도 통과했다.
첫 빌드의 PORT 누락 실패와 `PORT=24422 BASE_PATH=/`를 지정한 성공 로그를 모두 보존했다.
기존 번들 크기·비모듈 비교 스크립트 경고는 남아 있다.

이번 검수에서 신규 패치의 실제 P0/P1/P2 제품 오류는 발견하지 못했다.
따라서 기능·번역값 수정 없이 검수 코드·근거·인계 문서와 패치 산출물만 보강했다.
이는 모든 환경에서 결함이 없다는 보증이 아니다.

구형 기준은 **현재도 257/261 통과·4실패**이다. 모두 적용 전 소스·테스트와 같으며,
단위 혼합 입력 허용 기대 1건과 준비 답변/단계 선택 전 시작 차단 기대 3건의 충돌이다.
정식 소스나 검사 기준을 바꿔 통과로 꾸미지 않았다.
초기 HTTP404는 과거 URL 부재로 원인 미확정이지만 이번 30여정에서 재현되지 않았다.
현재 진입 화면·favicon의 HTTP200도 확인했다. 이 미확정 사건을 해결 완료로 표시하지 않는다.
상세 원인과 경계는 `STUDIO_CAREER_REVIEW_ISSUE_TRIAGE.md`에 있다.

공식 결과지 계약·실제 서버·실기기 Safari·원어민 검수·사용성/효과 연구는 여전히 미확인이다.
외국어 리소스는 AI 초안 상태를 유지하며, 영어 fallback을 완료 번역으로 승격하지 않았다.
공개 배포·GitHub push는 하지 않았다.

## 최초 QA: 실제 클릭 흐름

브라우저에서 다음을 확인했습니다.

- 검사 없음 → 직접 정한 진로 → 과제 저장 가능. 기존 일반/청소년 Studio 링크를 보존.
- 합성 성인 결과 → 추천 후보 선택 → 제목/방법/완료 기준/남길 근거 작성 → 저장.
  저장만으로 시작하지 않으며, 이후 명시적 시작/멈춤/재개/실행 종료를 확인.
- 경험 필드는 처음에 비어 있고 자동 성과 서술을 만들지 않음.
  실제 작성한 action/learning만 선택·확인 → 미리보기 → 로컬 JSON 다운로드.
- 확인 전 내보내기 차단. 미선택 필드·전체 PASS 점수·개인 메모는 소재에 포함되지 않음.
- 과제 수정 후 최초 revision 1을 유지하면서 revision 2 생성.
  재확인 전 내보내기 차단, 재확인 후 실행 revision 1/확인 revision 2를 구분.
- 결과지 v2 입력 시 v1 스냅샷 보존·내보내기 차단, 재확인 후
  원래 v1/새 확인 v2를 모두 참조. 동일 id/version의 다른 내용은 거부.
- 저장/시작/경험 만들기/확인 더블클릭 각각 레코드·확인 이력 한 건만 생성.

주요 클릭 여정은 영어에서, 검사 없는 직접 진로 경로는 별도 합성 모바일 컨텍스트에서
검증했습니다. 아래 225조합은 동일한 유효 합성 상태를 사용한 UI/레이아웃 검수이며
각 조합에서 전체 실행 여정을 반복했다는 의미가 아닙니다.

## 보존·복원·오류

- 실행 중 언어 변경에도 입력·페이지·`?qa=keep#timer`와 실행 유지.
- 멈춤 상태 71,147ms에서 2.5초간 증가 없음. 재개 후 증가 확인.
- 새로고침 후 82,151ms의 같은 실행을 일시정지로 복구, 추가 2.5초간 오프라인 시간 증가 없음.
- 복구는 메모리 상태를 먼저 일시정지로 만들고 다음 변경 때 저장합니다.
  그 전 원시 localStorage phase/lastAt은 running일 수 있으므로 외부 어댑터도
  반드시 `parseBackup`/`recover`를 거쳐 사용해야 합니다. 재확인 없이 오프라인 시간을 합산하지 않습니다.
- 실제 백업 다운로드(합성 자료 4,989바이트; 결과1/과제1/실행2/경험1) → 복원 미리보기 수량 일치.
  취소는 저장 문자열까지 동일, 확인하면 해당 검토 자료를 교체.
- 손상 JSON·다른 owner·끊어진 run.taskId 모두 적용 전 거부, 미리보기 없음·현재 바이트/owner 불변.
- 기존 Studio의 합성 sentinel이 byte-identical, 기존 review 키는 null 유지.
- 저장소 쓰기에 의도적 QuotaExceededError 주입: 오류 표시, 저장 완료 표시 숨김,
  백업 비활성화 및 현재 영구 저장 문자열 불변 확인. 테스트 후 mock 제거·정상 재접속.
- 키보드 native select/화살표, Tab/Enter의 탐색·시작·종료, Space의 일시정지 확인.
  시작 포커스는 선택기에 지정 후 수행했습니다.
- reduced-motion에서 transition 0s / animation none / hover transform none 확인.
