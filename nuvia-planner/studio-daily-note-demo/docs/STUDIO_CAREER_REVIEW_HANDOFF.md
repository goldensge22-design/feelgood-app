## 공식 연동과 검토 어댑터의 차이

현재 소스에는 성인 결과지의 직업 추천 TOP5 원본 wire contract나 자소서 API가 없습니다.
본 패치는 공식 계약을 추정·수정하거나 공식 연동 완료로 표현하지 않습니다.

`src/career-review/model.ts`의 `Report`는 **로컬 검토 어댑터 계약**입니다.
원본의 네 영역 순서·식별자·점수·단위·수준·해석과 직업 TOP5 배열의
원래 순서·rank·식별자·이름·출처를 복사해서 받습니다.
정답률↔표준점수 변환, 점수 절단점, 새로운 유형·해석, 적합도, 추천 재정렬/재계산은 없습니다.
TOP5 순서와 rank가 일치하지 않거나 영역/직업 식별자가 중복되면 조용히 정렬하지 않고 거부합니다.
청소년 결과를 성인 직업 계약으로 재명명하지 않고 거부합니다.

입력의 `schema`는 `nuvia-career-review-report/v1`,
`population`은 `adult`입니다. 필수 구조:

```text
id, version
source: {name, issuedAt, uri}
synthetic: boolean
pass: [{id, score, unit, level, interpretation}] // planning,attention,simultaneous,successive 각 하나
occupations: [{id, rank, label, source}] // 원본 배열 그대로 5개, rank 1..5
```

원본 속성은 추가 속성도 포함해 로컬 스냅샷으로 보존합니다.
동일 id/version에 다른 내용이 들어오면 덮어쓰지 않습니다. 바뀐 원본은 새 version으로 받아야 합니다.
로컬 JSON 가져오기는 인증된 결과 수신이 아니며, synthetic=false도 실제 서버 검증을 뜻하지 않습니다.
정식 연결 전 개발자가 실제 원본 키/척도/연령/해석/추천 출처와 위 어댑터를
대조하고 무손실 매핑 시험을 해야 합니다. **공식 wire 호환성은 아직 미확인입니다.**

합성 예시의 네 값·수준과 직업 후보는 UI 검토용 고정 fixture입니다.
실제 검사 산출·직업 적합도나 효과 검증 결과가 아닙니다.
예시만 표시 단계에서 현지화하며 실제 가져온 이름·해석과 사용자 원문은 번역하지 않습니다.

## 과제·실행·경험의 버전

- 사용자는 원본 추천 후보 또는 직접 정한 직업을 선택하고 제목/방법/완료 기준/남길 근거를 작성합니다.
- 저장은 실행이 아닙니다. 최초 계획과 수정 계획은 각각 새 revision으로 남습니다.
- 한 실행만 열 수 있고 실행 시작 당시 task revision을 고정합니다. 실행 중 계획 교체는 막습니다.
- 중단 시간은 누적하지 않습니다. 새로고침·복원은 실행을 일시정지로 복구하고 오프라인 시간을 더하지 않습니다.
- 실행 종료는 과제 완성/외부 수행 검증이 아닙니다. 시간만으로 성과를 생성하지 않습니다.
- 종료된 실행에만 경험카드를 연결하며 같은 실행의 중복 카드 생성을 막습니다.
- 경험 필드는 빈 상태에서 직접 작성하고, 선택한 비어 있지 않은 항목만 명시적으로 확인합니다.
- 확인된 경험 스냅샷은 history에 남고 이후 수정/재확인은 새 버전이 됩니다.
- 현재 과제 revision 또는 활성 결과지 version이 달라지면 기존 확인을 내보내기에 사용할 수 없습니다.
- 재확인은 과거 실행을 새 계획으로 바꾸지 않습니다. 원래 실행 revision과 새로 확인한 revision/결과지 참조를 나란히 보존합니다.
- 선택한 문장마다 경험 id, 경험 version, 실행 id, 실행 당시 task revision을 추적할 수 있습니다.
- 원본/실행 연결이 없거나 손상된 백업은 적용 전에 거부합니다. 원본 삭제 기능은 제공하지 않습니다.

## 내보내기와 백업

자소서 연동용 내보내기는 `nuvia-local-experience-material/v1` 로컬 JSON입니다.
사용자 확인 문장과 원본/실행 참조, 선택 직업 및 원래 추천 출처를 담습니다.
검사 네 영역 전체 점수·해석이나 기존 개인 메모는 자동 포함하지 않습니다.
자동 자소서 생성, 서버 업로드, 외부 동기화, 능력/성실성/인지 향상 판정은 없습니다.
검사 해석/활동을 확인한 것이 검사 타당성이나 인지 효과를 검증한 것은 아닙니다.

백업은 이 분리된 검토 공간만 포함하는 평문 JSON입니다. 내보내기 소재와 다릅니다.
복원은 형식·참조·버전·소유자 검증 후 범위를 미리 보고 사용자가 확인해야 적용합니다.
취소/손상/다른 소유자의 파일은 현재 상태를 교체하지 않습니다.
소유자 확인은 오입력 방지이며 암호학적 인증·변조 방지나 계정 복구를 뜻하지 않습니다.
서로 다른 브라우저의 백업은 자동으로 같은 소유자로 취급하지 않습니다.
