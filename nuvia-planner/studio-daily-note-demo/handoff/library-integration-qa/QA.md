## 수정한 문제와 재검사

- P1: 360px에서 새 연습 패널이 기존 3열 작업대에 끼어 실행 조작을 가렸다. 패널을 전체 행으로 배치하고 스크롤 여백을 확보했다. 포인터 강제 클릭 없이 E2E를 재통과했다.
- P2: 모바일의 기존 버튼 열 지정이 숨은 열을 만들어 입력칸을 좁혔다. 연결 과제에 한정해 1열을 적용하고 패널 너비가 카드의 80% 이상인지 자동 검사했다. 최종 캡처를 다시 확인했다.
- P2: 저장 알림이 라이브러리 문항을 덮었다. 라이브러리가 있는 화면에서는 알림을 문서 흐름에 배치했다.
- 자동화 오류: 초기 fixture 주입이 sandbox 리포트 iframe의 localStorage까지 접근했다. 테스트를 최상위 프레임으로 제한했다. 제품 iframe의 보안 설정은 변경하지 않았다.

최종 변경 범위의 재현된 P0/P1 오류는 남지 않았다. 이는 전체 서비스·실제 서버·모든 기기의 무오류 보장이 아니다.

## 백업 검사 한계

가상 HTTPS origin에서 Chromium 다운로드가 취소되어, 테스트는 내보내기 버튼이 만든 **동일한 Blob**을 받아 기존 파일 업로드·검증·확인·복원 경로로 왕복했다. JSON 생성·연결 보존·실제 복원 UI는 통과했지만 운영 주소의 파일 저장 동작은 통과로 간주하지 않는다. 실제 배포 후 다운로드·업로드를 별도로 확인해야 한다. 기존 사용자 데이터는 테스트하지 않았다.
