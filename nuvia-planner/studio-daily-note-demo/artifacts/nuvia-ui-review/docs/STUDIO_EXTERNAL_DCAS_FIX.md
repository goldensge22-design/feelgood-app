# 외부 데모의 D-CAS 출처·연령 수정

## 원인과 수정 범위
외부 체험 초기화가 내부 검토용 K-PASS 표준점수 예시를 재사용했다. 외부 전용 합성 결과 생성기를 분리했다. 정식 플래너, 결과지, D-CAS 엔진·검증기, 실제 서버 계약 및 15개 언어 리소스는 수정하지 않았다.

|외부 대상|가상 검사 출처|연령 계약|
|---|---|---|
|중고등학교|D-CAS 청소년용 합성 예시|`middle` (중학생 예시, 청소년)|
|대학교|D-CAS 성인용 합성 예시|`adult` (대학생·성인)|
|기업|D-CAS 성인용 합성 예시|`adult` (대학생·성인)|

합성 검사일은 2026-10-01이다. `schemaVersion=1.1`, `instrument=dcas`, `metric=accuracy_rate`이며 모든 영역 단위가 `%`다. 기존 D-CAS 계약 예시의 값과 명시적 분류를 읽기 전용으로 재사용한다.

|영역|가상 정답률|예시 수준|
|---|---|---|
|계획|42%|하|
|주의|58%|중|
|동시|76%|상|
|순차|65%|중|

지원 순서는 계획, 강점 순서는 동시다. 값에서 상중하를 역산하거나 새 점수 경계를 만들지 않았다. 이는 계약 형태를 충족하는 합성 예시이며 청소년/성인 규준·실제 검사 해석을 검증한 자료가 아니다. 두 연령의 예시 숫자가 같다고 두 연령의 검사 규준이 같다는 뜻은 아니다.

## 기존 저장 기록 보호
- 새 외부 공간: `nuvia:studio:external-demo:dcas:v1:<대상>`.
- 이전 외부 공간: `nuvia:studio:external-demo:v1:<대상>` 및 `:id`를 변경·삭제·변환하지 않는다.
- 이전 체험 기록이 있는 브라우저에는 별도 보존 안내를 표시한다. 같은 URL에서 새 D-CAS 체험이 시작하므로 이전 타이머나 과제 진행을 이어받는 마이그레이션이 아니다.
- 기존 K-PASS 표준점수에 단순히 `%`를 붙이거나 D-CAS라는 이름으로 바꾸지 않았다. 이전 회차 근거·월간 집계도 새 공간에 합산하지 않는다.
- 일반 개인/내부 검토 저장 키는 변경하지 않는다. 이전 기록이 필요하면 해당 버전의 읽기 전용 확인이나 별도 백업 절차를 사용해야 하며 새 공간으로 임의 변환하지 않는다.

## 개발 검증
- 외부 데모 단위 검사: 68건 PASS. 출처·연령·점수 종류·4영역 단위/값/분류·순서, 기존 공식 검증기 통과, 리포트의 D-CAS 표기와 표준점수 배제, 새/이전 키 구분, 백업 왕복을 포함한다.
- Studio 핵심 검사: 1,392건 PASS.
- 기존 15개 언어: 각 1,138키 리소스 검증 PASS, 리소스 수정 없음.
- TypeScript와 production build PASS. 큰 번들 경고는 남아 있다.
- 이번 빌드는 게시·배포가 아니다.

## 실제 브라우저 QA 결과
실제 사용자의 저장 내용을 건드리지 않고 별도 새 브라우저 컨텍스트를 사용했다. 기존 브라우저 상태 검수는 생성한 가상 K-PASS 체험 기록으로 재현했다.

|대상|새 상태 1440px / 360px|이전 기록이 있는 상태 1440px / 360px|
|---|---|---|
|기업|첫 화면·리포트·설정 PASS|첫 화면·리포트·설정 PASS|
|대학교|첫 화면·리포트·설정 PASS|첫 화면·리포트·설정 PASS|
|중고등학교|첫 화면·리포트·설정 PASS|첫 화면·리포트·설정 PASS|

- 총 36개 화면 상태에서 잘못된 K-PASS/KPASS/표준점수/standard score 표기 및 가로 넘침을 발견하지 않았다.
- 세 대상의 D-CAS 출처·연령 계약·4영역 정답률과 수준이 일치했다. 리포트 iframe 내용도 확인했다.
- 이전 공간의 상태 JSON 3개와 식별값 3개, 총 6개 문자열을 탐색·새로고침 전후 바이트 단위로 비교해 동일함을 확인했다.
- 새 공간의 workspaceId/cardId가 새로고침 후 유지됐다. 기존 기록을 새 점수 체계로 바꾼 것이 아니며 최초 합성 과제는 실행/완료/수행 근거 없이 시작했다.
- 외부 `demo` 경로에 `review=1`을 더해도 내부 QA/결과 입력 패널이 보이지 않았다.
- 개인정보 입력 금지·서버 미연결·평문 백업·가상 점수 안내와 펼친 도움말의 AI 초안 고지를 확인했다.
- 기업 월간 HTML 보고서 다운로드를 실제 실행해 D-CAS 성인 출처, 정답률과 데모 경고가 있고 금지 표기가 없음을 확인했다.
- 코드의 공식/이전 제품·API 및 i18n 리소스에 변경이 없는 것을 확인했다.

### 검수 중 장애와 남은 한계
첫 검수 도중 호스트가 502를 반환해 기존 브라우저 상태/일부 모바일 검수가 중단됐다. Studio 관리 워크플로를 다시 실행한 후 동일 tester가 미완료 범위만 이어서 확인했다. 최초 중단을 통과로 간주하지 않았다.

최종 확인에서 앱 예외는 관찰하지 않았다. 리포트 iframe은 `allow-scripts` 없는 sandbox에서 주입 스크립트를 차단했다는 콘솔 메시지가 계속 관찰됐다. 리포트 표시·다운로드는 정상이며 메시지를 없애려고 sandbox를 완화하지 않았다. 콘솔 전체 무오류라고 주장하지 않는다.

첫 화면 전환에서 DOM이 있으나 캡처가 잠깐 비는 현상 뒤 정상 표시됐다. 큰 번들 경고, 기존 기준본의 별도 4건 불일치, 원어민 미검수·실제 사용자 연구 미수행은 이번 수정으로 해소됐다고 주장하지 않는다. 실제 연령별 검사 규준 및 최신 개발자 연동본의 계약은 별도 확인 대상이다.

## 게시 및 되돌리기
- 현재 수정은 개발 소스와 미리보기에만 적용했다. 게시된 서비스의 재배포는 사용자가 별도로 승인·진행한다.
- 개발자 최신 브랜치와 외부 데모 변경만 비교하며 충돌 시 중단한다. 정식 결과지 파일을 이 수정으로 덮어쓰지 않는다.
- 되돌릴 때 외부 전용 결과 생성과 저장 키 선택을 직전 버전으로 돌릴 수 있다. 어느 저장 키도 자동 삭제하지 않으며, 되돌린 버전은 이전 외부 공간을 읽는다.
