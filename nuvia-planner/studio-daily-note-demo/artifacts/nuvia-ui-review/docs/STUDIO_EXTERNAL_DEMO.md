# Studio 외부 검토 데모 — 변경 및 검수 기록

후속 D-CAS 출처·연령 수정과 새/이전 브라우저 검수 결과는 `STUDIO_EXTERNAL_DCAS_FIX.md`를 참조한다. 아래 최초 검수 기록의 32건 검사는 후속 검사에서 68건으로 확대됐다.

## 제공 범위
- 기업: `/demo.html?audience=enterprise` → `/studio.html?demo=enterprise`
- 대학교: `/demo.html?audience=university` → `/studio.html?demo=university`
- 중고등학교: `/demo.html?audience=school` → `/studio.html?demo=school`
- 한 진입 페이지의 세 가지 구별되는 URL 상태이며, 실제 작동하는 기존 Studio를 공통으로 사용한다. 정적 작업대 모형이 아니다.
- 학교 예시는 중학생 단계로 시작한다. 대학·기업 예시는 대학/성인 단계로 시작한다.
- 기본 제공 과제와 검사 값은 합성 예시다. 미리 채운 과제만으로 목표 수행을 인정하지 않으며 시작·완료 기록도 생성하지 않는다.
- 외부 안내 페이지는 한국어, Studio 안전 안내는 한국어/영어다. 기존 15개 언어 리소스와 언어 선택·기존 fallback/엄격한 키 정책을 변경하지 않았다. 외국어는 AI 초안이며 원어민 검수 전이다. 새 외부 안내까지 15개 언어 번역 완료라고 주장하지 않는다.

## 보호와 한계
- 세 대상은 각각 독립 브라우저 저장 키를 사용한다. 기존 personal/review 저장을 읽어 오거나 초기화하지 않는다.
- 외부 데모에서는 `review=1`이 함께 있어도 내부 검토 패널을 켜지 않는다.
- 결과 JSON 입력, 전체 공간 QA 백업, 이전 화면 링크, 이전 개인 기록 복사 및 복원 입력을 외부 경로에서 숨겼다. 원래 개인·내부 검토 경로의 기능은 유지한다.
- 모든 외부 화면에 실제 D-CAS 결과 연결·로그인·서버 저장·동기화 없음, 실제 개인정보 및 검사 결과 입력 금지, 브라우저 잔존·평문 JSON 백업 안내를 표시한다. 월간 보고서 HTML/공유 미리보기에도 데모 안내를 넣는다.
- 사용자가 작성한 텍스트는 자동 익명화되지 않는다. 가상 내용만 입력해야 한다. 브라우저 프로필을 공유하면 같은 저장 내용이 보일 수 있다.
- UI 숨김과 URL 구분은 인증·권한 보안이 아니다. 같은 검토 아티팩트에 원래 검토 경로가 남아 있으므로 기관용 접근통제 서비스로 간주하면 안 된다.
- 공개 배포, main 병합/push, 정식 플래너·결과지·D-CAS·서버 코드 변경은 하지 않았다.

## 관찰된 오류와 미확인
- 서버 재시작 중 일시 502와 Vite 재연결이 있었고, 포트 점유 프로세스를 정리한 뒤 관리 워크플로가 정상 실행됐다.
- 리포트 sandbox iframe에서 `Blocked script execution in 'about:srcdoc'` 메시지가 관찰됐다. 리포트 표시·HTML 다운로드와 경고문은 정상이다. 기존 관찰이며 sandbox를 느슨하게 해 숨기지 않았다. 콘솔 전체 0건으로 보고하지 않는다.
- 초기 이동 직후 잠깐 빈 화면이 보였고 약 1초 뒤 정상 표시됐다. 언어 리소스 동시 로딩의 큰 번들 경고가 남는다.
- 이번 실제 클릭 검수는 대학의 모든 하위 탭, 로드맵 직접 클릭, 기업 리포트 다운로드, 15개 언어 전체 화면 재검수를 포함하지 않았다. 기존 검수 기록은 이번 새 안내 번역이나 모든 조합의 신규 검수로 대체 해석하지 않는다.
- 구형 기준본의 알려진 4건 불일치는 별개이며 이번 Studio 검사 통과로 해소됐다고 주장하지 않는다.
- 실제 학생·직원 사용성 연구, 원어민 검수, 인지 효과 검증은 수행하지 않았다.

## 적용과 되돌리기
- 새 파일: `demo.html`, `src/demo/*`, `tools/nuvia-studio/*external-demo-check*`.
- 기존 변경: StudioApp의 외부 안내·숨김 조건, store의 독립 저장·합성 초기화·리포트 안내, Vite의 demo HTML build 입력.
- 기존 데이터 스키마·공식 결과 계약·번역 JSON은 변경하지 않았다.
- 개발자 최신 소스와 변경 부분을 비교하고 충돌 시 적용을 중단한다. 이 문서는 최신 서버 연동본에 무조건 덮어써도 안전하다는 보장이 아니다.
- 되돌릴 때는 위 외부 분기/HTML build 입력과 새 파일만 제거하며 기존 작업을 함께 되돌리지 않는다. 기존 개인/검토 저장 키는 삭제하지 않는다. 외부 데모 저장은 사용자가 별도로 브라우저 사이트 데이터 관리에서 지울 수 있으며 개인 저장까지 지워질 수 있으므로 신중히 확인한다.
- 미리보기는 개발 서버 실행 중에만 제공한다. 사용자가 검증 후 공개 배포는 별도 승인/작업이다.
