## 실행한 검사
- 핵심 로직: **1,392 assertions 통과**. 81조합의 목표/강점, 두 순환, 실제 행동근거, 한실행, 보관/복귀, 7일 경계, 시간 선반, 로드맵 근거/선택/백업 포함.
- 최소 계획 로직: **48 checks 통과**. 미정 시간, 중복 생성, 기본값 증거 배제, 미정 반복/다음블록/예상비교 제외, 백업/복원. 이전 형식 양수시간 데이터는 테스트 안의 합성 fixture로 검증하며 실제 사용자 백업을 포함하지 않음.
- 기존 작업대 실제 Chromium 클릭: **43 checks 통과**.
- 최소 입력 실제 Chromium 클릭: **41 checks 통과**.
- 5활동·중/고/성인·리포트·실제 PDF 인쇄: **29 checks 통과**.
- 최종 승인 예시 실제 Chromium: **24 checks 통과**. 1440/768/360 넘침, 타이머 카드 통합, 자기 paused/보관 문구, 빈 보관 입력의 기존 깃발·시간 보존, 360px 클릭/키보드 배치·복귀 포커스/스크롤, 3주요 조작/더보기, 과목 아이콘, 개인 저장 분리, 시간합계, reduced-motion, 빈 화면/추가 폼.
- 타입 검사 / Vite production build: 통과. 빌드는 배포가 아님.
- 최종 전체 소스 ZIP을 별도 임시 폴더에 새로 풀어 **pnpm frozen-lockfile 오프라인 설치 → 루트 build(타입 검사 포함)**도 통과. ZIP CRC·금지 경로 제외·파일 SHA256 목록 검증 통과.
- 별도 브라우저 검수: 합성 한 여정에서 실행→멈춤→보관→새로고침→꺼내기→복귀→수동완료, 미정 경과타이머, 360px 키보드/취소·가독성, 콘솔 오류 없음.
- 그 검수에서 발견한 자기 보관 과제의 “다른 과제” 안내는 수정했고, 최종 Chromium의 전용 assertion으로 재확인. 두 번째 전체 검수는 실행하지 않음.
- 사용자 추가 QA의 네 항목을 반영: 빈 작업대/같은 보관 과제는 보관 실행 안내와 직접 복귀 버튼, 실제 다른 desk만 “다른 과제”; 360px 배치/복귀 뒤 제목 포커스·스크롤(reduced-motion 존중); 시작/수정/보관 3조작과 더보기 안 제외·색; 과목별 퍼플 책/플라스크/건물 표찰. 추가 클릭·키보드·포커스·보관 깃발 유지 검사를 별도로 수행.
- 보존 영역 `official`, 이전 개인 월간, enhancement 및 API 서버 소스는 시작 기준 대비 불변 확인.

## 이미지와의 차이·한계
- 승인 이미지의 큰 공간 구조, 무광 파일층/측면/받침, 전면 글자, 과목 네임택은 실제 DOM으로 구현. 이미지를 앱 배경으로 덮지 않음.
- 점수 숫자는 이미지대로 복사하지 않음. 실제 서버가 없으므로 미연결 상태이며 합성 검사를 명시 선택해야만 예시값 표시.
- 접근성/긴 제목과 상세 수정 때문에 원본 이미지보다 카드/버튼 간격이 넓고 세로 스크롤이 길다. 모바일은 현재 작업이 먼저이며 선반/컬렉션/보관함은 아래로 이어진다.
- 임시 Replit 개발 배너와 검토 전용 안내가 캡처에 보일 수 있음. 운영 제품의 시각 요소가 아님.
- 전문 3D 모델이 아니라 CSS의 얕은 책/종이/받침 표현. 실제 기능 UI이며 생성 이미지 대체가 아님.

## 남은 사항 — 전체 통과로 해석 금지
- 보존한 기준본의 과거 **4건 테스트 기대값 불일치**는 이번에 수정/재실행하지 않음. 기존 보고 분류: 점수 단위 혼합 1건, 계획/주의 시작 조건 기대 2건, 다단계 시작 비활성 기대 1건. 현 작업대에서 PASS 증거와 항상 시작 가능 정책을 별도로 검사했지만 이를 기준본 전체 통과로 바꾸지 않음.
- **사용자 확인 결과:** GitHub `811609f`는 사용자가 직접 Vitest **262개**, tsc, build 통과를 확인했다고 전달함. 이는 위 Replit 구형 기준본 4건과 별개이며, 이 에이전트가 원격을 받아 재실행하거나 이번 패치와 통합검증한 결과는 아님.
- 실제 서버/인증/학생 소유권/교사 권한/기기 동기화/공식 81유형별 해석표 미연결. 공식 통합 및 보안 QA 미실시.
- 신규 한국어 문구의 영어/크메르어/아랍어 전문 번역·원어민 검수는 미완료. 언어 전환/RTL 및 기존 상태 보존 검사는 번역 완성을 뜻하지 않음.
- 별도 `personal-monthly.html`은 별도 저장 공간. 작업대 리포트는 **작업대의 리포트 메뉴**로 확인하며 이전 화면과 자동 서버 동기화되지 않음.
- 운영 OS 알림·실제 HISTORY 서버·독립 검사 검증은 이번 신규 구현/검수 범위가 아님.
- 실제 학생 독립 사용성 시험·4주 추적·인지 향상 효과 연구 없음.
- 마지막 수정 후 확인 범위에서 실행불가/데이터손실/핵심 P0·P1 오류는 발견되지 않음. 정식 제품 전체에 오류가 없다는 보장은 아님.
