### 4. 같은 과제의 서로 다른 실제 행동
- 할 만큼 정하기: 범위/시간/첫 행동의 직접 입력·변경과 명시 확인, 과제 순서 이동을 저장합니다. 값이 같은 저장만으로 변경 근거를 만들지 않습니다.
- 지금 한 가지: 직접 행동을 고릅니다. 선택 행동만 크게 보여 주며 생각 보관·깃발은 필요할 때 엽니다.
- 전체 연결하기: 목표/마감/자료/준비물/결과물/관련 과제 중 실제 내용 둘 이상과 관계 문장을 직접 입력·확인해야 합니다.
- 단계대로 해보기: 실제 단계 둘 이상 작성·확정, 내부 단계 순서 변경, 직접 진행 표시가 필요합니다. 과제 목록 순서와 별도 데이터입니다.
- 통합: 계획 확정/실제 변경 후 실행 종료를 사용합니다.
- 기본값·사전 체크만으로 수행 처리하지 않습니다. 수행/명시 건너뜀/미확인을 구분하며 미확인 상태 문구는 일반 리포트에서 숨깁니다.
- ‘해당 없음’은 주의의 보관·복귀 상황을 돌아보는 닫힌 선택 영역에만 제공합니다. 목표 행동 수행을 대체하지 않습니다.
- 저학년의 그림+한 행동, 고학년 준비물·시간, 중학생 범위·마감, 고등학생 중간 마감/역산 표시, 성인 담당·선행·대기·인계를 같은 디자인 안에 제공합니다.

### 5. 행동카드·계획·실행

- ‘수업에서 일상으로’의 행동카드에서 ‘플래너에서 실행하기’는 같은 카드 ID를 엽니다. 과제를 새로 만들지 않습니다.

- 작은 첫 행동 후보는 학생이 직접 고릅니다. 준비 응답 없이 바로 시작해도 타이머가 작동합니다.
- 학생별 한 블록만 실행합니다. 멈춤/깃발/복귀/재접속이 원래 카드·단계·남은 예산·구간을 유지합니다.

- 5분 연장은 기존 실행과 같은 연습 식별자를 보존하여 같은 회차를 두 번 집계하지 않습니다.
- 일시정지 제외 경과와 본인이 수정한 실제 분량/시간을 저장합니다. 집중력/인지능력 수치로 표현하지 않습니다.
