# 개인화 행동카드·수업/캠프 보강 검토 패치

## 경계
- 기존 NUVIA PLANNER에 추가하는 **합성 데이터 전용 검토 화면**입니다. 기존 기준본·B형 v2·운영 화면을 교체하지 않습니다.
- 원출처 기준: `defa19d7c7601157b47ddb10cf4d62fdf9bebf82`.
- Replit 검토 착수 시점: `ddc5e70947d6f80215209ac79689712b7c1cf204`.
- 개발자의 최신 결과지/서버 연동본은 확보·검증하지 않았습니다. **최신본에 그대로 덮어써도 안전하다는 보장이 아닙니다.**
- `manifest.json`의 추가 파일만 복사하며 기존 파일은 자동 수정하지 않습니다. 의존하는 B형 v2의 engine/brandAssets 해시가 다르면 중단합니다.
- D-CAS 결과지, 심화 본문, 다른 프로그램, BrainMap, 서버, 인증, main, 공개 URL, 배포 설정을 변경하지 않습니다.

## 적용 전
1. 개발자가 최신 저장소·결과지 규칙·공식 유형 ID와 영역 매핑·지원/강점 순서·서버 변경을 확인합니다.
2. 기존 UI에서 정상 백업을 내리고 Git 변경도 따로 보관합니다. 브라우저 자료는 Git 백업에 포함되지 않습니다.
3. `main/master`가 아닌 별도 검토 브랜치를 만들고 작업 트리를 깨끗하게 합니다. 압축은 대상 저장소 밖에 풉니다.
4. `source` 디렉터리에 기존 B형 v2의 `src/adaptive/engine.ts`, `brandAssets.ts`가 있는지 확인합니다.
5. React/ReactDOM/Zod 의존성을 확인합니다. 없으면 개발자가 승인된 버전·잠금 파일 정책에 맞춰 별도 추가해야 합니다. 이 패치는 package.json을 덮어쓰지 않습니다.

```sh
# SOURCE는 외부 대상 저장소의 실제 NUVIA PLANNER source 경로입니다.
# HEAD는 개발자가 최신 기준을 검토한 정확한 SHA를 직접 넣으세요.
python3 install.py check --root "$SOURCE" --reviewed-head "$HEAD"
# 검토 승인 후 별도 브랜치에서만 실행:
python3 install.py apply --root "$SOURCE" --reviewed-head "$HEAD" --ack-latest-review
```

충돌·손상·다른 해시·기존 파일·더러운 작업 트리·main/master이면 쓰기 전에 중단합니다. 강제 덮어쓰기 옵션은 없습니다. 성공은 최신 서버 호환성 검증 성공을 뜻하지 않습니다.

## 빌드 연결: 개발자 수동 병합
새 화면은 `enhancement.html`이고 진입점은 `src/enhancement-main.tsx`입니다. Vite 개발 서버는 이 HTML을 직접 열 수 있습니다.
기존 Vite 다중 페이지 설정에 새 HTML **한 항목만** 추가합니다. 기존 설정 전체를 교체하지 마세요.

```ts
// 기존 build.rollupOptions.input 객체 안에만 추가하는 예시:
enhancement: path.resolve(import.meta.dirname, 'enhancement.html'),
```

이 예시는 대상 프로젝트의 Vite/경로 체계에 맞춰 병합해야 합니다. 단일 진입점/다른 번들러면 별도 검토하세요.
기존 플래너의 카드 연결 API나 실제 사용자 결과를 자동으로 이 데모에 넣지 마세요. 현재는 내부 합성 과제 연결만 작동합니다.

## 저장/공유
- 새 자료 키: `nuvia:enhancement:synthetic:v1` 및 이 키의 ID/역할 보조 키. 기존 플래너·HISTORY 기록을 읽거나 쓰지 않습니다.
- 역할 전환과 교사 공유는 동일 브라우저의 합성 자료 시연입니다. 보안 경계·실제 인증·서버 동기화·다른 기기 이어쓰기가 아닙니다.
- 백업은 같은 검토 공간의 합성 자료만 복원합니다. 다른 공간·손상 자료는 사전 거절합니다. 체크섬은 손상 감지이며 인증/암호화가 아닙니다.
- 수업 종료/공유 철회는 수업 공유만 제거하며 개인 카드·실행·경험은 유지합니다.
- 새 검토본의 저장 내용이 운영 사용자 데이터라는 의미는 없습니다. 실제 학생 정보를 입력하지 마세요.

## 되돌리기
1. 먼저 새 검토본 백업을 내려받습니다.
2. 별도 브랜치에서 아래를 실행합니다. 설치 이후 수정된 새 파일이 있으면 자동 삭제하지 않고 중단합니다.
```sh
python3 install.py rollback --root "$SOURCE"
```
3. 수동 추가한 Vite HTML 진입점만 개발자가 별도 제거합니다.
4. 기존 소스·기존 브라우저 저장소·서버는 복구 스크립트가 손대지 않습니다. 새 검토본 브라우저 자료도 자동 삭제하지 않습니다.
Git 전체 reset, 운영 데이터 초기화, ZIP 전체 덮어쓰기, 자동 push/배포를 하지 마세요.

타입 검사·빌드·기존 14개 테스트 파일의 미일치 4건 확인·새 81조합 테스트·타이머/백업 회귀·화면·권한·실제 결과지 계약을 개발자가 다시 확인해야 합니다.
정식 적용과 공개 배포는 사용자 승인 후 별도 작업입니다.
