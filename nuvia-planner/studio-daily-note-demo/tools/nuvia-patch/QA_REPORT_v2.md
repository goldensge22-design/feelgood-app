`/compare.html`은 `previous.html`과 새 후보 `/`를 **같은 격리된 데모 4개 블록(10·25·35·45분), 동일 PASS 4점수, 동일 장면과 날짜**로 보여 줍니다. 공식 기준본은 `/before.html`에서 별도로 보존합니다. 새 후보는 평면 목록에서 벗어나 시간순 선반, 밝은 윗면·과목색 정면·짙은 옆면을 가진 블록, 크기 차이, 선택 상세와 모바일 행 내부 실행 자리로 재구성했습니다. 실행은 집중 자리, 중단은 복귀 자리, 완료는 낮아진 블록으로 달라집니다. 입력을 자동 완료하거나 결과 점수를 숨기지 않습니다.

## 안전 패치와 승인 경계

패키지에는 지정 커밋 대비 `nuvia-planner/source/src`의 변경 파일만 들어 있습니다. `apply.py --check`는 파일을 쓰지 않고 모든 SHA-256을 먼저 검사합니다. 해시 충돌이 하나라도 나면 **전체 쓰기 중단**합니다. `apply.py`는 정상 적용 전에 원본 백업을 남기며 `--rollback`은 설치 후 파일이 변경됐으면 중단합니다. 이전 후보 ZIP과 이 새 후보를 연달아 적용하면 안 됩니다. 최신 결과지 연동본은 이 기준 해시와 다를 수 있으므로 **충돌 시 수동 병합 검토**, 강제 덮어쓰기 금지입니다.

지정 커밋의 임시 복제본에서 변경 파일 **9개**의 읽기 전용 check → 적용 → 재check(적용 완료 감지) → 백업 rollback → 재check를 확인했습니다. 임시 복제본의 한 소스 파일을 바꾼 뒤 재시도하면 충돌 1건으로 멈췄고 다른 변경 대상 파일의 해시는 그대로였습니다. 이 실험은 **최신 결과지 연동본 자체에 적용하거나 호환성을 증명한 것이 아닙니다.**

**검토 결론:** 시각·로컬 행동을 새 후보로 검토할 수 있습니다. 공식/최신 결과지 연동본에 바로 배포 가능한 완료본이라고 주장하지 않습니다. 승인 전까지 적용 보류.
