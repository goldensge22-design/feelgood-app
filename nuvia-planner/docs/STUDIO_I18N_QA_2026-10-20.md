# Studio 15개 언어 QA — 미통과

이 문서는 최신 Studio 후보에 대한 결과이며 기존 플래너 또는 다른 프로그램의 번역 품질을 판정하지 않습니다.
대상 15개 언어는 저장소 중앙 catalog의 실제 언어 코드 기준이며 `zh` 별칭은 별도 언어로 세지 않습니다.

ko→en→km→ar→ko를 로컬 production build의 격리 검토 화면에서 조작했습니다. 중단된 같은 과제와 시간은 유지됐지만, 이것은 번역 완료 또는 모든 입력·모든 경로 유지 검사를 뜻하지 않습니다. 문서 폭 1265 / 뷰포트 1280인 확인 화면에서 가로 넘침은 없었고 콘솔 오류/경고는 없었습니다.

이번 독립 재검수의 viewport 설정이 실제 크기에 반영되지 않아 360/768/1440 검증은 제작 도구의 제공 캡처·로그와 구분합니다. **15개 언어 모바일/인쇄 QA는 통과하지 않았습니다.**

## 코드 근거 / 우선순위

- P2: `src/studio/StudioApp.tsx` 언어 선택 및 `src/enhancement/model.ts`, `persistence.ts` 언어 값은 ko/en/km/ar 네 가지뿐.
- P2: `StudioApp.tsx`, `RunPanel.tsx`, `store.ts`, 리포트 등 다수 문구가 직접 하드코딩되어 있음.
- P2: `src/studio/task-copy.ts`의 작은 ko/en 사전은 전체 제품 번역이 아님. km/ar는 한국어 fallback.
- P2: `src/enhancement/copy.ts`의 en/km/ar는 Partial 사전. 누락 키 fallback을 번역 완료율에 포함하면 안 됨.
- P2: `studio.html` 문서 lang=ko 고정. root dir만 바뀌는 상태는 올바른 최종 다국어 계약이 아님.
- 미검수: 실번역 기반 긴 문장·RTL·화면낭독기·인쇄/PDF와 빠른 연속 언어 변경·query 보존.

## 재현 및 완료 기준

`nuvia-planner/studio`에서:

```sh
node tools/nuvia-studio/audit-languages.mjs --strict
```

현재 종료 코드 **1**. 이 검사는 선택값과 알려진 구현 누락의 감사이며, 번역 coverage 계산기나 브라우저 QA 대체물이 아닙니다.

원문/기존 공통 키부터 검색해 재사용하고 신규·변경 키만 번역합니다. 현재 없는 11개 언어를 단순히 선택기에 추가해 한국어 fallback만 보여주는 방식은 허용하지 않습니다. 모든 UI/aria/오류/리포트/인쇄 문구의 리소스·placeholder·원문 변경 상태를 검증한 뒤, 실제 15개 언어에서 핵심 전 경로와 PC/360px 검수를 수행해야 완료입니다.
