# NUVIA PLANNER 2.5 보강 릴리스

## 변경 내용

- 프로필 B를 연령별 독립 실행 루틴으로 분리했습니다. 초1~3은 그림/짧은 말의 준비·시작·확인, 초4~6은 숙제 단계 카드와 복귀 위치, 중학생은 과목·범위·오늘 분량 및 남은 범위/다음 10분, 고등학생은 마감별 계속·분할·이동 판단, 대학생·성인은 즉시 행동·답변 대기·확인 요청 및 인계 메모를 저장합니다.
- 데모 모드 성장 서클에 `예시 전략 이력 불러오기`를 추가했습니다. 예시 기록은 실제 KIDS/HISTORY 이력이 아님을 표시하며, 전략 재적용은 다른 영역·완료 여부·도움 횟수만 저장합니다. 작성한 서술 원문은 저장하지 않습니다.
- 백업 JSON을 같은 검증 경로로 직렬화·복원하는 자동 왕복 검증을 추가했습니다. 프로필 범위 불일치, 손상 JSON, 이전 적용 기록 연결 오류는 거부합니다.

## 자동 검증

- TypeScript: `tsc --noEmit`
- 테스트: Vitest 10개 파일 / 222개 테스트
- 새 테스트: `src/tests/backupRestore.test.ts`
  - 할 일, 단계, 준비물, 완료 기록, 반복, 성장 기록 JSON 왕복
  - 다른 프로필, 손상 JSON, 깨진 이전 기록 연결 거부
- 산출물: `npm run build:delivery`와 동일한 `tsc --noEmit && vite build && node scripts/package-delivery.mjs` 흐름으로 단일 HTML 생성

## 수동 QA 절차: 백업 복원 왕복

1. 같은 프로필·학년에서 할 일, 단계, 준비물, 반복 설정을 만들고 하나를 완료합니다.
2. 성장 화면에서 데모 전용 예시 전략 이력을 불러오고, 다른 영역 재적용의 완료 여부와 도움 횟수를 저장합니다.
3. `백업 내려받기`로 JSON을 저장합니다.
4. 같은 프로필·학년의 `백업 가져오기`에서 방금 JSON을 선택합니다.
5. 할 일 제목·단계·준비물 체크·완료 기록·반복 설정·성장 기록이 모두 남아 있는지 확인합니다.
6. 다른 프로필의 JSON, `{`처럼 손상된 JSON, 이전 적용 기록 ID를 바꾼 JSON을 각각 가져와 거부 안내가 표시되는지 확인합니다.

## 남은 한계

- 데모 예시 이력은 검수 편의를 위한 로컬 자기보고 예시이며 실제 KIDS/HISTORY 서비스 수행이나 외부 확인을 대체하지 않습니다.
- 브라우저 파일 선택 권한은 환경마다 달라 자동화에서 다운로드 파일 재업로드가 제한될 수 있습니다. 이 경우 자동 JSON 왕복 테스트와 위 수동 절차를 함께 사용합니다.
- 타이머는 완료·점수·인지 향상을 자동 판정하지 않습니다.
