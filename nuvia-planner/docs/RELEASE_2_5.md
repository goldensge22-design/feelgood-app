# NUVIA PLANNER 2.5 릴리스 검수

기준 브랜치: `codex/recover-planner-dcas81`

이 릴리스는 D-CAS, 결과지, 구형 BrainMap Planner를 변경하지 않고 NUVIA PLANNER의 실제 핵심 루프인 계획 → 실행 → 조정을 보강한다.

## 변경 내용

### 예상·실제 시간 조정

- 완료 뒤 예상과 실제 차이를 N분 길었어요/짧았어요/같았어요로 중립적으로 표시한다.
- 점수·등급·순위·인지능력 판단 없이 시간을 줄이기 / 일을 나누기 / 같은 시간으로 하기 중 하나를 고른다.
- 선택은 완료 과제의 `timeAdjustment`에 저장하고 반복으로 생성된 다음 과제의 `planningReference`에도 연결한다.
- 최근 선택은 다음 계획 조립 화면에서 참고 정보로만 표시하며 자동으로 시간을 바꾸지 않는다.

### 미완료 과제 재배치

- 날짜가 지났거나 잠시 멈춘 과제에만 다시 배치하기를 제공한다.
- 오늘 / 내일 / 이번 주를 직접 선택하고, 선택적으로 예상 시간을 줄이거나 남은 일을 두 단계로 나눈 뒤 저장한다.
- 저장 버튼을 누르기 전에는 날짜·완료 상태를 바꾸지 않으며 실패·벌점·경고로 표현하지 않는다.
- `rescheduleChoice`, `rescheduledAt`과 변경된 시간·단계를 workspace 및 백업 JSON에 보존한다.

### 오늘·주간 2.5D 작업 공간

- 기존 평면 progress bar를 실제 과제의 영역·아이콘·시간을 보여 주는 2.5D 시간 선반으로 교체했다.
- 학습(파랑·▤), 생활(주황·⌂), 업무(보라·◆)를 색과 아이콘으로 함께 구분한다.
- 과부하는 실패가 아니라 오늘 공간이 거의 찼어요. 하나를 다른 날로 옮길까요?로 안내한다.
- 카드 배치·눌림·완료 피드백은 180~200ms로 제한하고 `prefers-reduced-motion`에서는 애니메이션을 제거한다.
- 모바일에서는 44px 이동 버튼, 단일 열 선택/재배치, 내부 시간 블록 스크롤을 사용한다.

### 연속 기록 표현

- 주 화면의 연속 N일 표현과 별 보상 블록을 제거했다.
- 이번 주 7일 중 N일 기록과 7개 경로 점으로 바꾸고, 누락일은 벌점·초기화·실패로 계산하지 않는다고 명시했다.

### 성장 서클 데모 완주

- 데모 모드에만 예시 전략 이력 불러오기를 표시한다.
- 버튼은 HISTORY 전략 연결과 `strategyApplied: true`인 완료 예시 과제/자기보고 기록을 데모 저장소에 추가한다.
- 다른 영역에 써보기에서 이전과 다른 영역, 완료 여부, 도움 횟수를 저장한다.
- 사용자가 입력한 과제·계획·결과 서술 원문은 저장하지 않고 `taskContentStored: false`와 범주형 측정치만 남긴다.
- 적용 기록은 `self_report`, 외부 확인은 `verification`으로 분리한다.

### 백업 복원

`exportWorkspaceJson` → `restoreWorkspaceJson` → `validateWorkspace`를 내려받기, 파일 가져오기, 자동 왕복 검증이 공유한다. 다른 프로필/학년 scope, 손상 JSON, 없는 이전 기록을 가리키는 재적용 기록은 복원을 거부한다.

## 2026-09-20 추가 보강: 과목별 시간 블록과 시작·종료

이 절은 위의 기존 2.5 검수와 구분한 시간 블록 보강 기록이다. 작업 브랜치는 `codex/recover-planner-dcas81`이며 main 병합·푸시·배포를 하지 않았다. D-CAS, 결과지, 구형 BrainMap Planner 파일은 변경하지 않았다.

### 구현과 데이터

- 별도 할 일 저장소를 만들지 않고 기존 `PlannerTask`에 선택적 `timeBlock`을 추가했다. 기존 2.4 할 일은 접을 수 있는 기존 플래너에서 그대로 편집한다.
- 과목/활동·영역·범위·예상 시간·날짜·시작 시각을 생성/수정한다. 15·20·25·40·50분 추천과 직접 입력을 함께 제공한다.
- 오늘에는 선택한/다음 블록을 크게, 주간에는 과목 아이콘·색·범위·시각·분량·다음 시작 위치를 표시한다. A는 다중 블록 순서 이동, B는 한 블록 집중 스테이션과 접힌 대기 목록이 중심이다.
- 상태: `ready → running ↔ paused → review → closed`. 완료 여부는 종료 기록에서 사용자가 직접 고른 뒤 기존 완료 기록 경로로 전달한다. 미완료는 `paused`/이어갈 카드로 유지한다.
- 시작·중단·종료 경계의 시각만 작업 데이터에 저장한다. 중단 구간을 제외한 경과 시간을 합산하며 화면의 초 단위 tick은 저장하지 않는다. 수행 기록에는 분 단위 계획/실제 시간과 완료 자기보고만 연결하며 타이머 segment, 남은 초, 집중 점수를 넣지 않는다.
- 시간 만료는 `계속할까요?`만 표시한다. 자동 완료·실패·점수·인지능력 판정은 없다. 한 workspace의 다른 실행 블록/기존 할 일이 있으면 시작을 막는다.
- 종료 직후 어디까지/다음 시작 위치/선택적 시간 느낌과 완료 여부를 남긴다. 미완료 선택지는 정확히 5분 더 하기, 다음 시간 블록 만들기, 오늘 마치기다. 다음 블록 및 반복 카드에 이전 시작 위치를 전달한다.
- 완료 확인 문구에 단계·준비물을 모두 마쳤다는 의미를 명시했다. 도움 여부를 묻지 않은 시간 블록 완료 기록은 `helpReceived: false`로 단정하지 않고 생략하며 성장 화면에도 도움 미질문을 명시한다.
- 중단·실행·종료 기록 대기 상태는 새로고침/백업으로 복원된다. 데모의 프로필·연령 선택은 같은 탭의 새로고침에서 유지한다.
- 백업은 기존 export/restore/validate 경로를 공유한다. 시각 형식, 구간 겹침, 실제 시간 불일치, 없는 이전 블록, 복수 실행, 다른 프로필, 손상 JSON을 거부한다.

### 추가 수동 QA

1. 같은 프로필에서 수학/영어 블록을 만든다. 시간 추천 버튼과 직접 입력, 날짜/시각 수정, 단계/준비물 추가를 확인한다.
2. 연령별 준비 조건을 충족한 뒤 한 블록을 시작한다. 다른 카드 선택은 차단되고 중단/종료 안내가 나와야 한다.
3. 1분 블록이 끝날 때까지 두되 완료를 누르지 않는다. 완료 기록과 성장 기록이 생기면 실패다.
4. 중단 후 다음 시작 위치를 적고 새로고침한다. 같은 프로필/연령에서 중단 상태와 메모를 확인하고 재개한다. 중학생은 다음 10분 행동 없이 재개할 수 없어야 한다.
5. 종료 후 실제 시간과 짧은 기록을 확인한다. 미완료 3개 선택을 각각 시험한다. 5분 더 하기는 남은 원래 시간과 무관하게 5분이어야 한다.
6. 반복을 매일/평일로 설정하고 직접 완료한다. 새 반복 카드의 실행 시각/실제 시간은 초기화되고 다음 시작 위치는 남아야 한다.
7. 백업을 내려받고 같은 프로필에 업로드한다. 실행/중단/완료/반복/다음 시작 위치/성장 기록을 비교한다. 다른 프로필과 손상 파일은 거부되어야 한다.
8. 360px에서 준비/편집/실행/종료 폼을 끝까지 스크롤하고, 키보드로 모든 버튼/입력/접기를 조작한다.

### 시간 블록의 남은 한계

- 실제 시간은 사용자가 시작/중단/종료한 시각 사이의 **시계 경과 시간**이다. 중단하지 않고 브라우저를 닫거나 기기를 재우면 그 시간도 포함된다. 집중 시간이나 실제 학습량을 측정하지 않는다.
- 동시 실행 차단은 현재 프로필 workspace 내부 기준이다. 여러 탭/기기 사이의 실시간 잠금·동기화는 구현하지 않았다.
- 가용 시간은 같은 날 기준이다. 자정을 넘는 가용 구간, 일정 충돌 자동 해결, 알림/다크 모드/자유 드래그는 이번 범위 밖이다.
- 다음 블록 생성 시 현재 날짜와 기존 시작 시각을 초깃값으로 사용한다. 사용자가 직접 시각/날짜를 고치며 자동 이동하지 않는다.
- 실제 KIDS/HISTORY 연동 서비스의 외부 인증은 이번 로컬 검수 대상이 아니다. 기존 자기보고와 외부 확인의 분리는 유지한다.
- 모바일 검수는 브라우저의 360px 뷰포트 기준이다. 실제 휴대전화 OS/키보드와 실물 프린터 출력은 별도 기기 검수가 필요하다.

## 타이머 진입 간소화 (사용자 피드백 반영)

- 기본 생성 폼은 할 일과 시간 두 항목으로 줄였다. 과목·범위·날짜는 선택 설정으로 접고, 입력하지 않은 범위는 사용자가 적은 할 일을 사용한다. 고정된 수학 과목/19시를 임의 기본값으로 적용하지 않는다.
- 할 일 추가 후 입력 폼을 닫아 현재 카드를 바로 확인할 수 있게 했다.
- 시작 전의 빈 '다음 시작 위치' 입력란을 제거했다. 중단·종료할 때만 메모를 묻고, 이전 메모가 있으면 다음 카드에 계속 표시한다.
- 미완료 단계가 하나면 재선택 없이 시작할 수 있다. 단계가 여러 개면 사용자의 선택을 유지하며, 완료한 단계를 자동으로 다시 고르지 않는다.
- 카드에서 시간을 바로 고치고 '15분 시작'처럼 시간을 포함한 버튼을 누른다. 중복 수정 버튼은 '계획 수정 · 단계·준비물·반복' 메뉴 하나로 합쳤다.
- 연령별 도움은 준비가 더 필요할 때만 기본으로 펼친다. 저학년 준비 확인, 여러 단계 선택, 중학생 복귀 계획, 고등/성인 경로와 안전 제한은 보존한다.
- 회귀 검증: 14개 파일 259개 테스트, TypeScript 및 delivery 동등 빌드 통과. A/B 초등 고학년의 단일 단계 바로 시작·시간 수정·중단 메모·재개·종료를 실제 브라우저에서 검수했다. 360px/데스크톱 캡처와 콘솔도 확인했다. 이 절은 위의 기존 시작 조건 설명 중 '단일 단계도 다시 선택'하는 부분을 대체한다.
