# NUVIA Studio 최종 후보 검수 기록

상태: **소스 인계 검수 완료 / 운영 적용 보류 — 15개 언어·실서버 QA 미완료**

## 최종 재검수 요약

- 수신 ZIP SHA-256 확인 후 별도 `studio/` 폴더에 복구. 기존 제품을 덮어쓰지 않음.
- Windows x64에서 frozen-lockfile 설치, TypeScript, Vite production build 직접 통과.
- Studio 로직 1,392 assertions + 최소 입력 48 checks 직접 통과. 손상/다른 공간/연결 오류 백업과 정상 왕복 포함. 브라우저 파일 업로드 왕복 완료와는 구분.
- Replit 최종 수정 화면에서 수학 시작→14초 중단→`최종 QA · 3번부터` 표시→빈 보관 메모로 저장→새로고침 확인. “보관된 과제” 안내, 남은 24:46과 같은 깃발 유지. 자기 과제를 “다른 과제”로 오표시하던 문제 해결 확인.
- 키보드 Enter로 꺼내기 후 작업대 제목에 포커스, 화면 상단 약 62px 위치 확인. 자동 실행되지 않음.
- 시작/수정/보관 우선 및 제외·색상 더보기 분리, 수학 퍼플 책·과학 플라스크·역사 건물 아이콘 직접 확인.
- 로컬 production build에서도 수학 실행→7초 중단 확인. ko→en→km→ar→ko 전환 후 동일 과제·24:53 유지. 콘솔 오류/경고 없음.
- **15개 언어 검사 미통과:** 4개 언어만 선택 가능, 외국어 한국어 잔존, 11개 미구현. [언어별 결과](STUDIO_I18N_QA_2026-10-20.md) 참조.
- 최종 독립 브라우저의 뷰포트 변경 요청은 실제로 반영되지 않고 1280px로 유지됨. 이때 확인한 문서 폭은 1265px. 따라서 최종 360/768/1440 재확인을 직접 통과로 기록하지 않음. 제공된 제작 도구 캡처/로그와 아래 이전 직접 검수 결과는 별도 증거로 유지.
- 빌드의 이전 비교 화면 `compare-storage.js` classic script 경고 3건은 남음. public 파일은 복사되며 빌드 실패는 아니지만, 이전 비교 화면 전체 회귀는 이번 Studio 재검수와 구분.
- 제작 도구의 기존 기준본 테스트 기대값 불일치 4건은 별도 사본의 알려진 사항. GitHub 기존 기준선의 262개 통과와 혼합하지 않음.

## 범위와 기준선

- GitHub 기준: `codex/recover-planner-dcas81`, `811609f437c5cfb4a525a6465d1aec8774465766`.
- 승인된 화면: 사용자가 제공한 「내 하루 작업대」 데스크톱·모바일 이미지.
- 작업 대상: 리플릿 `studio.html` 후보와 그 재현 가능한 소스·인계 문서.
- 기존 `nuvia-planner/source`, 독립 HTML, D-CAS, 결과지, 구형 BrainMap은 새로운 작업대와 구분한다.
- `main` 병합, 운영 배포, 기존 공개 URL 교체는 이 검수의 완료 조건이 아니다.
- 이 문서의 “미확인”은 통과를 뜻하지 않는다. 외부 제작 도구의 테스트 보고와 직접 재현 결과를 구분한다.

## 완료 판정

P0(실행 불가·데이터 손실·핵심 결과 오류), P1(핵심 기능 오류)이 남으면 완성본으로 표시하지 않는다. 다국어 미검수, 실기기·실서버 미연결 등 남은 범위를 따로 명시한다. 테스트 개수만으로 승인 이미지 일치나 실제 연동 완료를 대체하지 않는다.

## 구현 중 후보의 직접 브라우저 확인

대상: Replit `studio.html?review=1`의 격리된 합성 데이터. 이 시점에는 제작 도구가 변경 중이므로 최종 커밋의 회귀 검사를 대체하지 않는다.

- 승인 이미지 예시의 시간 선반: 완료 15분 / 예정 35분 / 빈 시간 40분 / 사용 가능 90분 확인.
- 수학 문제집 명시적 시작, 8초 후 중단, `QA 3번부터` 깃발 저장, 추가 보관 문구 비운 채 보관, 새로고침: 원래 과제·깃발·24분 52초 유지.
- 작업대로 꺼내기만으로 자동 실행되지 않음. 이어가기 후 끝내고 돌아보기, 사용자 완료 확인·기록 저장 후 완료 모음 이동. 시간 선반은 완료 40 / 예정 10 / 빈 시간 40으로 변경되어 완료 계획 시간이 빈 시간으로 바뀌지 않음.
- 생활 과제 `QA 생활 미정 정리`를 추가 폼에서 저장: 미정 1개를 별도 표시하고 배치 합계에서 제외. 바로 시작하면 경과 시간 방식. 다른 과제의 작업대 이동 시 현재 실행 중단·종료 안내로 교체 차단.
- 미정 실행 중단→새로고침 시 16초 유지→재개→종료→아직 남음→오늘은 여기까지→저장. 미완료가 완료로 자동 변경되지 않음.
- 리포트에 실제 실행 0.28분·예상 미정·시간 차이 계산 안 함, 목표 활동 미확인으로 표시. 저장·선택·시작만으로 수행 확인으로 승격되지 않음.
- 확인한 360px 작업대에서 문서 가로폭 345px / 뷰포트 360px. 확인한 콘솔 오류·경고 없음. 이것은 모든 화면·언어에 대한 통과 판정이 아님.
- 나의 로드맵에서 수학 과제의 경험카드 생성→어려움·직접 행동·결과·배운 점 입력→저장·본인 확인→초안 선택→문장 초안 생성→배운 점 한 문장만 확인·내보내기 선택→공유 미리보기까지 직접 확인. 선택하지 않은 문장은 미리보기에 포함되지 않고 선택 문장의 원본 활동 참조가 표시됨. 실제 외부 전송·생성형 AI 호출은 하지 않음.
- 설정에서 영어 선택 후 같은 기록과 작업대가 유지됨. 다수 문구가 한국어 fallback이고 일부 버튼만 영어로 나타나므로 영어 번역 완료로 판정하지 않음.
- 백업 버튼 클릭 후 앱의 백업 완료 안내는 확인했지만 실제 로컬 다운로드 파일은 확인하지 못함. 이 확인만으로 백업 파일 업로드 왕복 검수를 통과 처리하지 않음.
