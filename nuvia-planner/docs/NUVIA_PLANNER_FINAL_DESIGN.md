# NUVIA PLANNER 학년·인지 특성별 활동 최종 설계

확정일: 2026-09-14
상태: 사용자 승인 최종 설계 / 2.3 제작 반영

## 제품 핵심
NUVIA PLANNER는 사용자가 실제 목표와 할 일을 입력하고, 인지 특성에 맞는 도움을 받아 계획·실행·점검·수정을 반복하는 생활 플래너다.

최종 구조: 학년별 실제 활동 × 인지 특성별 지원 × 수행에 따른 도움 조절.

## 학년별 실제 활동
- 초등 저학년: 오늘 숙제·준비물·생활 습관. 그림 선택과 짧은 직접 입력. 할 일 2~3개 순서 정하기, 준비물 하나씩 확인.
- 초등 고학년: 자기 숙제·준비물·짧은 공부 계획 직접 입력. 작은 행동으로 나누고 순서·분량 정하기, 누락 확인.
- 중학생: 과목별 숙제·수행평가·주간 학습 입력. 요일 배치·마감 충돌 조정, 중단 위치 기록·복귀.
- 고등학생: 시험 대비·탐구·장기 과제를 주간 목표와 연결. 역산 중간 목표, 시간 배분, 집중 구간 실행.
- 대학생: 강의 과제·팀 프로젝트·자격증·취업 준비. 중간 마감·역할·선행 작업·팀 일정 연결.

## 인지 특성별 지원
- 계획: 작업 분해 초안, 시간·마감 충돌 표시 → 사용자가 단계·우선순위·분량·시간을 수정.
- 주의: 현재 행동 강조, 보류 메모, 중단 위치 보관 → 방해 줄이기·한 구간 실행·복귀.
- 동시처리: 목표와 하위 과제 관계 지도 → 목표별 묶기·전체 진행 확인.
- 순차처리: 선행 작업과 현재–다음 행동 안내 → 순서 확인·단계 실행·누락 수정.

정식 서비스는 검사에서 확정된 Cognitive Profile을 입력받고 PLANNER가 검사 점수나 프로필을 재해석하지 않는다.

## 사용 흐름
1. 할 일 적기
2. 지금 시작하기
3. 끝나고 조정하기

할 일·이름·준비물은 직접 추가·수정·삭제 가능해야 하며 목록에 없는 준비물도 입력 가능해야 한다. 존재하지 않는 게임으로 유도하지 않는다.

## 제작 완료 판단
- 학년 변경 시 관리 범위·활동·조작이 실제로 달라진다.
- 같은 학년·과제에서도 지원 유형별 실제 판단·조작 과정이 구분된다.
- 중고대학생 자기 과제 입력이 가능하다.
- 순서·시간 변경, 중단 메모가 실제 수행에 반영된다.
- 할 일·준비물 수정·삭제와 진행 상태 저장이 작동한다.
