## 미검증·후속 작업

- 이 브랜치에는 `scripts/check-i18n.mjs`, `i18n/programs.json`, 플래너 locale manifest가 없다. 따라서 MASTER의 정적 i18n 검사와 전체 지원 언어 화면 검수는 실행할 수 없었다. 후보에는 한국어 하드코딩 UI가 남아 있으므로 다국어 완료로 판정하지 않는다.
- 초1–3, 초4–6, 중, 고, 대학생·성인 전 경로의 브라우저 종단 QA는 실행하지 못했다. 이번 수동 브라우저 검수는 중학생 데모 경로이고, 연령별 정적/단위 검사는 테스트에 포함된다.
- 실제 결과지 인증, 서버 저장·동기화, 외부 확인, 실기기 터치·가상 키보드, 장시간 타이머 종료, 전체 백업 파일 업로드는 이 로컬 브랜치 QA 범위에서 확인하지 못했다.
- 브라우저 자동화의 포인터 좌표가 화면 확대·스크롤 상태와 어긋나는 장면이 있어 일부 버튼은 키보드 Enter로 활성화해 확인했다. 실기기 마우스·터치 조작은 별도 확인이 필요하다.

이 후보는 대상 브랜치에 검토·통합용으로 저장할 수 있으나 위 미검증 항목을 해결하기 전 운영 배포 완료로 표시하지 않는다.
